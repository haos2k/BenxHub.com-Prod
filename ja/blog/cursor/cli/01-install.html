Cursor CLI のインストール

2026年2月24日·2 min read

インストールは簡単です。ターミナルで公式スクリプトを実行すると cursor コマンドが使えるようになります。プラットフォームごとに手順が異なります。

macOS / Linux / WSL

ターミナルで次を実行します：

  • スクリプトが cursor コマンドを自動でダウンロード・インストールします
  • インストール後はターミナルを閉じて開き直すか、source ~/.bashrc / source ~/.zshrc を実行して PATH を更新してください
