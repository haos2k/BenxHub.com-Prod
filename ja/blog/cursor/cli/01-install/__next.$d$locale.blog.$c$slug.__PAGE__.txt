3:Te0b,<p>インストールは簡単です。ターミナルで公式スクリプトを実行すると <code>cursor</code> コマンドが使えるようになります。プラットフォームごとに手順が異なります。</p>
<h2 id="macos--linux--wsl">macOS / Linux / WSL</h2>
<p>ターミナルで次を実行します：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">curl</span><span style="color:#A5D6FF"> https://cursor.com/install</span><span style="color:#79C0FF"> -fsS</span><span style="color:#FF7B72"> |</span><span style="color:#FFA657"> bash</span></span></code></pre></figure>
<ul>
<li>スクリプトが <code>cursor</code> コマンドを自動でダウンロード・インストールします</li>
<li>インストール後は<strong>ターミナルを閉じて開き直す</strong>か、<code>source ~/.bashrc</code> / <code>source ~/.zshrc</code> を実行して PATH を更新してください</li>
</ul>
<h2 id="windows-powershell">Windows (PowerShell)</h2>
<p>PowerShell を<strong>管理者として</strong>開き、次を実行します：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="powershell" data-theme="github-dark-default"><code data-language="powershell" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#E6EDF3">irm </span><span style="color:#A5D6FF">'https://cursor.com/install?win32=true'</span><span style="color:#FF7B72"> |</span><span style="color:#E6EDF3"> iex</span></span></code></pre></figure>
<h2 id="インストールの確認">インストールの確認</h2>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#79C0FF"> --version</span></span></code></pre></figure>
<p>バージョン番号が表示されればインストール成功です。</p>
<h2 id="初回利用ログイン">初回利用：ログイン</h2>
<p>初めて実行すると、Cursor アカウントへのログインを求められることがあります：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> auth</span><span style="color:#A5D6FF"> login</span></span></code></pre></figure>
<p>画面の指示に従い、ブラウザでログインを完了してください。同じマシンでは通常、再度ログインする必要はありません。</p>
<h2 id="まとめ">まとめ</h2>
<ul>
<li><strong>macOS / Linux</strong>: <code>curl ... | bash</code></li>
<li><strong>Windows</strong>: PowerShell で <code>irm ... | iex</code> を実行</li>
<li><strong>確認</strong>: <code>cursor --version</code></li>
<li><strong>ログイン</strong>: <code>cursor auth login</code></li>
</ul>
