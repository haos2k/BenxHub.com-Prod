Cursor CLI の基本使い方

2026年2月24日·2 min read

最も一般的な使い方: cursor agent

プロジェクトのディレクトリ内で次を実行します：

  • 対話的: AI が質問や提案をし、変更の承認・却下ができます
  • コンテキストを考慮: 現在のディレクトリのファイルを読んで回答や編集を行います

一発実行 vs 会話

タスクを直接任せたい場合: 指示を引用符で囲んで一度に送ります。

実行前に相談したい場合: 引数なしで cursor agent を実行すると 会話モード に入り、要件を段階的に説明でき、AI が変更前に確認してくれます。

作業ディレクトリの指定

デフォルトでは カレントディレクトリ を使用します。パスを指定するには --path を付けます：

コマンド早見表

コマンド 説明
cursor agent "do something" AI に実行させる（ファイルを変更可能）
cursor agent タスクなしで会話モードに入る
cursor ask "question" 質問のみ、ファイル編集なし（読み取り専用）
cursor --help 利用可能なオプションを表示

まとめ

  • 最も一般的: cursor agent "指示内容"
  • まず会話したい: cursor agent だけ実行
  • 編集せず質問: cursor ask "質問"
  • ディレクトリ指定: --path <path> を付ける
