3:T4503,<p><code>cursor agent</code> にコードを自動修正させ、テストを実行し、失敗したら AI にまた修正させる — <strong>全テストが通るまで繰り返す</strong> shell スクリプトを書きます。Y/N を押し続ける必要はありません。ループを AI に任せて別の用を済ませ、ターミナルに「tests passed」と出たら戻ってくればよいです。</p>
<h2 id="考え方">考え方</h2>
<pre><code>while tests don't pass:
    run tests → collect error output
    feed error output to cursor agent
    cursor agent fixes the code
    run tests again
</code></pre>
<p>「テスト実行 → 失敗 → AI に修正依頼 → 繰り返し」のループで、緑になるまで回します。シンプルですが効果的です。</p>
<h2 id="ステップ-1-前提の確認">ステップ 1: 前提の確認</h2>
<ul>
<li><code>cursor</code> がインストール済みでログイン済み（<code>cursor --version</code> で確認）</li>
<li>プロジェクトに <strong>ターミナルで実行できるテストコマンド</strong> があること。例：
<ul>
<li><code>npm test</code></li>
<li><code>pytest</code></li>
<li><code>go test ./...</code></li>
<li><code>cargo test</code></li>
</ul>
</li>
<li>テスト失敗時に非ゼロの終了コードを返すこと（多くのテストフレームワークはデフォルトでそうなっています）</li>
</ul>

9:T4503,<p><code>cursor agent</code> にコードを自動修正させ、テストを実行し、失敗したら AI にまた修正させる — <strong>全テストが通るまで繰り返す</strong> shell スクリプトを書きます。Y/N を押し続ける必要はありません。ループを AI に任せて別の用を済ませ、ターミナルに「tests passed」と出たら戻ってくればよいです。</p>
<h2 id="考え方">考え方</h2>
<pre><code>while tests don't pass:
    run tests → collect error output
    feed error output to cursor agent
    cursor agent fixes the code
    run tests again
</code></pre>
<p>「テスト実行 → 失敗 → AI に修正依頼 → 繰り返し」のループで、緑になるまで回します。シンプルですが効果的です。</p>
<h2 id="ステップ-1-前提の確認">ステップ 1: 前提の確認</h2>
<ul>
<li><code>cursor</code> がインストール済みでログイン済み（<code>cursor --version</code> で確認）</li>
<li>プロジェクトに <strong>ターミナルで実行できるテストコマンド</strong> があること。例：
<ul>
<li><code>npm test</code></li>
<li><code>pytest</code></li>
<li><code>go test ./...</code></li>
<li><code>cargo test</code></li>
</ul>
</li>
<li>テスト失敗時に非ゼロの終了コードを返すこと（多くのテストフレームワークはデフォルトでそうなっています）</li>
</ul>
