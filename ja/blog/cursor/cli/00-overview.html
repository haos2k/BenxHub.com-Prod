Cursor CLI チュートリアル — 概要

2026年2月24日·2 min read

Cursor CLI を使うと、Cursor の AI 機能をターミナルから直接呼び出せます — Cursor のウィンドウは不要です。AI にコードを書かせたり、ファイルを編集させたり、質問に答えさせたりできます。ターミナル中心のエンジニアには、いつでも呼べるアシスタントのようなものです。

CLI を学ぶ理由

シナリオ Cursor ウィンドウ Cursor CLI
サーバーでコードを編集 SSH + リモート設定や同期が必要 ターミナルで直接コマンド実行
スクリプト・CI 自動化 パイプラインに組み込みづらい 非対話モード、1 コマンドで実行
すでにターミナルで作業中 IDE に切り替えて戻る必要がある 同じウィンドウで AI に質問
キーボード中心のワークフロー マウスクリックが避けられない すべてコマンドで完結

要するに：CLI なら AI があなたのワークフローに合わせてくれます。IDE に合わせる必要はありません。

コースマップ

ファイル トピック 目安時間
01-install インストールと確認 5 分
02-basic-usage 基本使い方：コマンドと会話 10 分
03-modes 3 モード：Agent / Plan / Ask 8 分
04-non-interactive 非対話モードとスクリプト 8 分
05-tips ヒントと FAQ 5 分
06-cursor-cli-with-worktree Worktree と CLI で並行開発 8 分
07-unlimit-loop-debug 無限デバッグループ：テストが通るまで繰り返し実行 10 分

前提条件

  • Cursor がインストール済み（または少なくともログインできる Cursor アカウント）
  • Cursor のサブスクリプション（CLI 利用にはサブスクが必要）
  • ターミナルの基本操作

まず 01-install で CLI をセットアップしてください。
