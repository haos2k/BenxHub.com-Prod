<h2 id="agent-モードデフォルト">Agent モード（デフォルト）</h2>
<p><strong>用途</strong>: AI にコードを直接編集・機能追加・リファクタリングさせる。議論より結果が欲しいとき。</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#A5D6FF"> "Change login to use JWT"</span></span></code></pre></figure>
<ul>
<li>ファイルを読み・編集し、コマンドを実行することもある</li>
<li>各ステップで承認・却下できる — 主導権はあなた</li>
</ul>
<h2 id="plan-モード">Plan モード</h2>
<p><strong>用途</strong>: 進め方に自信がない、AI に一気に変えられるのが心配なとき。承認前に計画を見る。</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#79C0FF"> --plan</span><span style="color:#A5D6FF"> "Refactor the entire API layer"</span></span></code></pre></figure>
<ul>
<li>AI が質問し、アプローチを提案する</li>
<li>同意した場合にのみ実行 — 予期せぬ変更なし</li>
</ul>
<p><strong>いつ使うか</strong>: 大規模な変更や「コミット前にしっかり確認したい」とき。</p>
<h2 id="ask-モード読み取り専用">Ask モード（読み取り専用）</h2>
<p><strong>用途</strong>: 「このコードは何をしている？」「もっと良い書き方は？」と聞きたいだけで、<strong>ファイルは一切変更したくない</strong>とき。</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> ask</span><span style="color:#A5D6FF"> "What is the logic in src/auth.ts?"</span></span></code></pre></figure>
<ul>
<li>読み取り・分析・回答のみ — 書き込みはしない</li>
<li>CI や「触らずに確認だけしたい」環境向け</li>
</ul>
<h2 id="会話中のモード切り替え">会話中のモード切り替え</h2>
<p>すでに <code>cursor agent</code> の会話中なら、<strong>スラッシュコマンド</strong>で即切り替え可能：</p>
<ul>
<li><code>/plan</code> → Plan モードへ（計画→実行）</li>
<li><code>/ask</code> → Ask モードへ（読み取り専用、自由に質問）</li>
</ul>
<p>終了してやり直す必要はありません。走りながらギアを変えるようなものです。</p>
<h2 id="まとめ">まとめ</h2>
<ul>
<li><strong>Agent</strong>: 実行し、ファイルを編集 — 結果が欲しいときに</li>
<li><strong>Plan</strong>: 先に計画、承認後に実行 — 安全に進めたいときに</li>
<li><strong>Ask</strong>: 質問のみ、読み取り専用 — 変更なしで答えが欲しいときに</li>
</ul>

<p>すでに <code>cursor agent</code> の会話中なら、<strong>スラッシュコマンド</strong>で即切り替え可能：</p>
<ul>
<li><code>/plan</code> → Plan モードへ（計画→実行）</li>
<li><code>/ask</code> → Ask モードへ（読み取り専用、自由に質問）</li>
</ul>
<p>終了してやり直す必要はありません。走りながらギアを変えるようなものです。</p>
<h2 id="まとめ">まとめ</h2>
<ul>
<li><strong>Agent</strong>: 実行し、ファイルを編集 — 結果が欲しいときに</li>
<li><strong>Plan</strong>: 先に計画、承認後に実行 — 安全に進めたいときに</li>
<li><strong>Ask</strong>: 質問のみ、読み取り専用 — 変更なしで答えが欲しいときに</li>
</ul>
