<h2 id="クラウド実行--c----cloud">クラウド実行: -c / --cloud</h2>
<p>重いタスク — リポジトリ全体の分析、大きなドキュメント生成、多段階のリファクタ — をローカルで回すと、ターミナルを開いたままにしておく必要がある。ノートPCを閉じたり接続が切れたりすると実行も止まる。</p>
<p><strong><code>-c</code></strong>（または <strong><code>--cloud</code></strong>）を使うと、<strong>この会話</strong> をクラウドの Agent に渡せる：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#A5D6FF"> "Analyze the whole project and write architecture doc to docs/architecture.md"</span><span style="color:#79C0FF"> -c</span></span></code></pre></figure>
<ul>
<li>送信後、タスクは Cursor のクラウドで実行される</li>
<li>ターミナルを閉じても、シャットダウンしても、別の作業に移ってもよい</li>
<li>後から、同じ Cursor アカウントで別のデバイスから <code>--resume</code> でその会話に戻り、結果を確認したり追加の指示を送ったりできる</li>
</ul>
<p>つまり <strong><code>-c</code></strong> = 「クラウドで実行；PCの前で待たなくてよい」。</p>

<h2 id="セッションとクラウドの組み合わせ">セッションとクラウドの組み合わせ</h2>
<p>典型的な流れ：</p>
<ol>
<li><code>-c</code> でタスクを開始し、クラウドで実行させる</li>
<li>ターミナルを閉じる</li>
<li>後で <code>cursor agent ls</code> でその会話を探す</li>
<li><code>cursor agent --resume=that-id</code> で再接続し、結果を確認するか、さらに指示を送る</li>
</ol>
<p>これで「長時間タスク」と「複数デバイス・シャットダウン」の両方に対応できる。</p>
<h2 id="まとめ">まとめ</h2>
<ul>
<li><strong><code>cursor agent ls</code></strong>: 再開したい会話を探すために一覧表示</li>
<li><strong><code>--resume</code></strong>: 直近を再開；<strong><code>--resume=ID</code></strong>: 指定した会話を再開</li>
<li><strong><code>-c</code> / <code>--cloud</code></strong>: いまのタスクをクラウドで実行；ターミナルを閉じても後から <code>--resume</code> で再開できる</li>
</ul>
