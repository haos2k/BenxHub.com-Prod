3:T10e5,<p>会話しかできないアシスタントは、優秀な人を雇っておきながら道具をひとつも渡していないようなものです。もったいない。</p>
<p><strong>Skills</strong> は、アシスタントに実際の仕事をさせるための装備です。</p>
<h2 id="このページで学べること">このページで学べること</h2>
<ul>
<li>Skill とは何か</li>
<li>組み込み Skill の有効化</li>
<li>自作 Skill の追加</li>
<li>読み込み順序と優先度</li>
</ul>
<hr>
<h2 id="skill-とは">Skill とは？</h2>
<p>Skill は多くの場合 <code>SKILL.md</code> という説明ファイルです。そこには次のようなことが書かれています。</p>
<ul>
<li>その Skill で何ができるか</li>
<li>どんな状況で使うべきか</li>
<li>どのツールや手順が許されるか</li>
</ul>
<p>言ってみれば <strong>アシスタント用の業務マニュアル</strong> です。Web 閲覧用マニュアルを渡せばネット検索ができ、ファイル操作用マニュアルを渡せば文書整理ができます。</p>
<hr>
<h2 id="組み込みとカスタム">組み込みとカスタム</h2>
<p>OpenClaw には便利な組み込み Skill があり、コミュニティも新しい Skill を追加し続けています。できることは次の 2 つです。</p>
<ul>
<li><strong>組み込み Skill をそのまま使う</strong></li>
<li><strong>自分で <code>SKILL.md</code> を書いて追加する</strong></li>
</ul>
<hr>
<h2 id="カスタム-skill-を作るときの正しいやり方">カスタム Skill を作るときの正しいやり方</h2>
<p>Skill を追加・変更したい場合、<strong>OpenClaw リポジトリ内の元ファイルは編集しない</strong> でください。更新時に上書きされる可能性があります。</p>
<p>代わりに次の場所に置きます。</p>
<pre><code>~/.openclaw/skills/&#x3C;skill-name>/SKILL.md
</code></pre>
<p><strong>優先順</strong></p>
<pre><code>workspace/skills  →  ~/.openclaw/skills  →  組み込み  →  extraDirs
</code></pre>
<p>最初に一致したものが使われます。</p>
<hr>
<h2 id="ダッシュボードから-skill-を管理する">ダッシュボードから Skill を管理する</h2>
<p>Control UI の <strong>Skills</strong> タブでは次のことができます。</p>
<ul>
<li>利用可能な Skill の一覧確認</li>
<li>クリックで有効化 / 無効化</li>
<li>API key が必要な Skill の設定</li>
<li>コミュニティ Skill の導入</li>
</ul>
<p>保存後は多くの場合、Gateway を再起動しなくてもホットリロードされます。</p>
<hr>
<h2 id="カスタムフォルダから読み込む">カスタムフォルダから読み込む</h2>
<p>自作 Skill をひとつの場所にまとめたいなら:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="json5" data-theme="github-dark"><code data-language="json5" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D">// ~/.openclaw/openclaw.json</span></span>
<span data-line=""><span style="color:#E1E4E8">{</span></span>
<span data-line=""><span style="color:#9ECBFF">  "skills"</span><span style="color:#E1E4E8">: {</span></span>
<span data-line=""><span style="color:#9ECBFF">    "load"</span><span style="color:#E1E4E8">: {</span></span>
<span data-line=""><span style="color:#9ECBFF">      "extraDirs"</span><span style="color:#E1E4E8">: [</span><span style="color:#9ECBFF">"/あなたの Skill フォルダ"</span><span style="color:#E1E4E8">]</span></span>
<span data-line=""><span style="color:#E1E4E8">    }</span></span>
<span data-line=""><span style="color:#E1E4E8">  }</span></span>
<span data-line=""><span style="color:#E1E4E8">}</span></span></code></pre></figure>
