1a:T2010,<p>ここまで来たなら、OpenClaw をゼロから動くところまで組み上げたということです。お疲れさまでした。</p>

<h2 id="このページで学べること">このページで学べること</h2>
<ul>
<li>設定ファイルの場所と 2 つの編集方法</li>
<li>最小構成の読み方</li>
<li>環境変数で API key を安全に扱う方法</li>

<hr>
<h2 id="設定ファイルはどこ">設定ファイルはどこ？</h2>
<pre><code>~/.openclaw/openclaw.json
</code></pre>
<p>形式は <strong>JSON5</strong> です。コメントや末尾カンマが使えるので、通常の JSON よりかなり書きやすいです。</p>
<p>編集方法は 2 つあります。</p>
<ul>
<li>Control UI の <strong>フォームモード</strong> を使う</li>
<li><strong>Raw JSON</strong> に切り替えて直接編集する</li>
</ul>
<p>どちらも同じファイルを編集しています。</p>
<hr>

<h2 id="api-key-を正しく保存する">API key を正しく保存する</h2>
<p>できるなら <strong>API key を config に直書きしない</strong> ほうが安全です。</p>
<p>環境変数を使いましょう。</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># .env またはシステム環境変数に設定</span></span>
<span data-line=""><span style="color:#E6EDF3">ANTHROPIC_API_KEY</span><span style="color:#FF7B72">=</span><span style="color:#A5D6FF">sk-ant-xxxxx</span></span></code></pre></figure>
<blockquote>
<p>⚠️ Gateway を <code>systemd</code> などのサービスとして動かす場合、そのサービスが <code>.env</code> を読み込んでいるか確認してください。読み込めていないと API key が見えず、「Shell env off」のようなエラーにつながります。</p>
</blockquote>

<h2 id="設定ファイルはどこ">設定ファイルはどこ？</h2>
<pre><code>~/.openclaw/openclaw.json
</code></pre>
<p>形式は <strong>JSON5</strong> です。コメントや末尾カンマが使えるので、通常の JSON よりかなり書きやすいです。</p>
<p>編集方法は 2 つあります。</p>
<ul>
<li>Control UI の <strong>フォームモード</strong> を使う</li>
<li><strong>Raw JSON</strong> に切り替えて直接編集する</li>
</ul>
<p>どちらも同じファイルを編集しています。</p>

<h2 id="api-key-を正しく保存する">API key を正しく保存する</h2>
<p>できるなら <strong>API key を config に直書きしない</strong> ほうが安全です。</p>
<p>環境変数を使いましょう。</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># .env またはシステム環境変数に設定</span></span>
<span data-line=""><span style="color:#E6EDF3">ANTHROPIC_API_KEY</span><span style="color:#FF7B72">=</span><span style="color:#A5D6FF">sk-ant-xxxxx</span></span></code></pre></figure>
<blockquote>
<p>⚠️ Gateway を <code>systemd</code> などのサービスとして動かす場合、そのサービスが <code>.env</code> を読み込んでいるか確認してください。読み込めていないと API key が見えず、「Shell env off」のようなエラーにつながります。</p>
</blockquote>
