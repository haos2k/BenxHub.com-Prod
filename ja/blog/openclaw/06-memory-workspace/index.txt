<h2 id="workspace-とは">Workspace とは？</h2>
<p>Workspace は <strong>アシスタント専用の仕事部屋</strong> です。</p>
<ul>
<li>読むファイル、書く文書、実行するスクリプトはそのフォルダ内で扱われます</li>
<li>複数の Workspace を作れば、仕事をきれいに分離できます</li>
</ul>
<pre><code>~/.openclaw/workspace-main        ← メインアシスタントの部屋
~/.openclaw/workspace-project-a   ← プロジェクト A の部屋
~/.openclaw/workspace-project-b   ← プロジェクト B の部屋
</code></pre>
<p>これで「個人の日記を整理して」と「プロジェクト A のコードを書いて」が混ざりません。</p>
<hr>
<h2 id="memory-はどう動く">Memory はどう動く？</h2>
<p>OpenClaw は会話の重要な情報を <strong>Memory</strong> として保存し、あとから検索・参照できるようにします。</p>
<p>つまり、<strong>前に伝えたことを覚えていられる</strong> ということです。</p>
<blockquote>
<p>⚠️ すぐ忘れるように感じるときは次を確認:</p>
<ul>
<li>Memory が有効か。意味検索には OpenAI API key が必要な場合があります</li>
<li>古い Memory が整理、圧縮、削除されていないか</li>
<li>新しいセッションを開いていないか。新規セッションは短期文脈が空です</li>
</ul>
</blockquote>
