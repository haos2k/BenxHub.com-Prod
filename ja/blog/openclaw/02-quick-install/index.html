インストール前に確認する 2 点

必要なものは多くありませんが、この 2 つは必須です。

1. Node.js（LTS 版）

2. AI モデル用の API key

Anthropic Claude や OpenAI などのクラウドモデルを使うなら API key が必要です。完全オフラインにしたいならローカルモデルでも構いません。この連載ではクラウドモデルを前提に進めます。

💡 API key の取得方法が分からない場合は「Anthropic API key」などで検索すれば、だいたい数分でたどり着けます。

OpenClaw をインストールする

公式ドキュメントでは git ベースのインストール方法 が推奨されています。あとで更新やデバッグがしやすいからです。

Windows

⚠️ 「git not found」や「openclaw が認識されない」で止まる場合は、Git を PATH に追加してターミナルを再起動してください。

初回起動: アシスタントを誕生させる

インストール後、次を実行します。

初回実行ではオンボーディングウィザード が起動し、次のようなことを聞かれます。

  1. どの AI モデルを使うか
  2. API key は何か
  3. ワークスペースをどこに置くか

入力が終われば、最初のアシスタントがその場で生まれます。

💡 「wake up my friend」のまま長く止まる場合は、API key、ネットワーク、ターミナルのエラーメッセージを確認しましょう。

オンボーディングが終わると何ができる？

  • ダッシュボードログイン用の token
  • 基本設定ファイル ~/.openclaw/openclaw.json
  • すでに動き始めている最初の AI アシスタント

ダッシュボードを開く

Gateway を動かしたまま、ブラウザで次を開きます。

http://127.0.0.1:18789/

よくある表示

表示 対処
pairing required openclaw devices list の後に openclaw devices approve <id>
token を要求される オンボーディングでもらった token を貼る
反応がない openclaw gateway が動いたままか確認
