<h2 id="インストール前に確認する-2-点">インストール前に確認する 2 点</h2>
<p>必要なものは多くありませんが、この 2 つは必須です。</p>
<p><strong>1. Node.js（LTS 版）</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">node</span><span style="color:#79B8FF"> --version</span></span>
<span data-line=""><span style="color:#6A737D"># バージョンが表示されれば OK</span></span></code></pre></figure>
<p><strong>2. AI モデル用の API key</strong></p>
<p>Anthropic Claude や OpenAI などのクラウドモデルを使うなら API key が必要です。完全オフラインにしたいならローカルモデルでも構いません。この連載ではクラウドモデルを前提に進めます。</p>
<blockquote>
<p>💡 API key の取得方法が分からない場合は「Anthropic API key」などで検索すれば、だいたい数分でたどり着けます。</p>
</blockquote>
<hr>
<h2 id="openclaw-をインストールする">OpenClaw をインストールする</h2>
<p>公式ドキュメントでは <strong>git ベースのインストール方法</strong> が推奨されています。あとで更新やデバッグがしやすいからです。</p>
<p><strong>macOS / Linux</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># docs.openclaw.ai の Quick Start の手順に従う</span></span>
<span data-line=""><span style="color:#6A737D"># 多くの場合は 1 行の curl スクリプトで始められる</span></span></code></pre></figure>
<p><strong>Windows</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># まず Git が入っていて PATH に通っているか確認</span></span>
<span data-line=""><span style="color:#B392F0">git</span><span style="color:#79B8FF"> --version</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#6A737D"># その後 docs.openclaw.ai の Windows 手順に従う</span></span></code></pre></figure>
<blockquote>
<p>⚠️ 「git not found」や「openclaw が認識されない」で止まる場合は、Git を PATH に追加してターミナルを再起動してください。</p>
</blockquote>

<h2 id="初回起動-アシスタントを誕生させる">初回起動: アシスタントを誕生させる</h2>
<p>インストール後、次を実行します。</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">openclaw</span><span style="color:#9ECBFF"> gateway</span></span></code></pre></figure>
<p><strong>初回実行ではオンボーディングウィザード</strong> が起動し、次のようなことを聞かれます。</p>
<ol>
<li>どの AI モデルを使うか</li>
<li>API key は何か</li>
<li>ワークスペースをどこに置くか</li>
</ol>
<p>入力が終われば、最初のアシスタントがその場で生まれます。</p>
<blockquote>
<p>💡 「wake up my friend」のまま長く止まる場合は、API key、ネットワーク、ターミナルのエラーメッセージを確認しましょう。</p>
</blockquote>
