<p><strong>1. Node.js（LTS 版）</strong></p>

<blockquote>
<p>💡 API key の取得方法が分からない場合は「Anthropic API key」などで検索すれば、だいたい数分でたどり着けます。</p>

<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># まず Git が入っていて PATH に通っているか確認</span></span>
