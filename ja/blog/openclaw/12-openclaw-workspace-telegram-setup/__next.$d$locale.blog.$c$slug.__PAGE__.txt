3:T4428,<p>「今日の日記を整理して」と頼んだのに、仕事プロジェクトのファイルまで触られたら困りますよね。</p>
<p>それは <strong>Workspace の切り分けが不十分</strong> なときに起きます。このガイドで一気に整理しましょう。</p>
<h2 id="このページで学べること">このページで学べること</h2>
<ul>
<li>全体の流れ: グループ → アシスタント → Workspace</li>
<li>複数 Workspace の初期化</li>
<li>Agents + Bindings の完全設定</li>
<li>設定が効いているか確認する方法</li>
</ul>
<hr>
<h2 id="全体像">全体像</h2>
<p>目指す構成は次のとおりです。</p>
<pre><code>Telegram グループ A  →  Assistant A  →  Workspace A（この中だけ触る）
Telegram グループ B  →  Assistant B  →  Workspace B（この中だけ触る）
DM                   →  Main Assistant → Main Workspace
</code></pre>
<p>実現のための手順は 3 つ。<strong>Workspace を作る → Agent を定義する → Bindings を定義する</strong>。</p>
<hr>
<h2 id="手順-1-workspace-を作る">手順 1: Workspace を作る</h2>
<p>各アシスタントには専用ディレクトリが必要です。次のように初期化します。</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">openclaw</span><span style="color:#A5D6FF"> setup</span><span style="color:#79C0FF"> --workspace</span><span style="color:#A5D6FF"> "~/.openclaw/workspace-main"</span></span>
<span data-line=""><span style="color:#FFA657">openclaw</span><span style="color:#A5D6FF"> setup</span><span style="color:#79C0FF"> --workspace</span><span style="color:#A5D6FF"> "~/.openclaw/workspace-project-a"</span></span>
<span data-line=""><span style="color:#FFA657">openclaw</span><span style="color:#A5D6FF"> setup</span><span style="color:#79C0FF"> --workspace</span><span style="color:#A5D6FF"> "~/.openclaw/workspace-project-b"</span></span></code></pre></figure>
<p>各 Workspace には <code>AGENTS.md</code>、<code>SOUL.md</code>、<code>IDENTITY.md</code> など必要なファイルが自動生成されます。</p>
<blockquote>
<p>💡 ディレクトリが存在しなくてもコマンドが作ってくれます。Git から既存 Workspace を clone したなら、初期化を省いて Config でパスを指定するだけでも構いません。</p>
</blockquote>
<hr>

<h2 id="手順-3-保存して確認する">手順 3: 保存して確認する</h2>
<p><strong>Web UI から</strong>: Config ページで <strong>Save / Apply</strong> を押します。</p>
<p><strong>ファイルを直接編集した場合</strong>: <code>~/.openclaw/openclaw.json</code> を保存します。多くの場合ホットリロードされますが、不安なら再起動します。</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">openclaw</span><span style="color:#A5D6FF"> gateway</span></span></code></pre></figure>
<p><strong>確認方法</strong></p>
<ul>
<li>各 Telegram グループでメッセージを送り、正しいアシスタントが返事するか確認する</li>
<li><code>openclaw doctor</code> で簡易ヘルスチェックを行う</li>
</ul>

<h2 id="このページで学べること">このページで学べること</h2>
<ul>
<li>全体の流れ: グループ → アシスタント → Workspace</li>
<li>複数 Workspace の初期化</li>

<hr>
<h2 id="全体像">全体像</h2>
<p>目指す構成は次のとおりです。</p>
<pre><code>Telegram グループ A  →  Assistant A  →  Workspace A（この中だけ触る）
Telegram グループ B  →  Assistant B  →  Workspace B（この中だけ触る）
DM                   →  Main Assistant → Main Workspace
</code></pre>
<p>実現のための手順は 3 つ。<strong>Workspace を作る → Agent を定義する → Bindings を定義する</strong>。</p>
<hr>
<h2 id="手順-1-workspace-を作る">手順 1: Workspace を作る</h2>
<p>各アシスタントには専用ディレクトリが必要です。次のように初期化します。</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">openclaw</span><span style="color:#A5D6FF"> setup</span><span style="color:#79C0FF"> --workspace</span><span style="color:#A5D6FF"> "~/.openclaw/workspace-main"</span></span>
<span data-line=""><span style="color:#FFA657">openclaw</span><span style="color:#A5D6FF"> setup</span><span style="color:#79C0FF"> --workspace</span><span style="color:#A5D6FF"> "~/.openclaw/workspace-project-a"</span></span>
<span data-line=""><span style="color:#FFA657">openclaw</span><span style="color:#A5D6FF"> setup</span><span style="color:#79C0FF"> --workspace</span><span style="color:#A5D6FF"> "~/.openclaw/workspace-project-b"</span></span></code></pre></figure>
<p>各 Workspace には <code>AGENTS.md</code>、<code>SOUL.md</code>、<code>IDENTITY.md</code> など必要なファイルが自動生成されます。</p>
<blockquote>
<p>💡 ディレクトリが存在しなくてもコマンドが作ってくれます。Git から既存 Workspace を clone したなら、初期化を省いて Config でパスを指定するだけでも構いません。</p>
</blockquote>
