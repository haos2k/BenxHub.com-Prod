1 つの Gateway で複数アシスタント: Bindings で正しいメッセージを正しい Agent へ

2026年3月8日·4 min read

仕事用グループも個人チャットも同じアシスタントに任せると、すぐに混線します。

それを解決するのが 複数 Agent + Bindings です。場面ごとに適切なアシスタントを出せます。

  • Telegram グループ ID の調べ方
