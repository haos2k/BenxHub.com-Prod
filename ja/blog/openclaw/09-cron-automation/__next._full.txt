<h2 id="cron-と-heartbeat-とは">Cron と Heartbeat とは？</h2>
<p><strong>Cron</strong> は「この時間にこの作業をする」という予定表です。</p>
<ul>
<li>毎朝 9 時: 昨日のメールを要約する</li>
<li>毎週月曜: 今週の重要な TODO を知らせる</li>
<li>毎晩: 今日のメモをアーカイブする</li>
</ul>
<p><strong>Heartbeat</strong> は、たとえば 30 分ごとにアシスタントが自動で目を覚まし、やるべきことがあるか確認する仕組みです。</p>
<blockquote>
<p>💡 30 分ごとに heartbeat のログが出ても正常です。</p>
</blockquote>

<h2 id="ダッシュボードで-cron-を設定する">ダッシュボードで Cron を設定する</h2>
<p>Control UI の <strong>Cron</strong> タブを開きます。</p>
<ul>
<li><strong>Add schedule</strong>: Cron 式とタスク内容を入力</li>
<li><strong>Enable / disable</strong>: 個別のジョブを停止 / 再開</li>
<li><strong>Run now</strong>: 時刻を待たずに手動実行</li>
</ul>

<h2 id="cron-構文の早見表">Cron 構文の早見表</h2>
<pre><code>* * * * *
│ │ │ │ └─ 曜日 (0-7、0 と 7 は日曜)
│ │ │ └─── 月 (1-12)
│ │ └───── 日 (1-31)
│ └─────── 時 (0-23)
└───────── 分 (0-59)
</code></pre>
<p>よく使う例:</p>
<pre><code>0 9 * * *      ← 毎日 9:00
0 9 * * 1      ← 毎週月曜 9:00
0 */6 * * *    ← 6 時間ごと
</code></pre>

<h2 id="発火しないときはここを確認">発火しないときはここを確認</h2>
<ol>
<li>Config で Cron が有効か</li>
<li>タイムゾーンが正しいか</li>
<li><code>openclaw logs --follow</code> にエラーが出ていないか</li>
<li>Gateway を再起動してみる</li>
</ol>
<blockquote>
<p>⚠️ 定期タスクもモデル資源を消費します。大量のスケジュールと大量の会話を同時に流すと HTTP 429 のような制限に当たることがあります。重いタスクは専用 Agent に分けるのが安全です。</p>
</blockquote>
