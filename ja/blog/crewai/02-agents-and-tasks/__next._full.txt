1b:T1962,<p>CrewAI の初回失敗は API ではなく、<strong>役割分担の崩れ</strong>が原因であることが多いです。<br>
原則は 1 つだけ。<strong>1 Agent = 1 専門、1 Task = 1 仕事</strong>。</p>
<h2 id="まず-agent-を分け次に-task-を書く">まず Agent を分け、次に Task を書く</h2>
<p>考え方:</p>
<ul>
<li>Agent は「誰が」</li>
<li>Task は「何を」</li>
<li>Context は「前工程から何を渡すか」</li>
</ul>
<p>1 つの Agent に調査・執筆・レビューを同時にさせると、全部中途半端になりがちです。</p>

<h2 id="初心者がハマる-3-つの罠">初心者がハマる 3 つの罠</h2>
<ol>
<li><strong>Task 記述が短すぎる</strong>：必要な形式が伝わらない</li>
<li><strong>expected_output がない</strong>：毎回フォーマットが揺れる</li>
<li><strong>context がない</strong>：後続タスクが前段結果を受け取れない</li>
</ol>
<h2 id="シンプルなチェックリスト">シンプルなチェックリスト</h2>
<p>YAML を書いたら毎回この 5 つを確認:</p>
<ul>
<li>Agent は 1 つの専門に絞れているか？</li>
<li>Task は 1 つのことだけしているか？</li>
<li><code>expected_output</code> に形式が明記されているか？</li>
<li>依存関係に <code>context</code> があるか？</li>
<li>出力担当に <code>output_file</code> を設定したか？</li>
</ul>

<span data-line=""><span style="color:#85E89D">  allow_delegation</span><span style="color:#E1E4E8">: </span><span style="color:#79B8FF">false</span></span></code></pre></figure>

<h2 id="初心者がハマる-3-つの罠">初心者がハマる 3 つの罠</h2>
<ol>
<li><strong>Task 記述が短すぎる</strong>：必要な形式が伝わらない</li>
<li><strong>expected_output がない</strong>：毎回フォーマットが揺れる</li>
<li><strong>context がない</strong>：後続タスクが前段結果を受け取れない</li>
</ol>
<h2 id="シンプルなチェックリスト">シンプルなチェックリスト</h2>
<p>YAML を書いたら毎回この 5 つを確認:</p>
<ul>
<li>Agent は 1 つの専門に絞れているか？</li>
<li>Task は 1 つのことだけしているか？</li>
<li><code>expected_output</code> に形式が明記されているか？</li>
<li>依存関係に <code>context</code> があるか？</li>
<li>出力担当に <code>output_file</code> を設定したか？</li>
</ul>
