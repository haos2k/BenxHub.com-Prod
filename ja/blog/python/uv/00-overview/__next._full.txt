1a:T114d,<p>uv は Astral が Rust で構築した<strong>超高速 Python パッケージ・プロジェクト管理ツール</strong>で、依存関係のインストール・仮想環境・Python バージョン管理・CLI ツールの実行を一つに統合しています。一言で言えば：<strong>pip + virtualenv + pyenv + pipx の合体強化版 — しかも速すぎて現実を疑うほど。</strong></p>
<p>pip・poetry・pipenv と比べると、uv の優位性は <strong>10〜100 倍の速度</strong>・最小限のディスク使用量・単一ツールで全フローを完結できること。日常開発・CI/CD・スクリプト実行に特に適しています — 複数のツールを切り替える必要がもうありません。1 つの段ボール箱だけで暮らす猫のようですが、その箱があらゆる機能を持ち、ターボモード付き。</p>
<h2 id="適用シナリオ">適用シナリオ</h2>
<ul>
<li><strong>新プロジェクトをゼロから始める</strong>：<code>uv init</code> で即作成、依存関係も即インストール — pip のスピナーを眺める時間はもう不要</li>
<li><strong>既存の requirements.txt からの移行</strong>：<code>uv pip compile</code> で直接取り込み、痛みのないアップグレード</li>
<li><strong>スクリプトの一時的な依存関係</strong>：<code>uv run --with rich script.py</code> — venv を作る必要なし</li>
<li><strong>CLI ツールの実行</strong>：<code>uvx ruff</code> で随時実行、pipx のようで N 倍速い</li>
<li><strong>向いていない</strong>：Python 2 を使い続けているレガシープロジェクト — まず移行を検討して、uv に時間旅行を求めないように</li>
</ul>
