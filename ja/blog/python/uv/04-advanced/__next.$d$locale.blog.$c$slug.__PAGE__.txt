<h2 id="python-バージョン管理">Python バージョン管理</h2>
<p>uv は Python のダウンロードと管理が組み込まれています — pyenv を別途インストールする必要はありません。</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># 複数バージョンをインストール</span></span>
<span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> python</span><span style="color:#A5D6FF"> install</span><span style="color:#79C0FF"> 3.10</span><span style="color:#79C0FF"> 3.11</span><span style="color:#79C0FF"> 3.12</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># プロジェクトのバージョンを固定（.python-version を生成）</span></span>
<span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> python</span><span style="color:#A5D6FF"> pin</span><span style="color:#79C0FF"> 3.11</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># 特定バージョンで venv を作成</span></span>
<span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> venv</span><span style="color:#79C0FF"> --python</span><span style="color:#79C0FF"> 3.12</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># 特定バージョンで実行</span></span>
<span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> run</span><span style="color:#79C0FF"> --python</span><span style="color:#79C0FF"> 3.10</span><span style="color:#A5D6FF"> pytest</span></span></code></pre></figure>
<p>バージョンを初めて使う際は自動ダウンロード — 以降はキャッシュからすぐ使えます。</p>
<h2 id="pip-互換インターフェース">pip 互換インターフェース</h2>
<p>既存の CI・Docker・スクリプトがまだ <code>pip</code> を使っている？uv がドロップイン置き換えを提供：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># pip install -r requirements.txt と同等</span></span>
<span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> pip</span><span style="color:#A5D6FF"> install</span><span style="color:#79C0FF"> -r</span><span style="color:#A5D6FF"> requirements.txt</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># requirements をコンパイル（クロスプラットフォーム・再現可能）</span></span>
<span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> pip</span><span style="color:#A5D6FF"> compile</span><span style="color:#A5D6FF"> requirements.in</span><span style="color:#79C0FF"> --universal</span><span style="color:#79C0FF"> -o</span><span style="color:#A5D6FF"> requirements.txt</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># 環境を同期（ロックファイルに厳密に従う）</span></span>
<span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> pip</span><span style="color:#A5D6FF"> sync</span><span style="color:#A5D6FF"> requirements.txt</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># venv を作成</span></span>
<span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> venv</span></span></code></pre></figure>
<p><code>uv pip</code> に切り替えると、パラメータはほぼ同じで速度が一桁違います — 自転車からオートバイに乗り換えるようなもの：道は同じ、体験は全然違う。大きな変更を避けてレガシープロジェクトをアップグレードしたい？まず <code>uv pip</code> に変えるだけで痛みなく飛躍します。</p>
<h2 id="全域ツールインストールuv-tool">全域ツールインストール（uv tool）</h2>
<p>よく使うツールを毎回 <code>uvx</code> で実行したくない？全域インストールする：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> tool</span><span style="color:#A5D6FF"> install</span><span style="color:#A5D6FF"> ruff</span></span>
<span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> tool</span><span style="color:#A5D6FF"> install</span><span style="color:#A5D6FF"> httpie</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># 以降は直接呼び出せる</span></span>
<span data-line=""><span style="color:#FFA657">ruff</span><span style="color:#A5D6FF"> check</span><span style="color:#A5D6FF"> .</span></span>
<span data-line=""><span style="color:#FFA657">http</span><span style="color:#A5D6FF"> https://httpbin.org/get</span></span></code></pre></figure>
<p>単一ツールまたは全ツールをアップグレード：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> tool</span><span style="color:#A5D6FF"> upgrade</span><span style="color:#A5D6FF"> ruff</span></span>
<span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> tool</span><span style="color:#A5D6FF"> upgrade</span><span style="color:#79C0FF"> --all</span></span></code></pre></figure>
<blockquote>
<p><code>uv tool install</code> は独立した環境を作成するので、プロジェクトの依存関係と衝突しません。プロジェクトでバージョン固定が必要なツールは、引き続き <code>uv add --dev</code> を使ってください。</p>
</blockquote>
<h2 id="スクリプトロックファイルと-shebang">スクリプトロックファイルと shebang</h2>

<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> lock</span><span style="color:#79C0FF"> --script</span><span style="color:#A5D6FF"> example.py</span></span></code></pre></figure>

<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> tool</span><span style="color:#A5D6FF"> install</span><span style="color:#A5D6FF"> ruff</span></span>
<span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> tool</span><span style="color:#A5D6FF"> install</span><span style="color:#A5D6FF"> httpie</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># 以降は直接呼び出せる</span></span>
<span data-line=""><span style="color:#FFA657">ruff</span><span style="color:#A5D6FF"> check</span><span style="color:#A5D6FF"> .</span></span>
<span data-line=""><span style="color:#FFA657">http</span><span style="color:#A5D6FF"> https://httpbin.org/get</span></span></code></pre></figure>
<p>単一ツールまたは全ツールをアップグレード：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> tool</span><span style="color:#A5D6FF"> upgrade</span><span style="color:#A5D6FF"> ruff</span></span>
<span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> tool</span><span style="color:#A5D6FF"> upgrade</span><span style="color:#79C0FF"> --all</span></span></code></pre></figure>
<blockquote>
<p><code>uv tool install</code> は独立した環境を作成するので、プロジェクトの依存関係と衝突しません。プロジェクトでバージョン固定が必要なツールは、引き続き <code>uv add --dev</code> を使ってください。</p>
</blockquote>
<h2 id="スクリプトロックファイルと-shebang">スクリプトロックファイルと shebang</h2>
<p>単一スクリプトも再現可能にしたい？依存関係をロックできます：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> lock</span><span style="color:#79C0FF"> --script</span><span style="color:#A5D6FF"> example.py</span></span></code></pre></figure>
<p><code>example.py.lock</code> が生成されます。<code>uv run example.py</code> を実行するとこのロックファイルが使われます。</p>
<p>または実行ファイルにする：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E">#!/usr/bin/env -S uv run --script</span></span>
<span data-line=""><span style="color:#8B949E"># /// script</span></span>
<span data-line=""><span style="color:#8B949E"># dependencies = ["httpx"]</span></span>
<span data-line=""><span style="color:#8B949E"># ///</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#FFA657">import</span><span style="color:#A5D6FF"> httpx</span></span>
<span data-line=""><span style="color:#79C0FF">print</span><span style="color:#E6EDF3">(</span><span style="color:#A5D6FF">httpx.get</span><span style="color:#E6EDF3">(</span><span style="color:#FFA657">"https://example.com"</span><span style="color:#E6EDF3">))</span></span></code></pre></figure>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">chmod</span><span style="color:#A5D6FF"> +x</span><span style="color:#A5D6FF"> fetch</span></span>
<span data-line=""><span style="color:#FFA657">./fetch</span></span></code></pre></figure>
