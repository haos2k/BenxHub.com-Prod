<h2 id="コンセプト-2uvlock-は依存関係のスナップショット">コンセプト 2：uv.lock は依存関係のスナップショット</h2>
<p><code>pyproject.toml</code> は「何が欲しいか」を書きます（例：<code>requests>=2.31</code>）。<code>uv.lock</code> は「実際にインストールされたバージョン」を記録します — すべての推移的依存関係まで正確に。</p>
<ul>
<li><strong>なぜロックファイルが必要か？</strong> すべての人・すべての CI・本番環境が完全に同じ依存関係ツリーをインストールすることを保証します。「私の環境では動く、あなたの環境では壊れる」はもうなし。</li>
<li><strong>コミットすべきか？</strong> はい。<code>uv.lock</code> はバージョン管理に入れて、チームと CI が同じ依存関係ツリーを使えるようにしてください。</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># ロックファイルを更新（例：パッケージをアップグレード）</span></span>

<h2 id="コンセプト-3venv-はプロジェクト専用のサンドボックス">コンセプト 3：.venv はプロジェクト専用のサンドボックス</h2>
<p>uv はプロジェクトルートに <code>.venv</code> を作成します — <code>uv add</code> したすべてのパッケージはここに入り、システム Python から隔離されます。</p>
<ul>
<li><strong>手動で activate する必要があるか？</strong> いいえ。<code>uv run</code> が自動的にこの環境を使います。</li>
<li><strong>コミットすべきか？</strong> いいえ。<code>.venv</code> は <code>.gitignore</code> に入れてください。</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># 環境を手動同期（例：新しくクローンした後）</span></span>
<span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> sync</span></span>
<span data-line=""><span style="color:#79C0FF">source</span><span style="color:#A5D6FF"> .venv/bin/activate</span><span style="color:#8B949E">  # その後 python、pytest などを直接使える</span></span></code></pre></figure>
<h2 id="コンセプト-4uv-run-は楽ちんな実行エントリーポイント">コンセプト 4：uv run は楽ちんな実行エントリーポイント</h2>
<p><code>uv run</code> は：</p>
<ol>
<li>ロックファイルが pyproject.toml と整合しているか確認</li>
<li>.venv がロックファイルと同期していることを確認</li>
<li>正しい環境で指定したコマンドを実行</li>
</ol>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> run</span><span style="color:#A5D6FF"> python</span><span style="color:#A5D6FF"> main.py</span></span>
<span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> run</span><span style="color:#A5D6FF"> pytest</span></span>
<span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> run</span><span style="color:#A5D6FF"> flask</span><span style="color:#A5D6FF"> run</span><span style="color:#79C0FF"> -p</span><span style="color:#79C0FF"> 3000</span></span></code></pre></figure>
<p>activate を覚える必要も、環境の間違いを心配する必要もない — uv に任せるだけ。トイレの場所を考えなくても自然に向かう猫のように。この「開けば動く」体験は、一度使ったら戻れません。</p>
