3:T1917,<p>Most first-time CrewAI failures are not API issues. They come from <strong>messy role assignment</strong>.<br>
Remember one rule: <strong>one agent, one specialty; one task, one job</strong>. Your success rate jumps quickly.</p>
<h2 id="split-agents-first-then-write-tasks">Split agents first, then write tasks</h2>
<p>Think like this:</p>
<ul>
<li>Agent = "who"</li>
<li>Task = "what"</li>
<li>Context = "what data gets handed from previous step to next"</li>
</ul>
<p>If one agent does research, writing, and review all at once, it usually does all three shallowly.</p>

<h2 id="top-3-beginner-pitfalls">Top 3 beginner pitfalls</h2>
<ol>
<li><strong>Task description is too short</strong>: model does not know your required format</li>
<li><strong>No expected_output</strong>: output format drifts every run</li>
<li><strong>No context</strong>: downstream task cannot access previous results</li>
</ol>
<h2 id="a-simple-checklist">A simple checklist</h2>
<p>After each YAML edit, ask these five questions:</p>
<ul>
<li>Does this agent have only one specialty?</li>
<li>Does this task do only one job?</li>
<li>Is output format clear in <code>expected_output</code>?</li>
<li>Did I define dependencies with <code>context</code>?</li>
<li>Who writes files? Did I set <code>output_file</code>?</li>
</ul>
