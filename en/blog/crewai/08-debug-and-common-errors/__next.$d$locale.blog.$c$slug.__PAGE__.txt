<h2 id="8-most-common-problems">8 most common problems</h2>
<table>
<thead>
<tr>
<th>Symptom</th>
<th>Common cause</th>
<th>Quick fix</th>
</tr>
</thead>
<tbody>
<tr>
<td>Output format changes every run</td>
<td><code>expected_output</code> too vague</td>
<td>Add format constraints; use <code>output_pydantic</code> when needed</td>
</tr>
<tr>
<td>Downstream task gets no data</td>
<td>Missing <code>context</code></td>
<td>Define explicit chaining in <code>tasks.yaml</code></td>
</tr>
<tr>
<td>Tool is never called</td>
<td>Task prompt lacks tool-use condition</td>
<td>Force "use tool first" in task instruction</td>
</tr>
<tr>
<td>Cost spikes</td>
<td>Task too long and repetitive calls</td>
<td>Split tasks, shorten prompts, add caching</td>
</tr>
<tr>
<td>Severe hallucination</td>
<td>Missing source constraints</td>
<td>Require source URL and citation format</td>
</tr>
<tr>
<td>Workflow gets stuck</td>
<td>Incomplete branch conditions</td>
<td>Verify router return values and listener mappings</td>
</tr>
<tr>
<td>Crashes at startup</td>
<td>Environment variables missing</td>
<td>Check <code>.env</code> and API keys</td>
</tr>
<tr>
<td>Performance unstable</td>
<td>Test inputs are not fixed</td>
<td>Build fixed test inputs and acceptance rules</td>
</tr>
</tbody>
</table>
<h2 id="recommended-debug-order">Recommended debug order</h2>
<ol>
<li>Check config first: <code>agents.yaml</code>, <code>tasks.yaml</code></li>
<li>Check inputs next: whether <code>inputs</code> are stable</li>
<li>Check tools next: parameters and return format</li>
<li>Check model last: temperature, context window, cost</li>
</ol>
<p>Do not reverse this order. Many people blame the model first, while the real issue is one missing YAML line.</p>
<h2 id="one-very-useful-trick">One very useful trick</h2>
<p>For every task, add "output summary" and "key field checks," such as:</p>
<ul>
<li>Is there a conclusion?</li>
<li>Are there sources?</li>
<li>Does it follow markdown structure?</li>
</ul>
<p>Treat these as mini unit tests inside the workflow.</p>
