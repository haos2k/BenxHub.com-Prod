3:Td59,<h2 id="the-most-common-approach-cursor-agent">The Most Common Approach: <code>cursor agent</code></h2>
<p>Run this inside your project directory:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#A5D6FF"> "Add a README to this project"</span></span></code></pre></figure>
<ul>
<li><strong>Interactive</strong>: the AI will ask questions and make suggestions; you can accept or reject changes</li>
<li><strong>Context-aware</strong>: it reads files in the current directory to inform its responses and edits</li>
</ul>
<h2 id="one-shot-vs-conversation">One-Shot vs. Conversation</h2>
<p><strong>Want to delegate a task directly:</strong> Put the instruction in quotes and send it all at once.</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#A5D6FF"> "Refactor the auth module to use JWT"</span></span></code></pre></figure>
<p><strong>Want to discuss before acting:</strong> Run <code>cursor agent</code> without any arguments to enter <strong>conversation mode</strong>, where you can describe your requirements step by step and the AI will clarify before making changes.</p>
