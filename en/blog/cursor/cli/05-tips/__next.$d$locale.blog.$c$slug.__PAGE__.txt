3:Td81,<p>A few practical tips and answers to the most common questions — solve "where was I?" and "why can't I use this?" in one shot.</p>
<h2 id="tips">Tips</h2>
<h3 id="1-resume-the-previous-conversation">1. Resume the Previous Conversation</h3>
<p>Closed mid-session and want to pick up where you left off? No need to start over:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#79B8FF"> --resume</span></span></code></pre></figure>
<p>This loads the most recent conversation with all context intact — like hitting "resume" on a paused video.</p>
<h3 id="2-confirm-before-running-commands">2. Confirm Before Running Commands</h3>
<p>The Agent may want to run commands like <code>npm install</code> or <code>git</code>.</p>
<ul>
<li><strong>Interactive mode</strong>: it will ask you first</li>
<li>If you're cautious, tell it in conversation: "Ask me before running any commands"</li>
</ul>
<p>That way there won't be any "wait, when did it run that?" moments.</p>
<h3 id="3-use-cli-and-ide-together">3. Use CLI and IDE Together</h3>
<p>The CLI and the Cursor window <strong>can be used at the same time</strong> — it's not either/or:</p>
<ul>
<li>Use the window for main development, browsing the file tree, using Tab completion</li>
<li>Use the CLI for small tasks, looking things up, running automation</li>
</ul>
<p>One handles the main battle, the other handles skirmishes — divide and conquer.</p>
<h2 id="faq">FAQ</h2>
<p><strong>Q: <code>cursor: command not found</code>?</strong>
A: Restart your terminal after installation, or run <code>source ~/.zshrc</code> (or <code>~/.bashrc</code>). Make sure the install path is in your <code>PATH</code> — the classic "installed the tool but the system can't find it" problem is almost always a PATH issue.</p>
<p><strong>Q: Is the CLI paid?</strong>
A: Yes. You need a Cursor subscription to use the CLI — it's the same subscription as the IDE.</p>
<p><strong>Q: Can I use it on a server / in Docker?</strong>
A: Yes. The requirements are: can run the install script, and can log in to Cursor (or set up a token). Watch out for network and authorization — don't expect it to reach Cursor's cloud in a restricted network environment.</p>
<p><strong>Q: Is it the same as the Agent in the Cursor window?</strong>
A: It's the same underlying capability. The difference is that the CLI is a terminal interface, supports non-interactive mode, and integrates with scripts and CI — same AI, different interface.</p>
<h2 id="summary">Summary</h2>
<ul>
<li><strong>Resume conversation</strong>: <code>cursor agent --resume</code></li>
<li><strong>Command confirmation</strong>: you can ask it to "confirm before running any commands"</li>
<li><strong>CLI and IDE</strong>: can be used together, not mutually exclusive</li>
<li><strong>When stuck</strong>: check <code>cursor --help</code> and the official docs — most issues have known solutions</li>
</ul>
