3:T422b,<p>Write a shell script that has <code>cursor agent</code> automatically fix code, run tests, and if they fail let the AI fix again — <strong>repeating until all tests pass</strong>. No need to sit there pressing Y/N. Hand the loop to the AI and go do something else — come back when the terminal shows "tests passed."</p>
<h2 id="core-concept">Core Concept</h2>
<pre><code>while tests don't pass:
    run tests → collect error output
    feed error output to cursor agent
    cursor agent fixes the code
    run tests again
</code></pre>
<p>It's a "run tests → fail → tell AI to fix → repeat" loop until green. Simple and direct, but effective.</p>
<h2 id="step-1-check-prerequisites">Step 1: Check Prerequisites</h2>
<ul>
<li><code>cursor</code> is installed and logged in (<code>cursor --version</code> to verify)</li>
<li>The project has a <strong>test command that runs in the terminal</strong>, such as:
<ul>
<li><code>npm test</code></li>
<li><code>pytest</code></li>
<li><code>go test ./...</code></li>
<li><code>cargo test</code></li>
</ul>
</li>
<li>Tests return a non-zero exit code on failure (almost all test frameworks do this by default)</li>
</ul>
<h2 id="step-2-the-simplest-script">Step 2: The Simplest Script</h2>
<p>Create <code>debug-loop.sh</code>:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E">#!/bin/bash</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#E6EDF3">MAX_LOOPS</span><span style="color:#FF7B72">=</span><span style="color:#A5D6FF">10</span><span style="color:#8B949E">        # max iterations to prevent truly infinite loops</span></span>
<span data-line=""><span style="color:#E6EDF3">TEST_CMD</span><span style="color:#FF7B72">=</span><span style="color:#A5D6FF">"npm test"</span><span style="color:#8B949E"> # replace with your test command</span></span>
<span data-line=""><span style="color:#E6EDF3">loop</span><span style="color:#FF7B72">=</span><span style="color:#A5D6FF">0</span></span>
<span data-line=""> </span>

<span data-line=""><span style="color:#79C0FF">  echo</span><span style="color:#A5D6FF"> "=== Loop $((</span><span style="color:#FFA657">loop</span><span style="color:#A5D6FF"> + </span><span style="color:#79C0FF">1</span><span style="color:#A5D6FF">)) ==="</span></span>
<span data-line=""> </span>

<span data-line=""> </span>
<span data-line=""><span style="color:#FF7B72">  if</span><span style="color:#E6EDF3"> [ $EXIT_CODE </span><span style="color:#FF7B72">-eq</span><span style="color:#79C0FF"> 0</span><span style="color:#E6EDF3"> ]; </span><span style="color:#FF7B72">then</span></span>

<span data-line=""> </span>
<span data-line=""><span style="color:#79C0FF">echo</span><span style="color:#A5D6FF"> "⚠️  Reached max loops (</span><span style="color:#E6EDF3">$MAX_LOOPS</span><span style="color:#A5D6FF">). Stopping. Please investigate manually."</span></span>

<h2 id="step-3-run-the-script">Step 3: Run the Script</h2>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">chmod</span><span style="color:#A5D6FF"> +x</span><span style="color:#A5D6FF"> debug-loop.sh</span></span>

<p>Now you can make coffee, reply to messages, and come back when you see <code>✅ Tests passed!</code> in the terminal. If it hits MAX_LOOPS without passing, it's time for human intervention.</p>

<h2 id="safety-considerations">Safety Considerations</h2>
<table>
<thead>
<tr>
<th>Risk</th>
<th>How to Mitigate</th>
</tr>
</thead>
<tbody>
<tr>
<td>AI breaks more files</td>
<td><code>git commit</code> first to save state, <code>git checkout .</code> to revert if needed</td>
</tr>
<tr>
<td>Too many loops waste quota</td>
<td>Set a reasonable <code>MAX_LOOPS</code> (5–15 recommended)</td>
</tr>
<tr>
<td>AI modifies test files</td>
<td>Explicitly say "do not modify test files" in the prompt</td>
</tr>
<tr>
<td>Different failures each loop</td>
<td>Keep logs (enhanced version) for post-analysis</td>
</tr>
</tbody>
</table>
<h2 id="summary">Summary</h2>
<ol>
<li><strong>Script structure</strong>: run tests → fail → feed to AI → repeat until pass or hit limit</li>
<li><strong>Key parameters</strong>: <code>TEST_CMD</code> (test command), <code>MAX_LOOPS</code> (maximum iterations)</li>
<li><strong>Be specific in your prompt</strong>: state the language, restrict which directories to modify, no touching test files</li>
<li><strong><code>git commit</code> first</strong> — easy to revert if things go wrong, and peace of mind</li>
</ol>

9:T422b,<p>Write a shell script that has <code>cursor agent</code> automatically fix code, run tests, and if they fail let the AI fix again — <strong>repeating until all tests pass</strong>. No need to sit there pressing Y/N. Hand the loop to the AI and go do something else — come back when the terminal shows "tests passed."</p>
<h2 id="core-concept">Core Concept</h2>
<pre><code>while tests don't pass:
    run tests → collect error output
    feed error output to cursor agent
    cursor agent fixes the code
    run tests again
</code></pre>
<p>It's a "run tests → fail → tell AI to fix → repeat" loop until green. Simple and direct, but effective.</p>
<h2 id="step-1-check-prerequisites">Step 1: Check Prerequisites</h2>
<ul>
<li><code>cursor</code> is installed and logged in (<code>cursor --version</code> to verify)</li>
<li>The project has a <strong>test command that runs in the terminal</strong>, such as:
<ul>
<li><code>npm test</code></li>
<li><code>pytest</code></li>
<li><code>go test ./...</code></li>
<li><code>cargo test</code></li>
</ul>
</li>
<li>Tests return a non-zero exit code on failure (almost all test frameworks do this by default)</li>
</ul>

<p>Create <code>debug-loop.sh</code>:</p>
