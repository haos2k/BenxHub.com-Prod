3:T1715,<p><a href="05-tips">05-tips</a> already mentioned <code>cursor agent --resume</code> to continue the last conversation. This post completes <strong>sessions</strong> and <strong>cloud execution</strong>: how to list past conversations, which one to resume, and using <strong><code>-c</code></strong> to run a task in the cloud so you can close the terminal or laptop and it still finishes in the background.</p>
<h2 id="session-resume---resume">Session resume: --resume</h2>
<p>You closed the terminal mid-conversation, or the task was too long and you stopped it—next time you want to continue from the same thread:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#79B8FF"> --resume</span></span></code></pre></figure>
<p>This loads the <strong>most recent</strong> conversation; context and previous instructions are still there, no need to re-describe the request.</p>
<h3 id="resuming-a-specific-conversation">Resuming a specific conversation</h3>
<p>If you have more than one conversation and want to resume <strong>a particular one</strong>:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#79B8FF"> --resume=chat-id-here</span></span></code></pre></figure>
<p>Get the <code>chat-id</code> from “list conversations,” below.</p>
<h2 id="list-all-conversations-cursor-agent-ls">List all conversations: cursor agent ls</h2>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> ls</span></span></code></pre></figure>
<p>This lists past conversations (with ID or identifier). Find the one you want and pass its ID to <code>--resume=ID</code>.</p>
<p>Quick reference:</p>
<table>
<thead>
<tr>
<th>Command</th>
<th>Purpose</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>cursor agent ls</code></td>
<td>List all conversations</td>
</tr>
<tr>
<td><code>cursor agent --resume</code></td>
<td>Resume the most recent</td>
</tr>
<tr>
<td><code>cursor agent --resume=chat-id</code></td>
<td>Resume a specific conversation</td>
</tr>
</tbody>
</table>
<h2 id="cloud-execution--c----cloud">Cloud execution: -c / --cloud</h2>
<p>Some tasks are heavy: full-repo analysis, large doc generation, multi-step refactors. Running locally means keeping the terminal open; closing the laptop or losing connection stops the run.</p>
<p>With <strong><code>-c</code></strong> (or <strong><code>--cloud</code></strong>) you hand <strong>this conversation</strong> to the cloud Agent:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "Analyze the whole project and write architecture doc to docs/architecture.md"</span><span style="color:#79B8FF"> -c</span></span></code></pre></figure>
<ul>
<li>After you send it, the task runs on Cursor’s cloud</li>
<li>You can close the terminal, shut down, or switch to something else</li>
<li>Later, from any device with the same Cursor account, use <code>--resume</code> to rejoin that conversation and see the result or add more instructions</li>
</ul>
<p>So <strong><code>-c</code></strong> = “run this in the cloud; I don’t have to wait at the computer.”</p>
<h3 id="when-to-use--c">When to use -c?</h3>
<table>
<thead>
<tr>
<th>Situation</th>
<th>Suggestion</th>
</tr>
</thead>
<tbody>
<tr>
<td>Task will take a long time</td>
<td>Use <code>-c</code> so it runs in the cloud; it can finish after you close</td>
</tr>
<tr>
<td>Quick one-off question or small edit</td>
<td>Skip <code>-c</code>; run locally</td>
</tr>
<tr>
<td>Unstable network or prefer not to rely on cloud</td>
<td>Run locally, but keep the connection up</td>
</tr>
</tbody>
</table>
<h2 id="sessions--cloud-together">Sessions + cloud together</h2>
<p>A typical flow:</p>
<ol>
<li>Start a task with <code>-c</code> so it runs in the cloud</li>
<li>Close the terminal</li>
<li>Later run <code>cursor agent ls</code> to find that conversation</li>
<li><code>cursor agent --resume=that-id</code> to rejoin, see the result, or send more instructions</li>
</ol>
<p>That way you cover both “long-running tasks” and “multiple devices / shutdown.”</p>
<h2 id="summary">Summary</h2>
<ul>
<li><strong><code>cursor agent ls</code></strong>: List all conversations so you can find the one to resume</li>
<li><strong><code>--resume</code></strong>: Resume the latest; <strong><code>--resume=ID</code></strong>: Resume a specific conversation</li>
<li><strong><code>-c</code> / <code>--cloud</code></strong>: Run the current task in the cloud; you can close the terminal and resume later with <code>--resume</code></li>
</ul>
