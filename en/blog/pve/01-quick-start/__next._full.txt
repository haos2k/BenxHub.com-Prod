19:Tf9b,<p>This guide takes the shortest path to get you a <strong>bootable Debian virtual machine</strong> — your first working environment in PVE. Like getting a first pet: make sure it can eat and sleep first; advanced techniques come later.</p>
<h2 id="prerequisites">Prerequisites</h2>
<ul>
<li>64-bit CPU with <strong>Intel VT-x</strong> or <strong>AMD-V</strong> enabled (without this, VMs will refuse to start)</li>
<li>Minimum 2 GB RAM (8 GB+ recommended — otherwise it'll feel like a 2010 computer)</li>
<li>At least one working network card</li>
<li>A host or server that can boot from USB</li>
</ul>
<h2 id="minimal-example-create-your-first-virtual-machine">Minimal Example: Create Your First Virtual Machine</h2>
<h3 id="step-1-log-in-to-the-web-interface">Step 1: Log In to the Web Interface</h3>
<p>After installation, open <code>https://&#x3C;PVE-IP>:8006</code> and log in with <code>root</code> and the password you set during installation. Your browser may warn about the certificate — it's self-signed, so click "Advanced" → "Proceed anyway." Homelab life.</p>
<h3 id="step-2-download-the-system-image">Step 2: Download the System Image</h3>
<ol>
<li>Select the <code>local</code> storage under your node in the left panel</li>
<li>Go to <code>Content</code>, click <code>Download from URL</code></li>
<li>Enter:
<ul>
<li>URL: <code>https://cloud.debian.org/images/cloud/bookworm/latest/debian-12-generic-amd64.qcow2</code></li>
<li>File Name: <code>debian-12-cloud.qcow2</code></li>
</ul>
</li>
<li>Click <code>Query URL</code> then start the download (go get a coffee)</li>
</ol>
<h3 id="step-3-create-the-virtual-machine">Step 3: Create the Virtual Machine</h3>
<ol>
<li>Click <code>Create VM</code> in the top right</li>
<li><code>General</code>: set Name to <code>test-vm</code> (or whatever you like)</li>
<li><code>OS</code>: for a cloud image you can skip the disc setup</li>
<li><code>Disks</code>: select <strong>Use existing disk image</strong>, choose the <code>debian-12-cloud.qcow2</code> you just downloaded</li>
<li><code>CPU</code>: 1 vCPU is fine to start</li>
<li><code>Memory</code>: 512–1024 MB to test the waters</li>
<li><code>Network</code>: default <code>vmbr0</code> is fine</li>
<li><code>Confirm</code> → <code>Finish</code></li>
</ol>
<h3 id="step-4-start-and-verify">Step 4: Start and Verify</h3>
<ol>
<li>Right-click the VM → <code>Start</code></li>
<li>Open <code>Console</code> (noVNC)</li>
<li>If you see the Debian boot screen or login prompt, you've succeeded — congratulations, your first VM is live.</li>
</ol>
<h2 id="common-troubleshooting">Common Troubleshooting</h2>

<tr>
<th>Symptom</th>
<th>What to Check</th>
</tr>
</thead>

<td>Can't access web interface</td>
<td>Check if port 8006 is reachable, confirm <code>pveproxy</code> is running</td>
</tr>
<tr>
<td>VM won't start</td>
<td>Is VT-x / AMD-V enabled in BIOS? Without it, VMs simply won't start</td>
</tr>
<tr>
<td>Can't find image file</td>
<td>Back to <code>local -> Content</code> — check if the download completed</td>
</tr>
<tr>
<td>VM has no network</td>
<td>Check that <code>vmbr0</code> is correctly bound to a physical NIC</td>
</tr>
</tbody>
</table>
