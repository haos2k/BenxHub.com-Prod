<hr>
<h2 id="what-is-a-workspace">What Is a Workspace?</h2>
<p>Think of a workspace as <strong>your assistant's private office</strong>:</p>
<ul>
<li>Files it reads, documents it writes, and scripts it runs all happen inside that folder</li>
<li>You can create multiple workspaces so different jobs stay separated</li>
</ul>
<pre><code>~/.openclaw/workspace-main        ← office for your main assistant
~/.openclaw/workspace-project-a   ← office for project A
~/.openclaw/workspace-project-b   ← office for project B
</code></pre>
<p>That way, "organize my personal journal" and "write code for project A" do not get mixed together.</p>
<hr>
<h2 id="how-does-memory-work">How Does Memory Work?</h2>
<p>OpenClaw stores important pieces of conversation as <strong>memory</strong>, so the assistant can search and reuse them later.</p>
<p>In plain English: <strong>your assistant remembers things you told it before</strong>.</p>
<blockquote>
<p>⚠️ If it feels forgetful, check these:</p>
<ul>
<li>Is memory enabled? Semantic search may require an OpenAI API key</li>
<li>Was old memory cleaned up, compacted, or limited by length?</li>
<li>Did you start a brand-new session? New sessions start with an empty short-term context</li>
</ul>
</blockquote>
<hr>

<h2 id="one-command-backup">One-Command Backup</h2>
<p>Your entire OpenClaw life mostly lives under <code>~/.openclaw</code>. Back it up regularly:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># Copy everything to a backup location</span></span>
<span data-line=""><span style="color:#FFA657">cp</span><span style="color:#79C0FF"> -r</span><span style="color:#A5D6FF"> ~/.openclaw</span><span style="color:#A5D6FF"> ~/backup/openclaw-backup-</span><span style="color:#E6EDF3">$(</span><span style="color:#FFA657">date</span><span style="color:#A5D6FF"> +%Y%m%d</span><span style="color:#E6EDF3">)</span></span></code></pre></figure>
<blockquote>
<p>💡 Moving to a new computer? Copy the whole <code>~/.openclaw</code> folder and you can often continue without running onboarding again.</p>
</blockquote>
