<h2 id="two-ways-to-edit-config-form-mode-vs-raw-json">Two Ways to Edit Config: Form Mode vs Raw JSON</h2>
<p>Go to the <strong>Config</strong> page and you will see two editing styles:</p>
<p><strong>Form mode</strong>: visually structured fields, ideal for beginners or small changes.</p>
<p><strong>Raw JSON mode</strong>: direct config editing, best for advanced users or large edits.</p>
<p>Both modes edit the same file: <code>~/.openclaw/openclaw.json</code>.</p>
<hr>

<h2 id="do-not-forget-to-save">Do Not Forget to Save</h2>
<p>Click <strong>Save / Apply</strong>. OpenClaw will:</p>
<ol>
<li>Validate the config</li>
<li>Apply it, usually with hot reload</li>
</ol>
<blockquote>
<p>⚠️ If you get a <code>baseHash</code> conflict, someone or something changed the config in another place. Reload the config and try again.</p>
</blockquote>

<h2 id="two-ways-to-edit-config-form-mode-vs-raw-json">Two Ways to Edit Config: Form Mode vs Raw JSON</h2>
<p>Go to the <strong>Config</strong> page and you will see two editing styles:</p>
<p><strong>Form mode</strong>: visually structured fields, ideal for beginners or small changes.</p>
<p><strong>Raw JSON mode</strong>: direct config editing, best for advanced users or large edits.</p>
<p>Both modes edit the same file: <code>~/.openclaw/openclaw.json</code>.</p>
