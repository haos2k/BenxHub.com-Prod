1a:Te87,<p>An assistant that can only chat is like hiring a brilliant employee and giving them no tools. Waste of talent.</p>
<p><strong>Skills</strong> are how you equip your assistant to actually do things.</p>
<h2 id="what-youll-learn">What You'll Learn</h2>
<ul>
<li>Understand what a Skill is</li>
<li>Enable built-in skills</li>
<li>Add your own custom skills</li>
<li>Understand skill priority and load paths</li>
</ul>
<hr>
<h2 id="what-is-a-skill">What Is a Skill?</h2>
<p>A Skill is usually a small instruction document called <code>SKILL.md</code>. It explains:</p>
<ul>
<li>What the skill can do</li>
<li>When it should be used</li>
<li>Which tools and steps are allowed</li>
</ul>
<p>Think of it as <strong>the assistant's playbook</strong>. Give it a browser playbook and it can search the web. Give it a file playbook and it can organize your documents.</p>
<hr>
<h2 id="built-in-vs-custom">Built-in vs Custom</h2>
<p>OpenClaw ships with some useful built-in skills, and the community keeps adding more. You can either:</p>
<ul>
<li><strong>Use built-in skills directly</strong> from the dashboard</li>
<li><strong>Write your own</strong> with a simple <code>SKILL.md</code> file</li>
</ul>
<hr>
<h2 id="the-smart-way-to-create-custom-skills">The Smart Way to Create Custom Skills</h2>
<p>If you want to change or add a skill, <strong>do not edit the original files in the OpenClaw repo</strong>. The next update may overwrite them and ruin your day.</p>
<p>Put your custom version here instead:</p>
<pre><code>~/.openclaw/skills/&#x3C;skill-name>/SKILL.md
</code></pre>
<p><strong>Priority order</strong></p>
<pre><code>workspace/skills  →  ~/.openclaw/skills  →  built-in  →  extraDirs
</code></pre>
<p>The first match wins.</p>
<hr>
<h2 id="manage-skills-from-the-dashboard">Manage Skills from the Dashboard</h2>
<p>Open Control UI → <strong>Skills</strong> tab. From there you can:</p>
<ul>
<li>View every available skill</li>
<li>Enable or disable them with one click</li>
<li>Configure skills that need API keys</li>
<li>Install community-contributed skills</li>
</ul>
<p>After saving, OpenClaw usually hot-reloads the changes without restarting the Gateway.</p>
<hr>
<h2 id="load-skills-from-a-custom-folder">Load Skills from a Custom Folder</h2>
<p>If you want to keep all your custom skills in one central directory:</p>
