<hr>
<h2 id="where-is-the-config-file">Where Is the Config File?</h2>
<pre><code>~/.openclaw/openclaw.json
</code></pre>
<p>The format is <strong>JSON5</strong>, which means comments and trailing commas are allowed. Much friendlier than plain JSON.</p>
<p>You can edit it in two ways:</p>
<ul>
<li>Use the <strong>form mode</strong> in Control UI if you want something beginner-friendly</li>
<li>Switch to <strong>Raw JSON</strong> if you want precision and speed</li>
</ul>
<p>Both modes edit the same file and save back to the same path.</p>
<hr>

<h2 id="the-right-way-to-store-api-keys">The Right Way to Store API Keys</h2>
<p><strong>Do not hard-code API keys into config if you can avoid it.</strong></p>
<p>Environment variables are safer:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># Put this in .env or in your system environment</span></span>
<span data-line=""><span style="color:#E1E4E8">ANTHROPIC_API_KEY</span><span style="color:#F97583">=</span><span style="color:#9ECBFF">sk-ant-xxxxx</span></span></code></pre></figure>
<blockquote>
<p>⚠️ If the Gateway runs as a system service such as <code>systemd</code>, make sure the service loads your <code>.env</code>. Otherwise the assistant may fail because it cannot see the API key, and you may run into errors like "Shell env off".</p>
</blockquote>

<h2 id="the-universal-debugging-tool">The Universal Debugging Tool</h2>
<p>When something feels wrong, start here:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">openclaw</span><span style="color:#9ECBFF"> logs</span><span style="color:#79B8FF"> --follow</span></span></code></pre></figure>
<p>Real-time logs answer a surprising number of questions.</p>

</tr>
<tr>

<td>Model compatibility issue, check the docs</td>
</tr>
<tr>
<td>Context got truncated</td>
<td>Start a new session or compact context as recommended</td>
</tr>
</tbody>
</table>

<span data-line=""><span style="color:#E1E4E8">    }</span></span>
<span data-line=""><span style="color:#E1E4E8">  },</span></span>
<span data-line=""><span style="color:#9ECBFF">  "bindings"</span><span style="color:#E1E4E8">: [</span></span>
<span data-line=""><span style="color:#E1E4E8">    { </span><span style="color:#9ECBFF">"agentId"</span><span style="color:#E1E4E8">: </span><span style="color:#9ECBFF">"main"</span><span style="color:#E1E4E8">, </span><span style="color:#9ECBFF">"match"</span><span style="color:#E1E4E8">: { </span><span style="color:#9ECBFF">"channel"</span><span style="color:#E1E4E8">: </span><span style="color:#9ECBFF">"telegram"</span><span style="color:#E1E4E8"> } }</span></span>
<span data-line=""><span style="color:#E1E4E8">  ]</span></span>
<span data-line=""><span style="color:#E1E4E8">}</span></span></code></pre></figure>
<p>Get the simple version working first. Then add more features gradually.</p>
<hr>
<h2 id="the-right-way-to-store-api-keys">The Right Way to Store API Keys</h2>
<p><strong>Do not hard-code API keys into config if you can avoid it.</strong></p>
<p>Environment variables are safer:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># Put this in .env or in your system environment</span></span>
<span data-line=""><span style="color:#E1E4E8">ANTHROPIC_API_KEY</span><span style="color:#F97583">=</span><span style="color:#9ECBFF">sk-ant-xxxxx</span></span></code></pre></figure>
<blockquote>
<p>⚠️ If the Gateway runs as a system service such as <code>systemd</code>, make sure the service loads your <code>.env</code>. Otherwise the assistant may fail because it cannot see the API key, and you may run into errors like "Shell env off".</p>
</blockquote>

<p>When something feels wrong, start here:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">openclaw</span><span style="color:#9ECBFF"> logs</span><span style="color:#79B8FF"> --follow</span></span></code></pre></figure>
