<h2 id="two-things-to-check-before-installing">Two Things to Check Before Installing</h2>
<p>You do not need much, but these two are non-negotiable:</p>
<p><strong>1. Node.js (LTS version)</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">node</span><span style="color:#79C0FF"> --version</span></span>
<span data-line=""><span style="color:#8B949E"># If you see a version number, you are good</span></span></code></pre></figure>
<p><strong>2. An API key for your AI model</strong></p>
<p>If you want to use cloud models such as Anthropic Claude or OpenAI, you need an API key. If you want to stay fully offline, you can use a local model instead. This series assumes a cloud model by default.</p>
<blockquote>
<p>💡 Not sure how to get an API key? Search for something like "Anthropic API key" and you can usually get it done in a few minutes.</p>
</blockquote>
<hr>
<h2 id="install-openclaw">Install OpenClaw</h2>
<p>The official docs recommend the <strong>git-based installation method</strong>, because it is easier to update and debug later.</p>
<p><strong>macOS / Linux</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># Follow the Quick Start commands from docs.openclaw.ai</span></span>
<span data-line=""><span style="color:#8B949E"># In most cases this is a one-line curl script</span></span></code></pre></figure>
<p><strong>Windows</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># First make sure Git is installed and added to PATH</span></span>
<span data-line=""><span style="color:#FFA657">git</span><span style="color:#79C0FF"> --version</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># Then follow the Windows installation guide on docs.openclaw.ai</span></span></code></pre></figure>
<blockquote>
<p>⚠️ Stuck on "git not found" or "openclaw is not recognized"? Add Git to your system PATH, then restart the terminal and try again.</p>
</blockquote>
<hr>
<h2 id="first-launch-hatch-your-assistant">First Launch: Hatch Your Assistant</h2>
<p>After installation, run:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">openclaw</span><span style="color:#A5D6FF"> gateway</span></span></code></pre></figure>
<p><strong>The first run opens the onboarding wizard</strong>, which asks a few simple questions:</p>
<ol>
<li>Which AI model do you want to use?</li>
<li>What is your API key?</li>
<li>Where should the workspace live?</li>
</ol>
<p>Fill those in and OpenClaw will hatch your first assistant for you.</p>
<blockquote>
<p>💡 Stuck for a long time at "wake up my friend"? Double-check the API key, your internet connection, and any error messages printed in the terminal.</p>
</blockquote>
<hr>

<li>A base config file at <code>~/.openclaw/openclaw.json</code></li>
<li>Your first AI assistant, already running</li>
</ul>
