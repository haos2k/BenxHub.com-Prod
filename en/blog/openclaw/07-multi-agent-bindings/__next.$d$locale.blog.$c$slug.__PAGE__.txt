<h3 id="step-2-add-routing-rules-in-bindings">Step 2: Add Routing Rules in <code>bindings</code></h3>
<p>Think of it like a receptionist:</p>
<p>"Messages from group A go to assistant A. Messages from group B go to assistant B. Everything else goes to the default one."</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="json5" data-theme="github-dark-default"><code data-language="json5" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#E6EDF3">{</span></span>
<span data-line=""><span style="color:#A5D6FF">  "bindings"</span><span style="color:#E6EDF3">: [</span></span>
<span data-line=""><span style="color:#E6EDF3">    { </span><span style="color:#A5D6FF">"agentId"</span><span style="color:#E6EDF3">: </span><span style="color:#A5D6FF">"project-a"</span><span style="color:#E6EDF3">, </span><span style="color:#A5D6FF">"match"</span><span style="color:#E6EDF3">: { </span><span style="color:#A5D6FF">"channel"</span><span style="color:#E6EDF3">: </span><span style="color:#A5D6FF">"telegram"</span><span style="color:#E6EDF3">, </span><span style="color:#A5D6FF">"peer"</span><span style="color:#E6EDF3">: { </span><span style="color:#A5D6FF">"kind"</span><span style="color:#E6EDF3">: </span><span style="color:#A5D6FF">"group"</span><span style="color:#E6EDF3">, </span><span style="color:#A5D6FF">"id"</span><span style="color:#E6EDF3">: </span><span style="color:#A5D6FF">"-1001234567890"</span><span style="color:#E6EDF3"> } } },</span></span>
<span data-line=""><span style="color:#E6EDF3">    { </span><span style="color:#A5D6FF">"agentId"</span><span style="color:#E6EDF3">: </span><span style="color:#A5D6FF">"project-b"</span><span style="color:#E6EDF3">, </span><span style="color:#A5D6FF">"match"</span><span style="color:#E6EDF3">: { </span><span style="color:#A5D6FF">"channel"</span><span style="color:#E6EDF3">: </span><span style="color:#A5D6FF">"telegram"</span><span style="color:#E6EDF3">, </span><span style="color:#A5D6FF">"peer"</span><span style="color:#E6EDF3">: { </span><span style="color:#A5D6FF">"kind"</span><span style="color:#E6EDF3">: </span><span style="color:#A5D6FF">"group"</span><span style="color:#E6EDF3">, </span><span style="color:#A5D6FF">"id"</span><span style="color:#E6EDF3">: </span><span style="color:#A5D6FF">"-1009876543210"</span><span style="color:#E6EDF3"> } } },</span></span>
<span data-line=""><span style="color:#E6EDF3">    { </span><span style="color:#A5D6FF">"agentId"</span><span style="color:#E6EDF3">: </span><span style="color:#A5D6FF">"main"</span><span style="color:#E6EDF3">,      </span><span style="color:#A5D6FF">"match"</span><span style="color:#E6EDF3">: { </span><span style="color:#A5D6FF">"channel"</span><span style="color:#E6EDF3">: </span><span style="color:#A5D6FF">"telegram"</span><span style="color:#E6EDF3"> } }</span></span>
<span data-line=""><span style="color:#E6EDF3">  ]</span></span>
<span data-line=""><span style="color:#E6EDF3">}</span></span></code></pre></figure>
<blockquote>
<p>⚠️ <strong>Binding order matters a lot.</strong> More specific rules must come first. Matching is "first hit wins."</p>
</blockquote>
