<h3 id="case-2-it-asks-for-a-token">Case 2: It Asks for a Token</h3>
<p>The onboarding flow gave you a token earlier. This is where you paste it. Save it in Settings and you usually will not need to paste it again later.</p>
<blockquote>
<p>💡 Tokens are stored in the UI settings. Passwords only live in memory and disappear when the session ends. That is intentional for security.</p>
</blockquote>
<h3 id="case-3-remote-access-from-a-vps-or-lan">Case 3: Remote Access from a VPS or LAN</h3>
<p>If your Gateway is not running locally but on a remote server:</p>
<ul>
<li>You must use a token or device pairing</li>
<li>If you see <code>unauthorized</code>, first check <code>gateway.bind</code> and confirm the token was entered correctly</li>
</ul>
