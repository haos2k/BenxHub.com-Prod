<h2 id="suggestions-de-conception-du-flow">Suggestions de conception du Flow</h2>
<ol>
<li>Gardez chaque méthode <code>@listen</code> focalisée sur un seul job</li>
<li>Concentrez les branchements dans <code>@router</code>, évitez les gros blocs if/else partout</li>
<li>Utilisez un état typé <code>BaseModel</code>, pas un dict brut</li>
</ol>
<p>Avec ce style, vous pourrez relire le code dans six mois sans vous sentir archéologue.</p>
<h2 id="quand-utiliser-le-flow-">Quand utiliser le Flow ?</h2>
<ul>
<li>Le workflow a plus de 3 étapes</li>
<li>Il existe des conditions de branchement claires</li>
<li>Plusieurs crews doivent être coordonnés</li>
</ul>
<p>Si votre workflow se limite à « recherche + rédaction de rapport », un seul crew suffit.</p>
