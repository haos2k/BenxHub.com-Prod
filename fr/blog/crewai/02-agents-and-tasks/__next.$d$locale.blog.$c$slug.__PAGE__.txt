3:T1aa3,<p>La plupart des échecs CrewAI des débutants ne viennent pas de l'API. Ils viennent d'<strong>un mauvais découpage des rôles</strong>.<br>
Une règle à retenir : <strong>un agent, une spécialité ; une tâche, un job</strong>. Votre taux de succès monte vite.</p>
<h2 id="découper-les-agents-dabord-puis-écrire-les-tâches">Découper les agents d'abord, puis écrire les tâches</h2>
<p>Raisonnez ainsi :</p>
<ul>
<li>Agent = « qui »</li>
<li>Tâche = « quoi »</li>
<li>Context = « quelles données passent de l'étape précédente à la suivante »</li>
</ul>
<p>Si un seul agent fait recherche, rédaction et relecture, il fait généralement les trois de façon superficielle.</p>

<h2 id="les-3-pièges-les-plus-fréquents-pour-les-débutants">Les 3 pièges les plus fréquents pour les débutants</h2>
<ol>
<li><strong>Description de tâche trop courte</strong> : le modèle ne sait pas quel format vous exigez</li>
<li><strong>Pas d'expected_output</strong> : le format de sortie change à chaque exécution</li>
<li><strong>Pas de context</strong> : la tâche suivante ne peut pas accéder aux résultats précédents</li>
</ol>
<h2 id="une-checklist-simple">Une checklist simple</h2>
<p>Après chaque modification YAML, posez-vous ces cinq questions :</p>
<ul>
<li>Cet agent a-t-il une seule spécialité ?</li>
<li>Cette tâche fait-elle un seul job ?</li>
<li>Le format de sortie est-il clair dans <code>expected_output</code> ?</li>
<li>Ai-je défini les dépendances avec <code>context</code> ?</li>
<li>Qui écrit les fichiers ? Ai-je défini <code>output_file</code> ?</li>
</ul>
