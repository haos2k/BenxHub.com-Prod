Donnez des super-pouvoirs à votre assistant : les Skills le transforment de bavard en acteur

8 mars 2026·2 min read

Un assistant qui ne sait que discuter, c'est comme embaucher un employé brillant sans lui donner d'outils. Gaspillage de talent.

Les Skills sont la façon d'équiper votre assistant pour qu'il fasse vraiment des choses.

Ce que vous allez apprendre

  • Comprendre ce qu'est une Skill
  • Activer les skills intégrées
  • Ajouter vos propres skills personnalisées
  • Comprendre la priorité et les chemins de chargement des skills

Qu'est-ce qu'une Skill ?

Une Skill est généralement un petit document d'instructions nommé SKILL.md. Il explique :

  • Ce que la skill peut faire
  • Quand elle doit être utilisée
  • Quels outils et étapes sont autorisés

Pensez-y comme au playbook de l'assistant. Donnez-lui un playbook navigateur et il peut chercher sur le web. Donnez-lui un playbook fichiers et il peut organiser vos documents.

Intégrées vs personnalisées

OpenClaw embarque des skills intégrées utiles, et la communauté en ajoute. Vous pouvez :

  • Utiliser les skills intégrées directement depuis le tableau de bord
  • Écrire les vôtres avec un simple fichier SKILL.md

La bonne façon de créer des skills personnalisées

Pour modifier ou ajouter une skill, ne modifiez pas les fichiers d'origine dans le dépôt OpenClaw. La prochaine mise à jour pourrait les écraser et gâcher votre journée.

Mettez plutôt votre version personnalisée ici :

~/.openclaw/skills/<skill-name>/SKILL.md

Ordre de priorité

workspace/skills  →  ~/.openclaw/skills  →  intégrées  →  extraDirs

La première correspondance l'emporte.

Gérer les skills depuis le tableau de bord

Ouvrez l'interface de contrôle → onglet Skills. Vous pouvez :

  • Voir toutes les skills disponibles
  • Les activer ou désactiver en un clic
  • Configurer les skills qui nécessitent des clés API
  • Installer des skills fournies par la communauté

Après enregistrement, OpenClaw recharge généralement les changements à chaud sans redémarrer la Gateway.
