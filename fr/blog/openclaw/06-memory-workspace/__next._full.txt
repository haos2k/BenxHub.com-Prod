1a:Tf7c,<p>Vous avez déjà passé la moitié d'une conversation à apprendre quelque chose à une IA, pour qu'elle oublie tout la fois suivante ?</p>

<hr>
<h2 id="quest-ce-quun-espace-de-travail-">Qu'est-ce qu'un espace de travail ?</h2>
<p>Imaginez un espace de travail comme <strong>le bureau privé de votre assistant</strong> :</p>
<ul>
<li>Les fichiers qu'il lit, les documents qu'il écrit et les scripts qu'il exécute se trouvent dans ce dossier</li>
<li>Vous pouvez créer plusieurs espaces pour séparer les différents usages</li>
</ul>
<pre><code>~/.openclaw/workspace-main        ← bureau de votre assistant principal
~/.openclaw/workspace-project-a   ← bureau du projet A
~/.openclaw/workspace-project-b   ← bureau du projet B
</code></pre>
<p>Ainsi, « organise mon journal personnel » et « écris le code du projet A » ne se mélangent pas.</p>
<hr>
<h2 id="comment-fonctionne-la-mémoire-">Comment fonctionne la mémoire ?</h2>
<p>OpenClaw stocke des éléments importants des conversations en <strong>mémoire</strong>, pour que l'assistant puisse les rechercher et les réutiliser plus tard.</p>
<p>En clair : <strong>votre assistant se souvient de ce que vous lui avez dit</strong>.</p>
<blockquote>
<p>⚠️ S'il semble oublier, vérifiez :</p>
<ul>
<li>La mémoire est-elle activée ? La recherche sémantique peut nécessiter une clé API OpenAI</li>
<li>L'ancienne mémoire a-t-elle été nettoyée, compactée ou limitée en longueur ?</li>
<li>Avez-vous démarré une toute nouvelle session ? Les nouvelles sessions commencent avec un contexte court terme vide</li>
</ul>
</blockquote>
