<h2 id="deux-façons-déditer-la-config--formulaire-vs-raw-json">Deux façons d'éditer la config : formulaire vs Raw JSON</h2>
<p>Allez sur la page <strong>Config</strong> et vous verrez deux modes d'édition :</p>
<p><strong>Mode formulaire</strong> : champs structurés visuellement, idéal pour les débutants ou les petites modifications.</p>
<p><strong>Mode Raw JSON</strong> : édition directe de la config, pour les utilisateurs avancés ou les grosses modifications.</p>
<p>Les deux modes éditent le même fichier : <code>~/.openclaw/openclaw.json</code>.</p>

<h2 id="deux-façons-déditer-la-config--formulaire-vs-raw-json">Deux façons d'éditer la config : formulaire vs Raw JSON</h2>
<p>Allez sur la page <strong>Config</strong> et vous verrez deux modes d'édition :</p>
<p><strong>Mode formulaire</strong> : champs structurés visuellement, idéal pour les débutants ou les petites modifications.</p>
<p><strong>Mode Raw JSON</strong> : édition directe de la config, pour les utilisateurs avancés ou les grosses modifications.</p>
<p>Les deux modes éditent le même fichier : <code>~/.openclaw/openclaw.json</code>.</p>
