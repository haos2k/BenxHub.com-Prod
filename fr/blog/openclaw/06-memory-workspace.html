Où est le cerveau de votre assistant ? Comprendre mémoire et espaces de travail

8 mars 2026·2 min read

Vous avez déjà passé la moitié d'une conversation à apprendre quelque chose à une IA, pour qu'elle oublie tout la fois suivante ?

Cet article est là pour résoudre cette frustration.

Ce que vous allez apprendre

  • Comprendre ce qu'est un espace de travail et pourquoi c'est important
  • Apprendre comment fonctionne la mémoire
  • Savoir où sont stockées vos données
  • Sauvegarder toute votre configuration en une commande

Qu'est-ce qu'un espace de travail ?

Imaginez un espace de travail comme le bureau privé de votre assistant :

  • Les fichiers qu'il lit, les documents qu'il écrit et les scripts qu'il exécute se trouvent dans ce dossier
  • Vous pouvez créer plusieurs espaces pour séparer les différents usages
~/.openclaw/workspace-main        ← bureau de votre assistant principal
~/.openclaw/workspace-project-a   ← bureau du projet A
~/.openclaw/workspace-project-b   ← bureau du projet B

Ainsi, « organise mon journal personnel » et « écris le code du projet A » ne se mélangent pas.

Comment fonctionne la mémoire ?

OpenClaw stocke des éléments importants des conversations en mémoire, pour que l'assistant puisse les rechercher et les réutiliser plus tard.

En clair : votre assistant se souvient de ce que vous lui avez dit.

⚠️ S'il semble oublier, vérifiez :

  • La mémoire est-elle activée ? La recherche sémantique peut nécessiter une clé API OpenAI
  • L'ancienne mémoire a-t-elle été nettoyée, compactée ou limitée en longueur ?
  • Avez-vous démarré une toute nouvelle session ? Les nouvelles sessions commencent avec un contexte court terme vide

Où sont stockées les données ?

Type Chemin
Fichier de config ~/.openclaw/openclaw.json
Espaces de travail ~/.openclaw/workspace-<nom>/
Sessions et mémoire sous-dossiers sous ~/.openclaw/
