<h2 id="deux-points-à-vérifier-avant-dinstaller">Deux points à vérifier avant d'installer</h2>
<p>Il ne faut pas grand-chose, mais ces deux points sont non négociables :</p>
<p><strong>1. Node.js (version LTS)</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">node</span><span style="color:#79B8FF"> --version</span></span>
<span data-line=""><span style="color:#6A737D"># Si vous voyez un numéro de version, c'est bon</span></span></code></pre></figure>
<p><strong>2. Une clé API pour votre modèle IA</strong></p>
<p>Pour utiliser des modèles cloud (Anthropic Claude, OpenAI, etc.), il vous faut une clé API. Pour rester entièrement hors ligne, vous pouvez utiliser un modèle local. Cette série suppose un modèle cloud par défaut.</p>
<blockquote>
<p>💡 Vous ne savez pas comment obtenir une clé API ? Cherchez « Anthropic API key » (ou équivalent) : en général c'est réglé en quelques minutes.</p>
</blockquote>

<h2 id="installer-openclaw">Installer OpenClaw</h2>
<p>La doc officielle recommande <strong>l'installation via Git</strong>, plus simple à mettre à jour et à déboguer ensuite.</p>
<p><strong>macOS / Linux</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># Suivez les commandes Quick Start de docs.openclaw.ai</span></span>
<span data-line=""><span style="color:#6A737D"># Dans la plupart des cas, c'est un script curl en une ligne</span></span></code></pre></figure>
<p><strong>Windows</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># Vérifiez d'abord que Git est installé et dans le PATH</span></span>
<span data-line=""><span style="color:#B392F0">git</span><span style="color:#79B8FF"> --version</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#6A737D"># Puis suivez le guide d'installation Windows sur docs.openclaw.ai</span></span></code></pre></figure>
<blockquote>
<p>⚠️ Bloqué sur « git introuvable » ou « openclaw non reconnu » ? Ajoutez Git au PATH système, redémarrez le terminal et réessayez.</p>
</blockquote>
<hr>
<h2 id="premier-lancement--faites-éclore-votre-assistant">Premier lancement : faites éclore votre assistant</h2>
<p>Après l'installation, lancez :</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">openclaw</span><span style="color:#9ECBFF"> gateway</span></span></code></pre></figure>
<p><strong>Le premier lancement ouvre l'assistant de configuration</strong>, qui pose quelques questions simples :</p>
<ol>
<li>Quel modèle IA voulez-vous utiliser ?</li>
<li>Quelle est votre clé API ?</li>
<li>Où doit vivre l'espace de travail ?</li>
</ol>
<p>Répondez et OpenClaw fera éclore votre premier assistant.</p>
<blockquote>
<p>💡 Bloqué longtemps sur « wake up my friend » ? Vérifiez la clé API, la connexion Internet et les messages d'erreur affichés dans le terminal.</p>
</blockquote>

<ul>
<li>Un <strong>token</strong> pour la connexion au tableau de bord</li>
<li>Un fichier de config de base dans <code>~/.openclaw/openclaw.json</code></li>
<li>Votre premier assistant IA, déjà en cours d'exécution</li>
</ul>
