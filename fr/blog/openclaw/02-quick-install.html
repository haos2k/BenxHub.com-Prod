Installer OpenClaw en 5 minutes : guide pour un premier lancement réussi

8 mars 2026·3 min read

La plupart des tutoriels perdent les gens à cette étape précise. L'objectif de celui-ci est simple : vous faire réussir du premier coup.

Ce que vous allez apprendre

  • Vérifier les prérequis avant l'installation
  • Installer OpenClaw
  • Terminer la configuration et créer votre premier assistant
  • Ouvrir le tableau de bord avec succès

Deux points à vérifier avant d'installer

Il ne faut pas grand-chose, mais ces deux points sont non négociables :

1. Node.js (version LTS)

2. Une clé API pour votre modèle IA

Pour utiliser des modèles cloud (Anthropic Claude, OpenAI, etc.), il vous faut une clé API. Pour rester entièrement hors ligne, vous pouvez utiliser un modèle local. Cette série suppose un modèle cloud par défaut.

💡 Vous ne savez pas comment obtenir une clé API ? Cherchez « Anthropic API key » (ou équivalent) : en général c'est réglé en quelques minutes.

Installer OpenClaw

La doc officielle recommande l'installation via Git, plus simple à mettre à jour et à déboguer ensuite.

macOS / Linux

Windows

⚠️ Bloqué sur « git introuvable » ou « openclaw non reconnu » ? Ajoutez Git au PATH système, redémarrez le terminal et réessayez.

Premier lancement : faites éclore votre assistant

Après l'installation, lancez :

Le premier lancement ouvre l'assistant de configuration, qui pose quelques questions simples :

  1. Quel modèle IA voulez-vous utiliser ?
  2. Quelle est votre clé API ?
  3. Où doit vivre l'espace de travail ?

Répondez et OpenClaw fera éclore votre premier assistant.

💡 Bloqué longtemps sur « wake up my friend » ? Vérifiez la clé API, la connexion Internet et les messages d'erreur affichés dans le terminal.

Que obtenez-vous après la configuration ?

  • Un token pour la connexion au tableau de bord
  • Un fichier de config de base dans ~/.openclaw/openclaw.json
  • Votre premier assistant IA, déjà en cours d'exécution

Ouvrir le tableau de bord

Avec la passerelle toujours en cours d'exécution, ouvrez votre navigateur :

http://127.0.0.1:18789/

Situations courantes

Ce que vous voyez Que faire
pairing required Exécutez openclaw devices list, puis openclaw devices approve <id>
Demande de token Collez le token obtenu lors de la configuration
Pas de réponse Vérifiez que openclaw gateway tourne toujours

Suite

Votre assistant est maintenant à la maison. Ensuite, nous rendrons le flux de connexion et l'interface du tableau de bord beaucoup moins mystérieux.
