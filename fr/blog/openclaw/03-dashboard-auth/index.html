Le tableau de bord vous bloque ? Comprendre l'authentification OpenClaw en 3 minutes

8 mars 2026·3 min read

« Token ? Appairage ? Je voulais juste ouvrir une page web. »

Cette réaction est tout à fait compréhensible. Cet article existe pour que vous cessiez d'avoir peur de l'écran de connexion.

Ce que vous allez apprendre

  • Comprendre la relation entre la Gateway et le tableau de bord
  • Identifier les trois situations d'authentification les plus courantes
  • Apprendre comment l'accès distant est configuré
  • Changer la langue de l'interface

Démarrer la Gateway en premier

Le tableau de bord n'est qu'une fenêtre. Le vrai travail se fait dans la Gateway. Sans elle, la page web n'est qu'une coquille vide.

Ne continuez qu'après avoir vu quelque chose comme « Gateway running ».

Ouvrir le tableau de bord

http://127.0.0.1:18789/

Si vous avez configuré un basePath comme /openclaw :

http://127.0.0.1:18789/openclaw

Authentification : que dois-je saisir ?

Cas 1 : Vous voyez pairing required

OpenClaw demande en substance : « Qui êtes-vous ? Je ne connais pas encore cet appareil. »

Actualisez le navigateur et vous devriez être connecté.

Cas 2 : Demande de token

L'assistant de configuration vous a donné un token plus tôt. C'est ici que vous le collez. Enregistrez-le dans Paramètres et vous n'aurez généralement plus à le coller plus tard.

💡 Les tokens sont stockés dans les paramètres de l'interface. Les mots de passe ne vivent qu'en mémoire et disparaissent à la fin de la session. C'est voulu pour la sécurité.

Cas 3 : Accès distant depuis un VPS ou le LAN

Si votre Gateway ne tourne pas en local mais sur un serveur distant :

  • Vous devez utiliser un token ou l'appairage d'appareil
  • Si vous voyez unauthorized, vérifiez d'abord gateway.bind et confirmez que le token a été saisi correctement

Changer de langue

L'interface de contrôle prend en charge plusieurs langues, dont l'anglais, le chinois traditionnel et le chinois simplifié.

Ouvrez la section Access, choisissez une langue, et le navigateur s'en souviendra la prochaine fois.

Suite

Une fois connecté, vous êtes dans la salle de contrôle principale d'OpenClaw. Ensuite, connectons Telegram pour appeler votre assistant depuis votre téléphone.
