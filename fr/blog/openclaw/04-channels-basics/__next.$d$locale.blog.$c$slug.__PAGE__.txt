3:T1a06,<p>Si votre assistant ne fonctionne que dans un navigateur, en quoi est-ce différent de discuter sur un site IA classique ?</p>
<p>Les <strong>canaux</strong> sont la réponse : ils permettent à votre assistant de vivre dans les applications que vous utilisez déjà au quotidien.</p>
<h2 id="ce-que-vous-allez-apprendre">Ce que vous allez apprendre</h2>
<ul>
<li>Comprendre ce qu'est un canal</li>
<li>Configurer un bot Telegram</li>
<li>Contrôler comment votre assistant parle dans les groupes</li>
<li>Voir ce que permettent plusieurs canaux</li>
</ul>
<hr>
<h2 id="quest-ce-quun-canal-">Qu'est-ce qu'un canal ?</h2>
<p>Imaginez un canal comme <strong>l'une des plusieurs portes</strong> vers le même assistant :</p>
<ul>
<li><strong>WebChat</strong> : la porte navigateur, déjà installée pour vous</li>
<li><strong>Bot Telegram</strong> : la porte téléphone</li>
<li><strong>WhatsApp</strong> : une autre porte</li>
<li><strong>Slack, Discord, iMessage...</strong> : encore d'autres portes</li>
</ul>
<p>Le même assistant peut avoir plusieurs portes ouvertes en même temps. Quelle que soit la porte utilisée, vous atteignez le même assistant.</p>
<hr>
<h2 id="webchat--prêt-à-lemploi-sans-configuration-supplémentaire">WebChat : prêt à l'emploi sans configuration supplémentaire</h2>
<p>Ouvrez le tableau de bord, onglet <strong>Chat</strong> à gauche, choisissez un agent et commencez à discuter. C'est le canal le plus simple et il ne nécessite aucune configuration supplémentaire.</p>
<p>Parfait aussi pour vérifier que votre assistant fonctionne avant de brancher d'autres applications.</p>
<hr>
<h2 id="configurer-un-bot-telegram">Configurer un bot Telegram</h2>
<h3 id="étape-1--créer-le-bot-avec-botfather">Étape 1 : Créer le bot avec BotFather</h3>
<ol>
<li>Ouvrez Telegram et cherchez <code>@BotFather</code></li>
<li>Envoyez <code>/newbot</code></li>
<li>Suivez les instructions pour le nom du bot</li>
<li>Copiez votre <strong>token de bot</strong>, par ex. <code>123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11</code></li>
</ol>
<h3 id="étape-2--configurer-channelstelegram-dans-openclaw">Étape 2 : Configurer <code>channels.telegram</code> dans OpenClaw</h3>
<p>Ouvrez le tableau de bord → Config → trouvez <code>channels.telegram</code> et remplissez par exemple :</p>

<h3 id="étape-3--tester">Étape 3 : Tester</h3>
<p>Cherchez votre bot sur Telegram et envoyez « hello ». Votre assistant devrait répondre.</p>
<blockquote>
<p>⚠️ Le premier message privé peut nécessiter un appairage. Suivez les instructions de la réponse du bot.</p>
</blockquote>

<h2 id="comment-configurer-les-groupes-">Comment configurer les groupes ?</h2>

<span data-line=""><span style="color:#9ECBFF">      "groups"</span><span style="color:#E1E4E8">: {</span></span>
<span data-line=""><span style="color:#9ECBFF">        "*"</span><span style="color:#E1E4E8">: { </span><span style="color:#9ECBFF">"requireMention"</span><span style="color:#E1E4E8">: </span><span style="color:#79B8FF">true</span><span style="color:#E1E4E8"> }</span></span>

<p>L'assistant ne parlera que lorsqu'on mentionne explicitement le bot.</p>
