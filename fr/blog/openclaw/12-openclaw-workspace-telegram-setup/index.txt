1b:T43af,<p>Vous avez déjà demandé à votre assistant « organise le journal d'aujourd'hui » et le voir toucher aux fichiers de votre projet pro ?</p>
<p>C'est ce qui se passe quand <strong>les espaces de travail ne sont pas bien configurés</strong>. Ce guide corrige ça en une fois.</p>
<h2 id="ce-que-vous-allez-apprendre">Ce que vous allez apprendre</h2>
<ul>
<li>Comprendre le flux complet : groupe → assistant → espace de travail</li>
<li>Initialiser plusieurs espaces de travail</li>
<li>Configurer Agents + Bindings de bout en bout</li>
<li>Vérifier que la configuration fonctionne vraiment</li>
</ul>
<hr>
<h2 id="lidée-densemble">L'idée d'ensemble</h2>
<p>L'architecture cible est simple :</p>
<pre><code>Groupe Telegram A  →  Assistant A  →  Espace A (touche uniquement ces fichiers)
Groupe Telegram B  →  Assistant B  →  Espace B (touche uniquement ces fichiers)
Messages directs   →  Assistant principal → Espace principal
</code></pre>
<p>Pour y arriver, trois étapes : <strong>créer les espaces → définir les agents → définir les bindings</strong>.</p>
<hr>
<h2 id="étape-1--créer-les-espaces-de-travail">Étape 1 : Créer les espaces de travail</h2>
<p>Chaque assistant a besoin de son propre répertoire. Initialisez-les avec :</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">openclaw</span><span style="color:#A5D6FF"> setup</span><span style="color:#79C0FF"> --workspace</span><span style="color:#A5D6FF"> "~/.openclaw/workspace-main"</span></span>
<span data-line=""><span style="color:#FFA657">openclaw</span><span style="color:#A5D6FF"> setup</span><span style="color:#79C0FF"> --workspace</span><span style="color:#A5D6FF"> "~/.openclaw/workspace-project-a"</span></span>
<span data-line=""><span style="color:#FFA657">openclaw</span><span style="color:#A5D6FF"> setup</span><span style="color:#79C0FF"> --workspace</span><span style="color:#A5D6FF"> "~/.openclaw/workspace-project-b"</span></span></code></pre></figure>
<p>Chaque espace reçoit automatiquement les fichiers nécessaires (AGENTS.md, SOUL.md, IDENTITY.md, etc.).</p>
<blockquote>
<p>💡 Si le répertoire n'existe pas encore, la commande le crée. Si vous avez cloné un espace existant depuis Git, vous pouvez sauter l'initialisation et pointer directement le chemin dans la Config.</p>
</blockquote>
<hr>

26:T43af,<p>Vous avez déjà demandé à votre assistant « organise le journal d'aujourd'hui » et le voir toucher aux fichiers de votre projet pro ?</p>
<p>C'est ce qui se passe quand <strong>les espaces de travail ne sont pas bien configurés</strong>. Ce guide corrige ça en une fois.</p>
<h2 id="ce-que-vous-allez-apprendre">Ce que vous allez apprendre</h2>
<ul>
<li>Comprendre le flux complet : groupe → assistant → espace de travail</li>
<li>Initialiser plusieurs espaces de travail</li>
<li>Configurer Agents + Bindings de bout en bout</li>
<li>Vérifier que la configuration fonctionne vraiment</li>
</ul>
<hr>
<h2 id="lidée-densemble">L'idée d'ensemble</h2>
<p>L'architecture cible est simple :</p>
<pre><code>Groupe Telegram A  →  Assistant A  →  Espace A (touche uniquement ces fichiers)
Groupe Telegram B  →  Assistant B  →  Espace B (touche uniquement ces fichiers)
Messages directs   →  Assistant principal → Espace principal
</code></pre>
<p>Pour y arriver, trois étapes : <strong>créer les espaces → définir les agents → définir les bindings</strong>.</p>
<hr>
<h2 id="étape-1--créer-les-espaces-de-travail">Étape 1 : Créer les espaces de travail</h2>
<p>Chaque assistant a besoin de son propre répertoire. Initialisez-les avec :</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">openclaw</span><span style="color:#A5D6FF"> setup</span><span style="color:#79C0FF"> --workspace</span><span style="color:#A5D6FF"> "~/.openclaw/workspace-main"</span></span>
<span data-line=""><span style="color:#FFA657">openclaw</span><span style="color:#A5D6FF"> setup</span><span style="color:#79C0FF"> --workspace</span><span style="color:#A5D6FF"> "~/.openclaw/workspace-project-a"</span></span>
<span data-line=""><span style="color:#FFA657">openclaw</span><span style="color:#A5D6FF"> setup</span><span style="color:#79C0FF"> --workspace</span><span style="color:#A5D6FF"> "~/.openclaw/workspace-project-b"</span></span></code></pre></figure>
<p>Chaque espace reçoit automatiquement les fichiers nécessaires (AGENTS.md, SOUL.md, IDENTITY.md, etc.).</p>
<blockquote>
<p>💡 Si le répertoire n'existe pas encore, la commande le crée. Si vous avez cloné un espace existant depuis Git, vous pouvez sauter l'initialisation et pointer directement le chemin dans la Config.</p>
</blockquote>
