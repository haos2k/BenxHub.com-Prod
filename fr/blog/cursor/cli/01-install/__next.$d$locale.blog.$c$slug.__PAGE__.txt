3:Td40,<p>L'installation est simple : exécutez le script officiel dans votre terminal et la commande <code>cursor</code> sera disponible. Les instructions varient selon la plateforme.</p>
<h2 id="macos--linux--wsl">macOS / Linux / WSL</h2>
<p>Exécutez ceci dans votre terminal :</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">curl</span><span style="color:#9ECBFF"> https://cursor.com/install</span><span style="color:#79B8FF"> -fsS</span><span style="color:#F97583"> |</span><span style="color:#B392F0"> bash</span></span></code></pre></figure>
<ul>
<li>Le script télécharge et installe automatiquement la commande <code>cursor</code></li>
<li>Après l'installation, <strong>fermez et rouvrez votre terminal</strong>, ou exécutez <code>source ~/.bashrc</code> / <code>source ~/.zshrc</code> pour mettre à jour votre PATH</li>
</ul>
<h2 id="windows-powershell">Windows (PowerShell)</h2>
<p>Ouvrez PowerShell <strong>en tant qu'administrateur</strong> et exécutez :</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="powershell" data-theme="github-dark"><code data-language="powershell" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#E1E4E8">irm </span><span style="color:#9ECBFF">'https://cursor.com/install?win32=true'</span><span style="color:#F97583"> |</span><span style="color:#E1E4E8"> iex</span></span></code></pre></figure>
<h2 id="vérifier-linstallation">Vérifier l'installation</h2>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#79B8FF"> --version</span></span></code></pre></figure>
<p>Si un numéro de version s'affiche, l'installation a réussi.</p>
<h2 id="premier-usage--connexion">Premier usage : connexion</h2>
<p>La première fois, il peut vous demander de vous connecter à votre compte Cursor :</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> auth</span><span style="color:#9ECBFF"> login</span></span></code></pre></figure>
<p>Suivez les instructions à l'écran pour terminer la connexion via le navigateur. Sur la même machine, vous n'aurez généralement pas besoin de vous reconnecter.</p>
<h2 id="résumé">Résumé</h2>
<ul>
<li><strong>macOS / Linux</strong> : <code>curl ... | bash</code></li>
<li><strong>Windows</strong> : exécutez <code>irm ... | iex</code> dans PowerShell</li>
<li><strong>Vérifier</strong> : <code>cursor --version</code></li>
<li><strong>Connexion</strong> : <code>cursor auth login</code></li>
</ul>
