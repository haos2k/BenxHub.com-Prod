#cursor#cli#agent

Utilisation de base de Cursor CLI

24 févr. 2026·2 min read

Approche la plus courante : cursor agent

Exécutez ceci dans le répertoire du projet :

  • Interactif : l'IA pose des questions et fait des suggestions ; vous pouvez accepter ou refuser les changements
  • Conscient du contexte : il lit les fichiers du répertoire courant pour ses réponses et modifications

Une seule commande vs conversation

Vous voulez déléguer une tâche directement : Mettez l'instruction entre guillemets et envoyez tout d'un coup.

Vous voulez discuter avant d'agir : Lancez cursor agent sans argument pour entrer en mode conversation, où vous décrivez vos besoins étape par étape et l'IA précise avant de modifier.

Spécifier le répertoire de travail

Par défaut il utilise le répertoire courant. Pour spécifier un chemin, ajoutez --path :

Référence rapide des commandes

Commande Description
cursor agent "do something" Demander à l'IA de le faire (peut modifier des fichiers)
cursor agent Entrer en mode conversation sans tâche
cursor ask "question" Poser une question uniquement, pas d'édition (lecture seule)
cursor --help Voir toutes les options disponibles

Résumé

  • Le plus courant : cursor agent "votre instruction"
  • Vous voulez d'abord discuter : lancez simplement cursor agent
  • Poser une question sans éditer : utilisez cursor ask "question"
  • Spécifier le répertoire : ajoutez --path <path>
