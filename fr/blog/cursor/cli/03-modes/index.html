Cursor CLI trois modes : Agent / Plan / Ask

24 févr. 2026·3 min read

Trois modes, une phrase pour les distinguer : qui peut toucher à votre code, et qui ne fait que parler. Une fois ça compris, choisir le bon mode est simple.

Comparaison en une phrase

Mode Une phrase Modifie-t-il vos fichiers ?
Agent « Fais » quelque chose pour moi ✅ Oui
Plan « Planifie » d'abord comment faire, puis je décide Pas encore — seulement après votre approbation
Ask Juste « pose » une question ou consulte ❌ Non

Imaginez trois collègues : Agent dit « donne-moi, je m'en occupe » ; Plan dit « je te rédige une proposition à valider d'abord » ; Ask dit « je ne fais que répondre, je ne touche pas aux fichiers » — choisissez la bonne personne et vous vous évitez la moitié des soucis.

Mode Agent (par défaut)

Cas d'usage : Faire éditer le code directement par l'IA, ajouter des fonctionnalités ou refactoriser. Vous voulez des résultats, pas une discussion.

  • Lit les fichiers, les modifie, peut exécuter des commandes
  • Vous acceptez ou refusez chaque étape — vous gardez le contrôle

Mode Plan

Cas d'usage : Pas sûr de comment aborder quelque chose, ou inquiet que l'IA modifie trop d'un coup ? Voyez le plan avant de donner le feu vert.

  • L'IA posera quelques questions et proposera une approche
  • Elle n'agit qu'après votre accord — pas de surprises

Quand l'utiliser : Pour des changements importants, ou quand vous voulez « voir clair avant de valider ».

Mode Ask (lecture seule)

Cas d'usage : Vous voulez juste demander « que fait ce code » ou « y a-t-il une meilleure façon d'écrire ça » — et vous ne voulez absolument pas que des fichiers soient modifiés.

  • Ne fait que lire, analyser et répondre — n'écrit jamais
  • Idéal pour la CI ou les environnements où vous ne voulez qu'inspecter, pas modifier

Changer de mode en plein dialogue

Déjà dans une conversation cursor agent ? Utilisez les commandes slash pour changer instantanément :

  • /plan → Passer en mode Plan (planifier d'abord, agir après)
  • /ask → Passer en mode Ask (lecture seule, posez vos questions)

Pas besoin de quitter et de relancer — comme changer de vitesse à la volée.

Résumé

  • Agent : fait le travail, modifie les fichiers — à utiliser quand vous voulez des résultats
  • Plan : planifie d'abord, n'agit qu'après votre approbation — à utiliser quand vous voulez de la sécurité
  • Ask : questions uniquement, lecture seule — à utiliser quand vous voulez des réponses sans modification
