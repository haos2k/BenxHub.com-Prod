3:T1918,<p><a href="05-tips">05-tips</a> a déjà évoqué <code>cursor agent --resume</code> pour reprendre la dernière conversation. Ce billet complète <strong>sessions</strong> et <strong>exécution cloud</strong> : comment lister les conversations passées, laquelle reprendre, et utiliser <strong><code>-c</code></strong> pour exécuter une tâche dans le cloud afin qu’elle continue après fermeture du terminal ou de l’appareil.</p>
<h2 id="reprise-de-session----resume">Reprise de session : --resume</h2>
<p>Vous avez fermé le terminal en plein dialogue ou la tâche était longue et vous l’avez arrêtée — la prochaine fois vous voulez reprendre au même fil :</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#79C0FF"> --resume</span></span></code></pre></figure>
<p>Cela charge la conversation <strong>la plus récente</strong> ; le contexte et les instructions précédentes sont toujours là, pas besoin de redécrire la demande.</p>
<h3 id="reprendre-une-conversation-précise">Reprendre une conversation précise</h3>
<p>Si vous avez plusieurs conversations et voulez reprendre <strong>une en particulier</strong> :</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#79C0FF"> --resume=chat-id-here</span></span></code></pre></figure>
<p>Récupérez le <code>chat-id</code> via « lister les conversations », ci-dessous.</p>
<h2 id="lister-toutes-les-conversations--cursor-agent-ls">Lister toutes les conversations : cursor agent ls</h2>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#A5D6FF"> ls</span></span></code></pre></figure>
<p>Liste les conversations passées (avec ID ou identifiant). Repérez celle que vous voulez et passez son ID à <code>--resume=ID</code>.</p>
<p>Référence rapide :</p>
<table>
<thead>
<tr>
<th>Commande</th>
<th>Usage</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>cursor agent ls</code></td>
<td>Lister toutes les conversations</td>
</tr>
<tr>
<td><code>cursor agent --resume</code></td>
<td>Reprendre la plus récente</td>
</tr>
<tr>
<td><code>cursor agent --resume=chat-id</code></td>
<td>Reprendre une conversation précise</td>
</tr>
</tbody>
</table>
<h2 id="exécution-cloud---c----cloud">Exécution cloud : -c / --cloud</h2>
<p>Certaines tâches sont lourdes : analyse du repo entier, génération de grosse doc, refactors en plusieurs étapes. Exécuter en local impose de garder le terminal ouvert ; fermer le portable ou perdre la connexion arrête l’exécution.</p>
<p>Avec <strong><code>-c</code></strong> (ou <strong><code>--cloud</code></strong>) vous confiez <strong>cette conversation</strong> à un Agent cloud :</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#A5D6FF"> "Analyze the whole project and write architecture doc to docs/architecture.md"</span><span style="color:#79C0FF"> -c</span></span></code></pre></figure>
<ul>
<li>Après l’envoi, la tâche s’exécute sur le cloud Cursor</li>
<li>Vous pouvez fermer le terminal, éteindre ou passer à autre chose</li>
<li>Plus tard, depuis n’importe quel appareil avec le même compte Cursor, utilisez <code>--resume</code> pour rejoindre cette conversation et voir le résultat ou ajouter des instructions</li>
</ul>
<p>Donc <strong><code>-c</code></strong> = « exécuter dans le cloud ; je n’ai pas besoin d’attendre devant l’ordinateur ».</p>
<h3 id="quand-utiliser--c-">Quand utiliser -c ?</h3>
<table>
<thead>
<tr>
<th>Situation</th>
<th>Suggestion</th>
</tr>
</thead>
<tbody>
<tr>
<td>La tâche va prendre longtemps</td>
<td>Utilisez <code>-c</code> pour qu’elle tourne dans le cloud ; elle peut finir après que vous ayez fermé</td>
</tr>
<tr>
<td>Question rapide ou petite modification</td>
<td>Passez <code>-c</code> ; exécutez en local</td>
</tr>
<tr>
<td>Réseau instable ou préférence de ne pas dépendre du cloud</td>
<td>Exécutez en local, mais gardez la connexion</td>
</tr>
</tbody>
</table>
<h2 id="sessions-et-cloud-ensemble">Sessions et cloud ensemble</h2>
<p>Flux typique :</p>
<ol>
<li>Démarrez une tâche avec <code>-c</code> pour qu’elle tourne dans le cloud</li>
<li>Fermez le terminal</li>
<li>Plus tard exécutez <code>cursor agent ls</code> pour retrouver cette conversation</li>
<li><code>cursor agent --resume=that-id</code> pour rejoindre, voir le résultat ou envoyer d’autres instructions</li>
</ol>
<p>Vous couvrez ainsi « tâches longues » et « plusieurs appareils / extinction ».</p>
<h2 id="résumé">Résumé</h2>
<ul>
<li><strong><code>cursor agent ls</code></strong> : Lister les conversations pour trouver celle à reprendre</li>
<li><strong><code>--resume</code></strong> : Reprendre la dernière ; <strong><code>--resume=ID</code></strong> : Reprendre une conversation précise</li>
<li><strong><code>-c</code> / <code>--cloud</code></strong> : Exécuter la tâche en cours dans le cloud ; vous pouvez fermer le terminal et reprendre plus tard avec <code>--resume</code></li>
</ul>
