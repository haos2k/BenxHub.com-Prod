Tutoriel Cursor CLI — Aperçu

24 févr. 2026·2 min read

Cursor CLI permet d'invoquer les capacités IA de Cursor directement depuis le terminal — sans ouvrir la fenêtre Cursor. Vous pouvez demander à l'IA d'écrire du code, modifier des fichiers ou répondre à des questions. Pour ceux qui vivent dans le terminal, c'est comme avoir un assistant disponible à tout moment.

Pourquoi apprendre la CLI ?

Scénario Avec la fenêtre Cursor Avec Cursor CLI
Modifier du code sur un serveur Nécessite SSH + config distante ou sync Exécuter les commandes directement dans le terminal
Scripts, automatisation CI Difficile à intégrer dans un pipeline Mode non interactif, une seule commande
Déjà en train de travailler dans le terminal Il faut passer à l'IDE et revenir Poser la question à l'IA dans la même fenêtre
Préférer un flux au clavier Clics souris inévitables Tout se fait en commandes

En bref : la CLI fait suivre votre flux de travail à l'IA, au lieu de vous forcer à vous adapter à l'IDE.

Prérequis

  • Cursor installé (ou au moins un compte Cursor pour vous connecter)
  • Un abonnement Cursor (la CLI nécessite un abonnement)
  • Maîtrise basique du terminal
