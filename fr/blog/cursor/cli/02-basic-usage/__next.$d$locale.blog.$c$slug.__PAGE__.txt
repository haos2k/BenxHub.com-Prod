3:Te07,<h2 id="approche-la-plus-courante--cursor-agent">Approche la plus courante : <code>cursor agent</code></h2>
<p>Exécutez ceci dans le répertoire du projet :</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "Add a README to this project"</span></span></code></pre></figure>
<ul>
<li><strong>Interactif</strong> : l'IA pose des questions et fait des suggestions ; vous pouvez accepter ou refuser les changements</li>
<li><strong>Conscient du contexte</strong> : il lit les fichiers du répertoire courant pour ses réponses et modifications</li>
</ul>
<h2 id="une-seule-commande-vs-conversation">Une seule commande vs conversation</h2>
<p><strong>Vous voulez déléguer une tâche directement :</strong> Mettez l'instruction entre guillemets et envoyez tout d'un coup.</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "Refactor the auth module to use JWT"</span></span></code></pre></figure>
<p><strong>Vous voulez discuter avant d'agir :</strong> Lancez <code>cursor agent</code> sans argument pour entrer en <strong>mode conversation</strong>, où vous décrivez vos besoins étape par étape et l'IA précise avant de modifier.</p>
<h2 id="spécifier-le-répertoire-de-travail">Spécifier le répertoire de travail</h2>
