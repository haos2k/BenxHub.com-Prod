Gestion des sessions et exécution cloud Cursor CLI

9 mars 2026·3 min read

05-tips a déjà évoqué cursor agent --resume pour reprendre la dernière conversation. Ce billet complète sessions et exécution cloud : comment lister les conversations passées, laquelle reprendre, et utiliser -c pour exécuter une tâche dans le cloud afin qu’elle continue après fermeture du terminal ou de l’appareil.

Reprise de session : --resume

Vous avez fermé le terminal en plein dialogue ou la tâche était longue et vous l’avez arrêtée — la prochaine fois vous voulez reprendre au même fil :

Cela charge la conversation la plus récente ; le contexte et les instructions précédentes sont toujours là, pas besoin de redécrire la demande.

Reprendre une conversation précise

Si vous avez plusieurs conversations et voulez reprendre une en particulier :

Récupérez le chat-id via « lister les conversations », ci-dessous.

Lister toutes les conversations : cursor agent ls

Liste les conversations passées (avec ID ou identifiant). Repérez celle que vous voulez et passez son ID à --resume=ID.

Référence rapide :

Commande Usage
cursor agent ls Lister toutes les conversations
cursor agent --resume Reprendre la plus récente
cursor agent --resume=chat-id Reprendre une conversation précise

Exécution cloud : -c / --cloud

Certaines tâches sont lourdes : analyse du repo entier, génération de grosse doc, refactors en plusieurs étapes. Exécuter en local impose de garder le terminal ouvert ; fermer le portable ou perdre la connexion arrête l’exécution.

Avec -c (ou --cloud) vous confiez cette conversation à un Agent cloud :

  • Après l’envoi, la tâche s’exécute sur le cloud Cursor
  • Vous pouvez fermer le terminal, éteindre ou passer à autre chose
  • Plus tard, depuis n’importe quel appareil avec le même compte Cursor, utilisez --resume pour rejoindre cette conversation et voir le résultat ou ajouter des instructions

Donc -c = « exécuter dans le cloud ; je n’ai pas besoin d’attendre devant l’ordinateur ».

Quand utiliser -c ?

Situation Suggestion
La tâche va prendre longtemps Utilisez -c pour qu’elle tourne dans le cloud ; elle peut finir après que vous ayez fermé
Question rapide ou petite modification Passez -c ; exécutez en local
Réseau instable ou préférence de ne pas dépendre du cloud Exécutez en local, mais gardez la connexion

Sessions et cloud ensemble

Flux typique :

  1. Démarrez une tâche avec -c pour qu’elle tourne dans le cloud
  2. Fermez le terminal
  3. Plus tard exécutez cursor agent ls pour retrouver cette conversation
  4. cursor agent --resume=that-id pour rejoindre, voir le résultat ou envoyer d’autres instructions

Vous couvrez ainsi « tâches longues » et « plusieurs appareils / extinction ».

Résumé

  • cursor agent ls : Lister les conversations pour trouver celle à reprendre
  • --resume : Reprendre la dernière ; --resume=ID : Reprendre une conversation précise
  • -c / --cloud : Exécuter la tâche en cours dans le cloud ; vous pouvez fermer le terminal et reprendre plus tard avec --resume
