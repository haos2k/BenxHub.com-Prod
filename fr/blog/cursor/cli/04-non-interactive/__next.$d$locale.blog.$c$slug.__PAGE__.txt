3:T12b3,<p><strong>Mode interactif</strong> : l'IA pose des questions, vous appuyez sur O/N et confirmez étape par étape — comme en pair programming.
<strong>Mode non interactif</strong> : vous donnez une instruction, elle s'exécute jusqu'au bout, <strong>personne n'a besoin d'appuyer sur des touches</strong>. Idéal pour les scripts ou les pipelines CI — laissez l'IA travailler pendant que vous faites autre chose.</p>
<h2 id="utilisation-de-base">Utilisation de base</h2>
<p>Ajoutez <code>--no-interactive</code> (ou le raccourci <code>-n</code>) :</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "Add a .editorconfig to the project"</span><span style="color:#79B8FF"> --no-interactive</span></span></code></pre></figure>
<ul>
<li>L'IA s'exécute directement sans s'arrêter pour demander une entrée</li>
<li>Idéal pour : tâches prévisibles et répétables (ajouter des commentaires, corriger le lint, reformater selon les standards, etc.)</li>
</ul>
<h2 id="utilisation-dans-un-script">Utilisation dans un script</h2>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D">#!/bin/bash</span></span>
<span data-line=""><span style="color:#79B8FF">cd</span><span style="color:#9ECBFF"> /path/to/project</span></span>
<span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "Run the linter and fix issues per CONTRIBUTING.md"</span><span style="color:#79B8FF"> --no-interactive</span></span></code></pre></figure>
<ul>
<li>Convient pour le nettoyage automatique du code, les refactors simples, l'ajout de commentaires</li>
<li>Rappel : l'environnement CI doit pouvoir s'authentifier sur Cursor (exécutez <code>cursor auth login</code> avant ou utilisez un token) — sinon l'IA ne pourra rien faire</li>
</ul>
<h2 id="spécifier-un-modèle-optionnel">Spécifier un modèle (optionnel)</h2>
<p>Pour utiliser un modèle précis pour l'exécution :</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "Rewrite this comment"</span><span style="color:#79B8FF"> --model</span><span style="color:#9ECBFF"> claude-3-5-sonnet</span><span style="color:#79B8FF"> --no-interactive</span></span></code></pre></figure>
<p>Consultez la doc officielle pour les noms de modèles disponibles — n'inventez pas d'IDs de modèle.</p>
<h2 id="exécution-dans-le-cloud--c">Exécution dans le cloud (-c)</h2>
<p>Tâche lourde et vous ne voulez pas bloquer le terminal ? Utilisez <code>-c</code> pour la déléguer au cloud :</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "Analyze the entire repo and generate an architecture document"</span><span style="color:#79B8FF"> -c</span></span></code></pre></figure>
<ul>
<li><code>-c</code> confie la conversation à un Agent cloud pour la suite</li>
<li>Vous pouvez fermer le terminal — vous pourrez vous reconnecter à la conversation plus tard. Pensez-y comme une « exécution en arrière-plan », mais c'est l'IA qui travaille pour vous en arrière-plan.</li>
</ul>
<h2 id="résumé">Résumé</h2>
<ul>
<li><strong>Non interactif</strong> : ajoutez <code>--no-interactive</code> ou <code>-n</code>, personne n'a besoin d'appuyer sur des touches</li>
<li><strong>Scripts/CI</strong> : même commande — assurez-vous que l'environnement peut se connecter à Cursor</li>
<li><strong>Spécifier un modèle</strong> : <code>--model model-name</code></li>
<li><strong>Tâches longues</strong> : utilisez <code>-c</code> pour déléguer au cloud, ça fonctionne même si vous éteignez</li>
</ul>
