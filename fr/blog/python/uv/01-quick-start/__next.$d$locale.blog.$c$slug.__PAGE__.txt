3:T15e8,<p>Ce guide emprunte le chemin le plus court pour vous donner <strong>un projet Python fonctionnel</strong> — votre premier environnement utilisable avec uv. Comme adopter un premier petit loutre : assurez-vous qu'il puisse manger et dormir d'abord ; les techniques avancées de câlin viendront plus tard.</p>
<h2 id="prérequis">Prérequis</h2>
<ul>
<li>uv installé (voir la commande d'installation dans la <a href="00-overview">Vue d'ensemble</a>)</li>
<li>Le terminal peut exécuter la commande <code>uv</code></li>
</ul>
<h2 id="exemple-minimal--créer-votre-premier-projet">Exemple minimal : créer votre premier projet</h2>
<h3 id="étape-1--vérifier-que-uv-est-installé">Étape 1 : Vérifier que uv est installé</h3>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">uv</span><span style="color:#79B8FF"> --version</span></span></code></pre></figure>
<p>Si un numéro de version s'affiche, c'est bon. Sinon, relancez le script d'installation et redémarrez le terminal.</p>
<h3 id="étape-2--initialiser-le-projet">Étape 2 : Initialiser le projet</h3>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">uv</span><span style="color:#9ECBFF"> init</span><span style="color:#9ECBFF"> my-app</span></span>
<span data-line=""><span style="color:#79B8FF">cd</span><span style="color:#9ECBFF"> my-app</span></span></code></pre></figure>
<p>uv crée automatiquement <code>pyproject.toml</code>, <code>.python-version</code>, <code>main.py</code> et <code>README.md</code>. La structure ressemble à ceci :</p>
<pre><code>my-app/
├── .gitignore
├── .python-version
├── README.md
├── main.py
└── pyproject.toml
</code></pre>
<h3 id="étape-3--exécuter-le-programme-par-défaut">Étape 3 : Exécuter le programme par défaut</h3>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">uv</span><span style="color:#9ECBFF"> run</span><span style="color:#9ECBFF"> main.py</span></span></code></pre></figure>
<p>Vous verrez <code>Hello from my-app!</code> — félicitations, votre premier projet est vivant.</p>
<h3 id="étape-4--ajouter-une-dépendance-et-exécuter">Étape 4 : Ajouter une dépendance et exécuter</h3>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">uv</span><span style="color:#9ECBFF"> add</span><span style="color:#9ECBFF"> requests</span></span></code></pre></figure>
<p>Puis modifiez <code>main.py</code> pour l'essayer :</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="python" data-theme="github-dark"><code data-language="python" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#F97583">import</span><span style="color:#E1E4E8"> requests</span></span>
<span data-line=""><span style="color:#E1E4E8">r </span><span style="color:#F97583">=</span><span style="color:#E1E4E8"> requests.get(</span><span style="color:#9ECBFF">"https://httpbin.org/get"</span><span style="color:#E1E4E8">)</span></span>
<span data-line=""><span style="color:#79B8FF">print</span><span style="color:#E1E4E8">(r.status_code)</span></span></code></pre></figure>
<p>Exécutez :</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">uv</span><span style="color:#9ECBFF"> run</span><span style="color:#9ECBFF"> main.py</span></span></code></pre></figure>
<p>Si vous voyez <code>200</code>, la dépendance a bien été installée dans l'environnement virtuel — pas de <code>pip install</code> manuel, pas de <code>source .venv/bin/activate</code>. Cette sensation de fluidité, c'est le bonheur de uv.</p>
