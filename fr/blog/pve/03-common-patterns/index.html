Proxmox VE Modèles courants : sauvegarde, clone et migration

24 févr. 2026·3 min read

Cet article se concentre sur les cinq opérations quotidiennes les plus courantes, avec des modèles pratiques utilisables tout de suite. Maîtrisez ces modèles et vous gérerez 80 % des scénarios — les 20 % restants sont pour la section avancée.

Modèle 1 : Sauvegarder une machine virtuelle

Objectif : conserver une sauvegarde périodique permettant une restauration — ainsi si ça casse, vous ne repartez pas de zéro.

Planifiez-la dans : Datacenter -> Sauvegarde -> Ajouter, définissez une heure (ex. 02:00 quotidien). Configurez et oubliez.

Le mode snapshot permet de sauvegarder pendant que la VM tourne — comme photographier un chat qui dort sans le réveiller.

Modèle 2 : Cloner une machine virtuelle

Objectif : copier rapidement un environnement existant sans réinstaller from scratch.

Différence en une phrase : full = indépendant, prend de l'espace ; linked = économise l'espace, mais dépend du disque parent. Ne supprimez pas le disque parent — les clones liés casseront avec lui.

Modèle 3 : Migration à chaud

Objectif : déplacer une VM vers un autre nœud sans l'arrêter — pas d'interruption de service.

Prérequis : le nœud cible doit pouvoir accéder au même disque (stockage partagé idéal).

Si le disque est sur local, il faut généralement migrer le disque d'abord ou passer au stockage partagé — sinon migrate vous dira « je ne trouve pas le disque ».

Modèle 4 : Créer un conteneur LXC

Objectif : lancer rapidement un environnement Linux léger pour faire tourner un service — utilise moins de ressources qu'une VM.

LXC démarre vite et consomme peu — idéal pour faire tourner beaucoup de petits services. Comme une portée de loutres, chacune avec très peu de surcoût.

Modèle 5 : Snapshots et retour arrière

Objectif : avant une mise à jour majeure ou un changement de configuration, laisser un point de restauration auquel « revenir ».

Prenez l'habitude de faire un snapshot avant les opérations majeures : snapshot d'abord, puis agir. Le temps de débogage économisé pourra être consacré à mieux.
