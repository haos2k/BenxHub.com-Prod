3:T11d1,<p>Ce guide emprunte le chemin le plus court pour vous donner <strong>une machine virtuelle Debian bootable</strong> — votre premier environnement fonctionnel sous PVE. Comme adopter un premier animal : assurez-vous d'abord qu'il peut manger et dormir ; les techniques avancées viendront plus tard.</p>
<h2 id="prérequis">Prérequis</h2>
<ul>
<li>CPU 64 bits avec <strong>Intel VT-x</strong> ou <strong>AMD-V</strong> activé (sans cela, les VM refuseront de démarrer)</li>
<li>Minimum 2 Go de RAM (8 Go+ recommandé — sinon ça ressemblera à un PC de 2010)</li>
<li>Au moins une carte réseau fonctionnelle</li>
<li>Un hôte ou serveur pouvant démarrer depuis une clé USB</li>
</ul>
<h2 id="exemple-minimal--créer-votre-première-machine-virtuelle">Exemple minimal : créer votre première machine virtuelle</h2>
<h3 id="étape-1--connexion-à-linterface-web">Étape 1 : Connexion à l'interface web</h3>
<p>Après l'installation, ouvrez <code>https://&#x3C;IP-PVE>:8006</code> et connectez-vous avec <code>root</code> et le mot de passe défini lors de l'installation. Votre navigateur peut avertir sur le certificat — il est auto-signé, cliquez sur « Avancé » → « Continuer quand même ». La vie en homelab.</p>
<h3 id="étape-2--télécharger-limage-système">Étape 2 : Télécharger l'image système</h3>
<ol>
<li>Sélectionnez le stockage <code>local</code> sous votre nœud dans le panneau de gauche</li>
<li>Allez dans <code>Contenu</code>, cliquez sur <code>Télécharger depuis une URL</code></li>
<li>Saisissez :
<ul>
<li>URL : <code>https://cloud.debian.org/images/cloud/bookworm/latest/debian-12-generic-amd64.qcow2</code></li>
<li>Nom du fichier : <code>debian-12-cloud.qcow2</code></li>
</ul>
</li>
<li>Cliquez sur <code>Interroger l'URL</code> puis lancez le téléchargement (allez prendre un café)</li>
</ol>
<h3 id="étape-3--créer-la-machine-virtuelle">Étape 3 : Créer la machine virtuelle</h3>
<ol>
<li>Cliquez sur <code>Créer une VM</code> en haut à droite</li>
<li><code>Général</code> : définissez le nom sur <code>test-vm</code> (ou ce que vous voulez)</li>
<li><code>OS</code> : pour une image cloud vous pouvez ignorer la configuration du disque</li>
<li><code>Disques</code> : sélectionnez <strong>Utiliser une image disque existante</strong>, choisissez le <code>debian-12-cloud.qcow2</code> que vous venez de télécharger</li>
<li><code>CPU</code> : 1 vCPU suffit pour commencer</li>
<li><code>Mémoire</code> : 512–1024 Mo pour tester</li>
<li><code>Réseau</code> : le <code>vmbr0</code> par défaut convient</li>
<li><code>Confirmer</code> → <code>Terminer</code></li>
</ol>
<h3 id="étape-4--démarrer-et-vérifier">Étape 4 : Démarrer et vérifier</h3>
<ol>
<li>Clic droit sur la VM → <code>Démarrer</code></li>
<li>Ouvrez la <code>Console</code> (noVNC)</li>
<li>Si vous voyez l'écran de démarrage Debian ou l'invite de connexion, c'est réussi — félicitations, votre première VM est en ligne.</li>
</ol>
