Proxmox VE Démarrage rapide : créer votre première VM

24 févr. 2026·3 min read

Ce guide emprunte le chemin le plus court pour vous donner une machine virtuelle Debian bootable — votre premier environnement fonctionnel sous PVE. Comme adopter un premier animal : assurez-vous d'abord qu'il peut manger et dormir ; les techniques avancées viendront plus tard.

Prérequis

  • CPU 64 bits avec Intel VT-x ou AMD-V activé (sans cela, les VM refuseront de démarrer)
  • Minimum 2 Go de RAM (8 Go+ recommandé — sinon ça ressemblera à un PC de 2010)
  • Au moins une carte réseau fonctionnelle
  • Un hôte ou serveur pouvant démarrer depuis une clé USB

Exemple minimal : créer votre première machine virtuelle

Étape 1 : Connexion à l'interface web

Après l'installation, ouvrez https://<IP-PVE>:8006 et connectez-vous avec root et le mot de passe défini lors de l'installation. Votre navigateur peut avertir sur le certificat — il est auto-signé, cliquez sur « Avancé » → « Continuer quand même ». La vie en homelab.

Étape 2 : Télécharger l'image système

  1. Sélectionnez le stockage local sous votre nœud dans le panneau de gauche
  2. Allez dans Contenu, cliquez sur Télécharger depuis une URL
  3. Saisissez :
    • URL : https://cloud.debian.org/images/cloud/bookworm/latest/debian-12-generic-amd64.qcow2
    • Nom du fichier : debian-12-cloud.qcow2
  4. Cliquez sur Interroger l'URL puis lancez le téléchargement (allez prendre un café)

Étape 3 : Créer la machine virtuelle

  1. Cliquez sur Créer une VM en haut à droite
  2. Général : définissez le nom sur test-vm (ou ce que vous voulez)
  3. OS : pour une image cloud vous pouvez ignorer la configuration du disque
  4. Disques : sélectionnez Utiliser une image disque existante, choisissez le debian-12-cloud.qcow2 que vous venez de télécharger
  5. CPU : 1 vCPU suffit pour commencer
  6. Mémoire : 512–1024 Mo pour tester
  7. Réseau : le vmbr0 par défaut convient
  8. Confirmer → Terminer

Étape 4 : Démarrer et vérifier

  1. Clic droit sur la VM → Démarrer
  2. Ouvrez la Console (noVNC)
  3. Si vous voyez l'écran de démarrage Debian ou l'invite de connexion, c'est réussi — félicitations, votre première VM est en ligne.

Dépannage courant

Symptôme À vérifier
Impossible d'accéder à l'interface web Vérifiez que le port 8006 est accessible, confirmez que pveproxy tourne
La VM ne démarre pas VT-x / AMD-V est-il activé dans le BIOS ? Sans cela, les VM ne démarreront tout simplement pas
Fichier image introuvable Retournez dans local -> Contenu — vérifiez que le téléchargement est terminé
La VM n'a pas de réseau Vérifiez que vmbr0 est bien lié à une NIC physique
