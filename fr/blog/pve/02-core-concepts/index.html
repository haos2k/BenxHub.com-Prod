Proxmox VE Concepts fondamentaux : VM, LXC, stockage et réseau

24 févr. 2026·3 min read

Avant de cliquer au hasard, intégrez ces quatre concepts : vous verrez plus clair sur « dois-je utiliser une VM ou un LXC, où mettre le disque, comment connecter le réseau ». Comme lire les descriptions des compétences avant de jouer — sinon vous continuerez à mourir.

Concept 1 : La différence entre VM et LXC

Type Technologie Caractéristiques
VM KVM/QEMU OS complet, forte isolation, exécute Windows et Linux
LXC Linux Containers Léger, démarrage rapide, forte densité, mais Linux uniquement

Décision en une phrase : besoin d'isolation complète ou d'exécuter Windows → VM ; vouloir économiser les ressources et le service est sous Linux → LXC. Choisir à tort, c'est comme partir en randonnée en tongs — pas impossible, mais vous allez souffrir.

Concept 2 : Votre choix de stockage détermine jusqu'où vous irez

Choisir mal le stockage et vous vous heurterez à des murs avec la HA et la migration plus tard. Types courants :

  • local : stockage répertoire mono-nœud, adapté aux débutants
  • local-lvm : LVM local, bon pour les snapshots et clones
  • NFS/CIFS : stockage réseau partagé, capable de traverser les nœuds
  • ZFS/Ceph : solutions avancées pour la réplication et la haute disponibilité

Pour la migration à chaud ou la HA, les disques doivent généralement être sur un stockage partagé — sinon la VM ne peut pas être déplacée. Comme déménager alors que les meubles sont encore enfermés chez quelqu'un d'autre.

Concept 3 : Le modèle réseau (vmbr0)

PVE utilise le réseau en pont par défaut : vmbr0 fait le pont vers une NIC physique, les VM semblent directement connectées au switch physique. En bref : un câble virtuel, tout le monde partage la NIC sortante.

Concept 4 : Nœuds et cluster

  • Nœud unique : une machine gère tout, bien pour démarrer et les homelabs
  • Cluster : plusieurs hôtes gérés ensemble, supporte la migration et la HA — comme former une équipe pour un donjon

En une phrase : plan de gestion unifié, ressources planifiables, la défaillance peut être reprise. Comprendre ce concept d'abord rend la section avancée bien plus facile à suivre.
