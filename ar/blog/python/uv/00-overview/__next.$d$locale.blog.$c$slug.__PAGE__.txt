3:T1203,<p>uv هو <strong>أداة سريعة البرق لإدارة حزم Python والمشاريع</strong> مبنية بـ Rust من Astral. تدمج تثبيت التبعيات والبيئات الافتراضية وإدارة إصدارات Python وتنفيذ أدوات CLI في ثنائي واحد. باختصار: <strong>pip + virtualenv + pyenv + pipx مجتمعة ومُعزَّزة — وبسرعة تجعلك تشكك في الواقع.</strong></p>
<p>مقارنةً بـ pip وpoetry وpipenv، مزايا uv هي <strong>سرعة 10–100 مرة</strong>، الحد الأدنى من استخدام القرص، وأداة واحدة لسير العمل بأكمله. مناسب بشكل خاص للتطوير اليومي وCI/CD وتنفيذ السكريبتات — لا مزيد من التبديل بين أدوات متعددة.</p>
<h2 id="حالات-الاستخدام">حالات الاستخدام</h2>
<ul>
<li><strong>بدء مشروع جديد من الصفر</strong>: <code>uv init</code> يُنشئه فوراً، التبعيات تثبّت فوراً — لا مزيد من مشاهدة دوّامة pip</li>
<li><strong>الترحيل من requirements.txt موجود</strong>: <code>uv pip compile</code> يأخذه مباشرةً، ترقية بدون ألم</li>
<li><strong>تبعيات السكريبت المؤقتة</strong>: <code>uv run --with rich script.py</code> — لا حاجة لإعداد venv</li>
<li><strong>تشغيل أدوات CLI</strong>: <code>uvx ruff</code> عند الطلب، مثل pipx لكن أضعاف أسرع</li>
<li><strong>غير موصى به</strong>: المشاريع القديمة التي لا تزال على Python 2 — فكّر في ترحيلها أولاً، لا تطلب من uv السفر عبر الزمن</li>
</ul>
