البداية السريعة مع Proxmox VE: إنشاء أول آلة افتراضية

24 2月 2026·2 min read

يسلك هذا الدليل أقصر طريق للحصول على آلة افتراضية Debian قابلة للإقلاع — أول بيئة عاملة في PVE.

المتطلبات الأساسية

  • وحدة معالجة مركزية 64-بت مع Intel VT-x أو AMD-V مفعّل (بدون هذا، الآلات الافتراضية سترفض البدء)
  • 2 GB RAM كحد أدنى (8 GB+ موصى به — وإلا سيشعر مثل حاسوب 2010)
  • بطاقة شبكة عاملة واحدة على الأقل
  • مضيف أو خادم يمكنه الإقلاع من USB

مثال بسيط: إنشاء أول آلة افتراضية

الخطوة 1: تسجيل الدخول إلى واجهة الويب

بعد التثبيت، افتح https://<PVE-IP>:8006 وسجّل الدخول بـ root وكلمة المرور التي ضبطتها أثناء التثبيت. قد يُحذّرك المتصفح بشأن الشهادة — إنها موقّعة ذاتياً، لذا انقر "متقدم" → "المتابعة على أي حال."

الخطوة 2: تنزيل صورة النظام

  1. اختر تخزين local تحت عقدتك في اللوحة اليسرى
  2. اذهب إلى Content، انقر Download from URL
  3. أدخل:
    • URL: https://cloud.debian.org/images/cloud/bookworm/latest/debian-12-generic-amd64.qcow2
    • File Name: debian-12-cloud.qcow2
  4. انقر Query URL ثم ابدأ التنزيل (اذهب واصنع قهوة)

الخطوة 3: إنشاء الآلة الافتراضية

  1. انقر Create VM في الزاوية العلوية اليمنى
  2. General: اضبط الاسم على test-vm (أو أي اسم تريد)
  3. OS: لصورة سحابية يمكنك تخطي إعداد القرص
  4. Disks: اختر Use existing disk image، اختر debian-12-cloud.qcow2 التي نزّلتها للتو
  5. CPU: 1 vCPU كافٍ للبداية
  6. Memory: 512–1024 MB لاختبار المياه
  7. Network: افتراضي vmbr0 جيد
  8. Confirm → Finish

الخطوة 4: التشغيل والتحقق

  1. انقر بالزر الأيمن على الـ VM → Start
  2. افتح Console (noVNC)
  3. إذا رأيت شاشة إقلاع Debian أو موجّه تسجيل الدخول، نجحت — تهانينا، أول آلة افتراضية لك حية.

استكشاف الأخطاء الشائعة

العَرَض ما يجب التحقق منه
لا يمكن الوصول إلى واجهة الويب تحقق ما إذا كان المنفذ 8006 وصولي، تأكد أن pveproxy يعمل
الـ VM لا يبدأ هل VT-x / AMD-V مفعّل في BIOS؟ بدونه، الآلات الافتراضية ببساطة لن تبدأ
لا يمكن إيجاد ملف الصورة ارجع إلى local -> Content — تحقق ما إذا اكتمل التنزيل
الـ VM ليس له شبكة تحقق أن vmbr0 مرتبط بشكل صحيح ببطاقة شبكة مادية
