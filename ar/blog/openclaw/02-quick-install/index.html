شيئان للتحقق منهما قبل التثبيت

لا تحتاج الكثير، لكن هذين الأمرين لا خيار فيهما:

1. Node.js (الإصدار LTS)

2. مفتاح API لنموذج الذكاء الاصطناعي

إذا أردت استخدام نماذج سحابية مثل Anthropic Claude أو OpenAI، تحتاج مفتاح API. إذا أردت البقاء بالكامل دون اتصال، يمكنك استخدام نموذج محلي. تفترض هذه السلسلة استخدام نموذج سحابي بشكل افتراضي.

💡 لست متأكداً من كيفية الحصول على مفتاح API؟ ابحث عن "Anthropic API key" وستتمكن من إنجازه في دقائق قليلة.

التشغيل الأول: احتضان مساعدك

بعد التثبيت، شغّل:

التشغيل الأول يفتح معالج الإعداد، الذي يطرح أسئلة بسيطة:

  1. أي نموذج ذكاء اصطناعي تريد استخدامه؟
  2. ما هو مفتاح API الخاص بك؟
  3. أين يجب أن تعيش مساحة العمل؟

أجب عليها وسيقوم OpenClaw بإنشاء أول مساعد لك.

💡 عالق لفترة طويلة عند "wake up my friend"؟ تحقق من مفتاح API واتصالك بالإنترنت وأي رسائل خطأ تظهر في المحطة.

ماذا تحصل بعد الإعداد؟

  • رمز لتسجيل الدخول إلى لوحة التحكم
  • ملف إعداد أساسي في ~/.openclaw/openclaw.json
  • أول مساعد ذكي لك، يعمل بالفعل

فتح لوحة التحكم

مع استمرار تشغيل Gateway، افتح متصفحك:

http://127.0.0.1:18789/

المواقف الشائعة

ما تراه ما تفعله
pairing required شغّل openclaw devices list، ثم openclaw devices approve <id>
طلب رمز الصق الرمز من الإعداد
لا استجابة تأكد من أن openclaw gateway لا يزال يعمل

الخطوة التالية
