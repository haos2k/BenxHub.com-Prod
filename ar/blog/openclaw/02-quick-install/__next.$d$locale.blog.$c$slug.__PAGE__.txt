<h2 id="شيئان-للتحقق-منهما-قبل-التثبيت">شيئان للتحقق منهما قبل التثبيت</h2>
<p>لا تحتاج الكثير، لكن هذين الأمرين لا خيار فيهما:</p>
<p><strong>1. Node.js (الإصدار LTS)</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">node</span><span style="color:#79C0FF"> --version</span></span>
<span data-line=""><span style="color:#8B949E"># إذا رأيت رقم إصدار، فأنت جاهز</span></span></code></pre></figure>
<p><strong>2. مفتاح API لنموذج الذكاء الاصطناعي</strong></p>
<p>إذا أردت استخدام نماذج سحابية مثل Anthropic Claude أو OpenAI، تحتاج مفتاح API. إذا أردت البقاء بالكامل دون اتصال، يمكنك استخدام نموذج محلي. تفترض هذه السلسلة استخدام نموذج سحابي بشكل افتراضي.</p>
<blockquote>
<p>💡 لست متأكداً من كيفية الحصول على مفتاح API؟ ابحث عن "Anthropic API key" وستتمكن من إنجازه في دقائق قليلة.</p>
</blockquote>

<h2 id="تثبيت-openclaw">تثبيت OpenClaw</h2>
<p>تنصح الوثائق الرسمية بـ <strong>طريقة التثبيت المبنية على git</strong>، لأنها أسهل في التحديث والتصحيح لاحقاً.</p>
<p><strong>macOS / Linux</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># اتبع أوامر Quick Start من docs.openclaw.ai</span></span>
<span data-line=""><span style="color:#8B949E"># في معظم الحالات هذا سكريبت curl بسطر واحد</span></span></code></pre></figure>
<p><strong>Windows</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># تأكد أولاً من تثبيت Git وإضافته إلى PATH</span></span>
<span data-line=""><span style="color:#FFA657">git</span><span style="color:#79C0FF"> --version</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># ثم اتبع دليل تثبيت Windows على docs.openclaw.ai</span></span></code></pre></figure>
<blockquote>
<p>⚠️ عالق في "git not found" أو "openclaw is not recognized"؟ أضف Git إلى PATH الخاص بالنظام، ثم أعد تشغيل المحطة الطرفية وحاول مجدداً.</p>
</blockquote>
<hr>
<h2 id="التشغيل-الأول-احتضان-مساعدك">التشغيل الأول: احتضان مساعدك</h2>
<p>بعد التثبيت، شغّل:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">openclaw</span><span style="color:#A5D6FF"> gateway</span></span></code></pre></figure>
<p><strong>التشغيل الأول يفتح معالج الإعداد</strong>، الذي يطرح أسئلة بسيطة:</p>
<ol>
<li>أي نموذج ذكاء اصطناعي تريد استخدامه؟</li>
<li>ما هو مفتاح API الخاص بك؟</li>
<li>أين يجب أن تعيش مساحة العمل؟</li>
</ol>
<p>أجب عليها وسيقوم OpenClaw بإنشاء أول مساعد لك.</p>
<blockquote>
<p>💡 عالق لفترة طويلة عند "wake up my friend"؟ تحقق من مفتاح API واتصالك بالإنترنت وأي رسائل خطأ تظهر في المحطة.</p>
</blockquote>
<hr>
<h2 id="ماذا-تحصل-بعد-الإعداد">ماذا تحصل بعد الإعداد؟</h2>

<li>ملف إعداد أساسي في <code>~/.openclaw/openclaw.json</code></li>
<li>أول مساعد ذكي لك، يعمل بالفعل</li>
</ul>
