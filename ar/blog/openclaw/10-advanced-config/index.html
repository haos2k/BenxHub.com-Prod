النظام يتصرف بشكل غريب؟ دليل الإعدادات المتقدمة والتصحيح

8 3月 2026·3 min read

إذا وصلت حتى هنا، فقد بنيت OpenClaw من الصفر حتى العمل. عمل رائع.

هذه المقالة الأخيرة تجمع العادات التي تجعل إعدادك أكثر استقراراً وأسهل في الصيانة.

ما الذي ستتعلمه

  • إيجاد ملف الإعداد وفهم طريقتَي التعديل
  • التعرف على بنية إعداد عمل بسيط
  • تخزين مفاتيح API بأمان مع متغيرات البيئة
  • استخدام أمر التصحيح الأكثر فائدة وقراءة رسائل الخطأ الشائعة
  • اختيار مسار الإصدار المناسب

أين يوجد ملف الإعداد؟

~/.openclaw/openclaw.json

الصيغة هي JSON5، مما يعني أن التعليقات والفواصل اللاحقة مسموح بها. أكثر صداقةً بكثير من JSON العادي.

يمكنك تعديله بطريقتين:

  • استخدم وضع النموذج في Control UI إذا أردت شيئاً مناسباً للمبتدئين
  • انتقل إلى Raw JSON إذا أردت الدقة والسرعة

كلا الوضعَين يعدّلان نفس الملف ويحفظان في نفس المسار.

كيف يبدو إعداد عمل بسيط؟

اجعل الإصدار البسيط يعمل أولاً. ثم أضف المزيد من الميزات تدريجياً.

الطريقة الصحيحة لتخزين مفاتيح API

لا تضمّن مفاتيح API في الإعداد إذا أمكنك تجنب ذلك.

متغيرات البيئة أكثر أماناً:

⚠️ إذا كان Gateway يعمل كخدمة نظام مثل systemd، تأكد من أن الخدمة تحمّل ملف .env الخاص بك. وإلا قد يفشل المساعد لأنه لا يستطيع رؤية مفتاح API، وقد تصطدم بأخطاء مثل "Shell env off".

أداة التصحيح الشاملة

عندما يبدو شيء خاطئاً، ابدأ هنا:

السجلات الفورية تجيب على عدد مدهش من الأسئلة.

أخطاء شائعة:

رسالة الخطأ السبب المحتمل
HTTP 429 طلبات API كثيرة جداً، وصلت إلى حد المعدل
unauthorized مشكلة في الرمز أو gateway.bind
content tool_use input field required مشكلة توافق النموذج، تحقق من الوثائق
Context got truncated ابدأ جلسة جديدة أو اضغط السياق كما يُوصى

أي مسار إصدار تستخدم؟

مسار الإصدار الأفضل لـ
Stable الاستخدام اليومي، الافتراضي الأكثر أماناً
Beta تجربة الميزات الجديدة وقبول بعض الأخطاء
Dev المطورون الراغبون في أحدث التغييرات أولاً

💡 قبل ترقية رئيسية، احتفظ بنسخة احتياطية من ~/.openclaw حتى يكون لديك دائماً مسار للتراجع.

السلسلة مكتملة: ما الذي يمكنك فعله الآن؟

عبر هذه المقالات، تعلمت كيف:

  1. تفهم الفكرة الجوهرية خلف OpenClaw
  2. تثبّته وتشغّله للمرة الأولى
  3. تتعامل مع مصادقة لوحة التحكم
  4. تربط Telegram وقنوات أخرى
  5. تجعل المساعد أكثر كفاءة بالمهارات
  6. تدير الذاكرة ومساحات العمل
  7. تقسم العمل عبر وكلاء متعددين
  8. تنشر Gateway على VPS
  9. تؤتمت المهام مع Cron
  10. تصحّح وتضبط النظام كمحترف

للحصول على تفاصيل أعمق، تعامل دائماً مع الوثائق الرسمية في docs.openclaw.ai كمصدر الحقيقة.

مساعدك الذكي جاهز. اجعله يعمل من أجلك.
