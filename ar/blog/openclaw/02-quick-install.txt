<p><strong>1. Node.js (الإصدار LTS)</strong></p>

<blockquote>
<p>💡 لست متأكداً من كيفية الحصول على مفتاح API؟ ابحث عن "Anthropic API key" وستتمكن من إنجازه في دقائق قليلة.</p>

<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">node</span><span style="color:#79B8FF"> --version</span></span>

<p><strong>2. مفتاح API لنموذج الذكاء الاصطناعي</strong></p>
<p>إذا أردت استخدام نماذج سحابية مثل Anthropic Claude أو OpenAI، تحتاج مفتاح API. إذا أردت البقاء بالكامل دون اتصال، يمكنك استخدام نموذج محلي. تفترض هذه السلسلة استخدام نموذج سحابي بشكل افتراضي.</p>
<blockquote>
<p>💡 لست متأكداً من كيفية الحصول على مفتاح API؟ ابحث عن "Anthropic API key" وستتمكن من إنجازه في دقائق قليلة.</p>
</blockquote>

<h2 id="التشغيل-الأول-احتضان-مساعدك">التشغيل الأول: احتضان مساعدك</h2>
<p>بعد التثبيت، شغّل:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">openclaw</span><span style="color:#9ECBFF"> gateway</span></span></code></pre></figure>
<p><strong>التشغيل الأول يفتح معالج الإعداد</strong>، الذي يطرح أسئلة بسيطة:</p>
<ol>
<li>أي نموذج ذكاء اصطناعي تريد استخدامه؟</li>
<li>ما هو مفتاح API الخاص بك؟</li>
<li>أين يجب أن تعيش مساحة العمل؟</li>
</ol>
<p>أجب عليها وسيقوم OpenClaw بإنشاء أول مساعد لك.</p>
<blockquote>
<p>💡 عالق لفترة طويلة عند "wake up my friend"؟ تحقق من مفتاح API واتصالك بالإنترنت وأي رسائل خطأ تظهر في المحطة.</p>
</blockquote>
