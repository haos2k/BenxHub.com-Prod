دليل Cursor CLI — نظرة عامة

24 2月 2026·2 min read

يتيح لك Cursor CLI استدعاء قدرات الذكاء الاصطناعي في Cursor مباشرة من الطرفية — دون الحاجة إلى نافذة Cursor. يمكنك أن تطلب من الذكاء الاصطناعي كتابة الكود أو تعديل الملفات أو الإجابة على الأسئلة. للمهندسين الذين يعملون في الطرفية، كأن يكون لديك مساعد جاهز في كل وقت.

لماذا تتعلم CLI؟

السيناريو باستخدام نافذة Cursor باستخدام Cursor CLI
تعديل الكود على خادم يتطلب SSH وإعداد عن بُعد أو مزامنة تشغيل الأوامر مباشرة في الطرفية
كتابة السكربتات وأتمتة CI صعب دمجه في خط الأنابيب وضع غير تفاعلي، أمر واحد للتشغيل
العمل بالفعل في الطرفية يجب التبديل إلى بيئة التطوير والعودة اسأل الذكاء الاصطناعي في نفس النافذة
تفضيل سير عمل باللوحة المفاتيح النقر بالفأرة لا مفر منه كل شيء يتم بالأوامر

باختصار: CLI يجعل الذكاء الاصطناعي يتبع سير عملك، بدلاً من إجبارك على التكيف مع بيئة التطوير.

خريطة الدورة

الملف الموضوع الوقت التقريبي
01-install التثبيت والتحقق 5 دقائق
02-basic-usage الاستخدام الأساسي: الأوامر والمحادثة 10 دقائق
03-modes ثلاثة أوضاع: Agent / Plan / Ask 8 دقائق
04-non-interactive الوضع غير التفاعلي والسكربتات 8 دقائق
05-tips نصائح وأسئلة شائعة 5 دقائق
06-cursor-cli-with-worktree CLI مع Worktree للتطوير المتوازي 8 دقائق
07-unlimit-loop-debug حلقة تصحيح لا نهائية: التشغيل حتى تمر الاختبارات 10 دقائق

المتطلبات المسبقة

  • Cursor مثبت (أو على الأقل حساب Cursor يمكنك تسجيل الدخول إليه)
  • اشتراك Cursor (يتطلب CLI اشتراكاً)
  • إلمام أساسي بالطرفية

ابدأ من 01-install لإعداد CLI أولاً.
