<h2 id="وضع-agent-الافتراضي">وضع Agent (الافتراضي)</h2>
<p><strong>حالة الاستخدام</strong>: أن يعدّل الذكاء الاصطناعي الكود مباشرة أو يضيف ميزات أو يعيد الهيكلة. تريد النتائج، لا النقاش.</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#A5D6FF"> "Change login to use JWT"</span></span></code></pre></figure>
<ul>
<li>يقرأ الملفات، يعدّلها، وقد يشغّل أوامر</li>
<li>يمكنك قبول أو رفض كل خطوة — أنت المسيطر</li>
</ul>
<h2 id="وضع-plan">وضع Plan</h2>
<p><strong>حالة الاستخدام</strong>: غير متأكد كيف تتعامل مع شيء، أو قلق من أن يغيّر الذكاء الاصطناعي الكثير دفعة واحدة؟ اعرض الخطة قبل الإذن.</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#79C0FF"> --plan</span><span style="color:#A5D6FF"> "Refactor the entire API layer"</span></span></code></pre></figure>
<ul>
<li>يطرح الذكاء الاصطناعي بعض الأسئلة ويقترح نهجاً</li>
<li>ينفّذ فقط بعد موافقتك — دون مفاجآت</li>
</ul>
<p><strong>متى تستخدمه</strong>: للتغييرات الكبيرة، أو عندما تريد "أن ترى الأمر بوضوح قبل الالتزام."</p>
<h2 id="وضع-ask-قراءة-فقط">وضع Ask (قراءة فقط)</h2>
<p><strong>حالة الاستخدام</strong>: تريد فقط أن تسأل "ماذا يفعل هذا الكود" أو "هل هناك طريقة أفضل لكتابة هذا" — ولا تريد <strong>أبداً</strong> تغيير أي ملفات.</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> ask</span><span style="color:#A5D6FF"> "What is the logic in src/auth.ts?"</span></span></code></pre></figure>
<ul>
<li>يقرأ ويحلل ويجيب فقط — لا يكتب أبداً</li>
<li>مفيد لـ CI أو بيئات تريد فيها الفحص فقط دون التعديل</li>
</ul>
<h2 id="التبديل-بين-الأوضاع-أثناء-المحادثة">التبديل بين الأوضاع أثناء المحادثة</h2>
<p>أنت بالفعل داخل محادثة <code>cursor agent</code>؟ استخدم <strong>أوامر الشرطة</strong> للتبديل فوراً:</p>
<ul>
<li><code>/plan</code> → التبديل لوضع Plan (خطة أولاً، تنفيذ لاحقاً)</li>
<li><code>/ask</code> → التبديل لوضع Ask (قراءة فقط، اسأل بحرية)</li>
</ul>
<p>لا حاجة للخروج وإعادة التشغيل — كالتبديل بين السرعات أثناء السير.</p>
<h2 id="ملخص">ملخص</h2>
<ul>
<li><strong>Agent</strong>: ينفّذ ويعدّل الملفات — استخدمه عندما تريد النتائج</li>
<li><strong>Plan</strong>: يخطّط أولاً، ينفّذ فقط بعد موافقتك — استخدمه عندما تريد الأمان</li>
<li><strong>Ask</strong>: أسئلة فقط، قراءة فقط — استخدمه عندما تريد إجابات دون تغييرات</li>
</ul>
