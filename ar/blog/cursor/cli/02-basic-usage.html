الاستخدام الأساسي لـ Cursor CLI

24 2月 2026·2 min read

الطريقة الأكثر شيوعاً: cursor agent

شغّل هذا داخل مجلد المشروع:

  • تفاعلي: الذكاء الاصطناعي يطرح أسئلة ويقترح؛ يمكنك قبول أو رفض التغييرات
  • واعٍ بالسياق: يقرأ الملفات في المجلد الحالي لتحسين الردود والتعديلات

أمر واحد مقابل المحادثة

تريد تفويض مهمة مباشرة: ضع التعليمات بين علامتي اقتباس وأرسلها دفعة واحدة.

تريد النقاش قبل التنفيذ: شغّل cursor agent دون وسائط للدخول إلى وضع المحادثة، حيث تصف متطلباتك خطوة بخطوة ويتوضيح الذكاء الاصطناعي قبل إجراء التغييرات.

تحديد مجلد العمل

افتراضياً يستخدم المجلد الحالي. لتحديد مسار، أضف --path:

مرجع الأوامر السريع

الأمر الوصف
cursor agent "do something" اطلب من الذكاء الاصطناعي تنفيذها (يمكنه تعديل الملفات)
cursor agent الدخول لوضع المحادثة دون مهمة
cursor ask "question" سؤال فقط، لا تعديل ملفات (قراءة فقط)
cursor --help عرض كل الخيارات المتاحة

ملخص

  • الأكثر شيوعاً: cursor agent "تعليماتك"
  • تريد الدردشة أولاً: شغّل cursor agent فقط
  • اسأل دون تعديل: استخدم cursor ask "سؤال"
  • تحديد المجلد: أضف --path <path>
