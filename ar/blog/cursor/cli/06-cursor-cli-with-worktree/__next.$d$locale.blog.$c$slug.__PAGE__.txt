└── my-app--feature-payment/  ← feature/payment
</code></pre>

<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#79C0FF">cd</span><span style="color:#A5D6FF"> ~/projects/my-app--feature-payment</span></span>

<p>CLI يستخدم <strong>المجلد الحالي</strong> كسياقه افتراضياً، فكلا الطرفيتين يعدّلان فقط worktree الخاص به. هذا "وكيلا CLI يعملان بالتوازي" — لا حاجة لفتح نافذتي Cursor، توفير موارد وتجنّب تبديل السياق.</p>
<h2 id="دون-تغيير-المجلد-استخدم---path-لاستهداف-worktree">دون تغيير المجلد: استخدم <code>--path</code> لاستهداف Worktree</h2>
<p>أنت في مجلد المشروع الرئيسي لكن تريد أن يعمل CLI على worktree معيّن:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#79C0FF">cd</span><span style="color:#A5D6FF"> ~/projects/my-app</span></span>

<p><code>--path</code> يحدد له أي مجلد ينظر — مسار الـ worktree. مفيد عند التعامل مع worktree واحد في المرة، أو عندما يكون المسار ثابتاً في سكربت.</p>
<h2 id="غير-تفاعلي--worktree-سكربتات--عمليات-دفعة">غير تفاعلي + Worktree (سكربتات / عمليات دفعة)</h2>
<p>تشغيل نفس نوع المهمة على عدة worktrees بالتسلسل (مثلاً إضافة README للكل، إصلاح lint في الكل):</p>

<h2 id="العلاقة-مع-worktree--نوافذ-متعددة">العلاقة مع "Worktree + نوافذ متعددة"</h2>
<ul>
<li><strong>نوافذ متعددة</strong>: كل نافذة Cursor تفتح worktree، باستخدام Agent والـ Chat والإكمال Tab في الـ IDE.</li>
<li><strong>CLI + Worktree</strong>: طرفية + <code>cursor agent</code> — نفس فكرة "مجلد واحد، سياق واحد"، فقط افتح طرفيات أكثر للتوزيع المتوازي.</li>
</ul>
<p>يمكنك أيضاً المزج: التطوير الرئيسي في النافذة، واستخدام CLI على الخادم لإصلاحات صغيرة على فرع آخر.</p>
<h2 id="ملخص">ملخص</h2>
<ul>
<li><strong>Worktree</strong> = مجلدات متعددة، فروع متعددة؛ <strong>CLI</strong> = يعمل على المجلد الحالي أو <code>--path</code> → ثنائي طبيعي.</li>
<li><strong>متوازي</strong>: افتح طرفيات متعددة، كل واحدة <code>cd</code> إلى worktree مختلف، ثم شغّل <code>cursor agent</code>.</li>
<li><strong>طرفية واحدة</strong>: استخدم <code>--path &#x3C;worktree-path></code> لاستهداف الـ worktree المطلوب.</li>
<li><strong>سكربتات/دفعة</strong>: <code>--path</code> + <code>--no-interactive</code> لتشغيل نفس المهمة على عدة worktrees.</li>
</ul>

<h2 id="العلاقة-مع-worktree--نوافذ-متعددة">العلاقة مع "Worktree + نوافذ متعددة"</h2>
<ul>
<li><strong>نوافذ متعددة</strong>: كل نافذة Cursor تفتح worktree، باستخدام Agent والـ Chat والإكمال Tab في الـ IDE.</li>
<li><strong>CLI + Worktree</strong>: طرفية + <code>cursor agent</code> — نفس فكرة "مجلد واحد، سياق واحد"، فقط افتح طرفيات أكثر للتوزيع المتوازي.</li>
</ul>
<p>يمكنك أيضاً المزج: التطوير الرئيسي في النافذة، واستخدام CLI على الخادم لإصلاحات صغيرة على فرع آخر.</p>
<h2 id="ملخص">ملخص</h2>
<ul>
<li><strong>Worktree</strong> = مجلدات متعددة، فروع متعددة؛ <strong>CLI</strong> = يعمل على المجلد الحالي أو <code>--path</code> → ثنائي طبيعي.</li>
<li><strong>متوازي</strong>: افتح طرفيات متعددة، كل واحدة <code>cd</code> إلى worktree مختلف، ثم شغّل <code>cursor agent</code>.</li>
<li><strong>طرفية واحدة</strong>: استخدم <code>--path &#x3C;worktree-path></code> لاستهداف الـ worktree المطلوب.</li>
<li><strong>سكربتات/دفعة</strong>: <code>--path</code> + <code>--no-interactive</code> لتشغيل نفس المهمة على عدة worktrees.</li>
</ul>
