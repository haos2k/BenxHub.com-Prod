تثبيت Cursor CLI

24 2月 2026·1 min read

التثبيت بسيط: شغّل السكربت الرسمي في الطرفية وستصبح أمر cursor متاحاً. تختلف التعليمات حسب المنصة.

macOS / Linux / WSL

شغّل هذا في الطرفية:

  • يقوم السكربت بتحميل وتثبيت أمر cursor تلقائياً
  • بعد التثبيت، أغلق الطرفية وافتحها من جديد، أو شغّل source ~/.bashrc / source ~/.zshrc لتحديث PATH

Windows (PowerShell)

افتح PowerShell كمسؤول وشغّل:

التحقق من التثبيت

إذا ظهر رقم إصدار، فالتثبيت نجح.

أول استخدام: تسجيل الدخول

أول مرة تشغّله قد يُطلب منك تسجيل الدخول إلى حساب Cursor:

اتبع التعليمات على الشاشة لإكمال تسجيل الدخول عبر المتصفح. على نفس الجهاز عادة لن تحتاج لتسجيل الدخول مرة أخرى.

ملخص

  • macOS / Linux: curl ... | bash
  • Windows: شغّل irm ... | iex في PowerShell
  • التحقق: cursor --version
  • تسجيل الدخول: cursor auth login
