1b:T468d,<p>اكتب سكربت shell يجعل <code>cursor agent</code> يصلح الكود تلقائياً ويشغّل الاختبارات، وإذا فشلت يدع الذكاء الاصطناعي يصلح مرة أخرى — <strong>ويكرر حتى تمر كل الاختبارات</strong>. لا حاجة للجلوس والضغط Y/N. سلّم الحلقة للذكاء الاصطناعي واذهب لشغل آخر — ارجع عندما تظهر الطرفية "tests passed."</p>
<h2 id="الفكرة-الأساسية">الفكرة الأساسية</h2>
<pre><code>while tests don't pass:
    run tests → collect error output
    feed error output to cursor agent
    cursor agent fixes the code
    run tests again
</code></pre>
<p>حلقة "شغّل الاختبارات → فشل → أخبر الذكاء الاصطناعي يصلح → كرر" حتى تنجح. بسيطة ومباشرة لكن فعّالة.</p>
<h2 id="الخطوة-1-التحقق-من-المتطلبات">الخطوة 1: التحقق من المتطلبات</h2>
<ul>
<li><code>cursor</code> مثبت ومسجّل الدخول (<code>cursor --version</code> للتحقق)</li>
<li>المشروع لديه <strong>أمر اختبار يشغّل في الطرفية</strong>، مثل:
<ul>
<li><code>npm test</code></li>
<li><code>pytest</code></li>
<li><code>go test ./...</code></li>
<li><code>cargo test</code></li>
</ul>
</li>
<li>الاختبارات تُرجع كود خروج غير صفري عند الفشل (تقريباً كل أطر الاختبار تفعل ذلك افتراضياً)</li>
</ul>

26:T468d,<p>اكتب سكربت shell يجعل <code>cursor agent</code> يصلح الكود تلقائياً ويشغّل الاختبارات، وإذا فشلت يدع الذكاء الاصطناعي يصلح مرة أخرى — <strong>ويكرر حتى تمر كل الاختبارات</strong>. لا حاجة للجلوس والضغط Y/N. سلّم الحلقة للذكاء الاصطناعي واذهب لشغل آخر — ارجع عندما تظهر الطرفية "tests passed."</p>
<h2 id="الفكرة-الأساسية">الفكرة الأساسية</h2>
<pre><code>while tests don't pass:
    run tests → collect error output
    feed error output to cursor agent
    cursor agent fixes the code
    run tests again
</code></pre>
<p>حلقة "شغّل الاختبارات → فشل → أخبر الذكاء الاصطناعي يصلح → كرر" حتى تنجح. بسيطة ومباشرة لكن فعّالة.</p>
<h2 id="الخطوة-1-التحقق-من-المتطلبات">الخطوة 1: التحقق من المتطلبات</h2>
<ul>
<li><code>cursor</code> مثبت ومسجّل الدخول (<code>cursor --version</code> للتحقق)</li>
<li>المشروع لديه <strong>أمر اختبار يشغّل في الطرفية</strong>، مثل:
<ul>
<li><code>npm test</code></li>
<li><code>pytest</code></li>
<li><code>go test ./...</code></li>
<li><code>cargo test</code></li>
</ul>
</li>
<li>الاختبارات تُرجع كود خروج غير صفري عند الفشل (تقريباً كل أطر الاختبار تفعل ذلك افتراضياً)</li>
</ul>

<h2 id="نسخة-محسّنة-حفظ-سجلات-لكل-حلقة">نسخة محسّنة: حفظ سجلات لكل حلقة</h2>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E">#!/bin/bash</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#E6EDF3">MAX_LOOPS</span><span style="color:#FF7B72">=</span><span style="color:#A5D6FF">10</span></span>
<span data-line=""><span style="color:#E6EDF3">TEST_CMD</span><span style="color:#FF7B72">=</span><span style="color:#A5D6FF">"npm test"</span></span>
<span data-line=""><span style="color:#E6EDF3">LOG_DIR</span><span style="color:#FF7B72">=</span><span style="color:#A5D6FF">"debug-logs"</span></span>

<span data-line=""><span style="color:#FF7B72">while</span><span style="color:#E6EDF3"> [ $loop </span><span style="color:#FF7B72">-lt</span><span style="color:#E6EDF3"> $MAX_LOOPS ]; </span><span style="color:#FF7B72">do</span></span>

<span data-line=""><span style="color:#79C0FF">  echo</span><span style="color:#A5D6FF"> "=== Loop $((</span><span style="color:#FFA657">loop</span><span style="color:#A5D6FF"> + </span><span style="color:#79C0FF">1</span><span style="color:#A5D6FF">)) ==="</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#E6EDF3">  LOG_FILE</span><span style="color:#FF7B72">=</span><span style="color:#A5D6FF">"</span><span style="color:#E6EDF3">$LOG_DIR</span><span style="color:#A5D6FF">/loop-$((</span><span style="color:#FFA657">loop</span><span style="color:#A5D6FF"> + </span><span style="color:#79C0FF">1</span><span style="color:#A5D6FF">)).log"</span></span>
<span data-line=""><span style="color:#E6EDF3">  TEST_OUTPUT</span><span style="color:#FF7B72">=</span><span style="color:#E6EDF3">$(</span><span style="color:#79C0FF">eval</span><span style="color:#A5D6FF"> "</span><span style="color:#E6EDF3">$TEST_CMD</span><span style="color:#A5D6FF">"</span><span style="color:#FF7B72"> 2>&#x26;1</span><span style="color:#FF7B72"> |</span><span style="color:#FFA657"> tee</span><span style="color:#A5D6FF"> "</span><span style="color:#E6EDF3">$LOG_FILE</span><span style="color:#A5D6FF">"</span><span style="color:#E6EDF3">)</span></span>
<span data-line=""><span style="color:#E6EDF3">  EXIT_CODE</span><span style="color:#FF7B72">=</span><span style="color:#E6EDF3">${PIPESTATUS[0]}</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#FF7B72">  if</span><span style="color:#E6EDF3"> [ $EXIT_CODE </span><span style="color:#FF7B72">-eq</span><span style="color:#79C0FF"> 0</span><span style="color:#E6EDF3"> ]; </span><span style="color:#FF7B72">then</span></span>

<span data-line=""><span style="color:#79C0FF">    exit</span><span style="color:#79C0FF"> 0</span></span>

<span data-line=""> </span>
<span data-line=""><span style="color:#FFA657">  cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#A5D6FF"> "Tests failed with the following errors. Please fix the code to make the tests pass:</span></span>
<span data-line=""> </span>

<span data-line=""> </span>
<span data-line=""><span style="color:#E6EDF3">  loop</span><span style="color:#FF7B72">=</span><span style="color:#E6EDF3">$((</span><span style="color:#FFA657">loop</span><span style="color:#A5D6FF"> +</span><span style="color:#79C0FF"> 1</span><span style="color:#E6EDF3">))</span></span>

<span data-line=""> </span>
