<h3 id="1-استئناف-المحادثة-السابقة">1. استئناف المحادثة السابقة</h3>
<p>أغلقت في منتصف الجلسة وتريد متابعة من حيث توقفت؟ لا حاجة للبدء من جديد:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#79B8FF"> --resume</span></span></code></pre></figure>
<p>هذا يحمّل أحدث محادثة مع كل السياق — كضغط "استئناف" على فيديو متوقف.</p>
<h3 id="2-التأكيد-قبل-تشغيل-الأوامر">2. التأكيد قبل تشغيل الأوامر</h3>
<p>قد يريد الـ Agent تشغيل أوامر مثل <code>npm install</code> أو <code>git</code>.</p>
<ul>
<li><strong>الوضع التفاعلي</strong>: سيسألك أولاً</li>
<li>إن كنت حذراً، قل له في المحادثة: "اسألني قبل تشغيل أي أوامر"</li>
</ul>
<p>هكذا لن تكون لحظات من نوع "متى شغّل ذلك؟".</p>
<h3 id="3-استخدم-cli-و-ide-معاً">3. استخدم CLI و IDE معاً</h3>
<p>يمكن استخدام <strong>CLI ونافذة Cursor في الوقت نفسه</strong> — ليست إما/أو:</p>
<ul>
<li>استخدم النافذة للتطوير الرئيسي وتصفح شجرة الملفات والإكمال بـ Tab</li>
<li>استخدم CLI للمهام الصغيرة والاستعلام وتشغيل الأتمتة</li>
</ul>
<p>واحد يتولى المعركة الرئيسية والآخر المناوشات — فرّق تسد.</p>
<h2 id="أسئلة-شائعة">أسئلة شائعة</h2>
<p><strong>س: <code>cursor: command not found</code>؟</strong>
ج: أعد تشغيل الطرفية بعد التثبيت، أو شغّل <code>source ~/.zshrc</code> (أو <code>~/.bashrc</code>). تأكد أن مسار التثبيت في <code>PATH</code> — مشكلة "ثبّت الأداة لكن النظام لا يجدها" تكون في الغالب مشكلة PATH.</p>
<p><strong>س: هل CLI مدفوع؟</strong>
ج: نعم. تحتاج اشتراك Cursor لاستخدام CLI — وهو نفس اشتراك الـ IDE.</p>
<p><strong>س: هل يمكن استخدامه على خادم / في Docker؟</strong>
ج: نعم. المتطلبات: القدرة على تشغيل سكربت التثبيت، وتسجيل الدخول إلى Cursor (أو إعداد token). انتبه للشبكة والتفويض — لا تتوقع الوصول إلى سحابة Cursor في بيئة شبكة مقيدة.</p>
<p><strong>س: هل هو نفسه الـ Agent في نافذة Cursor؟</strong>
ج: نفس القدرة الأساسية. الفرق أن CLI واجهة طرفية، يدعم الوضع غير التفاعلي ويتكامل مع السكربتات وCI — نفس الذكاء الاصطناعي، واجهة مختلفة.</p>
<h2 id="ملخص">ملخص</h2>
<ul>
<li><strong>استئناف المحادثة</strong>: <code>cursor agent --resume</code></li>
<li><strong>تأكيد الأوامر</strong>: يمكنك أن تطلب "تأكيد قبل تشغيل أي أوامر"</li>
<li><strong>CLI و IDE</strong>: يمكن استخدامهما معاً، لا يستبعد أحدهما الآخر</li>
<li><strong>عند التعثّر</strong>: راجع <code>cursor --help</code> والوثائق الرسمية — معظم المشاكل لها حلول معروفة</li>
</ul>
