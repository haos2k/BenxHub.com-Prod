1b:T30fc,<p>المنشور السابق <a href="08-worktree-merge">08-worktree-merge</a> غطى worktree التلقائي في Cursor وApply. هذا يتعمق في أمرين: <strong>Best-of-N</strong> (نفس الـ prompt، نماذج متعددة بالتوازي، ثم اختر واحداً لتطبيقه) و<strong>worktrees.json</strong> (تثبيت تلقائي للتبعيات، تشغيل migrations، نسخ <code>.env</code> عند إنشاء worktree).</p>
<h2 id="best-of-n-prompt-واحد-نماذج-متعددة-دفعة-واحدة">Best-of-N: prompt واحد، نماذج متعددة دفعة واحدة</h2>
<p><strong>Best-of-N</strong> يعني: ترسل مهمة واحدة، Cursor يشغّل <strong>نماذج متعددة</strong> في worktrees منفصلة، وتحصل على "بطاقات" متعددة كل واحدة بتغييرات نموذج واحد — <strong>اختر واحدة واضغط Apply</strong>.</p>

<h3 id="كيف-تستخدمه">كيف تستخدمه</h3>
<p>في Cursor، عند بدء Agent اختر "نماذج متعددة" أو خيار Best-of-N (حسب الواجهة الحالية). بعد إرسال الـ prompt سترى بطاقات متعددة؛ انتقل بينها للمقارنة ثم <strong>Apply</strong> التي تريدها على main.</p>
<p>إن طبّقت أكثر من بطاقة من نفس تشغيل Best-of-N (مثلاً Apply A ثم B)، قد يسأل Cursor: <strong>دمج مع حل تعارضات</strong>، أو <strong>Full Overwrite</strong> (استبدال الملف بالكامل).</p>
<h2 id="worktreesjson-تجهيز-البيئة-عند-إنشاء-worktree">worktrees.json: تجهيز البيئة عند إنشاء worktree</h2>
<p>عند إنشاء Cursor لـ worktree، ينسخ <strong>الملفات المتتبعة</strong> من المجلد الرئيسي افتراضياً، لكنه لا يثبت التبعيات ولا ينسخ <code>.env</code> ولا يشغّل migrations قاعدة البيانات.<br>
مع <strong><code>.cursor/worktrees.json</code></strong> يمكنك تحديد <strong>أوامر تُشغّل بعد إنشاء كل worktree جديد</strong>، مثل <code>npm ci</code>، <code>cp .env</code>، <code>npm run db:migrate</code>.</p>
<h3 id="أين-يكون-الإعداد">أين يكون الإعداد؟</h3>

<ol>
<li>جذر المشروع: <code>.cursor/worktrees.json</code></li>
<li>مسار الـ worktree</li>
</ol>
<p>عادة ضعه في <strong>جذر المشروع</strong>: <code>.cursor/worktrees.json</code>.</p>

<h3 id="كيف-تستخدمه">كيف تستخدمه</h3>
<p>في Cursor، عند بدء Agent اختر "نماذج متعددة" أو خيار Best-of-N (حسب الواجهة الحالية). بعد إرسال الـ prompt سترى بطاقات متعددة؛ انتقل بينها للمقارنة ثم <strong>Apply</strong> التي تريدها على main.</p>

<h2 id="worktreesjson-تجهيز-البيئة-عند-إنشاء-worktree">worktrees.json: تجهيز البيئة عند إنشاء worktree</h2>
