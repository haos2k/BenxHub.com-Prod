<h2 id="استئناف-الجلسة---resume">استئناف الجلسة: --resume</h2>
<p>أغلقت الطرفية في منتصف المحادثة، أو كانت المهمة طويلة فأوقفتها — في المرة القادمة تريد المتابعة من نفس الخيط:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#79C0FF"> --resume</span></span></code></pre></figure>
<p>هذا يحمّل <strong>أحدث</strong> محادثة؛ السياق والتعليمات السابقة ما زالت هناك، لا حاجة لإعادة وصف الطلب.</p>
<h3 id="استئناف-محادثة-معيّنة">استئناف محادثة معيّنة</h3>
<p>إن كان لديك أكثر من محادثة وتريد استئناف <strong>واحدة بعينها</strong>:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#79C0FF"> --resume=chat-id-here</span></span></code></pre></figure>
<p>احصل على <code>chat-id</code> من "عرض المحادثات" أدناه.</p>
<h2 id="عرض-كل-المحادثات-cursor-agent-ls">عرض كل المحادثات: cursor agent ls</h2>

<h2 id="التنفيذ-السحابي--c----cloud">التنفيذ السحابي: -c / --cloud</h2>
<p>بعض المهام ثقيلة: تحليل المستودع بالكامل، توليد وثائق كبيرة، إعادة هيكلة متعددة الخطوات. التشغيل محلياً يعني إبقاء الطرفية مفتوحة؛ إغلاق الجهاز أو فقدان الاتصال يوقف التشغيل.</p>
<p>مع <strong><code>-c</code></strong> (أو <strong><code>--cloud</code></strong>) تسلّم <strong>هذه المحادثة</strong> لـ Agent سحابي:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#A5D6FF"> "Analyze the whole project and write architecture doc to docs/architecture.md"</span><span style="color:#79C0FF"> -c</span></span></code></pre></figure>
<ul>
<li>بعد الإرسال، المهمة تعمل على سحابة Cursor</li>
<li>يمكنك إغلاق الطرفية أو الإيقاف أو التبديل لشيء آخر</li>
<li>لاحقاً، من أي جهاز بنفس حساب Cursor، استخدم <code>--resume</code> للانضمام مرة أخرى لتلك المحادثة ورؤية النتيجة أو إضافة تعليمات أكثر</li>
</ul>
<p>إذن <strong><code>-c</code></strong> = "شغّلها في السحابة؛ لا حاجة للانتظار عند الجهاز."</p>

<h2 id="الجلسات--السحابة-معاً">الجلسات + السحابة معاً</h2>
<p>تدفق نموذجي:</p>
<ol>
<li>ابدأ مهمة بـ <code>-c</code> لتعمل في السحابة</li>
<li>أغلق الطرفية</li>
<li>لاحقاً شغّل <code>cursor agent ls</code> لإيجاد تلك المحادثة</li>
<li><code>cursor agent --resume=that-id</code> للانضمام مرة أخرى، رؤية النتيجة، أو إرسال تعليمات إضافية</li>
</ol>
<p>هكذا تغطّي "مهام طويلة" و"أجهزة متعددة / إيقاف".</p>
<h2 id="ملخص">ملخص</h2>
<ul>
<li><strong><code>cursor agent ls</code></strong>: عرض كل المحادثات لإيجاد التي تستأنفها</li>
<li><strong><code>--resume</code></strong>: استئناف الأحدث؛ <strong><code>--resume=ID</code></strong>: استئناف محادثة معيّنة</li>
<li><strong><code>-c</code> / <code>--cloud</code></strong>: تشغيل المهمة الحالية في السحابة؛ يمكنك إغلاق الطرفية والاستئناف لاحقاً بـ <code>--resume</code></li>
</ul>

<li>ابدأ مهمة بـ <code>-c</code> لتعمل في السحابة</li>
<li>أغلق الطرفية</li>
<li>لاحقاً شغّل <code>cursor agent ls</code> لإيجاد تلك المحادثة</li>
<li><code>cursor agent --resume=that-id</code> للانضمام مرة أخرى، رؤية النتيجة، أو إرسال تعليمات إضافية</li>
</ol>
<p>هكذا تغطّي "مهام طويلة" و"أجهزة متعددة / إيقاف".</p>
<h2 id="ملخص">ملخص</h2>
<ul>
<li><strong><code>cursor agent ls</code></strong>: عرض كل المحادثات لإيجاد التي تستأنفها</li>
<li><strong><code>--resume</code></strong>: استئناف الأحدث؛ <strong><code>--resume=ID</code></strong>: استئناف محادثة معيّنة</li>
<li><strong><code>-c</code> / <code>--cloud</code></strong>: تشغيل المهمة الحالية في السحابة؛ يمكنك إغلاق الطرفية والاستئناف لاحقاً بـ <code>--resume</code></li>
</ul>
