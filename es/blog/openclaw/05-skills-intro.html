Dale superpoderes a tu asistente: Skills lo convierten en alguien que actúa

8 3月 2026·2 min read

Un asistente que solo sabe conversar es como contratar a una persona brillante y no darle herramientas. Talento desperdiciado.

Las Skills son la forma de equiparlo para hacer cosas reales.

Qué vas a aprender

  • Entender qué es una Skill
  • Activar Skills integradas
  • Añadir Skills personalizadas
  • Entender prioridad y rutas de carga

¿Qué es una Skill?

Una Skill suele ser un documento llamado SKILL.md que explica:

  • Qué puede hacer
  • Cuándo conviene usarla
  • Qué herramientas y pasos puede seguir

Piénsalo como el manual de trabajo del asistente. Si le das un manual para navegar por la web, podrá buscar información. Si le das uno para leer y escribir archivos, podrá organizar documentos.

Integradas vs personalizadas

OpenClaw trae varias Skills integradas y la comunidad sigue aportando más. Puedes:

  • Usar las integradas directamente desde el dashboard
  • Escribir la tuya con un simple archivo SKILL.md

La forma inteligente de crear Skills propias

Si quieres modificar o añadir una Skill, no toques los archivos originales del repo de OpenClaw. La próxima actualización puede sobrescribirlos.

Pon tu versión aquí:

~/.openclaw/skills/<nombre-skill>/SKILL.md

Orden de prioridad

workspace/skills  →  ~/.openclaw/skills  →  integradas  →  extraDirs

La primera coincidencia gana.

Gestionar Skills desde el dashboard

Abre Control UI → pestaña Skills. Desde ahí puedes:

  • Ver todas las Skills disponibles
  • Activarlas o desactivarlas con un clic
  • Configurar Skills que necesiten API keys
  • Instalar Skills de la comunidad

Después de guardar, OpenClaw normalmente recarga en caliente sin reiniciar el Gateway.
