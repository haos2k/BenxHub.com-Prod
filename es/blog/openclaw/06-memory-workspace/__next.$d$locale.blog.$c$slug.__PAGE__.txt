<hr>
<h2 id="qué-es-un-workspace">¿Qué es un Workspace?</h2>
<p>Piensa en el workspace como <strong>la oficina privada del asistente</strong>:</p>
<ul>
<li>Los archivos que lee, los documentos que escribe y los scripts que ejecuta viven ahí</li>
<li>Puedes crear varios workspaces para separar distintos trabajos</li>
</ul>
<pre><code>~/.openclaw/workspace-main        ← oficina del asistente principal
~/.openclaw/workspace-project-a   ← oficina del proyecto A
~/.openclaw/workspace-project-b   ← oficina del proyecto B
</code></pre>
<p>Así "ordena mi diario personal" y "escribe código para el proyecto A" no terminan mezclados.</p>
<hr>
<h2 id="cómo-funciona-la-memoria">¿Cómo funciona la memoria?</h2>
<p>OpenClaw guarda partes importantes de la conversación como <strong>memoria</strong> para poder buscarlas y reutilizarlas después.</p>
<p>En lenguaje simple: <strong>el asistente recuerda cosas que ya le contaste</strong>.</p>
<blockquote>
<p>⚠️ Si parece olvidadizo, revisa esto:</p>
<ul>
<li>¿La memoria está activada? La búsqueda semántica puede requerir una API key de OpenAI</li>
<li>¿La memoria antigua fue compactada, limpiada o limitada por longitud?</li>
<li>¿Abriste una sesión nueva? Una sesión nueva empieza con contexto corto vacío</li>
</ul>
</blockquote>
