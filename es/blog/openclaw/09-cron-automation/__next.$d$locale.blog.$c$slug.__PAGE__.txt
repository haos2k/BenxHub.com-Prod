<h2 id="qué-son-cron-y-heartbeat">¿Qué son Cron y Heartbeat?</h2>
<p><strong>Cron</strong> significa "haz esta tarea a esta hora", como si le dejaras agenda hecha al asistente:</p>
<ul>
<li>Cada día a las 9: resume los correos de ayer</li>
<li>Cada lunes: recuérdame lo importante de la semana</li>
<li>Cada noche: archiva las notas del día</li>
</ul>
<p><strong>Heartbeat</strong> significa que el asistente despierta a intervalos fijos, por ejemplo cada 30 minutos, comprueba si hay algo que hacer y actúa si hace falta.</p>
<blockquote>
<p>💡 Si ves un log de heartbeat cada 30 minutos, es totalmente normal.</p>
</blockquote>

<h2 id="casos-típicos-de-automatización">Casos típicos de automatización</h2>
<table>
<thead>
<tr>
<th>Tarea programada</th>
<th>Qué hace</th>
</tr>

<tr>

<td>Resume correo, calendario o noticias y te lo envía</td>
</tr>

<td>Te manda tu lista de tareas a la hora indicada</td>
</tr>
<tr>
<td>Monitorización</td>
<td>Revisa una API o una web cada hora y avisa si falla</td>
</tr>
<tr>
<td>Ordenar notas</td>
<td>Convierte notas sueltas en un documento más ordenado cada semana</td>
</tr>
</tbody>
</table>

<h2 id="configurar-cron-desde-el-dashboard">Configurar Cron desde el dashboard</h2>
<p>Abre Control UI → pestaña <strong>Cron</strong>:</p>
<ul>
<li><strong>Add schedule</strong>: escribe la expresión Cron y la tarea</li>
<li><strong>Enable / disable</strong>: pausa o reactiva cualquier job</li>
<li><strong>Run now</strong>: prueba el job al instante sin esperar</li>
</ul>
<hr>
<h2 id="chuleta-rápida-de-sintaxis-cron">Chuleta rápida de sintaxis Cron</h2>
<pre><code>* * * * *
│ │ │ │ └─ día de la semana (0-7, 0 y 7 son domingo)
│ │ │ └─── mes (1-12)
│ │ └───── día del mes (1-31)
│ └─────── hora (0-23)
└───────── minuto (0-59)
</code></pre>
<p>Ejemplos comunes:</p>
<pre><code>0 9 * * *      ← todos los días a las 9:00
0 9 * * 1      ← cada lunes a las 9:00
0 */6 * * *    ← cada 6 horas
</code></pre>
<hr>
<h2 id="no-se-ejecutó-el-job-revisa-esto-primero">¿No se ejecutó el job? Revisa esto primero</h2>
<ol>
<li>¿Cron está habilitado en la Config?</li>
<li>¿La zona horaria es correcta?</li>
<li>¿Los logs muestran un error? Ejecuta <code>openclaw logs --follow</code></li>
<li>Prueba reiniciar el Gateway</li>
</ol>
<blockquote>
<p>⚠️ Los jobs programados también consumen recursos del modelo. Si ejecutas muchos jobs y muchas conversaciones a la vez, puedes golpear límites como HTTP 429. Para trabajos pesados, mejor un agente dedicado.</p>
</blockquote>
