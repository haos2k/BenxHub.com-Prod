<p>No necesitas mucho, pero estas dos sí o sí:</p>
<p><strong>1. Node.js (versión LTS)</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">node</span><span style="color:#79B8FF"> --version</span></span>

<p><strong>2. Una API key para el modelo</strong></p>
<p>Si usas modelos en la nube como Anthropic Claude u OpenAI, necesitas API key. Si quieres quedarte 100% offline, puedes usar un modelo local. Esta serie asume un modelo en la nube.</p>
<blockquote>
<p>💡 ¿No sabes cómo conseguir la API key? Busca algo como "Anthropic API key" y normalmente en pocos minutos lo resuelves.</p>
</blockquote>

<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># Sigue los comandos de Quick Start en docs.openclaw.ai</span></span>

<p>Después de instalar, ejecuta:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">openclaw</span><span style="color:#9ECBFF"> gateway</span></span></code></pre></figure>

</blockquote>
