<h2 id="dos-cosas-que-debes-revisar-antes-de-instalar">Dos cosas que debes revisar antes de instalar</h2>
<p>No necesitas mucho, pero estas dos sí o sí:</p>
<p><strong>1. Node.js (versión LTS)</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">node</span><span style="color:#79C0FF"> --version</span></span>
<span data-line=""><span style="color:#8B949E"># Si ves un número de versión, todo bien</span></span></code></pre></figure>
<p><strong>2. Una API key para el modelo</strong></p>
<p>Si usas modelos en la nube como Anthropic Claude u OpenAI, necesitas API key. Si quieres quedarte 100% offline, puedes usar un modelo local. Esta serie asume un modelo en la nube.</p>
<blockquote>
<p>💡 ¿No sabes cómo conseguir la API key? Busca algo como "Anthropic API key" y normalmente en pocos minutos lo resuelves.</p>
</blockquote>

<h2 id="instalar-openclaw">Instalar OpenClaw</h2>
<p>La documentación oficial recomienda la <strong>instalación basada en git</strong>, porque luego es más fácil actualizar y depurar.</p>
<p><strong>macOS / Linux</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># Sigue los comandos de Quick Start en docs.openclaw.ai</span></span>

<p><strong>Windows</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># Primero confirma que Git está instalado y en PATH</span></span>
<span data-line=""><span style="color:#FFA657">git</span><span style="color:#79C0FF"> --version</span></span>

<span data-line=""><span style="color:#8B949E"># Luego sigue la guía de instalación para Windows en docs.openclaw.ai</span></span></code></pre></figure>

</blockquote>

<h2 id="primer-arranque-nace-tu-asistente">Primer arranque: nace tu asistente</h2>
<p>Después de instalar, ejecuta:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">openclaw</span><span style="color:#A5D6FF"> gateway</span></span></code></pre></figure>
<p><strong>La primera ejecución abre el asistente de onboarding</strong>, que te pregunta:</p>
<ol>
<li>¿Qué modelo de IA quieres usar?</li>
<li>¿Cuál es tu API key?</li>
<li>¿Dónde quieres guardar el workspace?</li>
</ol>
<p>Responde eso y OpenClaw te crea el primer asistente.</p>
<blockquote>
<p>💡 ¿Se queda mucho rato en "wake up my friend"? Revisa la API key, la conexión de red y los mensajes de error del terminal.</p>
</blockquote>

<li>Tu primer asistente de IA ya funcionando</li>
