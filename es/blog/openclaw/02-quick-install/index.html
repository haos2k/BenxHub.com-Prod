Instala OpenClaw en 5 minutos: guía sin atascarte en el primer arranque

8 3月 2026·3 min read

La mayoría de tutoriales pierde a la gente justo aquí. El objetivo de este: que te salga bien a la primera.

Qué vas a aprender

  • Comprobar los requisitos previos
  • Instalar OpenClaw
  • Completar el onboarding y crear tu primer asistente
  • Abrir el dashboard correctamente

Dos cosas que debes revisar antes de instalar

No necesitas mucho, pero estas dos sí o sí:

1. Node.js (versión LTS)

2. Una API key para el modelo

Si usas modelos en la nube como Anthropic Claude u OpenAI, necesitas API key. Si quieres quedarte 100% offline, puedes usar un modelo local. Esta serie asume un modelo en la nube.

💡 ¿No sabes cómo conseguir la API key? Busca algo como "Anthropic API key" y normalmente en pocos minutos lo resuelves.

Instalar OpenClaw

La documentación oficial recomienda la instalación basada en git, porque luego es más fácil actualizar y depurar.

macOS / Linux

Windows

⚠️ ¿Atascado con "git not found" o "openclaw no se reconoce"? Añade Git al PATH del sistema, reinicia la terminal y vuelve a probar.

Primer arranque: nace tu asistente

Después de instalar, ejecuta:

La primera ejecución abre el asistente de onboarding, que te pregunta:

  1. ¿Qué modelo de IA quieres usar?
  2. ¿Cuál es tu API key?
  3. ¿Dónde quieres guardar el workspace?

Responde eso y OpenClaw te crea el primer asistente.

💡 ¿Se queda mucho rato en "wake up my friend"? Revisa la API key, la conexión de red y los mensajes de error del terminal.

¿Qué obtienes al terminar el onboarding?

  • Un token para entrar al dashboard
  • El archivo base de configuración: ~/.openclaw/openclaw.json
  • Tu primer asistente de IA ya funcionando

Abre el dashboard

Con el gateway todavía en marcha, abre el navegador:

http://127.0.0.1:18789/

Situaciones comunes

Lo que ves Qué hacer
pairing required Ejecuta openclaw devices list y luego openclaw devices approve <id>
Pide token Pega el token del onboarding
No responde Comprueba que openclaw gateway sigue corriendo
