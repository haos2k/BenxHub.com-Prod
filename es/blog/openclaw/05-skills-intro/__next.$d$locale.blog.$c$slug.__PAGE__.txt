3:Tf16,<p>Un asistente que solo sabe conversar es como contratar a una persona brillante y no darle herramientas. Talento desperdiciado.</p>
<p>Las <strong>Skills</strong> son la forma de equiparlo para hacer cosas reales.</p>

<ul>
<li>Entender qué es una Skill</li>

</ul>
<hr>
<h2 id="qué-es-una-skill">¿Qué es una Skill?</h2>
<p>Una Skill suele ser un documento llamado <code>SKILL.md</code> que explica:</p>
<ul>
<li>Qué puede hacer</li>
<li>Cuándo conviene usarla</li>
<li>Qué herramientas y pasos puede seguir</li>
</ul>
<p>Piénsalo como <strong>el manual de trabajo del asistente</strong>. Si le das un manual para navegar por la web, podrá buscar información. Si le das uno para leer y escribir archivos, podrá organizar documentos.</p>
<hr>
<h2 id="integradas-vs-personalizadas">Integradas vs personalizadas</h2>
<p>OpenClaw trae varias Skills integradas y la comunidad sigue aportando más. Puedes:</p>
<ul>
<li><strong>Usar las integradas directamente</strong> desde el dashboard</li>
<li><strong>Escribir la tuya</strong> con un simple archivo <code>SKILL.md</code></li>
</ul>
<hr>
<h2 id="la-forma-inteligente-de-crear-skills-propias">La forma inteligente de crear Skills propias</h2>
<p>Si quieres modificar o añadir una Skill, <strong>no toques los archivos originales del repo de OpenClaw</strong>. La próxima actualización puede sobrescribirlos.</p>
<p>Pon tu versión aquí:</p>
<pre><code>~/.openclaw/skills/&#x3C;nombre-skill>/SKILL.md
</code></pre>
<p><strong>Orden de prioridad</strong></p>
<pre><code>workspace/skills  →  ~/.openclaw/skills  →  integradas  →  extraDirs
</code></pre>
<p>La primera coincidencia gana.</p>
<hr>
<h2 id="gestionar-skills-desde-el-dashboard">Gestionar Skills desde el dashboard</h2>
<p>Abre Control UI → pestaña <strong>Skills</strong>. Desde ahí puedes:</p>
<ul>
<li>Ver todas las Skills disponibles</li>
<li>Activarlas o desactivarlas con un clic</li>
<li>Configurar Skills que necesiten API keys</li>
<li>Instalar Skills de la comunidad</li>
</ul>
<p>Después de guardar, OpenClaw normalmente recarga en caliente sin reiniciar el Gateway.</p>
<hr>
<h2 id="cargar-skills-desde-una-carpeta-personalizada">Cargar Skills desde una carpeta personalizada</h2>
<p>Si quieres guardar todas tus Skills en un directorio central:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="json5" data-theme="github-dark"><code data-language="json5" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D">// ~/.openclaw/openclaw.json</span></span>
