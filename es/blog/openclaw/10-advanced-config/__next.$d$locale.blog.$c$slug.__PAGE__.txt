3:T1e7d,<p>Si llegaste hasta aquí, ya montaste OpenClaw desde cero hasta tenerlo funcionando. Nada mal.</p>
<p>Este artículo final reúne los hábitos que vuelven tu sistema más estable y más fácil de mantener.</p>
<h2 id="qué-vas-a-aprender">Qué vas a aprender</h2>
<ul>
<li>Encontrar el archivo de configuración y entender sus dos modos de edición</li>
<li>Reconocer la forma de una configuración mínima funcional</li>
<li>Guardar API keys con variables de entorno</li>
<li>Usar el comando de debugging más útil e interpretar errores comunes</li>
<li>Elegir la rama de versión adecuada</li>
</ul>
<hr>
<h2 id="dónde-está-el-archivo-de-configuración">¿Dónde está el archivo de configuración?</h2>
<pre><code>~/.openclaw/openclaw.json
</code></pre>
<p>El formato es <strong>JSON5</strong>, así que permite comentarios y comas finales. Mucho más amable que JSON puro.</p>
<p>Puedes editarlo de dos maneras:</p>
<ul>
<li>En <strong>modo formulario</strong> dentro de Control UI si quieres algo más amigable</li>
<li>En <strong>Raw JSON</strong> si quieres precisión y rapidez</li>
</ul>
<p>Ambos modos editan exactamente el mismo archivo.</p>
<hr>

<h2 id="la-forma-correcta-de-guardar-api-keys">La forma correcta de guardar API keys</h2>
<p><strong>Evita meter la API key directamente en la config si puedes.</strong></p>
<p>Las variables de entorno son más seguras:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># Pon esto en .env o en el entorno del sistema</span></span>
<span data-line=""><span style="color:#E6EDF3">ANTHROPIC_API_KEY</span><span style="color:#FF7B72">=</span><span style="color:#A5D6FF">sk-ant-xxxxx</span></span></code></pre></figure>
<blockquote>
<p>⚠️ Si el Gateway corre como servicio del sistema, por ejemplo con <code>systemd</code>, asegúrate de que ese servicio carga tu <code>.env</code>. Si no, el asistente puede fallar porque no ve la API key y aparecerán errores como "Shell env off".</p>
</blockquote>

<table>
<thead>
<tr>
<th>Error</th>
<th>Causa probable</th>
</tr>

<tr>
<td><code>HTTP 429</code></td>
<td>Demasiadas peticiones a la API; rate limit</td>
</tr>
<tr>
<td><code>unauthorized</code></td>
<td>Problema con token o con <code>gateway.bind</code></td>
</tr>
<tr>
<td><code>content tool_use input field required</code></td>
<td>Incompatibilidad de modelo; revisa la documentación</td>
</tr>
<tr>
<td>Contexto truncado</td>
<td>Abre una sesión nueva o compacta el contexto</td>
</tr>
</tbody>
</table>
