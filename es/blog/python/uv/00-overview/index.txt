1a:Tb76,<p>uv es una <strong>herramienta ultrarrápida para gestión de paquetes y proyectos Python</strong> construida en Rust por Astral. Integra instalación de dependencias, entornos virtuales, gestión de versiones de Python y ejecución de herramientas CLI en un solo binario.</p>
<p>Comparado con pip, poetry y pipenv, uv destaca por <strong>velocidad 10-100x</strong>, menor uso de disco y un flujo unificado.</p>
<h2 id="casos-de-uso">Casos de uso</h2>
<ul>
<li><strong>Crear proyecto nuevo desde cero</strong>: <code>uv init</code></li>
<li><strong>Migrar desde requirements.txt</strong>: <code>uv pip compile</code> y <code>uv add -r</code></li>
<li><strong>Dependencias temporales para scripts</strong>: <code>uv run --with rich script.py</code></li>
<li><strong>Ejecutar herramientas CLI</strong>: <code>uvx ruff</code></li>
<li><strong>No recomendado</strong>: proyectos legacy en Python 2</li>
</ul>
