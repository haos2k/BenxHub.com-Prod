<h2 id="prácticas-recomendadas">Prácticas recomendadas</h2>
<h3 id="1-commitear-siempre-uvlock">1) Commitear siempre <code>uv.lock</code></h3>
<p>Es la base de reproducibilidad entre máquinas, equipo y CI.</p>
<h3 id="2-nunca-commitear-venv">2) Nunca commitear <code>.venv</code></h3>
<p>Es artefacto local y debe estar en <code>.gitignore</code>.</p>
<h3 id="3-acotar-versiones-de-dependencias">3) Acotar versiones de dependencias</h3>
<p>Evita <code>requests</code> sin rango; mejor <code>requests>=2.31,&#x3C;3</code>.</p>
<h3 id="4-en-ci-usar-uv-sync-o-uv-pip-sync">4) En CI usar <code>uv sync</code> o <code>uv pip sync</code></h3>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="yaml" data-theme="github-dark"><code data-language="yaml" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#E1E4E8">- </span><span style="color:#85E89D">run</span><span style="color:#E1E4E8">: </span><span style="color:#9ECBFF">uv sync</span></span>
<span data-line=""><span style="color:#E1E4E8">- </span><span style="color:#85E89D">run</span><span style="color:#E1E4E8">: </span><span style="color:#9ECBFF">uv run pytest</span></span></code></pre></figure>
<p>Primero sincronizar, luego ejecutar.</p>
<h3 id="5-herramientas-de-desarrollo-en---dev">5) Herramientas de desarrollo en <code>--dev</code></h3>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">uv</span><span style="color:#9ECBFF"> add</span><span style="color:#79B8FF"> --dev</span><span style="color:#9ECBFF"> pytest</span><span style="color:#9ECBFF"> ruff</span><span style="color:#9ECBFF"> mypy</span></span></code></pre></figure>
<h2 id="errores-comunes">Errores comunes</h2>
<h3 id="error-1-mezclar-pip-install-y-uv-add">Error 1: mezclar <code>pip install</code> y <code>uv add</code></h3>
<p>Puede desincronizar lockfile y entorno.</p>
<h3 id="error-2-usar-uvx-para-tools-del-proyecto">Error 2: usar <code>uvx</code> para tools del proyecto</h3>
<p>Tools fijadas por versión del proyecto -> <code>uv add --dev</code> + <code>uv run</code>.</p>
<h3 id="error-3-editar-pyproject-manual-sin-cuidado">Error 3: editar pyproject manual sin cuidado</h3>
<p>Para dependencias, preferir <code>uv add</code> / <code>uv remove</code>.</p>
<h3 id="error-4-no-instalar-uv-en-ci">Error 4: no instalar uv en CI</h3>
<p>Instala uv oficialmente y evita resolver todo con pip tradicional.</p>
<h3 id="error-5-no-definir-requires-python">Error 5: no definir <code>requires-python</code></h3>
<p>Especifica versión mínima para evitar incompatibilidades.</p>
<hr>
<p>Este checklist no elimina todos los incidentes, pero reduce muchos errores evitables.</p>
