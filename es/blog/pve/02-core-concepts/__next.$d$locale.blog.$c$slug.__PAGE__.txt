<h2 id="concepto-1-diferencia-entre-vm-y-lxc">Concepto 1: diferencia entre VM y LXC</h2>
<table>
<thead>
<tr>
<th>Tipo</th>
<th>Tecnología</th>
<th>Características</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>VM</strong></td>
<td>KVM/QEMU</td>
<td>Sistema completo, alta aislación, corre Windows y Linux</td>
</tr>
<tr>
<td><strong>LXC</strong></td>
<td>Linux Containers</td>
<td>Ligero, arranque rápido, alta densidad, pero <strong>solo Linux</strong></td>
</tr>
</tbody>
</table>
<p>Regla rápida: necesitas aislación total o Windows -> VM; quieres eficiencia y servicio Linux -> LXC.</p>

<h2 id="concepto-2-almacenamiento-define-tus-límites">Concepto 2: almacenamiento define tus límites</h2>
<p>Elegir mal storage te limita en HA y migraciones.</p>
<ul>
<li><strong>local</strong>: almacenamiento local de un nodo</li>
<li><strong>local-lvm</strong>: LVM local, útil para snapshot y clone</li>
<li><strong>NFS/CIFS</strong>: almacenamiento compartido de red</li>
<li><strong>ZFS/Ceph</strong>: opciones avanzadas con replicación y HA</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">pvesm</span><span style="color:#9ECBFF"> status</span></span>
<span data-line=""><span style="color:#B392F0">pvesm</span><span style="color:#9ECBFF"> list</span><span style="color:#9ECBFF"> local</span></span></code></pre></figure>
<blockquote>
<p>Para live migration o HA, los discos suelen necesitar <strong>shared storage</strong>.</p>
</blockquote>
<h2 id="concepto-3-modelo-de-red-vmbr0">Concepto 3: modelo de red (vmbr0)</h2>
<p>PVE usa red tipo bridge: <code>vmbr0</code> puentea a NIC física y hace que las VMs parezcan conectadas al switch físico.</p>
