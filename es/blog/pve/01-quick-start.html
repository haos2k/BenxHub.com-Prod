Inicio rápido de Proxmox VE: crea tu primera VM

24 2月 2026·2 min read

Esta guía toma la ruta más corta para crear una máquina virtual Debian arrancable en PVE.

Requisitos previos

  • CPU 64-bit con Intel VT-x o AMD-V habilitado
  • Mínimo 2 GB RAM (recomendado 8 GB+)
  • Al menos una tarjeta de red funcional
  • Host/servidor que pueda arrancar por USB

Ejemplo mínimo: crear tu primera VM

Paso 1: login en interfaz web

Después de instalar, abre https://<PVE-IP>:8006 e inicia con root y tu contraseña.

Paso 2: descargar imagen de sistema

  1. En panel izquierdo, selecciona local
  2. Ve a Content y haz click en Download from URL
  3. Ingresa:
    • URL: https://cloud.debian.org/images/cloud/bookworm/latest/debian-12-generic-amd64.qcow2
    • File Name: debian-12-cloud.qcow2
  4. Click en Query URL e inicia descarga

Paso 3: crear la VM

  1. Click Create VM
  2. General: Name = test-vm
  3. OS: para cloud image puedes omitir disco ISO
  4. Disks: elige Use existing disk image y selecciona debian-12-cloud.qcow2
  5. CPU: 1 vCPU
  6. Memory: 512-1024 MB
  7. Network: deja vmbr0 por defecto
  8. Confirm -> Finish

Paso 4: arrancar y verificar

  1. Clic derecho en VM -> Start
  2. Abre Console (noVNC)
  3. Si ves pantalla de arranque/login de Debian, éxito

Troubleshooting común

Síntoma Revisar
No accede a interfaz web Puerto 8006 y estado de pveproxy
VM no arranca VT-x / AMD-V en BIOS
No aparece imagen Verifica descarga completa en local -> Content
VM sin red Revisar enlace de vmbr0 con NIC física
