3:Te51,<p>Algunos consejos prácticos y respuestas a las preguntas más frecuentes — resuelve "¿dónde me quedé?" y "¿por qué no puedo usar esto?" de una vez.</p>
<h2 id="consejos">Consejos</h2>
<h3 id="1-retomar-la-conversación-anterior">1. Retomar la conversación anterior</h3>
<p>¿Cerraste a mitad de sesión y quieres seguir donde lo dejaste? No hace falta empezar de cero:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#79C0FF"> --resume</span></span></code></pre></figure>
<p>Esto carga la conversación más reciente con todo el contexto — como darle a "reanudar" en un vídeo pausado.</p>
<h3 id="2-confirmar-antes-de-ejecutar-comandos">2. Confirmar antes de ejecutar comandos</h3>
<p>El Agent puede querer ejecutar comandos como <code>npm install</code> o <code>git</code>.</p>
<ul>
<li><strong>Modo interactivo</strong>: te preguntará antes</li>
<li>Si eres prudente, díselo en la conversación: "Pregúntame antes de ejecutar cualquier comando"</li>
</ul>
<p>Así no tendrás momentos de "espera, ¿cuándo ejecutó eso?".</p>
<h3 id="3-usar-cli-e-ide-a-la-vez">3. Usar CLI e IDE a la vez</h3>
<p>La CLI y la ventana de Cursor <strong>pueden usarse al mismo tiempo</strong> — no es uno u otro:</p>
<ul>
<li>Usa la ventana para el desarrollo principal, explorar el árbol de archivos, autocompletado con Tab</li>
<li>Usa la CLI para tareas pequeñas, consultas, automatización</li>
</ul>
<p>Uno se encarga de la batalla principal, el otro de los escarceos — divide y vencerás.</p>
<h2 id="faq">FAQ</h2>
<p><strong>P: ¿<code>cursor: command not found</code>?</strong>
R: Reinicia la terminal después de instalar, o ejecuta <code>source ~/.zshrc</code> (o <code>~/.bashrc</code>). Asegúrate de que la ruta de instalación esté en tu <code>PATH</code> — el clásico "instalé la herramienta pero el sistema no la encuentra" casi siempre es un problema de PATH.</p>
<p><strong>P: ¿La CLI es de pago?</strong>
R: Sí. Necesitas una suscripción a Cursor para usar la CLI — es la misma suscripción que el IDE.</p>
<p><strong>P: ¿Puedo usarla en un servidor / en Docker?</strong>
R: Sí. Los requisitos son: poder ejecutar el script de instalación y poder iniciar sesión en Cursor (o configurar un token). Cuidado con la red y la autorización — no esperes que llegue a la nube de Cursor en un entorno de red restringido.</p>
<p><strong>P: ¿Es lo mismo que el Agent en la ventana de Cursor?</strong>
R: Es la misma capacidad subyacente. La diferencia es que la CLI es una interfaz de terminal, soporta modo no interactivo y se integra con scripts y CI — mismo AI, interfaz distinta.</p>
<h2 id="resumen">Resumen</h2>
<ul>
<li><strong>Retomar conversación</strong>: <code>cursor agent --resume</code></li>
<li><strong>Confirmación de comandos</strong>: puedes pedirle "confirmar antes de ejecutar cualquier comando"</li>
<li><strong>CLI e IDE</strong>: pueden usarse juntos, no son excluyentes</li>
<li><strong>Si te atascas</strong>: revisa <code>cursor --help</code> y la documentación oficial — la mayoría de problemas tienen solución conocida</li>
</ul>
