3:T17dd,<p><a href="05-tips">05-tips</a> ya mencionó <code>cursor agent --resume</code> para continuar la última conversación. Este post completa <strong>sesiones</strong> y <strong>ejecución en la nube</strong>: cómo listar conversaciones pasadas, cuál reanudar, y usar <strong><code>-c</code></strong> para ejecutar una tarea en la nube y que siga tras cerrar la terminal o el equipo.</p>
<h2 id="reanudar-sesión---resume">Reanudar sesión: --resume</h2>
<p>Cerraste la terminal a mitad de conversación o la tarea era larga y la paraste — la próxima vez quieres seguir en el mismo hilo:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#79C0FF"> --resume</span></span></code></pre></figure>
<p>Carga la conversación <strong>más reciente</strong>; el contexto y las instrucciones anteriores siguen ahí, no hace falta volver a describir la petición.</p>
<h3 id="reanudar-una-conversación-concreta">Reanudar una conversación concreta</h3>
<p>Si tienes más de una conversación y quieres reanudar <strong>una en particular</strong>:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#79C0FF"> --resume=chat-id-here</span></span></code></pre></figure>
<p>Obtén el <code>chat-id</code> de "listar conversaciones", abajo.</p>
<h2 id="listar-todas-las-conversaciones-cursor-agent-ls">Listar todas las conversaciones: cursor agent ls</h2>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#A5D6FF"> ls</span></span></code></pre></figure>
<p>Lista conversaciones pasadas (con ID o identificador). Localiza la que quieras y pasa su ID a <code>--resume=ID</code>.</p>

<td>Reanudar la más reciente</td>

<h2 id="ejecución-en-la-nube--c----cloud">Ejecución en la nube: -c / --cloud</h2>
<p>Algunas tareas son pesadas: análisis de todo el repo, generación de documentación grande, refactors en varios pasos. Ejecutar en local implica tener la terminal abierta; cerrar el portátil o perder la conexión detiene la ejecución.</p>
<p>Con <strong><code>-c</code></strong> (o <strong><code>--cloud</code></strong>) pasas <strong>esta conversación</strong> a un Agent en la nube:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#A5D6FF"> "Analyze the whole project and write architecture doc to docs/architecture.md"</span><span style="color:#79C0FF"> -c</span></span></code></pre></figure>
<ul>
<li>Tras enviarlo, la tarea se ejecuta en la nube de Cursor</li>
<li>Puedes cerrar la terminal, apagar o cambiar a otra cosa</li>
<li>Más tarde, desde cualquier dispositivo con la misma cuenta de Cursor, usa <code>--resume</code> para volver a esa conversación y ver el resultado o añadir más instrucciones</li>
</ul>
<p>Así <strong><code>-c</code></strong> = "ejecutar en la nube; no tengo que esperar delante del ordenador."</p>
<h3 id="cuándo-usar--c">¿Cuándo usar -c?</h3>
<table>
<thead>
<tr>
<th>Situación</th>
<th>Sugerencia</th>
</tr>
</thead>
<tbody>
<tr>
<td>La tarea va a tardar mucho</td>
<td>Usa <code>-c</code> para que corra en la nube; puede terminar tras cerrar</td>
</tr>
<tr>
<td>Pregunta rápida o edición pequeña</td>
<td>Prescinde de <code>-c</code>; ejecuta en local</td>
</tr>
<tr>
<td>Red inestable o prefieres no depender de la nube</td>
<td>Ejecuta en local, pero mantén la conexión</td>
</tr>
</tbody>
</table>
<h2 id="sesiones-y-nube-juntas">Sesiones y nube juntas</h2>
<p>Flujo típico:</p>
<ol>
<li>Inicia una tarea con <code>-c</code> para que corra en la nube</li>
<li>Cierra la terminal</li>
<li>Más tarde ejecuta <code>cursor agent ls</code> para encontrar esa conversación</li>
<li><code>cursor agent --resume=that-id</code> para volver a unirte, ver el resultado o enviar más instrucciones</li>
</ol>
<p>Así cubres "tareas largas" y "varios dispositivos / apagado".</p>
<h2 id="resumen">Resumen</h2>
<ul>
<li><strong><code>cursor agent ls</code></strong>: Listar conversaciones para encontrar la que reanudar</li>
<li><strong><code>--resume</code></strong>: Reanudar la última; <strong><code>--resume=ID</code></strong>: Reanudar una conversación concreta</li>
<li><strong><code>-c</code> / <code>--cloud</code></strong>: Ejecutar la tarea actual en la nube; puedes cerrar la terminal y reanudar después con <code>--resume</code></li>
</ul>
