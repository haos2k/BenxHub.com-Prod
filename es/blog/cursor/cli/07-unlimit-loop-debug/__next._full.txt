1b:T42b4,<p>Escribe un script de shell que haga que <code>cursor agent</code> arregle el código automáticamente, ejecute los tests y si fallan deje que la IA arregle de nuevo — <strong>repitiendo hasta que pasen todos los tests</strong>. No hace falta quedarse pulsando Y/N. Delega el bucle a la IA y haz otra cosa — vuelve cuando la terminal muestre "tests passed."</p>
<h2 id="concepto-central">Concepto central</h2>
<pre><code>while tests don't pass:
    run tests → collect error output
    feed error output to cursor agent
    cursor agent fixes the code
    run tests again
</code></pre>
<p>Es un bucle "ejecutar tests → fallar → decir a la IA que arregle → repetir" hasta que pasen. Simple y directo, pero efectivo.</p>
<h2 id="paso-1-comprobar-requisitos">Paso 1: Comprobar requisitos</h2>
<ul>
<li><code>cursor</code> está instalado y con sesión iniciada (<code>cursor --version</code> para comprobar)</li>
<li>El proyecto tiene un <strong>comando de tests que se ejecuta en la terminal</strong>, por ejemplo:
<ul>
<li><code>npm test</code></li>
<li><code>pytest</code></li>
<li><code>go test ./...</code></li>
<li><code>cargo test</code></li>
</ul>
</li>
<li>Los tests devuelven código de salida distinto de cero al fallar (casi todos los frameworks lo hacen por defecto)</li>
</ul>

<h2 id="resumen">Resumen</h2>
<ol>
<li><strong>Estructura del script</strong>: ejecutar tests → fallar → pasar a la IA → repetir hasta pasar o límite</li>
<li><strong>Parámetros clave</strong>: <code>TEST_CMD</code> (comando de tests), <code>MAX_LOOPS</code> (máximo de iteraciones)</li>
<li><strong>Sé concreto en el prompt</strong>: indica el lenguaje, restringe qué directorios modificar, no tocar tests</li>
<li><strong><code>git commit</code> antes</strong> — fácil de revertir si algo sale mal y más tranquilidad</li>
</ol>

26:T42b4,<p>Escribe un script de shell que haga que <code>cursor agent</code> arregle el código automáticamente, ejecute los tests y si fallan deje que la IA arregle de nuevo — <strong>repitiendo hasta que pasen todos los tests</strong>. No hace falta quedarse pulsando Y/N. Delega el bucle a la IA y haz otra cosa — vuelve cuando la terminal muestre "tests passed."</p>
<h2 id="concepto-central">Concepto central</h2>
<pre><code>while tests don't pass:
    run tests → collect error output
    feed error output to cursor agent
    cursor agent fixes the code
    run tests again
</code></pre>
<p>Es un bucle "ejecutar tests → fallar → decir a la IA que arregle → repetir" hasta que pasen. Simple y directo, pero efectivo.</p>
<h2 id="paso-1-comprobar-requisitos">Paso 1: Comprobar requisitos</h2>
<ul>
<li><code>cursor</code> está instalado y con sesión iniciada (<code>cursor --version</code> para comprobar)</li>
<li>El proyecto tiene un <strong>comando de tests que se ejecuta en la terminal</strong>, por ejemplo:
<ul>
<li><code>npm test</code></li>
<li><code>pytest</code></li>
<li><code>go test ./...</code></li>
<li><code>cargo test</code></li>
</ul>
</li>
<li>Los tests devuelven código de salida distinto de cero al fallar (casi todos los frameworks lo hacen por defecto)</li>
</ul>
<h2 id="paso-2-el-script-más-simple">Paso 2: El script más simple</h2>
<p>Crea <code>debug-loop.sh</code>:</p>

<span data-line=""> </span>
<span data-line=""><span style="color:#E1E4E8">MAX_LOOPS</span><span style="color:#F97583">=</span><span style="color:#9ECBFF">10</span><span style="color:#6A737D">        # max iterations to prevent truly infinite loops</span></span>
<span data-line=""><span style="color:#E1E4E8">TEST_CMD</span><span style="color:#F97583">=</span><span style="color:#9ECBFF">"npm test"</span><span style="color:#6A737D"> # replace with your test command</span></span>

<span data-line=""> </span>
<span data-line=""><span style="color:#F97583">while</span><span style="color:#E1E4E8"> [ $loop </span><span style="color:#F97583">-lt</span><span style="color:#E1E4E8"> $MAX_LOOPS ]; </span><span style="color:#F97583">do</span></span>
<span data-line=""><span style="color:#79B8FF">  echo</span><span style="color:#9ECBFF"> ""</span></span>
<span data-line=""><span style="color:#79B8FF">  echo</span><span style="color:#9ECBFF"> "=== Loop $((</span><span style="color:#B392F0">loop</span><span style="color:#9ECBFF"> + </span><span style="color:#79B8FF">1</span><span style="color:#9ECBFF">)) ==="</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#6A737D">  # run tests and capture stdout + stderr</span></span>
<span data-line=""><span style="color:#E1E4E8">  TEST_OUTPUT</span><span style="color:#F97583">=</span><span style="color:#E1E4E8">$(</span><span style="color:#79B8FF">eval</span><span style="color:#9ECBFF"> "</span><span style="color:#E1E4E8">$TEST_CMD</span><span style="color:#9ECBFF">"</span><span style="color:#F97583"> 2>&#x26;1</span><span style="color:#E1E4E8">)</span></span>

<span data-line=""><span style="color:#79B8FF">    echo</span><span style="color:#9ECBFF"> "✅ Tests passed! Completed in $((</span><span style="color:#B392F0">loop</span><span style="color:#9ECBFF"> + </span><span style="color:#79B8FF">1</span><span style="color:#9ECBFF">)) loop(s)."</span></span>

<span data-line=""><span style="color:#F97583">  fi</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#79B8FF">  echo</span><span style="color:#9ECBFF"> "❌ Failed. Log saved to </span><span style="color:#E1E4E8">$LOG_FILE</span><span style="color:#9ECBFF">"</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#B392F0">  cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "Tests failed with the following errors. Please fix the code to make the tests pass:</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#E1E4E8">$TEST_OUTPUT</span><span style="color:#9ECBFF">"</span><span style="color:#79B8FF"> --model</span><span style="color:#9ECBFF"> gpt-codex-5.3-high</span><span style="color:#79B8FF"> --no-interactive</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#E1E4E8">  loop</span><span style="color:#F97583">=</span><span style="color:#E1E4E8">$((</span><span style="color:#B392F0">loop</span><span style="color:#9ECBFF"> +</span><span style="color:#79B8FF"> 1</span><span style="color:#E1E4E8">))</span></span>
<span data-line=""><span style="color:#F97583">done</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#79B8FF">echo</span><span style="color:#9ECBFF"> "⚠️  Reached max loops. Stopping. Check the logs in </span><span style="color:#E1E4E8">$LOG_DIR</span><span style="color:#9ECBFF">/."</span></span>
<span data-line=""><span style="color:#79B8FF">exit</span><span style="color:#79B8FF"> 1</span></span></code></pre></figure>
<p>Útil para revisar "qué falló en qué iteración" después.</p>
<h2 id="consideraciones-de-seguridad">Consideraciones de seguridad</h2>
<table>
<thead>
<tr>
<th>Riesgo</th>
<th>Cómo mitigar</th>
</tr>
</thead>
<tbody>
<tr>
<td>La IA rompe más archivos</td>
<td><code>git commit</code> antes para guardar estado, <code>git checkout .</code> para revertir si hace falta</td>
</tr>
<tr>
<td>Demasiadas iteraciones gastan cuota</td>
<td>Pon un <code>MAX_LOOPS</code> razonable (5–15 recomendado)</td>
</tr>
<tr>
<td>La IA modifica archivos de test</td>
<td>Di explícitamente en el prompt "do not modify test files"</td>
</tr>
<tr>
<td>Fallos distintos en cada iteración</td>
<td>Guarda logs (versión mejorada) para analizar después</td>
</tr>
</tbody>
</table>
<h2 id="resumen">Resumen</h2>
<ol>
<li><strong>Estructura del script</strong>: ejecutar tests → fallar → pasar a la IA → repetir hasta pasar o límite</li>
<li><strong>Parámetros clave</strong>: <code>TEST_CMD</code> (comando de tests), <code>MAX_LOOPS</code> (máximo de iteraciones)</li>
<li><strong>Sé concreto en el prompt</strong>: indica el lenguaje, restringe qué directorios modificar, no tocar tests</li>
<li><strong><code>git commit</code> antes</strong> — fácil de revertir si algo sale mal y más tranquilidad</li>
</ol>
