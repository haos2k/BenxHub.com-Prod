Cursor CLI consejos y FAQ

24 2月 2026·3 min read

Algunos consejos prácticos y respuestas a las preguntas más frecuentes — resuelve "¿dónde me quedé?" y "¿por qué no puedo usar esto?" de una vez.

Consejos

1. Retomar la conversación anterior

¿Cerraste a mitad de sesión y quieres seguir donde lo dejaste? No hace falta empezar de cero:

Esto carga la conversación más reciente con todo el contexto — como darle a "reanudar" en un vídeo pausado.

2. Confirmar antes de ejecutar comandos

El Agent puede querer ejecutar comandos como npm install o git.

  • Modo interactivo: te preguntará antes
  • Si eres prudente, díselo en la conversación: "Pregúntame antes de ejecutar cualquier comando"

Así no tendrás momentos de "espera, ¿cuándo ejecutó eso?".

3. Usar CLI e IDE a la vez

La CLI y la ventana de Cursor pueden usarse al mismo tiempo — no es uno u otro:

  • Usa la ventana para el desarrollo principal, explorar el árbol de archivos, autocompletado con Tab
  • Usa la CLI para tareas pequeñas, consultas, automatización

Uno se encarga de la batalla principal, el otro de los escarceos — divide y vencerás.

FAQ

P: ¿cursor: command not found? R: Reinicia la terminal después de instalar, o ejecuta source ~/.zshrc (o ~/.bashrc). Asegúrate de que la ruta de instalación esté en tu PATH — el clásico "instalé la herramienta pero el sistema no la encuentra" casi siempre es un problema de PATH.

P: ¿La CLI es de pago? R: Sí. Necesitas una suscripción a Cursor para usar la CLI — es la misma suscripción que el IDE.

P: ¿Puedo usarla en un servidor / en Docker? R: Sí. Los requisitos son: poder ejecutar el script de instalación y poder iniciar sesión en Cursor (o configurar un token). Cuidado con la red y la autorización — no esperes que llegue a la nube de Cursor en un entorno de red restringido.

P: ¿Es lo mismo que el Agent en la ventana de Cursor? R: Es la misma capacidad subyacente. La diferencia es que la CLI es una interfaz de terminal, soporta modo no interactivo y se integra con scripts y CI — mismo AI, interfaz distinta.

Resumen

  • Retomar conversación: cursor agent --resume
  • Confirmación de comandos: puedes pedirle "confirmar antes de ejecutar cualquier comando"
  • CLI e IDE: pueden usarse juntos, no son excluyentes
  • Si te atascas: revisa cursor --help y la documentación oficial — la mayoría de problemas tienen solución conocida
