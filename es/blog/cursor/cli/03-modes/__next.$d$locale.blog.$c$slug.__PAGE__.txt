3:T11e2,<p>Tres modos, una frase para distinguirlos: <strong>quién puede tocar tu código y quién solo puede hablar</strong>. Cuando lo tengas claro, elegir el modo correcto es fácil.</p>
<h2 id="comparación-en-una-frase">Comparación en una frase</h2>
<table>
<thead>
<tr>
<th>Modo</th>
<th>Una frase</th>
<th>¿Modifica tus archivos?</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>Agent</strong></td>
<td>"Haz" algo por mí</td>
<td>✅ Sí</td>
</tr>
<tr>
<td><strong>Plan</strong></td>
<td>"Planea" cómo hacerlo primero, luego yo decido</td>
<td>Aún no — solo después de que apruebes</td>
</tr>
<tr>
<td><strong>Ask</strong></td>
<td>Solo "pregunta" o consulta algo</td>
<td>❌ No</td>
</tr>
</tbody>
</table>
<p>Piénsalos como tres compañeros: Agent es el que dice "dámelo, yo lo hago"; Plan es el que dice "déjame escribir una propuesta para que la revises"; Ask es el que dice "solo respondo, no toco archivos" — elige a la persona adecuada y te ahorras la mitad de problemas.</p>
<h2 id="modo-agent-por-defecto">Modo Agent (por defecto)</h2>
<p><strong>Caso de uso</strong>: Que la IA edite código directamente, añada funciones o refactorice. Quieres resultados, no discusión.</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#A5D6FF"> "Change login to use JWT"</span></span></code></pre></figure>
<ul>
<li>Lee archivos, edita archivos, puede ejecutar comandos</li>
<li>Puedes aceptar o rechazar cada paso — tú mandas</li>
</ul>
<h2 id="modo-plan">Modo Plan</h2>
<p><strong>Caso de uso</strong>: ¿No sabes cómo enfocar algo o te preocupa que la IA cambie demasiado de golpe? Ve el plan antes de dar el visto bueno.</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#79C0FF"> --plan</span><span style="color:#A5D6FF"> "Refactor the entire API layer"</span></span></code></pre></figure>
<ul>
<li>La IA hará algunas preguntas y propondrá un enfoque</li>
<li>Solo actúa cuando estés de acuerdo — sin sorpresas</li>
</ul>
<p><strong>Cuándo usarlo</strong>: Para cambios grandes, o cuando quieras "verlo claro antes de comprometerte."</p>
<h2 id="modo-ask-solo-lectura">Modo Ask (solo lectura)</h2>
<p><strong>Caso de uso</strong>: Solo quieres preguntar "qué hace este código" o "hay una forma mejor de escribir esto" — y <strong>no quieres que se cambie ningún archivo</strong>.</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> ask</span><span style="color:#A5D6FF"> "What is the logic in src/auth.ts?"</span></span></code></pre></figure>
<ul>
<li>Solo lee, analiza y responde — nunca escribe</li>
<li>Ideal para CI o entornos donde solo quieres inspeccionar, no modificar</li>
</ul>
<h2 id="cambiar-de-modo-a-mitad-de-conversación">Cambiar de modo a mitad de conversación</h2>
<p>¿Ya estás en una conversación de <code>cursor agent</code>? Usa <strong>comandos slash</strong> para cambiar al instante:</p>
<ul>
<li><code>/plan</code> → Cambiar a modo Plan (plan primero, actuar después)</li>
<li><code>/ask</code> → Cambiar a modo Ask (solo lectura, pregunta libremente)</li>
</ul>
<p>No hace falta salir y reiniciar — es como cambiar de marcha sobre la marcha.</p>
<h2 id="resumen">Resumen</h2>
<ul>
<li><strong>Agent</strong>: hace el trabajo, modifica archivos — úsalo cuando quieras resultados</li>
<li><strong>Plan</strong>: planifica primero, actúa solo tras tu aprobación — úsalo cuando quieras seguridad</li>
<li><strong>Ask</strong>: solo preguntas, solo lectura — úsalo cuando quieras respuestas sin cambios</li>
</ul>
