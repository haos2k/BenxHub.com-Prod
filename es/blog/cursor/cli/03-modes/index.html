Cursor CLI tres modos: Agent / Plan / Ask

24 2月 2026·3 min read

Tres modos, una frase para distinguirlos: quién puede tocar tu código y quién solo puede hablar. Cuando lo tengas claro, elegir el modo correcto es fácil.

Comparación en una frase

Modo Una frase ¿Modifica tus archivos?
Agent "Haz" algo por mí ✅ Sí
Plan "Planea" cómo hacerlo primero, luego yo decido Aún no — solo después de que apruebes
Ask Solo "pregunta" o consulta algo ❌ No

Piénsalos como tres compañeros: Agent es el que dice "dámelo, yo lo hago"; Plan es el que dice "déjame escribir una propuesta para que la revises"; Ask es el que dice "solo respondo, no toco archivos" — elige a la persona adecuada y te ahorras la mitad de problemas.

Modo Agent (por defecto)

Caso de uso: Que la IA edite código directamente, añada funciones o refactorice. Quieres resultados, no discusión.

  • Lee archivos, edita archivos, puede ejecutar comandos
  • Puedes aceptar o rechazar cada paso — tú mandas

Modo Plan

Caso de uso: ¿No sabes cómo enfocar algo o te preocupa que la IA cambie demasiado de golpe? Ve el plan antes de dar el visto bueno.

  • La IA hará algunas preguntas y propondrá un enfoque
  • Solo actúa cuando estés de acuerdo — sin sorpresas

Cuándo usarlo: Para cambios grandes, o cuando quieras "verlo claro antes de comprometerte."

Modo Ask (solo lectura)

Caso de uso: Solo quieres preguntar "qué hace este código" o "hay una forma mejor de escribir esto" — y no quieres que se cambie ningún archivo.

  • Solo lee, analiza y responde — nunca escribe
  • Ideal para CI o entornos donde solo quieres inspeccionar, no modificar

Cambiar de modo a mitad de conversación

¿Ya estás en una conversación de cursor agent? Usa comandos slash para cambiar al instante:

  • /plan → Cambiar a modo Plan (plan primero, actuar después)
  • /ask → Cambiar a modo Ask (solo lectura, pregunta libremente)

No hace falta salir y reiniciar — es como cambiar de marcha sobre la marcha.

Resumen

  • Agent: hace el trabajo, modifica archivos — úsalo cuando quieras resultados
  • Plan: planifica primero, actúa solo tras tu aprobación — úsalo cuando quieras seguridad
  • Ask: solo preguntas, solo lectura — úsalo cuando quieras respuestas sin cambios
