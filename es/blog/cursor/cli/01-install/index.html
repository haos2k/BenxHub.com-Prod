Instalar Cursor CLI

24 2月 2026·1 min read

La instalación es sencilla: ejecuta el script oficial en tu terminal y tendrás disponible el comando cursor. Las instrucciones varían según la plataforma.

macOS / Linux / WSL

Ejecuta esto en tu terminal:

  • El script descarga e instala automáticamente el comando cursor
  • Después de instalar, cierra y vuelve a abrir la terminal, o ejecuta source ~/.bashrc / source ~/.zshrc para actualizar tu PATH

Windows (PowerShell)

Abre PowerShell como Administrador y ejecuta:

Verificar la instalación

Si aparece un número de versión, la instalación fue correcta.

Primer uso: iniciar sesión

La primera vez que lo ejecutes puede pedirte iniciar sesión en tu cuenta de Cursor:

Sigue las instrucciones en pantalla para completar el inicio de sesión en el navegador. En el mismo equipo normalmente no tendrás que iniciar sesión de nuevo.

Resumen

  • macOS / Linux: curl ... | bash
  • Windows: Ejecuta irm ... | iex en PowerShell
  • Verificar: cursor --version
  • Iniciar sesión: cursor auth login
