3:Td7f,<h2 id="enfoque-más-común-cursor-agent">Enfoque más común: <code>cursor agent</code></h2>
<p>Ejecuta esto dentro del directorio del proyecto:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "Add a README to this project"</span></span></code></pre></figure>
<ul>
<li><strong>Interactivo</strong>: la IA hará preguntas y sugerencias; puedes aceptar o rechazar cambios</li>
<li><strong>Consciente del contexto</strong>: lee archivos del directorio actual para sus respuestas y ediciones</li>
</ul>
<h2 id="un-solo-comando-vs-conversación">Un solo comando vs. conversación</h2>
<p><strong>Quieres delegar una tarea directamente:</strong> Pon la instrucción entre comillas y envíala de una vez.</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "Refactor the auth module to use JWT"</span></span></code></pre></figure>
<p><strong>Quieres discutir antes de actuar:</strong> Ejecuta <code>cursor agent</code> sin argumentos para entrar en <strong>modo conversación</strong>, donde puedes describir tus requisitos paso a paso y la IA aclarará antes de hacer cambios.</p>
<h2 id="especificar-el-directorio-de-trabajo">Especificar el directorio de trabajo</h2>
<p>Por defecto usa el <strong>directorio actual</strong>. Para especificar una ruta, añade <code>--path</code>:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "Check and fix TypeScript types"</span><span style="color:#79B8FF"> --path</span><span style="color:#9ECBFF"> ./src</span></span></code></pre></figure>
