Uso básico de Cursor CLI

24 2月 2026·2 min read

Enfoque más común: cursor agent

Ejecuta esto dentro del directorio del proyecto:

  • Interactivo: la IA hará preguntas y sugerencias; puedes aceptar o rechazar cambios
  • Consciente del contexto: lee archivos del directorio actual para sus respuestas y ediciones

Un solo comando vs. conversación

Quieres delegar una tarea directamente: Pon la instrucción entre comillas y envíala de una vez.

Quieres discutir antes de actuar: Ejecuta cursor agent sin argumentos para entrar en modo conversación, donde puedes describir tus requisitos paso a paso y la IA aclarará antes de hacer cambios.

Especificar el directorio de trabajo

Por defecto usa el directorio actual. Para especificar una ruta, añade --path:

Referencia rápida de comandos

Comando Descripción
cursor agent "do something" Pide a la IA que lo haga (puede modificar archivos)
cursor agent Entrar en modo conversación sin tarea
cursor ask "question" Solo preguntar, sin editar archivos (solo lectura)
cursor --help Ver todas las opciones disponibles

Resumen

  • Lo más común: cursor agent "tu instrucción"
  • Quieres chatear primero: solo ejecuta cursor agent
  • Preguntar sin editar: usa cursor ask "pregunta"
  • Especificar directorio: añade --path <path>
