3:T3252,<p>El objetivo de este post es simple: <strong>omite la filosofía, simplemente pon Envoy Gateway en marcha.</strong> Si logras llegar al servicio de ejemplo con éxito, ya has hecho más que todos los que siguen atascados en la página de inicio de la documentación.</p>
<h2 id="requisitos-previos">Requisitos Previos</h2>
<p>Necesitas al menos un clúster de Kubernetes funcionando, como:</p>
<ul>
<li>Local: <code>kind</code>, <code>minikube</code>, <code>k3d</code></li>
<li>Cloud: EKS, GKE, AKS</li>
<li>Laboratorio casero: K3s + MetalLB también funciona</li>
</ul>
<p>También necesitarás:</p>
<ul>
<li><code>kubectl</code></li>
<li><code>helm</code></li>
<li>Un clúster que pueda aprovisionar una dirección <code>LoadBalancer</code>, o uno donde estés bien usando <code>port-forward</code></li>
</ul>
<blockquote>
<p>⚠️ Si tu clúster no tiene soporte de <code>LoadBalancer</code>, la documentación oficial recomienda combinarlo con MetalLB. No tener una dirección externa no es el fin del mundo — simplemente harás las pruebas vía <code>port-forward</code>.</p>
</blockquote>
<h2 id="paso-1-instalar-envoy-gateway">Paso 1: Instalar Envoy Gateway</h2>
<p>Instala el plano de control:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">helm</span><span style="color:#9ECBFF"> install</span><span style="color:#9ECBFF"> eg</span><span style="color:#9ECBFF"> oci://docker.io/envoyproxy/gateway-helm</span><span style="color:#79B8FF"> \</span></span>

<span data-line=""><span style="color:#79B8FF">  -n</span><span style="color:#9ECBFF"> envoy-gateway-system</span><span style="color:#79B8FF"> \</span></span>
<span data-line=""><span style="color:#79B8FF">  --create-namespace</span></span></code></pre></figure>
<p>Espera a que esté listo:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">kubectl</span><span style="color:#9ECBFF"> wait</span><span style="color:#79B8FF"> --timeout=5m</span><span style="color:#79B8FF"> -n</span><span style="color:#9ECBFF"> envoy-gateway-system</span><span style="color:#79B8FF"> \</span></span>

<h2 id="paso-3-verificar-que-el-tráfico-fluye">Paso 3: Verificar Que el Tráfico Fluye</h2>
<h3 id="opción-a-el-clúster-tiene-un-loadbalancer">Opción A: El Clúster Tiene un LoadBalancer</h3>

<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#F97583">export</span><span style="color:#E1E4E8"> GATEWAY_HOST</span><span style="color:#F97583">=</span><span style="color:#E1E4E8">$(</span><span style="color:#B392F0">kubectl</span><span style="color:#9ECBFF"> get</span><span style="color:#9ECBFF"> gateway/eg</span><span style="color:#79B8FF"> -o</span><span style="color:#9ECBFF"> jsonpath='{.status.addresses[0].value}'</span><span style="color:#E1E4E8">)</span></span></code></pre></figure>
<p>Envía una solicitud:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">curl</span><span style="color:#79B8FF"> --verbose</span><span style="color:#79B8FF"> \</span></span>
<span data-line=""><span style="color:#79B8FF">  --header</span><span style="color:#9ECBFF"> "Host: www.example.com"</span><span style="color:#79B8FF"> \</span></span>
<span data-line=""><span style="color:#9ECBFF">  http://</span><span style="color:#E1E4E8">$GATEWAY_HOST</span><span style="color:#9ECBFF">/get</span></span></code></pre></figure>
<p>Si obtienes un HTTP <code>200</code>, significa que:</p>
<ul>
<li>El Gateway está funcionando como ingreso activo</li>
<li>El HTTPRoute se ha adjuntado correctamente</li>
<li>El servicio de backend está siendo enrutado correctamente</li>
</ul>
<h3 id="opción-b-sin-loadbalancer--usa-port-forward">Opción B: Sin LoadBalancer — Usa Port-Forward</h3>

<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">kubectl</span><span style="color:#79B8FF"> -n</span><span style="color:#9ECBFF"> envoy-gateway-system</span><span style="color:#9ECBFF"> port-forward</span><span style="color:#9ECBFF"> service/</span><span style="color:#E1E4E8">${ENVOY_SERVICE} </span><span style="color:#9ECBFF">8888:80</span></span></code></pre></figure>

<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">curl</span><span style="color:#79B8FF"> --verbose</span><span style="color:#79B8FF"> \</span></span>

<h2 id="lo-que-acabas-de-hacer-realmente">Lo Que Acabas de Hacer Realmente</h2>
<p>Solo ejecutaste unos pocos comandos, pero completaste toda una cadena de extremo a extremo:</p>
<ol>
<li>Instalaste <code>Envoy Gateway</code></li>
<li>Creaste un <code>GatewayClass</code> para indicarle al clúster qué controlador de gateway usar</li>
<li>Creaste un <code>Gateway</code> declarando el puerto y protocolo de ingreso</li>
<li>Creaste un <code>HTTPRoute</code> enrutando el tráfico al servicio de backend</li>
<li>Envoy Gateway tradujo estas declaraciones en configuración que Envoy Proxy puede ejecutar</li>
</ol>
<p>Esto es exactamente por qué Gateway API vale la pena usar. Escribes recursos de Kubernetes — no mantienes un montón de archivos de configuración de proxy a mano.</p>

<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">helm</span><span style="color:#9ECBFF"> install</span><span style="color:#9ECBFF"> eg</span><span style="color:#9ECBFF"> oci://docker.io/envoyproxy/gateway-helm</span><span style="color:#79B8FF"> \</span></span>
<span data-line=""><span style="color:#79B8FF">  --version</span><span style="color:#9ECBFF"> v1.7.0</span><span style="color:#79B8FF"> \</span></span>
<span data-line=""><span style="color:#79B8FF">  -n</span><span style="color:#9ECBFF"> envoy-gateway-system</span><span style="color:#79B8FF"> \</span></span>
<span data-line=""><span style="color:#79B8FF">  --create-namespace</span></span></code></pre></figure>
<p>Espera a que esté listo:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">kubectl</span><span style="color:#9ECBFF"> wait</span><span style="color:#79B8FF"> --timeout=5m</span><span style="color:#79B8FF"> -n</span><span style="color:#9ECBFF"> envoy-gateway-system</span><span style="color:#79B8FF"> \</span></span>
<span data-line=""><span style="color:#9ECBFF">  deployment/envoy-gateway</span><span style="color:#79B8FF"> \</span></span>
<span data-line=""><span style="color:#79B8FF">  --for=condition=Available</span></span></code></pre></figure>
<p>Una vez que esto se complete, el controlador de Envoy Gateway está corriendo en tu clúster. Ahora puede leer recursos de <code>Gateway API</code> y generar la configuración de Envoy correspondiente.</p>

<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">kubectl</span><span style="color:#9ECBFF"> apply</span><span style="color:#79B8FF"> -f</span><span style="color:#79B8FF"> \</span></span>

<h2 id="paso-3-verificar-que-el-tráfico-fluye">Paso 3: Verificar Que el Tráfico Fluye</h2>
<h3 id="opción-a-el-clúster-tiene-un-loadbalancer">Opción A: El Clúster Tiene un LoadBalancer</h3>
<p>Obtén la dirección del Gateway:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#F97583">export</span><span style="color:#E1E4E8"> GATEWAY_HOST</span><span style="color:#F97583">=</span><span style="color:#E1E4E8">$(</span><span style="color:#B392F0">kubectl</span><span style="color:#9ECBFF"> get</span><span style="color:#9ECBFF"> gateway/eg</span><span style="color:#79B8FF"> -o</span><span style="color:#9ECBFF"> jsonpath='{.status.addresses[0].value}'</span><span style="color:#E1E4E8">)</span></span></code></pre></figure>
<p>Envía una solicitud:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">curl</span><span style="color:#79B8FF"> --verbose</span><span style="color:#79B8FF"> \</span></span>
<span data-line=""><span style="color:#79B8FF">  --header</span><span style="color:#9ECBFF"> "Host: www.example.com"</span><span style="color:#79B8FF"> \</span></span>
<span data-line=""><span style="color:#9ECBFF">  http://</span><span style="color:#E1E4E8">$GATEWAY_HOST</span><span style="color:#9ECBFF">/get</span></span></code></pre></figure>
<p>Si obtienes un HTTP <code>200</code>, significa que:</p>
<ul>
<li>El Gateway está funcionando como ingreso activo</li>
<li>El HTTPRoute se ha adjuntado correctamente</li>
<li>El servicio de backend está siendo enrutado correctamente</li>
</ul>
<h3 id="opción-b-sin-loadbalancer--usa-port-forward">Opción B: Sin LoadBalancer — Usa Port-Forward</h3>
<p>Encuentra el servicio de Envoy:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#F97583">export</span><span style="color:#E1E4E8"> ENVOY_SERVICE</span><span style="color:#F97583">=</span><span style="color:#E1E4E8">$(</span><span style="color:#B392F0">kubectl</span><span style="color:#9ECBFF"> get</span><span style="color:#9ECBFF"> svc</span><span style="color:#79B8FF"> -n</span><span style="color:#9ECBFF"> envoy-gateway-system</span><span style="color:#79B8FF"> \</span></span>
<span data-line=""><span style="color:#79B8FF">  --selector=gateway.envoyproxy.io/owning-gateway-namespace=default,gateway.envoyproxy.io/owning-gateway-name=eg</span><span style="color:#79B8FF"> \</span></span>
<span data-line=""><span style="color:#79B8FF">  -o</span><span style="color:#9ECBFF"> jsonpath='{.items[0].metadata.name}'</span><span style="color:#E1E4E8">)</span></span></code></pre></figure>
<p>Reenvía el puerto local <code>8888</code> al puerto <code>80</code> del Gateway:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">kubectl</span><span style="color:#79B8FF"> -n</span><span style="color:#9ECBFF"> envoy-gateway-system</span><span style="color:#9ECBFF"> port-forward</span><span style="color:#9ECBFF"> service/</span><span style="color:#E1E4E8">${ENVOY_SERVICE} </span><span style="color:#9ECBFF">8888:80</span></span></code></pre></figure>
<p>En otra terminal:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">curl</span><span style="color:#79B8FF"> --verbose</span><span style="color:#79B8FF"> \</span></span>
<span data-line=""><span style="color:#79B8FF">  --header</span><span style="color:#9ECBFF"> "Host: www.example.com"</span><span style="color:#79B8FF"> \</span></span>
<span data-line=""><span style="color:#9ECBFF">  http://localhost:8888/get</span></span></code></pre></figure>
<p>Este es el camino de prueba local. Se siente un poco como entrar por la puerta trasera, pero si valida el enrutamiento, está bien — a veces la ingeniería es "hacer que funcione primero, luego hacerlo elegante."</p>
<h2 id="dónde-mirar-cuando-algo-falla">Dónde Mirar Cuando Algo Falla</h2>
<p>Los problemas más comunes no son que Envoy Gateway esté roto — es que un segmento de la cadena no se conectó:</p>
<table>
<thead>
<tr>
<th>Síntoma</th>
<th>Verificar Primero</th>
</tr>
</thead>

<tr>
<td><code>gateway/eg</code> no tiene dirección</td>
<td>¿Tiene el clúster una implementación de <code>LoadBalancer</code>?</td>

<td><code>curl</code> devuelve 404 o 503</td>
<td>Estado de <code>HTTPRoute</code>, <code>Service</code> y Pod de backend</td>

</table>

<h2 id="lo-que-acabas-de-hacer-realmente">Lo Que Acabas de Hacer Realmente</h2>
<p>Solo ejecutaste unos pocos comandos, pero completaste toda una cadena de extremo a extremo:</p>
<ol>
<li>Instalaste <code>Envoy Gateway</code></li>
<li>Creaste un <code>GatewayClass</code> para indicarle al clúster qué controlador de gateway usar</li>
<li>Creaste un <code>Gateway</code> declarando el puerto y protocolo de ingreso</li>
<li>Creaste un <code>HTTPRoute</code> enrutando el tráfico al servicio de backend</li>
<li>Envoy Gateway tradujo estas declaraciones en configuración que Envoy Proxy puede ejecutar</li>
</ol>
<p>Esto es exactamente por qué Gateway API vale la pena usar. Escribes recursos de Kubernetes — no mantienes un montón de archivos de configuración de proxy a mano.</p>
