3:Te1c,<p>실용적인 팁과 자주 나오는 질문에 대한 답 — "어디까지 했지?" "왜 안 써지지?"를 한 번에 해결.</p>
<h2 id="팁">팁</h2>
<h3 id="1-이전-대화-다시-이어하기">1. 이전 대화 다시 이어하기</h3>
<p>중간에 닫아버렸는데 이어서 하고 싶다면. 처음부터 다시 할 필요 없습니다:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#79C0FF"> --resume</span></span></code></pre></figure>
<p>가장 최근 대화가 컨텍스트와 함께 로드됩니다 — 일시 정지한 동영상의 "다시 보기"를 누르는 것과 같습니다.</p>
<h3 id="2-명령-실행-전에-확인받기">2. 명령 실행 전에 확인받기</h3>
<p>Agent가 <code>npm install</code>이나 <code>git</code> 같은 명령을 실행하려 할 수 있습니다.</p>
<ul>
<li><strong>대화형 모드</strong>: 그 전에 물어봅니다</li>
<li>조심하고 싶다면 대화에서 "어떤 명령이든 실행하기 전에 나한테 물어봐"라고 하면 됩니다</li>
</ul>
<p>"그거 언제 실행했지?" 하는 순간을 줄일 수 있습니다.</p>
<h3 id="3-cli와-ide-함께-쓰기">3. CLI와 IDE 함께 쓰기</h3>
<p>CLI와 Cursor 창은 <strong>동시에 사용할 수 있습니다</strong> — 둘 중 하나만이 아닙니다:</p>
<ul>
<li>창은 메인 개발·파일 트리 탐색·Tab 자동완성에</li>
<li>CLI는 작은 작업·검색·자동화에</li>
</ul>
<p>메인 전투는 창, 소규모 작업은 CLI — 역할 분담입니다.</p>
<h2 id="faq">FAQ</h2>
<p><strong>Q: <code>cursor: command not found</code>가 나와요.</strong>
A: 설치 후 터미널을 다시 켜거나, <code>source ~/.zshrc</code>(또는 <code>~/.bashrc</code>)를 실행하세요. 설치 경로가 <code>PATH</code>에 들어 있는지 확인하세요. "설치했는데 못 찾는다"는 거의 항상 PATH 문제입니다.</p>
<p><strong>Q: CLI는 유료인가요?</strong>
A: 네. CLI를 쓰려면 Cursor 구독이 필요하고, IDE와 같은 구독입니다.</p>
<p><strong>Q: 서버나 Docker에서 쓸 수 있나요?</strong>
A: 네. 조건은 설치 스크립트를 실행할 수 있고, Cursor에 로그인(또는 토큰 설정)할 수 있어야 합니다. 네트워크와 인증에 유의 — 제한된 네트워크에서는 Cursor 클라우드에 도달하지 못할 수 있습니다.</p>
<p><strong>Q: Cursor 창의 Agent와 같은 건가요?</strong>
A: 내부 능력은 같습니다. 차이는 CLI는 터미널 인터페이스이고, 비대화형 모드와 스크립트·CI 연동을 지원한다는 점입니다. 같은 AI, 다른 인터페이스입니다.</p>
<h2 id="요약">요약</h2>
<ul>
<li><strong>대화 재개</strong>: <code>cursor agent --resume</code></li>
<li><strong>명령 확인</strong>: "어떤 명령이든 실행 전에 확인해 달라"고 요청 가능</li>
<li><strong>CLI와 IDE</strong>: 동시 사용 가능, 둘 중 하나만이 아님</li>
<li><strong>막혔을 때</strong>: <code>cursor --help</code>와 공식 문서 확인 — 대부분 알려진 해결책이 있음</li>
</ul>
