Cursor CLI 기본 사용법

2026년 2월 24일·2 min read

가장 흔한 방식: cursor agent

프로젝트 디렉터리 안에서 다음을 실행하세요:

  • 대화형: AI가 질문하고 제안하며, 변경을 수락하거나 거절할 수 있습니다
  • 컨텍스트 인식: 현재 디렉터리 파일을 읽어 답변과 수정에 반영합니다

한 번에 실행 vs 대화

작업을 바로 맡기고 싶을 때: 지시를 따옴표로 감싸 한 번에 보냅니다.

실행 전에 논의하고 싶을 때: 인자 없이 cursor agent를 실행하면 대화 모드로 들어가, 요구사항을 단계별로 설명하고 AI가 변경 전에 확인해 줍니다.

작업 디렉터리 지정

기본값은 현재 디렉터리입니다. 경로를 지정하려면 --path를 붙이세요:

명령어 빠른 참조

명령 설명
cursor agent "do something" AI에게 실행 요청(파일 수정 가능)
cursor agent 작업 없이 대화 모드 진입
cursor ask "question" 질문만, 파일 수정 없음(읽기 전용)
cursor --help 사용 가능한 옵션 보기

요약

  • 가장 흔함: cursor agent "지시 내용"
  • 먼저 대화하고 싶을 때: cursor agent만 실행
  • 수정 없이 질문: cursor ask "질문"
  • 디렉터리 지정: --path <path> 추가
