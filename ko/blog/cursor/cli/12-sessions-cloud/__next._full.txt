<h2 id="세션-재개---resume">세션 재개: --resume</h2>
<p>대화 중간에 터미널을 닫았거나, 작업이 길어서 중단했을 때 — 다음에 같은 스레드에서 이어가고 싶다면:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#79B8FF"> --resume</span></span></code></pre></figure>
<p><strong>가장 최근</strong> 대화가 로드된다. 컨텍스트와 이전 지시가 그대로 있으므로 요청을 다시 설명할 필요가 없다.</p>
<h3 id="특정-대화만-재개하기">특정 대화만 재개하기</h3>
<p>대화가 여러 개 있고 <strong>특정한 것</strong>만 재개하고 싶을 때:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#79B8FF"> --resume=chat-id-here</span></span></code></pre></figure>
<p><code>chat-id</code>는 아래 "대화 목록"에서 확인한다.</p>
<h2 id="대화-목록-cursor-agent-ls">대화 목록: cursor agent ls</h2>

<h2 id="클라우드-실행--c----cloud">클라우드 실행: -c / --cloud</h2>
<p>무거운 작업 — 리포 전체 분석, 큰 문서 생성, 여러 단계 리팩터 — 을 로컬에서 돌리면 터미널을 계속 열어 두어야 한다. 노트북을 닫거나 연결이 끊기면 실행도 멈춘다.</p>
<p><strong><code>-c</code></strong>(또는 <strong><code>--cloud</code></strong>)를 쓰면 <strong>이 대화</strong>를 클라우드 Agent에게 넘길 수 있다:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "Analyze the whole project and write architecture doc to docs/architecture.md"</span><span style="color:#79B8FF"> -c</span></span></code></pre></figure>
<ul>
<li>보낸 뒤 작업은 Cursor 클라우드에서 실행된다</li>
<li>터미널을 닫아도, 전원을 꺼도, 다른 일을 해도 된다</li>
<li>나중에 같은 Cursor 계정으로 다른 기기에서 <code>--resume</code>으로 그 대화에 다시 들어가 결과를 보거나 지시를 더 보낼 수 있다</li>
</ul>
<p>즉 <strong><code>-c</code></strong> = "클라우드에서 실행；PC 앞에서 기다릴 필요 없음".</p>

<h2 id="세션과-클라우드-함께-쓰기">세션과 클라우드 함께 쓰기</h2>
<p>전형적인 흐름:</p>
<ol>
<li><code>-c</code>로 작업을 시작해 클라우드에서 돌리기</li>
<li>터미널 닫기</li>
<li>나중에 <code>cursor agent ls</code>로 그 대화 찾기</li>
<li><code>cursor agent --resume=that-id</code>로 다시 접속해 결과를 보거나 지시를 더 보내기</li>
</ol>
<p>이렇게 하면 "긴 작업"과 "여러 기기·종료"를 모두 커버한다.</p>
<h2 id="요약">요약</h2>
<ul>
<li><strong><code>cursor agent ls</code></strong>: 재개할 대화를 찾기 위해 목록 표시</li>
<li><strong><code>--resume</code></strong>: 가장 최근 재개；<strong><code>--resume=ID</code></strong>: 지정한 대화 재개</li>
<li><strong><code>-c</code> / <code>--cloud</code></strong>: 현재 작업을 클라우드에서 실행；터미널을 닫아도 나중에 <code>--resume</code>으로 재개 가능</li>
</ul>

26:T17ba,<p><a href="05-tips">05-tips</a>에서 이미 <code>cursor agent --resume</code>으로 마지막 대화를 이어가는 것을 다뤘다. 이 글은 <strong>세션</strong>과 <strong>클라우드 실행</strong>을 정리한다: 과거 대화 목록 보기, 어떤 걸 재개할지, **<code>-c</code>**로 작업을 클라우드에 넘겨 터미널이나 기기를 닫아도 백그라운드에서 끝까지 돌게 하는 방법.</p>
<h2 id="세션-재개---resume">세션 재개: --resume</h2>
<p>대화 중간에 터미널을 닫았거나, 작업이 길어서 중단했을 때 — 다음에 같은 스레드에서 이어가고 싶다면:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#79B8FF"> --resume</span></span></code></pre></figure>
<p><strong>가장 최근</strong> 대화가 로드된다. 컨텍스트와 이전 지시가 그대로 있으므로 요청을 다시 설명할 필요가 없다.</p>
<h3 id="특정-대화만-재개하기">특정 대화만 재개하기</h3>
<p>대화가 여러 개 있고 <strong>특정한 것</strong>만 재개하고 싶을 때:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#79B8FF"> --resume=chat-id-here</span></span></code></pre></figure>
<p><code>chat-id</code>는 아래 "대화 목록"에서 확인한다.</p>
<h2 id="대화-목록-cursor-agent-ls">대화 목록: cursor agent ls</h2>

<h2 id="클라우드-실행--c----cloud">클라우드 실행: -c / --cloud</h2>
<p>무거운 작업 — 리포 전체 분석, 큰 문서 생성, 여러 단계 리팩터 — 을 로컬에서 돌리면 터미널을 계속 열어 두어야 한다. 노트북을 닫거나 연결이 끊기면 실행도 멈춘다.</p>
<p><strong><code>-c</code></strong>(또는 <strong><code>--cloud</code></strong>)를 쓰면 <strong>이 대화</strong>를 클라우드 Agent에게 넘길 수 있다:</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "Analyze the whole project and write architecture doc to docs/architecture.md"</span><span style="color:#79B8FF"> -c</span></span></code></pre></figure>
<ul>
<li>보낸 뒤 작업은 Cursor 클라우드에서 실행된다</li>
<li>터미널을 닫아도, 전원을 꺼도, 다른 일을 해도 된다</li>
<li>나중에 같은 Cursor 계정으로 다른 기기에서 <code>--resume</code>으로 그 대화에 다시 들어가 결과를 보거나 지시를 더 보낼 수 있다</li>
</ul>
<p>즉 <strong><code>-c</code></strong> = "클라우드에서 실행；PC 앞에서 기다릴 필요 없음".</p>

</tr>
<tr>
<td>짧은 질문이나 작은 수정</td>

</tr>

<h2 id="세션과-클라우드-함께-쓰기">세션과 클라우드 함께 쓰기</h2>
<p>전형적인 흐름:</p>
<ol>
<li><code>-c</code>로 작업을 시작해 클라우드에서 돌리기</li>
<li>터미널 닫기</li>
<li>나중에 <code>cursor agent ls</code>로 그 대화 찾기</li>
<li><code>cursor agent --resume=that-id</code>로 다시 접속해 결과를 보거나 지시를 더 보내기</li>
</ol>
<p>이렇게 하면 "긴 작업"과 "여러 기기·종료"를 모두 커버한다.</p>
<h2 id="요약">요약</h2>
<ul>
<li><strong><code>cursor agent ls</code></strong>: 재개할 대화를 찾기 위해 목록 표시</li>
<li><strong><code>--resume</code></strong>: 가장 최근 재개；<strong><code>--resume=ID</code></strong>: 지정한 대화 재개</li>
<li><strong><code>-c</code> / <code>--cloud</code></strong>: 현재 작업을 클라우드에서 실행；터미널을 닫아도 나중에 <code>--resume</code>으로 재개 가능</li>
</ul>
