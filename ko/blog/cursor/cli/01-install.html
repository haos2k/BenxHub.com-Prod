Cursor CLI 설치하기

2026년 2월 24일·2 min read

설치는 간단합니다. 터미널에서 공식 스크립트를 실행하면 cursor 명령을 사용할 수 있습니다. 플랫폼에 따라 방법이 다릅니다.

macOS / Linux / WSL

터미널에서 다음을 실행하세요:

  • 스크립트가 cursor 명령을 자동으로 다운로드·설치합니다
  • 설치 후 터미널을 닫았다가 다시 열거나, source ~/.bashrc / source ~/.zshrc를 실행해 PATH를 갱신하세요

Windows (PowerShell)

PowerShell을 관리자 권한으로 열고 다음을 실행하세요:

설치 확인

버전 번호가 나오면 설치가 성공한 것입니다.

첫 사용: 로그인

처음 실행할 때 Cursor 계정 로그인을 요청할 수 있습니다:

화면 안내에 따라 브라우저에서 로그인을 완료하세요. 같은 기기에서는 보통 다시 로그인할 필요가 없습니다.

요약

  • macOS / Linux: curl ... | bash
  • Windows: PowerShell에서 irm ... | iex 실행
  • 확인: cursor --version
  • 로그인: cursor auth login
