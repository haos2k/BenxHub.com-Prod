<h2 id="이번-글에서-배울-것">이번 글에서 배울 것</h2>
<ul>
<li>전체 흐름 이해하기: 그룹 → 비서 → 워크스페이스</li>

<h2 id="전체-구조">전체 구조</h2>
<p>목표 아키텍처는 다음과 같습니다.</p>
<pre><code>Telegram 그룹 A  →  비서 A  →  Workspace A (이 안의 파일만 만짐)
Telegram 그룹 B  →  비서 B  →  Workspace B (이 안의 파일만 만짐)
개인 대화        →  메인 비서 → 메인 Workspace
</code></pre>
<p>이를 위해 필요한 단계는 세 가지입니다. <strong>Workspace 만들기 → Agent 정의하기 → Bindings 정의하기</strong>.</p>
<hr>
<h2 id="1단계-workspace-만들기">1단계: Workspace 만들기</h2>
<p>각 비서는 자기만의 디렉터리가 필요합니다. 다음처럼 초기화합니다.</p>

<p>💡 디렉터리가 없어도 명령이 만들어 줍니다. Git 에서 기존 Workspace 를 가져왔다면 초기화는 생략하고 Config 에 경로만 지정해도 됩니다.</p>

<h2 id="전체-구조">전체 구조</h2>
<p>목표 아키텍처는 다음과 같습니다.</p>
<pre><code>Telegram 그룹 A  →  비서 A  →  Workspace A (이 안의 파일만 만짐)
Telegram 그룹 B  →  비서 B  →  Workspace B (이 안의 파일만 만짐)
개인 대화        →  메인 비서 → 메인 Workspace
</code></pre>
<p>이를 위해 필요한 단계는 세 가지입니다. <strong>Workspace 만들기 → Agent 정의하기 → Bindings 정의하기</strong>.</p>
