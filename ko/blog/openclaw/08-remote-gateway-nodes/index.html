이 글에서는 Gateway 를 클라우드로 옮겨서 비서를 하루 종일 온라인 상태로 유지하는 방법을 설명합니다.

Gateway 는 어디에 둘 수 있을까?

위치 적합한 경우
로컬 컴퓨터 개인 테스트, 가끔 사용하는 용도
VPS / 클라우드 서버 24시간 상시 사용
집 NAS / 오래된 PC VPS 비용 없이 상시 대기

VPS 설치는 어떤 느낌일까?

Ubuntu 나 Debian 기반 VPS 에 접속한 뒤 docs.openclaw.ai 의 Linux 설치 절차를 따르면 됩니다. 로컬 설치와 거의 같고, 실행 위치만 원격이라는 차이뿐입니다.

원격 인증의 기본

Gateway 가 VPS 에 있다면 OpenClaw 는 당신이 정상 사용자임을 확인해야 합니다.

  • token 또는 장치 pairing 이 필요합니다
  • unauthorized 가 보이면 gateway.bind 와 token 값을 확인하세요

Tailscale 이 가장 깔끔한 선택

Tailscale 을 사용하면 휴대폰, 컴퓨터, VPS 가 같은 사설 네트워크에 있는 것처럼 동작합니다.

  1. VPS 와 내 컴퓨터 모두에 Tailscale 설치
  2. gateway.bind: tailnet 설정
  3. 어떤 장치에서든 Tailscale 을 통해 Gateway 에 접속

💡 Tailscale 은 Serve 기능으로 HTTPS 도 제공할 수 있어, 포트를 그대로 노출하는 것보다 더 안전한 경우가 많습니다.

Node 란 무엇인가?

여기서 재미있는 점은 Gateway 와 Node 를 서로 다른 장비에 둘 수 있다 는 것입니다.

  • Gateway: VPS 에서 실행되며 대화, 메모리, Telegram 등 "두뇌" 역할을 담당
  • Node: 집 컴퓨터에서 실행되며 브라우저 제어, 로컬 파일 접근, 화면 조작 같은 "손발" 역할을 담당

예를 들어 밖에서 Telegram 으로 "집 컴퓨터 브라우저를 열고 이 웹사이트를 확인해 줘"라고 말하면, Gateway 가 집의 Node 에게 일을 시키고 결과를 돌려줍니다.

SSH 와는 뭐가 다를까?

SSH 는 내가 직접 로그인해 명령을 쳐야 합니다. Node 는 비서가 대신 실행 해 주고, Skills, 워크스페이스, 대화와 자연스럽게 통합됩니다.
