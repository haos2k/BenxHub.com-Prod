<h2 id="tailscale-이-가장-깔끔한-선택">Tailscale 이 가장 깔끔한 선택</h2>
<p><strong>Tailscale</strong> 을 사용하면 휴대폰, 컴퓨터, VPS 가 같은 사설 네트워크에 있는 것처럼 동작합니다.</p>
<ol>
<li>VPS 와 내 컴퓨터 모두에 Tailscale 설치</li>
<li><code>gateway.bind: tailnet</code> 설정</li>
<li>어떤 장치에서든 Tailscale 을 통해 Gateway 에 접속</li>
</ol>
<blockquote>
<p>💡 Tailscale 은 Serve 기능으로 HTTPS 도 제공할 수 있어, 포트를 그대로 노출하는 것보다 더 안전한 경우가 많습니다.</p>
</blockquote>
<hr>
<h2 id="node-란-무엇인가">Node 란 무엇인가?</h2>
<p>여기서 재미있는 점은 <strong>Gateway 와 Node 를 서로 다른 장비에 둘 수 있다</strong> 는 것입니다.</p>
<ul>
<li><strong>Gateway</strong>: VPS 에서 실행되며 대화, 메모리, Telegram 등 "두뇌" 역할을 담당</li>
<li><strong>Node</strong>: 집 컴퓨터에서 실행되며 브라우저 제어, 로컬 파일 접근, 화면 조작 같은 "손발" 역할을 담당</li>
</ul>
<p>예를 들어 밖에서 Telegram 으로 "집 컴퓨터 브라우저를 열고 이 웹사이트를 확인해 줘"라고 말하면, Gateway 가 집의 Node 에게 일을 시키고 결과를 돌려줍니다.</p>
<p><strong>SSH 와는 뭐가 다를까?</strong></p>
<p>SSH 는 내가 직접 로그인해 명령을 쳐야 합니다. Node 는 <strong>비서가 대신 실행</strong> 해 주고, Skills, 워크스페이스, 대화와 자연스럽게 통합됩니다.</p>
