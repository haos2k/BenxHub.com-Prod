<h2 id="api-key-를-올바르게-보관하기">API key 를 올바르게 보관하기</h2>
<p>가능하면 <strong>API key 를 config 에 직접 쓰지 않는 편이 안전합니다.</strong></p>
<p>환경 변수를 사용하세요.</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># .env 또는 시스템 환경 변수에 설정</span></span>
<span data-line=""><span style="color:#E1E4E8">ANTHROPIC_API_KEY</span><span style="color:#F97583">=</span><span style="color:#9ECBFF">sk-ant-xxxxx</span></span></code></pre></figure>
<blockquote>
<p>⚠️ Gateway 를 <code>systemd</code> 같은 시스템 서비스로 실행한다면, 해당 서비스가 <code>.env</code> 를 읽는지 꼭 확인하세요. 그렇지 않으면 API key 를 찾지 못해 "Shell env off" 같은 문제가 생길 수 있습니다.</p>
</blockquote>

<span data-line=""><span style="color:#E1E4E8">  },</span></span>
<span data-line=""><span style="color:#9ECBFF">  "bindings"</span><span style="color:#E1E4E8">: [</span></span>

<h2 id="api-key-를-올바르게-보관하기">API key 를 올바르게 보관하기</h2>
<p>가능하면 <strong>API key 를 config 에 직접 쓰지 않는 편이 안전합니다.</strong></p>
<p>환경 변수를 사용하세요.</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># .env 또는 시스템 환경 변수에 설정</span></span>

<blockquote>
<p>⚠️ Gateway 를 <code>systemd</code> 같은 시스템 서비스로 실행한다면, 해당 서비스가 <code>.env</code> 를 읽는지 꼭 확인하세요. 그렇지 않으면 API key 를 찾지 못해 "Shell env off" 같은 문제가 생길 수 있습니다.</p>
</blockquote>
