<pre><code>http://127.0.0.1:18789/openclaw
</code></pre>

<h2 id="인증-도대체-뭘-입력해야-하나요">인증: 도대체 뭘 입력해야 하나요?</h2>
<h3 id="경우-1-pairing-required-가-뜬다">경우 1: <code>pairing required</code> 가 뜬다</h3>
<p>OpenClaw 가 "당신 누구세요? 이 장치는 아직 모릅니다"라고 묻는 상황입니다.</p>

<h3 id="경우-2-token-을-요구한다">경우 2: token 을 요구한다</h3>
<p>온보딩 때 받은 token 을 여기 붙여 넣으면 됩니다. Settings 에 저장하면 보통 다음부터는 다시 붙이지 않아도 됩니다.</p>
<blockquote>
<p>💡 Token 은 UI 설정에 저장됩니다. 비밀번호는 메모리 안에만 있다가 세션이 끝나면 사라집니다. 보안을 위한 의도적인 설계입니다.</p>
</blockquote>
<h3 id="경우-3-vps-또는-lan-에서-원격-접속">경우 3: VPS 또는 LAN 에서 원격 접속</h3>
<p>Gateway 가 로컬이 아니라 원격 서버에서 실행 중이라면:</p>

<li>token 또는 장치 pairing 이 필요합니다</li>

</ul>
