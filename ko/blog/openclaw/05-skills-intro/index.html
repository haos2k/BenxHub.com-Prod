비서에게 도구를 쥐여주자: Skills 로 말만 하는 존재에서 실행하는 존재로

Skills 는 비서가 실제로 일을 하게 만드는 장비입니다.

Skill 이란?

Skill 은 보통 SKILL.md 라는 설명 문서입니다. 여기에 다음이 적혀 있습니다.

  • 무엇을 할 수 있는지
  • 언제 써야 하는지
  • 어떤 도구와 절차를 사용할 수 있는지

즉 비서의 업무 매뉴얼 이라고 보면 됩니다. 웹 탐색 매뉴얼을 주면 인터넷 검색을 할 수 있고, 파일 작업 매뉴얼을 주면 문서를 정리할 수 있습니다.

내장 Skill vs 커스텀 Skill

OpenClaw 는 유용한 내장 Skill 을 제공하고, 커뮤니티도 계속 새로운 Skill 을 만들고 있습니다. 선택지는 두 가지입니다.

  • 내장 Skill 을 그대로 사용한다
  • 직접 SKILL.md 를 작성해 나만의 Skill 을 만든다

커스텀 Skill 을 만드는 올바른 방법

Skill 을 수정하거나 새로 만들 때 OpenClaw 저장소의 원본 파일은 건드리지 마세요. 다음 업데이트에서 덮어써질 수 있습니다.

대신 여기에 두세요:

~/.openclaw/skills/<skill-name>/SKILL.md

우선순위

workspace/skills  →  ~/.openclaw/skills  →  내장  →  extraDirs

먼저 매칭되는 것이 이깁니다.

대시보드에서 Skill 관리하기

Control UI 의 Skills 탭에서 다음을 할 수 있습니다.

  • 사용 가능한 Skill 목록 보기
  • 클릭 한 번으로 활성화 / 비활성화
  • API key 가 필요한 Skill 설정
  • 커뮤니티 Skill 설치

저장하면 대부분 Gateway 재시작 없이 바로 반영됩니다.
