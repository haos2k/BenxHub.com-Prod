<h2 id="skill-이란">Skill 이란?</h2>
<p>Skill 은 보통 <code>SKILL.md</code> 라는 설명 문서입니다. 여기에 다음이 적혀 있습니다.</p>
<ul>
<li>무엇을 할 수 있는지</li>
<li>언제 써야 하는지</li>

<p>즉 <strong>비서의 업무 매뉴얼</strong> 이라고 보면 됩니다. 웹 탐색 매뉴얼을 주면 인터넷 검색을 할 수 있고, 파일 작업 매뉴얼을 주면 문서를 정리할 수 있습니다.</p>

<h2 id="내장-skill-vs-커스텀-skill">내장 Skill vs 커스텀 Skill</h2>
<p>OpenClaw 는 유용한 내장 Skill 을 제공하고, 커뮤니티도 계속 새로운 Skill 을 만들고 있습니다. 선택지는 두 가지입니다.</p>
<ul>
<li><strong>내장 Skill 을 그대로 사용한다</strong></li>
<li><strong>직접 <code>SKILL.md</code> 를 작성해 나만의 Skill 을 만든다</strong></li>
</ul>
<hr>
<h2 id="커스텀-skill-을-만드는-올바른-방법">커스텀 Skill 을 만드는 올바른 방법</h2>
<p>Skill 을 수정하거나 새로 만들 때 <strong>OpenClaw 저장소의 원본 파일은 건드리지 마세요</strong>. 다음 업데이트에서 덮어써질 수 있습니다.</p>
<p>대신 여기에 두세요:</p>
<pre><code>~/.openclaw/skills/&#x3C;skill-name>/SKILL.md
</code></pre>
<p><strong>우선순위</strong></p>
<pre><code>workspace/skills  →  ~/.openclaw/skills  →  내장  →  extraDirs
</code></pre>
<p>먼저 매칭되는 것이 이깁니다.</p>
<hr>
<h2 id="대시보드에서-skill-관리하기">대시보드에서 Skill 관리하기</h2>

<ul>

<li>API key 가 필요한 Skill 설정</li>
<li>커뮤니티 Skill 설치</li>
</ul>
