<h2 id="workspace-란">Workspace 란?</h2>
<p>Workspace 는 <strong>비서만의 개인 사무실</strong> 입니다.</p>
<ul>
<li>비서가 읽는 파일, 쓰는 문서, 실행하는 스크립트는 이 폴더 안에서 이뤄집니다</li>
<li>여러 Workspace 를 만들면 서로 다른 일을 깔끔하게 분리할 수 있습니다</li>
</ul>
<pre><code>~/.openclaw/workspace-main        ← 메인 비서의 사무실
~/.openclaw/workspace-project-a   ← 프로젝트 A 의 사무실
~/.openclaw/workspace-project-b   ← 프로젝트 B 의 사무실
</code></pre>
<p>이렇게 하면 "개인 일기 정리해 줘"와 "프로젝트 A 코드 작성해 줘"가 섞이지 않습니다.</p>
<hr>
<h2 id="memory-는-어떻게-동작할까">Memory 는 어떻게 동작할까?</h2>
<p>OpenClaw 는 대화 중 중요한 정보를 <strong>Memory</strong> 로 저장해 두고 나중에 검색하거나 다시 참고할 수 있게 합니다.</p>
<p>쉽게 말해, <strong>예전에 말한 내용을 비서가 기억할 수 있게 되는 것</strong> 입니다.</p>
<blockquote>
<p>⚠️ 자꾸 잊는 것처럼 느껴진다면 다음을 확인하세요:</p>
<ul>
<li>Memory 기능이 켜져 있는가? 의미 검색에는 OpenAI API key 가 필요할 수 있습니다</li>
<li>오래된 Memory 가 정리, 압축, 길이 제한 처리되지 않았는가?</li>
<li>새 세션을 열지 않았는가? 새 세션은 단기 문맥이 비어 있습니다</li>
</ul>
</blockquote>
