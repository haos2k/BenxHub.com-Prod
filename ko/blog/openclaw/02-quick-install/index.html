5분 만에 설치하기: OpenClaw 첫 실행을 막힘 없이 끝내는 가이드

2026년 3월 8일·4 min read

많은 튜토리얼이 바로 이 단계에서 사람을 놓칩니다. 이 글의 목표는 하나입니다. 처음 한 번에 성공하게 만드는 것.

이번 글에서 배울 것

  • OpenClaw 설치

설치 전에 꼭 확인할 두 가지

많이 필요하지는 않지만, 이 두 개는 필수입니다.

1. Node.js (LTS 버전)

2. AI 모델용 API key

Anthropic Claude나 OpenAI 같은 클라우드 모델을 쓰려면 API key가 필요합니다. 완전 오프라인으로 가고 싶다면 로컬 모델을 사용해도 됩니다. 이 시리즈는 기본적으로 클라우드 모델을 기준으로 설명합니다.

💡 API key 발급 방법이 막막하다면 "Anthropic API key" 정도로 검색해 보면 보통 몇 분 안에 해결됩니다.

OpenClaw 설치하기

공식 문서에서는 git 기반 설치 방식 을 권장합니다. 나중에 업데이트와 디버깅이 더 쉽기 때문입니다.

macOS / Linux

Windows

⚠️ "git not found" 또는 "openclaw 를 인식할 수 없음"에서 막히면 Git 을 PATH 에 추가하고 터미널을 다시 열어 보세요.

첫 실행: 비서를 깨우기

설치가 끝났다면 다음을 실행합니다.

첫 실행에서는 온보딩 마법사 가 나타나 다음을 물어봅니다.

  1. 어떤 AI 모델을 쓸지
  2. API key 는 무엇인지
  3. 워크스페이스를 어디에 둘지

질문에 답하면 첫 번째 비서가 만들어집니다.

💡 "wake up my friend" 상태에서 오래 멈춘다면 API key, 네트워크, 터미널 에러 메시지를 먼저 확인하세요.

온보딩이 끝나면 무엇을 얻나?

  • 대시보드 로그인용 token
  • 기본 설정 파일 ~/.openclaw/openclaw.json
  • 이미 동작 중인 첫 AI 비서

대시보드 열기

Gateway 가 계속 실행 중인 상태에서 브라우저를 열고:

http://127.0.0.1:18789/

자주 보는 상황

화면 해결 방법
pairing required openclaw devices list 후 openclaw devices approve <id> 실행
token 입력 요청 온보딩에서 받은 token 붙여넣기
반응 없음 openclaw gateway 가 아직 켜져 있는지 확인
