<h2 id="설치-전에-꼭-확인할-두-가지">설치 전에 꼭 확인할 두 가지</h2>
<p>많이 필요하지는 않지만, 이 두 개는 필수입니다.</p>
<p><strong>1. Node.js (LTS 버전)</strong></p>

<p><strong>2. AI 모델용 API key</strong></p>
<p>Anthropic Claude나 OpenAI 같은 클라우드 모델을 쓰려면 API key가 필요합니다. 완전 오프라인으로 가고 싶다면 로컬 모델을 사용해도 됩니다. 이 시리즈는 기본적으로 클라우드 모델을 기준으로 설명합니다.</p>
<blockquote>
<p>💡 API key 발급 방법이 막막하다면 "Anthropic API key" 정도로 검색해 보면 보통 몇 분 안에 해결됩니다.</p>
</blockquote>
