3:T10bf,<p>이 가이드는 최단 경로로 <strong>부팅 가능한 Debian 가상 머신</strong>을 완성합니다 — PVE의 첫 번째 사용 가능한 환경 구축. 첫 반려동물을 키우는 것처럼: 먹고 자는 것부터 해결하고, 고급 기술은 나중에 배웁니다.</p>
<h2 id="사전-조건">사전 조건</h2>
<ul>
<li>64비트 CPU, <strong>Intel VT-x</strong> 또는 <strong>AMD-V</strong> 활성화 (없으면 VM이 시작되지 않습니다)</li>
<li>최소 2GB RAM (8GB 이상 권장 — 그 이하면 2010년 컴퓨터를 쓰는 기분)</li>
<li>사용 가능한 네트워크 카드 1장 이상</li>
<li>USB로 부팅 가능한 호스트 또는 서버</li>
</ul>
<h2 id="최소-예제-첫-번째-가상-머신-만들기">최소 예제: 첫 번째 가상 머신 만들기</h2>
<h3 id="1단계-웹-인터페이스-로그인">1단계: 웹 인터페이스 로그인</h3>
<p>설치 후 <code>https://&#x3C;PVE-IP>:8006</code>을 열고 <code>root</code>와 설치 시 설정한 비밀번호로 로그인합니다. 브라우저가 인증서에 대해 경고할 수 있습니다 — 자체 서명된 것이므로 "고급" → "계속 진행"을 클릭하세요. 홈랩 일상입니다.</p>
<h3 id="2단계-시스템-이미지-다운로드">2단계: 시스템 이미지 다운로드</h3>
<ol>
<li>왼쪽 패널에서 노드 하위의 <code>local</code> 스토리지 선택</li>
<li><code>Content</code>로 이동, <code>Download from URL</code> 클릭</li>
<li>입력:
<ul>
<li>URL: <code>https://cloud.debian.org/images/cloud/bookworm/latest/debian-12-generic-amd64.qcow2</code></li>
<li>File Name: <code>debian-12-cloud.qcow2</code></li>
</ul>
</li>
<li><code>Query URL</code> 클릭 후 다운로드 시작 (커피 한 잔 마시고 오세요)</li>
</ol>
<h3 id="3단계-가상-머신-만들기">3단계: 가상 머신 만들기</h3>
<ol>
<li>오른쪽 위 <code>Create VM</code> 클릭</li>
<li><code>General</code>: 이름에 <code>test-vm</code> (또는 원하는 이름) 입력</li>
<li><code>OS</code>: 클라우드 이미지 사용 시 디스크 설정 생략 가능</li>
<li><code>Disks</code>: <strong>Use existing disk image</strong> 선택, 방금 다운로드한 <code>debian-12-cloud.qcow2</code> 선택</li>
<li><code>CPU</code>: 1 vCPU면 충분</li>
<li><code>Memory</code>: 512~1024 MB로 테스트</li>
<li><code>Network</code>: 기본 <code>vmbr0</code> 사용</li>
<li><code>Confirm</code> → <code>Finish</code></li>
</ol>
<h3 id="4단계-시작-및-확인">4단계: 시작 및 확인</h3>
<ol>
<li>VM 오른쪽 클릭 → <code>Start</code></li>
<li><code>Console</code> (noVNC) 열기</li>
<li>Debian 부팅 화면이나 로그인 프롬프트가 보이면 성공 — 축하합니다, 첫 번째 VM 탄생!</li>
</ol>
