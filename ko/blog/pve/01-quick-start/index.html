Proxmox VE 빠른 시작: 첫 번째 VM 만들기

2026년 2월 24일·4 min read

이 가이드는 최단 경로로 부팅 가능한 Debian 가상 머신을 완성합니다 — PVE의 첫 번째 사용 가능한 환경 구축. 첫 반려동물을 키우는 것처럼: 먹고 자는 것부터 해결하고, 고급 기술은 나중에 배웁니다.

사전 조건

  • 64비트 CPU, Intel VT-x 또는 AMD-V 활성화 (없으면 VM이 시작되지 않습니다)
  • 최소 2GB RAM (8GB 이상 권장 — 그 이하면 2010년 컴퓨터를 쓰는 기분)
  • 사용 가능한 네트워크 카드 1장 이상
  • USB로 부팅 가능한 호스트 또는 서버

최소 예제: 첫 번째 가상 머신 만들기

1단계: 웹 인터페이스 로그인

설치 후 https://<PVE-IP>:8006을 열고 root와 설치 시 설정한 비밀번호로 로그인합니다. 브라우저가 인증서에 대해 경고할 수 있습니다 — 자체 서명된 것이므로 "고급" → "계속 진행"을 클릭하세요. 홈랩 일상입니다.

2단계: 시스템 이미지 다운로드

  1. 왼쪽 패널에서 노드 하위의 local 스토리지 선택
  2. Content로 이동, Download from URL 클릭
  3. 입력:
    • URL: https://cloud.debian.org/images/cloud/bookworm/latest/debian-12-generic-amd64.qcow2
    • File Name: debian-12-cloud.qcow2
  4. Query URL 클릭 후 다운로드 시작 (커피 한 잔 마시고 오세요)

3단계: 가상 머신 만들기

  1. 오른쪽 위 Create VM 클릭
  2. General: 이름에 test-vm (또는 원하는 이름) 입력
  3. OS: 클라우드 이미지 사용 시 디스크 설정 생략 가능
  4. Disks: Use existing disk image 선택, 방금 다운로드한 debian-12-cloud.qcow2 선택
  5. CPU: 1 vCPU면 충분
  6. Memory: 512~1024 MB로 테스트
  7. Network: 기본 vmbr0 사용
  8. Confirm → Finish

4단계: 시작 및 확인

  1. VM 오른쪽 클릭 → Start
  2. Console (noVNC) 열기
  3. Debian 부팅 화면이나 로그인 프롬프트가 보이면 성공 — 축하합니다, 첫 번째 VM 탄생!

일반적인 트러블슈팅

현상 확인 방향
웹 인터페이스 접근 불가 8006 포트 연결 확인, pveproxy 실행 중인지 확인
VM이 시작되지 않음 BIOS에서 VT-x / AMD-V 활성화 여부 확인? 없으면 VM 시작 불가
이미지 파일을 찾을 수 없음 local -> Content에서 다운로드 완료 여부 확인
VM 네트워크 연결 안 됨 vmbr0이 물리 NIC에 올바르게 바인딩되었는지 확인
