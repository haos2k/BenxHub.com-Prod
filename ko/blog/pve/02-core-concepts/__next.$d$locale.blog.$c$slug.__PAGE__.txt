<h2 id="개념-1-vm과-lxc의-차이">개념 1: VM과 LXC의 차이</h2>
<table>
<thead>
<tr>
<th>유형</th>
<th>기술</th>
<th>특성</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>VM</strong></td>
<td>KVM/QEMU</td>
<td>완전한 OS, 높은 격리성, Windows/Linux 모두 실행</td>
</tr>
<tr>
<td><strong>LXC</strong></td>
<td>Linux 컨테이너</td>
<td>경량·빠른 시작·높은 밀도, 단 <strong>Linux 전용</strong></td>
</tr>
</tbody>
</table>
<p><strong>한 문장 판단</strong>: 완전한 격리 또는 Windows 실행 필요 → VM; 리소스 절약이 목적이고 서비스가 Linux → LXC. 잘못 선택하면 슬리퍼 신고 등산하는 것과 같습니다 — 불가능하진 않지만 고생합니다.</p>

<h2 id="개념-2-스토리지-선택이-미래를-결정한다">개념 2: 스토리지 선택이 미래를 결정한다</h2>
<p>스토리지를 잘못 선택하면 나중에 HA, 마이그레이션에서 막힙니다. 일반적인 유형:</p>
<ul>
<li><strong>local</strong>: 단일 노드 디렉터리형, 입문자 친화적</li>
<li><strong>local-lvm</strong>: 로컬 LVM, 스냅샷과 클론에 편리</li>
<li><strong>NFS/CIFS</strong>: 공유 네트워크 스토리지, 크로스 노드 가능</li>
<li><strong>ZFS/Ceph</strong>: 복제와 고가용성을 위한 고급 솔루션</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># 현재 스토리지 상태 확인</span></span>
<span data-line=""><span style="color:#B392F0">pvesm</span><span style="color:#9ECBFF"> status</span></span>
<span data-line=""><span style="color:#B392F0">pvesm</span><span style="color:#9ECBFF"> list</span><span style="color:#9ECBFF"> local</span></span></code></pre></figure>
<blockquote>
<p>라이브 마이그레이션이나 HA를 하려면 디스크가 보통 <strong>공유 스토리지</strong>에 있어야 합니다 — 그렇지 않으면 VM을 옮길 수 없습니다. 이사하려는데 가구가 다른 사람 집에 잠겨 있는 것과 같습니다.</p>
</blockquote>
<h2 id="개념-3-네트워크-모델-vmbr0">개념 3: 네트워크 모델 (vmbr0)</h2>
<p>PVE는 기본적으로 브리지 네트워킹을 사용합니다: <code>vmbr0</code>이 물리 NIC에 브리지되어, VM이 물리 스위치에 직접 연결된 것처럼 보입니다. 간단히 말해: <strong>하나의 가상 케이블, 모두가 외부 NIC를 공유합니다.</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="text" data-theme="github-dark"><code data-language="text" data-theme="github-dark" style="display: grid;"><span data-line=""><span>[물리 NIC] --> [vmbr0] --> [VM1] [VM2] [VM3]</span></span></code></pre></figure>

<ul>
<li><strong>단일 노드</strong>: 머신 하나가 모든 것을 처리, 시작하기 좋고 홈랩에 적합</li>
<li><strong>클러스터</strong>: 여러 호스트를 함께 관리, 마이그레이션과 HA 지원 — 파티를 구성해 던전 공략하는 것처럼</li>
</ul>

<p>PVE는 기본적으로 브리지 네트워킹을 사용합니다: <code>vmbr0</code>이 물리 NIC에 브리지되어, VM이 물리 스위치에 직접 연결된 것처럼 보입니다. 간단히 말해: <strong>하나의 가상 케이블, 모두가 외부 NIC를 공유합니다.</strong></p>
