3:Tf8e,<p>uv는 Astral이 Rust로 만든 <strong>초고속 Python 패키지 및 프로젝트 관리 도구</strong>로, 의존성 설치·가상 환경·Python 버전 관리·CLI 도구 실행을 하나로 통합합니다. 간단히 말해: <strong>pip + virtualenv + pyenv + pipx의 합체 강화판 — 게다가 현실을 의심할 정도로 빠릅니다.</strong></p>
<p>pip·poetry·pipenv와 비교하면 uv의 장점은 <strong>10~100배 속도</strong>·최소 디스크 사용량·단일 도구로 전체 흐름 완결. 일상 개발·CI/CD·스크립트 실행에 특히 적합합니다 — 여러 도구를 전환할 필요가 없습니다. 골판지 상자 하나만 필요한 고양이처럼, 그 상자가 모든 기능을 갖추고 터보 모드까지 내장.</p>
<h2 id="적용-시나리오">적용 시나리오</h2>
<ul>
<li><strong>새 프로젝트를 처음부터 시작</strong>: <code>uv init</code>으로 즉시 생성, 의존성도 즉시 설치 — pip 스피너 보는 시간은 이제 끝</li>
<li><strong>기존 requirements.txt에서 마이그레이션</strong>: <code>uv pip compile</code>로 바로 받아들이기, 무통 업그레이드</li>
<li><strong>스크립트 임시 의존성</strong>: <code>uv run --with rich script.py</code> — venv 만들 필요 없음</li>
<li><strong>CLI 도구 실행</strong>: <code>uvx ruff</code> 즉시 실행, pipx 같지만 N배 빠름</li>
<li><strong>적합하지 않은 경우</strong>: Python 2를 계속 사용하는 레거시 프로젝트 — 먼저 이전을 고려하고, uv에게 시간 여행을 요구하지 마세요</li>
</ul>
