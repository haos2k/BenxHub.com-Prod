<h2 id="本篇學習目標">本篇學習目標</h2>
<ul>
<li>確認安裝前的必要條件</li>
<li>完成 OpenClaw 安裝</li>
<li>跑完 Onboarding 精靈，產生第一個助理</li>
<li>成功打開儀表板</li>
</ul>
<hr>
<h2 id="裝之前先確認這兩件事">裝之前先確認這兩件事</h2>
<p>不需要很多東西，但這兩樣缺一不可：</p>
<p><strong>1. Node.js（LTS 版本）</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">node</span><span style="color:#79C0FF"> --version</span></span>
<span data-line=""><span style="color:#8B949E"># 確認有印出版本號就對了</span></span></code></pre></figure>
<p><strong>2. AI 模型的 API Key</strong></p>
<p>用雲端模型（Anthropic Claude、OpenAI 等）需要 API key；想完全離線也可以，用本地模型就好。這個系列預設你用雲端模型。</p>
<blockquote>
<p>💡 不知道怎麼取得 API key？搜尋「Anthropic API key 申請」，通常 5 分鐘內搞定。</p>
</blockquote>
<hr>
<h2 id="安裝-openclaw">安裝 OpenClaw</h2>
<p>官方推薦用 <strong>git 安裝方式</strong>（方便之後更新和除錯）：</p>
<p><strong>macOS / Linux：</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># 依官方 docs.openclaw.ai 的 Quick Start 指令安裝</span></span>
<span data-line=""><span style="color:#8B949E"># 通常是一行 curl 腳本搞定</span></span></code></pre></figure>
<p><strong>Windows：</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># 先確認已安裝 Git 且加入 PATH</span></span>
<span data-line=""><span style="color:#FFA657">git</span><span style="color:#79C0FF"> --version</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># 再依 docs.openclaw.ai 的 Windows 說明安裝</span></span></code></pre></figure>
<blockquote>
<p>⚠️ 卡在「git not found」或「openclaw 無法辨識」？把 Git 加入系統 PATH，重開終端機再試一次。</p>
</blockquote>
<hr>
<h2 id="第一次啟動孵化助理">第一次啟動：孵化助理</h2>
<p>安裝完後，執行：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">openclaw</span><span style="color:#A5D6FF"> gateway</span></span></code></pre></figure>
<p><strong>第一次執行會進入 Onboarding 精靈</strong>，它會問你幾個問題：</p>
<ol>
<li>用哪個 AI 模型？</li>
<li>API key 是什麼？</li>
<li>工作區要放在哪裡？</li>
</ol>
<p>依畫面填完，它會幫你孵化出第一個助理。</p>
<blockquote>
<p>💡 卡在「wake up my friend」很久沒反應？先確認 API key 正確、網路正常，再看終端機有沒有錯誤訊息。</p>
</blockquote>
<hr>
<h2 id="onboarding-完成後你會得到什麼">Onboarding 完成後你會得到什麼？</h2>
<ul>
<li>一個 <strong>Token</strong>（之後登入儀表板要用）</li>
<li>基本設定檔：<code>~/.openclaw/openclaw.json</code></li>
<li>你的第一個 AI 助理，已經在運作了！</li>
</ul>
<hr>

</code></pre>
