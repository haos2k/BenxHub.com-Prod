助理的大腦在哪裡？搞懂記憶與工作區，再也不怕助理失憶

2026 年 3 月 8 日·3 min read

你有沒有遇過跟 AI 說了半天，下次對話它全忘了的崩潰感？

這篇就是來解決這個問題的。

本篇學習目標

  • 理解工作區（Workspace）的概念和用途
  • 知道記憶（Memory）怎麼運作
  • 了解資料存放的路徑
  • 學會一行指令備份所有設定

工作區（Workspace）是什麼？

把工作區想成助理的私人辦公室：

  • 助理讀的檔案、寫的文件、跑的腳本，都在這個資料夾裡操作
  • 你可以設多個工作區，讓不同任務有各自的空間
~/.openclaw/workspace-main        ← 私人助理的辦公室
~/.openclaw/workspace-project-a   ← 專案 A 的辦公室
~/.openclaw/workspace-project-b   ← 專案 B 的辦公室

這樣「幫我整理個人日記」和「幫我寫專案 A 的程式」就不會搞混在一起。

記憶（Memory）怎麼運作？

OpenClaw 會把對話中的重要資訊存成記憶，之後可以搜尋和引用。

簡單說：助理記得你告訴過他的事。

⚠️ 覺得助理老是忘記？檢查以下幾點：

  • 記憶功能有沒有啟用（語意搜尋可能需要 OpenAI API key）
  • 記憶有沒有被定期清理或達到長度限制
  • 是不是開了新的 session（新 session 的記憶是空的）

資料都存在哪裡？

類型 路徑
設定檔 ~/.openclaw/openclaw.json
工作區 ~/.openclaw/workspace-<名稱>/
Session 和記憶 ~/.openclaw/ 下各子目錄
