關掉電腦助理就消失？把 Gateway 搬到 VPS，24 小時隨時待命

2026 年 3 月 8 日·4 min read

你的助理不應該跟你的筆電一起休眠。

這篇告訴你怎麼把 Gateway 搬到雲端，讓助理全天候在線。

本篇學習目標

  • 知道 Gateway 可以放在哪些地方
  • 完成 VPS 上的安裝部署
  • 理解遠端連線的認證方式
  • 用 Tailscale 建立安全私有網路
  • 搞懂 Gateway 和 Node 的分工差異

Gateway 可以放哪裡？

位置 適合誰
本機電腦 個人測試、偶爾用用
VPS / 雲端伺服器 想要 24 小時隨時可用
家裡的 NAS / 舊電腦 不想花 VPS 費用，又想常駐

VPS 安裝大概長什麼樣？

登入你的 VPS（Ubuntu 或 Debian 最好），然後依照 docs.openclaw.ai 的 Linux 安裝步驟操作——跟本機安裝幾乎一樣，只是在遠端機器上執行。

遠端連線的認證問題

把 Gateway 裝在 VPS 上後，你從外面連進來，OpenClaw 需要確認「你是合法使用者」：

  • 一定要用 Token 或裝置配對，不然連不進去
  • 出現「unauthorized」？確認 gateway.bind 設定，以及 token 有沒有正確填入

用 Tailscale 最優雅（強烈推薦）

Tailscale 是一個免費的 VPN 工具，讓你的手機、電腦、VPS 像在同一個區網裡：

  1. VPS 和你的電腦都裝 Tailscale
  2. Gateway 設定 gateway.bind: tailnet
  3. 從任何裝置都可以透過 Tailscale 連到 Gateway

💡 Tailscale 還能用 Serve 功能提供 HTTPS，比直接暴露 port 安全多了。

什麼是 Node（節點）？

這裡有個很酷的概念——Gateway 和 Node 可以分開放：

  • Gateway：跑在 VPS 上，負責對話、記憶、Telegram 等所有「大腦」功能
  • Node：跑在你家電腦上，提供「手腳」：控制瀏覽器、讀寫本機檔案、操作螢幕

實際場景：你在外面用 Telegram 對助理說「幫我打開家裡電腦的瀏覽器查一下這個網頁」，Gateway 把任務傳給家裡的 Node 去執行，結果再傳回來。

這跟 SSH 有什麼不同？

SSH 需要你自己登入、自己打指令。用 Node 的話，助理幫你做，跟 Skills、工作區、對話全部整合在一起，你只要說話就好。
