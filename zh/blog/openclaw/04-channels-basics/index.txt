1b:T17b2,<p>如果你的 AI 助理只能在瀏覽器裡用，那跟在 ChatGPT 網頁上聊天有什麼差？</p>
<p>**Channel（通道）**就是解法：讓助理住在你平常就在用的 App 裡。</p>
<h2 id="本篇學習目標">本篇學習目標</h2>
<ul>
<li>理解什麼是 Channel</li>
<li>學會設定 Telegram Bot</li>
<li>知道怎麼在群組裡控制助理的發言方式</li>
<li>了解多 Channel 的可能性</li>
</ul>
<hr>
<h2 id="channel-是什麼">Channel 是什麼？</h2>
<p>你可以把 Channel 想成<strong>助理的多個門</strong>：</p>
<ul>
<li><strong>WebChat</strong>：瀏覽器裡的那扇門（已經幫你裝好了）</li>
<li><strong>Telegram Bot</strong>：你的手機那扇門</li>
<li><strong>WhatsApp</strong>：另一扇門</li>
<li><strong>Slack、Discord、iMessage…</strong>：更多門</li>
</ul>
<p>同一個助理，可以同時開多扇門，從哪裡進來都找得到他。</p>
<hr>
<h2 id="webchat不用設定就能用">WebChat：不用設定就能用</h2>
<p>打開儀表板，左側找到 <strong>Chat</strong> 標籤，選一個 Agent，直接開聊。這是最簡單的通道，不需要任何額外設定。</p>
<p>用來測試助理有沒有正常運作非常好用。</p>
<hr>
<h2 id="設定-telegram-bot手把手版">設定 Telegram Bot（手把手版）</h2>
<h3 id="步驟一去-botfather-建立-bot">步驟一：去 BotFather 建立 Bot</h3>
<ol>
<li>打開 Telegram，搜尋 <code>@BotFather</code></li>
<li>發送 <code>/newbot</code></li>
<li>依提示設定 Bot 名稱</li>
<li>取得你的 <strong>Bot Token</strong>（長這樣：<code>123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11</code>）</li>
</ol>
<h3 id="步驟二在-openclaw-config-裡設定">步驟二：在 OpenClaw Config 裡設定</h3>
<p>打開儀表板 → Config → 找到 <code>channels.telegram</code>，填入：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="json5" data-theme="github-dark-default"><code data-language="json5" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#E6EDF3">{</span></span>
<span data-line=""><span style="color:#A5D6FF">  "channels"</span><span style="color:#E6EDF3">: {</span></span>
<span data-line=""><span style="color:#A5D6FF">    "telegram"</span><span style="color:#E6EDF3">: {</span></span>
<span data-line=""><span style="color:#A5D6FF">      "enabled"</span><span style="color:#E6EDF3">: </span><span style="color:#79C0FF">true</span><span style="color:#E6EDF3">,</span></span>
<span data-line=""><span style="color:#A5D6FF">      "botToken"</span><span style="color:#E6EDF3">: </span><span style="color:#A5D6FF">"你的Bot Token貼這裡"</span><span style="color:#E6EDF3">,</span></span>
<span data-line=""><span style="color:#A5D6FF">      "dmPolicy"</span><span style="color:#E6EDF3">: </span><span style="color:#A5D6FF">"pairing"</span></span>
<span data-line=""><span style="color:#E6EDF3">    }</span></span>
<span data-line=""><span style="color:#E6EDF3">  }</span></span>
<span data-line=""><span style="color:#E6EDF3">}</span></span></code></pre></figure>
<h3 id="步驟三測試">步驟三：測試</h3>
<p>去 Telegram 搜尋你的 Bot，發一句「你好」，助理應該要回你了。</p>
<blockquote>
<p>⚠️ 第一次私聊 Bot 可能需要「配對」，依照 Bot 的回覆指示操作即可。</p>
</blockquote>
<hr>
<h2 id="加進群組怎麼設定">加進群組怎麼設定？</h2>
<p>在群組裡，你通常不希望有人說一句話助理就瘋狂回應（吵死了）。加個 <code>requireMention</code>：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="json5" data-theme="github-dark-default"><code data-language="json5" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#E6EDF3">{</span></span>
<span data-line=""><span style="color:#A5D6FF">  "channels"</span><span style="color:#E6EDF3">: {</span></span>
<span data-line=""><span style="color:#A5D6FF">    "telegram"</span><span style="color:#E6EDF3">: {</span></span>
<span data-line=""><span style="color:#A5D6FF">      "enabled"</span><span style="color:#E6EDF3">: </span><span style="color:#79C0FF">true</span><span style="color:#E6EDF3">,</span></span>
<span data-line=""><span style="color:#A5D6FF">      "botToken"</span><span style="color:#E6EDF3">: </span><span style="color:#A5D6FF">"你的Bot Token"</span><span style="color:#E6EDF3">,</span></span>
<span data-line=""><span style="color:#A5D6FF">      "dmPolicy"</span><span style="color:#E6EDF3">: </span><span style="color:#A5D6FF">"pairing"</span><span style="color:#E6EDF3">,</span></span>
<span data-line=""><span style="color:#A5D6FF">      "groups"</span><span style="color:#E6EDF3">: {</span></span>
<span data-line=""><span style="color:#A5D6FF">        "*"</span><span style="color:#E6EDF3">: { </span><span style="color:#A5D6FF">"requireMention"</span><span style="color:#E6EDF3">: </span><span style="color:#79C0FF">true</span><span style="color:#E6EDF3"> }</span></span>
<span data-line=""><span style="color:#E6EDF3">      }</span></span>
<span data-line=""><span style="color:#E6EDF3">    }</span></span>
<span data-line=""><span style="color:#E6EDF3">  }</span></span>
<span data-line=""><span style="color:#E6EDF3">}</span></span></code></pre></figure>
<p>這樣只有在訊息裡 @ 你的 Bot，助理才會出來說話。</p>
<hr>
<h2 id="一個-bot-不夠用">一個 Bot 不夠用？</h2>
<p><strong>不同群組讓不同助理回應、不同 Bot 帳號處理不同任務</strong>——這些進階玩法在第七篇「多代理與 Bindings」會詳細介紹。</p>

<h2 id="設定-telegram-bot手把手版">設定 Telegram Bot（手把手版）</h2>
<h3 id="步驟一去-botfather-建立-bot">步驟一：去 BotFather 建立 Bot</h3>
<ol>
<li>打開 Telegram，搜尋 <code>@BotFather</code></li>
<li>發送 <code>/newbot</code></li>
<li>依提示設定 Bot 名稱</li>
<li>取得你的 <strong>Bot Token</strong>（長這樣：<code>123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11</code>）</li>
</ol>
<h3 id="步驟二在-openclaw-config-裡設定">步驟二：在 OpenClaw Config 裡設定</h3>
<p>打開儀表板 → Config → 找到 <code>channels.telegram</code>，填入：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="json5" data-theme="github-dark-default"><code data-language="json5" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#E6EDF3">{</span></span>
<span data-line=""><span style="color:#A5D6FF">  "channels"</span><span style="color:#E6EDF3">: {</span></span>
<span data-line=""><span style="color:#A5D6FF">    "telegram"</span><span style="color:#E6EDF3">: {</span></span>
<span data-line=""><span style="color:#A5D6FF">      "enabled"</span><span style="color:#E6EDF3">: </span><span style="color:#79C0FF">true</span><span style="color:#E6EDF3">,</span></span>
<span data-line=""><span style="color:#A5D6FF">      "botToken"</span><span style="color:#E6EDF3">: </span><span style="color:#A5D6FF">"你的Bot Token貼這裡"</span><span style="color:#E6EDF3">,</span></span>
<span data-line=""><span style="color:#A5D6FF">      "dmPolicy"</span><span style="color:#E6EDF3">: </span><span style="color:#A5D6FF">"pairing"</span></span>
<span data-line=""><span style="color:#E6EDF3">    }</span></span>
<span data-line=""><span style="color:#E6EDF3">  }</span></span>
<span data-line=""><span style="color:#E6EDF3">}</span></span></code></pre></figure>
<h3 id="步驟三測試">步驟三：測試</h3>
<p>去 Telegram 搜尋你的 Bot，發一句「你好」，助理應該要回你了。</p>
<blockquote>
<p>⚠️ 第一次私聊 Bot 可能需要「配對」，依照 Bot 的回覆指示操作即可。</p>
</blockquote>
<hr>
<h2 id="加進群組怎麼設定">加進群組怎麼設定？</h2>
<p>在群組裡，你通常不希望有人說一句話助理就瘋狂回應（吵死了）。加個 <code>requireMention</code>：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="json5" data-theme="github-dark-default"><code data-language="json5" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#E6EDF3">{</span></span>
<span data-line=""><span style="color:#A5D6FF">  "channels"</span><span style="color:#E6EDF3">: {</span></span>
<span data-line=""><span style="color:#A5D6FF">    "telegram"</span><span style="color:#E6EDF3">: {</span></span>
<span data-line=""><span style="color:#A5D6FF">      "enabled"</span><span style="color:#E6EDF3">: </span><span style="color:#79C0FF">true</span><span style="color:#E6EDF3">,</span></span>
<span data-line=""><span style="color:#A5D6FF">      "botToken"</span><span style="color:#E6EDF3">: </span><span style="color:#A5D6FF">"你的Bot Token"</span><span style="color:#E6EDF3">,</span></span>
<span data-line=""><span style="color:#A5D6FF">      "dmPolicy"</span><span style="color:#E6EDF3">: </span><span style="color:#A5D6FF">"pairing"</span><span style="color:#E6EDF3">,</span></span>
<span data-line=""><span style="color:#A5D6FF">      "groups"</span><span style="color:#E6EDF3">: {</span></span>
<span data-line=""><span style="color:#A5D6FF">        "*"</span><span style="color:#E6EDF3">: { </span><span style="color:#A5D6FF">"requireMention"</span><span style="color:#E6EDF3">: </span><span style="color:#79C0FF">true</span><span style="color:#E6EDF3"> }</span></span>
<span data-line=""><span style="color:#E6EDF3">      }</span></span>
<span data-line=""><span style="color:#E6EDF3">    }</span></span>
<span data-line=""><span style="color:#E6EDF3">  }</span></span>
<span data-line=""><span style="color:#E6EDF3">}</span></span></code></pre></figure>
<p>這樣只有在訊息裡 @ 你的 Bot，助理才會出來說話。</p>
<hr>
<h2 id="一個-bot-不夠用">一個 Bot 不夠用？</h2>
<p><strong>不同群組讓不同助理回應、不同 Bot 帳號處理不同任務</strong>——這些進階玩法在第七篇「多代理與 Bindings」會詳細介紹。</p>
