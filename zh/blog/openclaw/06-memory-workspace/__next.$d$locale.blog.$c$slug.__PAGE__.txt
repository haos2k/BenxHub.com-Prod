<h2 id="本篇學習目標">本篇學習目標</h2>
<ul>
<li>理解工作區（Workspace）的概念和用途</li>
<li>知道記憶（Memory）怎麼運作</li>
<li>了解資料存放的路徑</li>
<li>學會一行指令備份所有設定</li>
</ul>
<hr>
<h2 id="工作區workspace是什麼">工作區（Workspace）是什麼？</h2>
<p>把工作區想成<strong>助理的私人辦公室</strong>：</p>
<ul>
<li>助理讀的檔案、寫的文件、跑的腳本，都在這個資料夾裡操作</li>
<li>你可以設多個工作區，讓不同任務有各自的空間</li>
</ul>
<pre><code>~/.openclaw/workspace-main        ← 私人助理的辦公室
~/.openclaw/workspace-project-a   ← 專案 A 的辦公室
~/.openclaw/workspace-project-b   ← 專案 B 的辦公室
</code></pre>
<p>這樣「幫我整理個人日記」和「幫我寫專案 A 的程式」就不會搞混在一起。</p>
<hr>
<h2 id="記憶memory怎麼運作">記憶（Memory）怎麼運作？</h2>
<p>OpenClaw 會把對話中的重要資訊存成<strong>記憶</strong>，之後可以搜尋和引用。</p>
<p>簡單說：<strong>助理記得你告訴過他的事</strong>。</p>
<blockquote>
<p>⚠️ 覺得助理老是忘記？檢查以下幾點：</p>
<ul>
<li>記憶功能有沒有啟用（語意搜尋可能需要 OpenAI API key）</li>
<li>記憶有沒有被定期清理或達到長度限制</li>
<li>是不是開了新的 session（新 session 的記憶是空的）</li>
</ul>
</blockquote>

</blockquote>
