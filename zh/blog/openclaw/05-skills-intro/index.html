助理開外掛！Skills 讓你的 AI 從「聊天機器」變「行動派」

2026 年 3 月 8 日·3 min read

一個只會聊天的助理，就像雇了個超聰明的員工，但不給他任何工具——白費了。

**Skills（技能）**就是給助理裝上工具的方式。

本篇學習目標

  • 理解 Skill 是什麼
  • 知道怎麼啟用內建技能
  • 學會新增自訂技能
  • 了解技能的優先順序與載入路徑

Skill 是什麼？

每個 Skill 就是一份「說明書」，通常叫做 SKILL.md，裡面寫著：

  • 這個技能能做什麼
  • 什麼情況下該用
  • 可以使用哪些工具和步驟

你可以把它想成助理的工作手冊：有了瀏覽網頁的手冊，他就能上網查資料；有了讀寫檔案的手冊，他就能整理你的文件。

內建 vs 自訂

OpenClaw 自帶一些常用技能，社群也在持續貢獻新的。你可以：

  • 直接用內建的：在儀表板的 Skills 區啟用就好
  • 自己寫一個：只要一個 SKILL.md 文字檔

自訂 Skill：聰明的做法

想改或新增技能，不要動 OpenClaw repo 裡的原始檔！一更新就被蓋掉了，你會哭的。

正確做法——把你的版本放在這裡：

~/.openclaw/skills/<技能名稱>/SKILL.md

優先順序（先命中先贏）：

你的 workspace/skills  →  ~/.openclaw/skills  →  內建  →  extraDirs

放在最前面的會優先被使用。

在儀表板管理 Skills

打開 Control UI → Skills 標籤，你可以：

  • 查看所有可用技能
  • 一鍵啟用 / 停用
  • 設定需要 API key 的技能
  • 安裝社群技能

改完設定後通常會熱重載，不用重開 Gateway。
