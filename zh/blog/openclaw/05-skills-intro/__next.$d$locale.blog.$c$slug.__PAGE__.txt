3:Te25,<p>一個只會聊天的助理，就像雇了個超聰明的員工，但不給他任何工具——白費了。</p>
<p>**Skills（技能）**就是給助理裝上工具的方式。</p>
<h2 id="本篇學習目標">本篇學習目標</h2>
<ul>
<li>理解 Skill 是什麼</li>
<li>知道怎麼啟用內建技能</li>
<li>學會新增自訂技能</li>
<li>了解技能的優先順序與載入路徑</li>
</ul>
<hr>
<h2 id="skill-是什麼">Skill 是什麼？</h2>
<p>每個 Skill 就是一份「說明書」，通常叫做 <code>SKILL.md</code>，裡面寫著：</p>
<ul>
<li>這個技能能做什麼</li>
<li>什麼情況下該用</li>
<li>可以使用哪些工具和步驟</li>
</ul>
<p>你可以把它想成<strong>助理的工作手冊</strong>：有了瀏覽網頁的手冊，他就能上網查資料；有了讀寫檔案的手冊，他就能整理你的文件。</p>
<hr>
<h2 id="內建-vs-自訂">內建 vs 自訂</h2>
<p>OpenClaw 自帶一些常用技能，社群也在持續貢獻新的。你可以：</p>
<ul>
<li><strong>直接用內建的</strong>：在儀表板的 Skills 區啟用就好</li>
<li><strong>自己寫一個</strong>：只要一個 <code>SKILL.md</code> 文字檔</li>
</ul>
<hr>
<h2 id="自訂-skill聰明的做法">自訂 Skill：聰明的做法</h2>
<p>想改或新增技能，<strong>不要動 OpenClaw repo 裡的原始檔</strong>！一更新就被蓋掉了，你會哭的。</p>
<p>正確做法——把你的版本放在這裡：</p>
<pre><code>~/.openclaw/skills/&#x3C;技能名稱>/SKILL.md
</code></pre>
<p><strong>優先順序（先命中先贏）：</strong></p>
<pre><code>你的 workspace/skills  →  ~/.openclaw/skills  →  內建  →  extraDirs
</code></pre>
<p>放在最前面的會優先被使用。</p>
<hr>
<h2 id="在儀表板管理-skills">在儀表板管理 Skills</h2>
<p>打開 Control UI → <strong>Skills</strong> 標籤，你可以：</p>
<ul>
<li>查看所有可用技能</li>
<li>一鍵啟用 / 停用</li>
<li>設定需要 API key 的技能</li>
<li>安裝社群技能</li>
</ul>
<p>改完設定後通常會熱重載，不用重開 Gateway。</p>
<hr>
<h2 id="用自訂資料夾載入">用自訂資料夾載入</h2>
<p>如果你想把所有自訂技能集中管理在某個地方：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="json5" data-theme="github-dark-default"><code data-language="json5" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E">// ~/.openclaw/openclaw.json</span></span>
<span data-line=""><span style="color:#E6EDF3">{</span></span>
<span data-line=""><span style="color:#A5D6FF">  "skills"</span><span style="color:#E6EDF3">: {</span></span>
<span data-line=""><span style="color:#A5D6FF">    "load"</span><span style="color:#E6EDF3">: {</span></span>
<span data-line=""><span style="color:#A5D6FF">      "extraDirs"</span><span style="color:#E6EDF3">: [</span><span style="color:#A5D6FF">"/你的自訂技能資料夾"</span><span style="color:#E6EDF3">]</span></span>
<span data-line=""><span style="color:#E6EDF3">    }</span></span>
<span data-line=""><span style="color:#E6EDF3">  }</span></span>
<span data-line=""><span style="color:#E6EDF3">}</span></span></code></pre></figure>
