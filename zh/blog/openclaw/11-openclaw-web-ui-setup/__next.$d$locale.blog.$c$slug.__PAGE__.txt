<h2 id="web-ui-的設定方式表單-vs-raw-json">Web UI 的設定方式：表單 vs Raw JSON</h2>
<p>進入 <strong>Config</strong> 頁，你有兩種選擇：</p>
<p><strong>表單模式</strong>：有格式好看的輸入欄位，適合初學者或改少量設定。</p>
<p><strong>Raw JSON 模式</strong>：直接編輯 JSON 設定檔，精準、快速，適合進階使用者或一次改很多東西。</p>
<p>兩種模式改的是同一份 <code>~/.openclaw/openclaw.json</code>，隨時可以切換。</p>
<hr>

<h2 id="設定完記得存檔">設定完記得存檔</h2>
<p>按 <strong>Save / Apply</strong>。OpenClaw 會：</p>
<ol>
<li>驗證設定格式（有錯就提示，不會寫入）</li>
<li>套用設定，通常自動熱重載</li>
</ol>
<blockquote>
<p>⚠️ 出現「baseHash 衝突」？設定被其他地方改過了——重新載入 Config 再改一次，再存。</p>
</blockquote>

<h2 id="web-ui-的設定方式表單-vs-raw-json">Web UI 的設定方式：表單 vs Raw JSON</h2>
<p>進入 <strong>Config</strong> 頁，你有兩種選擇：</p>
<p><strong>表單模式</strong>：有格式好看的輸入欄位，適合初學者或改少量設定。</p>
<p><strong>Raw JSON 模式</strong>：直接編輯 JSON 設定檔，精準、快速，適合進階使用者或一次改很多東西。</p>
<p>兩種模式改的是同一份 <code>~/.openclaw/openclaw.json</code>，隨時可以切換。</p>
<hr>
