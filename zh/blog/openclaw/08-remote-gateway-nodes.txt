<h2 id="vps-安裝大概長什麼樣">VPS 安裝大概長什麼樣？</h2>
<p>登入你的 VPS（Ubuntu 或 Debian 最好），然後依照 <a href="https://docs.openclaw.ai">docs.openclaw.ai</a> 的 Linux 安裝步驟操作——跟本機安裝幾乎一樣，只是在遠端機器上執行。</p>
<hr>
<h2 id="遠端連線的認證問題">遠端連線的認證問題</h2>
<p>把 Gateway 裝在 VPS 上後，你從外面連進來，OpenClaw 需要確認「你是合法使用者」：</p>
<ul>
<li><strong>一定要用 Token 或裝置配對</strong>，不然連不進去</li>
<li>出現「unauthorized」？確認 <code>gateway.bind</code> 設定，以及 token 有沒有正確填入</li>
</ul>
<hr>
<h2 id="用-tailscale-最優雅強烈推薦">用 Tailscale 最優雅（強烈推薦）</h2>
<p><strong>Tailscale</strong> 是一個免費的 VPN 工具，讓你的手機、電腦、VPS 像在同一個區網裡：</p>
<ol>
<li>VPS 和你的電腦都裝 Tailscale</li>
<li>Gateway 設定 <code>gateway.bind: tailnet</code></li>
<li>從任何裝置都可以透過 Tailscale 連到 Gateway</li>
</ol>
<blockquote>
<p>💡 Tailscale 還能用 Serve 功能提供 HTTPS，比直接暴露 port 安全多了。</p>
</blockquote>
<hr>
<h2 id="什麼是-node節點">什麼是 Node（節點）？</h2>
<p>這裡有個很酷的概念——<strong>Gateway 和 Node 可以分開放</strong>：</p>
<ul>
<li><strong>Gateway</strong>：跑在 VPS 上，負責對話、記憶、Telegram 等所有「大腦」功能</li>
<li><strong>Node</strong>：跑在你家電腦上，提供「手腳」：控制瀏覽器、讀寫本機檔案、操作螢幕</li>
</ul>
<p>實際場景：你在外面用 Telegram 對助理說「幫我打開家裡電腦的瀏覽器查一下這個網頁」，Gateway 把任務傳給家裡的 Node 去執行，結果再傳回來。</p>
<p><strong>這跟 SSH 有什麼不同？</strong></p>
<p>SSH 需要你自己登入、自己打指令。用 Node 的話，<strong>助理幫你做</strong>，跟 Skills、工作區、對話全部整合在一起，你只要說話就好。</p>
