3:Tf02,<p>「Token？pairing？我以為我只是要開個網頁而已啊！」</p>
<p>這種崩潰我完全理解。這篇就是為了讓你<strong>再也不怕登入畫面</strong>。</p>
<h2 id="本篇學習目標">本篇學習目標</h2>
<ul>
<li>理解 Gateway 和儀表板的關係</li>
<li>搞懂三種常見的認證情況</li>
<li>學會遠端連線的設定方式</li>
<li>順手改語言設定</li>
</ul>
<hr>
<h2 id="先把-gateway-跑起來">先把 Gateway 跑起來</h2>
<p>儀表板只是個視窗，真正在工作的是 <strong>Gateway</strong>。沒有 Gateway，打開網頁只會看到一片空白。</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">openclaw</span><span style="color:#9ECBFF"> gateway</span></span></code></pre></figure>
<p>看到類似「Gateway running」的訊息，才繼續下一步。</p>
<hr>
<h2 id="打開儀表板">打開儀表板</h2>
<pre><code>http://127.0.0.1:18789/
</code></pre>
<p>如果你有設定過 <code>basePath</code>（例如 <code>/openclaw</code>）：</p>
<pre><code>http://127.0.0.1:18789/openclaw
</code></pre>
<hr>
<h2 id="認證到底要填什麼">認證：到底要填什麼？</h2>
<h3 id="情況一出現pairing-required">情況一：出現「pairing required」</h3>
<p>這是 OpenClaw 在問「你是誰？我還不認識你這台電腦」。解法：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">openclaw</span><span style="color:#9ECBFF"> devices</span><span style="color:#9ECBFF"> list</span></span>
<span data-line=""><span style="color:#6A737D"># 找到待核准的 requestId</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#B392F0">openclaw</span><span style="color:#9ECBFF"> devices</span><span style="color:#9ECBFF"> approve</span><span style="color:#F97583"> &#x3C;</span><span style="color:#9ECBFF">requestI</span><span style="color:#E1E4E8">d</span><span style="color:#F97583">></span></span>
<span data-line=""><span style="color:#6A737D"># 替換成實際的 ID</span></span></code></pre></figure>
<p>完成後重新整理瀏覽器，就能進去了。</p>
<h3 id="情況二要求輸入-token">情況二：要求輸入 Token</h3>
<p>Onboarding 時有給你一個 token，就是現在要貼的東西。貼進去，在 Settings 存起來，以後就不用再貼了。</p>
<blockquote>
<p>💡 Token 存在 UI 設定裡。密碼的話，只存在記憶體中，關掉就消失——這是設計上刻意的，保護你的安全。</p>
</blockquote>
<h3 id="情況三遠端連線vps--lan">情況三：遠端連線（VPS / LAN）</h3>
<p>如果 Gateway 不是跑在本機，而是在遠端伺服器上：</p>
<ul>
<li>必須使用 Token 或裝置配對才能連線</li>
<li>出現「unauthorized」？先確認 <code>gateway.bind</code> 設定，以及 token 是否正確填入</li>
</ul>
<hr>
<h2 id="換個語言">換個語言？</h2>
<p>Control UI 支援繁體中文、簡體中文、英文等多種語言。</p>
<p>在 <strong>Access</strong> 區找到語言選單，選好後瀏覽器會記住，下次自動套用。</p>
<hr>
