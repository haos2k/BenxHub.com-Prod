<h2 id="打開儀表板">打開儀表板</h2>
<pre><code>http://127.0.0.1:18789/
</code></pre>
<p>如果你有設定過 <code>basePath</code>（例如 <code>/openclaw</code>）：</p>
<pre><code>http://127.0.0.1:18789/openclaw
</code></pre>

<h2 id="認證到底要填什麼">認證：到底要填什麼？</h2>
<h3 id="情況一出現pairing-required">情況一：出現「pairing required」</h3>
<p>這是 OpenClaw 在問「你是誰？我還不認識你這台電腦」。解法：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">openclaw</span><span style="color:#A5D6FF"> devices</span><span style="color:#A5D6FF"> list</span></span>

<span data-line=""><span style="color:#FFA657">openclaw</span><span style="color:#A5D6FF"> devices</span><span style="color:#A5D6FF"> approve</span><span style="color:#FF7B72"> &#x3C;</span><span style="color:#A5D6FF">requestI</span><span style="color:#E6EDF3">d</span><span style="color:#FF7B72">></span></span>
<span data-line=""><span style="color:#8B949E"># 替換成實際的 ID</span></span></code></pre></figure>
<p>完成後重新整理瀏覽器，就能進去了。</p>
<h3 id="情況二要求輸入-token">情況二：要求輸入 Token</h3>
<p>Onboarding 時有給你一個 token，就是現在要貼的東西。貼進去，在 Settings 存起來，以後就不用再貼了。</p>
<blockquote>
<p>💡 Token 存在 UI 設定裡。密碼的話，只存在記憶體中，關掉就消失——這是設計上刻意的，保護你的安全。</p>
</blockquote>
<h3 id="情況三遠端連線vps--lan">情況三：遠端連線（VPS / LAN）</h3>
<p>如果 Gateway 不是跑在本機，而是在遠端伺服器上：</p>
<ul>
<li>必須使用 Token 或裝置配對才能連線</li>
<li>出現「unauthorized」？先確認 <code>gateway.bind</code> 設定，以及 token 是否正確填入</li>
</ul>
