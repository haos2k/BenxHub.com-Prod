儀表板老是卡關？三分鐘搞懂 OpenClaw 認證

2026 年 3 月 8 日·3 min read

「Token？pairing？我以為我只是要開個網頁而已啊！」

這種崩潰我完全理解。這篇就是為了讓你再也不怕登入畫面。

本篇學習目標

  • 理解 Gateway 和儀表板的關係
  • 搞懂三種常見的認證情況
  • 學會遠端連線的設定方式
  • 順手改語言設定

先把 Gateway 跑起來

儀表板只是個視窗，真正在工作的是 Gateway。沒有 Gateway，打開網頁只會看到一片空白。

看到類似「Gateway running」的訊息，才繼續下一步。

打開儀表板

http://127.0.0.1:18789/

如果你有設定過 basePath（例如 /openclaw）：

http://127.0.0.1:18789/openclaw

認證：到底要填什麼？

情況一：出現「pairing required」

這是 OpenClaw 在問「你是誰？我還不認識你這台電腦」。解法：

完成後重新整理瀏覽器，就能進去了。

情況二：要求輸入 Token

Onboarding 時有給你一個 token，就是現在要貼的東西。貼進去，在 Settings 存起來，以後就不用再貼了。

💡 Token 存在 UI 設定裡。密碼的話，只存在記憶體中，關掉就消失——這是設計上刻意的，保護你的安全。

情況三：遠端連線（VPS / LAN）

如果 Gateway 不是跑在本機，而是在遠端伺服器上：

  • 必須使用 Token 或裝置配對才能連線
  • 出現「unauthorized」？先確認 gateway.bind 設定，以及 token 是否正確填入

換個語言？

Control UI 支援繁體中文、簡體中文、英文等多種語言。

在 Access 區找到語言選單，選好後瀏覽器會記住，下次自動套用。
