<p><strong><code>--resume</code></strong> 和 <strong><code>-c</code></strong> 解決的就是這兩件事：一個讓你接回上次的對話，一個讓任務在雲端繼續跑，你關機了也沒關係。</p>
<h2 id="--resume接回上次的對話">--resume：接回上次的對話</h2>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#79B8FF"> --resume</span></span></code></pre></figure>

<p><code>chat-id</code> 從下面這個指令取得。</p>

<h2 id="-c把任務丟給雲端跑">-c：把任務丟給雲端跑</h2>
<p>有些任務很重——全 repo 分析、產一大份文件、多輪重構——在本地跑要一直開著終端機，筆電關機或網路斷線就中斷。</p>
<p>用 <strong><code>-c</code></strong>（或 <code>--cloud</code>）把這一輪對話交給雲端 Agent 執行：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "分析整個專案並產出架構文件到 docs/architecture.md"</span><span style="color:#79B8FF"> -c</span></span></code></pre></figure>
<p>送出後任務在 Cursor 雲端跑，你可以關掉終端機、關機、去做別的事。之後在任意裝置開 CLI，用 <code>--resume</code> 接回那場對話，看結果或繼續追加指令。</p>
<p><code>-c</code> 等於：<strong>「這題交給雲端，我不必在電腦前等。」</strong></p>
<h3 id="什麼時候值得用--c">什麼時候值得用 -c</h3>
<table>
<thead>
<tr>
<th>情境</th>
<th>建議</th>
</tr>
</thead>
<tbody>
<tr>
<td>任務預期跑很久</td>
<td>用 <code>-c</code>，關機也能跑完</td>
</tr>
<tr>
<td>快速問一句、改小東西</td>
<td>不需要 <code>-c</code>，本地跑就好</td>
</tr>
<tr>
<td>網路不穩或不想依賴雲端</td>
<td>本地跑，但要保持連線</td>
</tr>
</tbody>
</table>
<h2 id="典型流程雲端--多裝置">典型流程：雲端 + 多裝置</h2>
<ol>
<li>開任務並加 <code>-c</code>，讓雲端跑</li>
<li>關終端機、去忙別的</li>
<li>之後跑 <code>cursor agent ls</code> 找到那場</li>
<li><code>cursor agent --resume=該場ID</code> 接回，看結果或再下指令</li>
</ol>
<p>長時間任務、關機、換裝置——這套組合都能兼顧。</p>
<hr>
<p><code>--resume</code> 讓對話有記憶、<code>-c</code> 讓任務不用你守著——兩個加在一起，等於 AI 不再只能在你開著電腦的時候才能工作。</p>
