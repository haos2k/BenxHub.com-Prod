Cursor CLI 基本指令：cursor agent 怎麼用

2026 年 2 月 24 日·3 min read

裝好 Cursor CLI 之後，九成的時間你只會用到一個指令：cursor agent。

cursor agent：交辦任務的入口

在你的專案目錄下：

AI 會讀目前目錄的檔案，然後動手——可能直接改，可能先問你幾個問題，你可以接受或拒絕每個修改，控制權一直在你手上。

一次給任務 vs 慢慢聊

想直接交辦： 把指令寫在引號裡一口氣給出去。

想先討論再動手： 只打 cursor agent 不帶任何參數，會進入對話模式。你可以逐步描述需求，AI 釐清完再動 code——適合那種「需求還沒想清楚」的場合，比起一次下錯指令再來回改，其實更省時間。

想指定在哪個目錄做事

預設是你當前所在的目錄。若要指定別的路徑：

這個在伺服器上遠端操作某個子目錄，或搭配 worktree 使用時很實用——06-cursor-cli-with-worktree 會講到。

只想問不想改：cursor ask

有時候你只是想問「這段 code 在幹嘛」，完全不希望 AI 碰任何檔案——這時用 cursor ask：

讀、分析、回答，但不寫入。放心問。

常用指令速查

指令 說明
cursor agent "做某事" 讓 AI 幫你做，可改檔案
cursor agent 進對話模式，不帶任務慢慢聊
cursor ask "問題" 只問問題，不改任何檔案
cursor --help 查看所有選項

用 cursor agent 交辦、用 cursor ask 提問，加上 --path 指定目錄——這三板斧先學熟，日常 80% 的用法都夠了。
