3:T1034,<p>裝好 Cursor CLI 之後，九成的時間你只會用到一個指令：<code>cursor agent</code>。</p>
<h2 id="cursor-agent交辦任務的入口">cursor agent：交辦任務的入口</h2>
<p>在你的專案目錄下：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "幫我把這個專案加上 README"</span></span></code></pre></figure>
<p>AI 會讀目前目錄的檔案，然後動手——可能直接改，可能先問你幾個問題，你可以接受或拒絕每個修改，控制權一直在你手上。</p>
<h2 id="一次給任務-vs-慢慢聊">一次給任務 vs 慢慢聊</h2>
<p><strong>想直接交辦：</strong> 把指令寫在引號裡一口氣給出去。</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "重構 auth 模組，改用 JWT"</span></span></code></pre></figure>
<p><strong>想先討論再動手：</strong> 只打 <code>cursor agent</code> 不帶任何參數，會進入<strong>對話模式</strong>。你可以逐步描述需求，AI 釐清完再動 code——適合那種「需求還沒想清楚」的場合，比起一次下錯指令再來回改，其實更省時間。</p>
<h2 id="想指定在哪個目錄做事">想指定在哪個目錄做事</h2>
<p>預設是你當前所在的目錄。若要指定別的路徑：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "檢查並修復 TypeScript 型別"</span><span style="color:#79B8FF"> --path</span><span style="color:#9ECBFF"> ./src</span></span></code></pre></figure>
<p>這個在伺服器上遠端操作某個子目錄，或搭配 worktree 使用時很實用——<a href="06-cursor-cli-with-worktree">06-cursor-cli-with-worktree</a> 會講到。</p>
<h2 id="只想問不想改cursor-ask">只想問不想改：cursor ask</h2>
<p>有時候你只是想問「這段 code 在幹嘛」，<strong>完全不希望 AI 碰任何檔案</strong>——這時用 <code>cursor ask</code>：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> ask</span><span style="color:#9ECBFF"> "src/auth.ts 的邏輯是什麼？"</span></span></code></pre></figure>
<p>讀、分析、回答，但不寫入。放心問。</p>
