1a:T18e0,<p><strong>Git Worktree</strong> 讓同一個 repo 可以同時在多個目錄、多個 branch 上工作。<strong>Cursor CLI</strong> 的規則是「在哪個目錄跑，就改哪個目錄」。</p>
<p>兩個加在一起，結論很直接：多開幾個終端機、各自 <code>cd</code> 到不同 worktree、各自跑 <code>cursor agent</code>，就等於<strong>多個 AI Agent 並行處理不同 branch</strong>——不用開一堆 Cursor 視窗，鍵盤流就能多線作戰。</p>
<h2 id="兩種並行方式">兩種並行方式</h2>
<table>
<thead>
<tr>
<th>做法</th>
<th>適合誰</th>
</tr>
</thead>
<tbody>
<tr>
<td>Worktree + 多個 Cursor <strong>視窗</strong></td>
<td>喜歡 IDE、要看檔案樹與預覽</td>
</tr>
<tr>
<td>Worktree + <strong>CLI 多終端機</strong></td>
<td>習慣鍵盤流、或在伺服器 / SSH 環境</td>
</tr>
</tbody>
</table>
<p>共通點是：每個 worktree 是獨立目錄，各自有獨立上下文，可以並行開發、互不踩腳。就像多個分身同時在不同 branch 上工。</p>
<h2 id="最直接的用法一個終端機對應一個-worktree">最直接的用法：一個終端機對應一個 Worktree</h2>
<p>假設你已經建好 worktree：</p>
<pre><code>~/projects/
├── my-app/                   ← main
├── my-app--feature-auth/     ← feature/auth
└── my-app--feature-payment/  ← feature/payment
</code></pre>
<p><strong>終端機 1</strong>（搞 auth）：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#79B8FF">cd</span><span style="color:#9ECBFF"> ~/projects/my-app--feature-auth</span></span>
<span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "實作 JWT 登入"</span></span></code></pre></figure>
<p><strong>終端機 2</strong>（搞 payment）：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#79B8FF">cd</span><span style="color:#9ECBFF"> ~/projects/my-app--feature-payment</span></span>
<span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "加上 Stripe 結帳流程"</span></span></code></pre></figure>
<p>兩個 Agent 各自在自己的 worktree 裡跑，互不干擾。省資源、省切換，比開兩個 Cursor 視窗還清爽。</p>
<h2 id="不想切目錄用---path-直接指定">不想切目錄：用 --path 直接指定</h2>
<p>人坐在主專案目錄，想讓 CLI 去改某個 worktree——加 <code>--path</code> 就好：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#79B8FF">cd</span><span style="color:#9ECBFF"> ~/projects/my-app</span></span>
<span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "幫 feature/auth 加上單元測試"</span><span style="color:#79B8FF"> --path</span><span style="color:#9ECBFF"> ../my-app--feature-auth</span></span></code></pre></figure>
<p>適合一次只處理一個 worktree、或腳本裡路徑固定的情境。</p>
<h2 id="批次任務對多個-worktree-跑同一件事">批次任務：對多個 Worktree 跑同一件事</h2>
<p>PR 前想對幾個 branch 都跑一次 lint 修復：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "依 .eslintrc 修復所有可自動修復的錯誤"</span><span style="color:#79B8FF"> --path</span><span style="color:#9ECBFF"> ../my-app--feature-auth</span><span style="color:#79B8FF"> --no-interactive</span></span>
<span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "依 .eslintrc 修復所有可自動修復的錯誤"</span><span style="color:#79B8FF"> --path</span><span style="color:#9ECBFF"> ../my-app--feature-payment</span><span style="color:#79B8FF"> --no-interactive</span></span></code></pre></figure>
<p>或寫成迴圈：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#F97583">for</span><span style="color:#E1E4E8"> dir </span><span style="color:#F97583">in</span><span style="color:#9ECBFF"> ../my-app--feature-auth</span><span style="color:#9ECBFF"> ../my-app--feature-payment</span><span style="color:#E1E4E8">; </span><span style="color:#F97583">do</span></span>
<span data-line=""><span style="color:#B392F0">  cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "修復 linter 錯誤"</span><span style="color:#79B8FF"> --path</span><span style="color:#9ECBFF"> "</span><span style="color:#E1E4E8">$dir</span><span style="color:#9ECBFF">"</span><span style="color:#79B8FF"> --no-interactive</span></span>
<span data-line=""><span style="color:#F97583">done</span></span></code></pre></figure>
<p>一次交代完，多個 branch 一起整理——PR 前的收尾作業交給腳本跑，你去做別的事。</p>
<hr>
<p>Worktree 本來就是「多目錄、多 branch」；CLI 本來就是「以目前目錄為上下文」——這兩個組合起來幾乎是天生的。你需要的只是多開幾個終端機視窗。</p>

<p>假設你已經建好 worktree：</p>
<pre><code>~/projects/
├── my-app/                   ← main
├── my-app--feature-auth/     ← feature/auth
└── my-app--feature-payment/  ← feature/payment
</code></pre>
<p><strong>終端機 1</strong>（搞 auth）：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#79B8FF">cd</span><span style="color:#9ECBFF"> ~/projects/my-app--feature-auth</span></span>
<span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "實作 JWT 登入"</span></span></code></pre></figure>
<p><strong>終端機 2</strong>（搞 payment）：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#79B8FF">cd</span><span style="color:#9ECBFF"> ~/projects/my-app--feature-payment</span></span>
<span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "加上 Stripe 結帳流程"</span></span></code></pre></figure>
<p>兩個 Agent 各自在自己的 worktree 裡跑，互不干擾。省資源、省切換，比開兩個 Cursor 視窗還清爽。</p>
<h2 id="不想切目錄用---path-直接指定">不想切目錄：用 --path 直接指定</h2>
<p>人坐在主專案目錄，想讓 CLI 去改某個 worktree——加 <code>--path</code> 就好：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#79B8FF">cd</span><span style="color:#9ECBFF"> ~/projects/my-app</span></span>
<span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "幫 feature/auth 加上單元測試"</span><span style="color:#79B8FF"> --path</span><span style="color:#9ECBFF"> ../my-app--feature-auth</span></span></code></pre></figure>
<p>適合一次只處理一個 worktree、或腳本裡路徑固定的情境。</p>
<h2 id="批次任務對多個-worktree-跑同一件事">批次任務：對多個 Worktree 跑同一件事</h2>
<p>PR 前想對幾個 branch 都跑一次 lint 修復：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "依 .eslintrc 修復所有可自動修復的錯誤"</span><span style="color:#79B8FF"> --path</span><span style="color:#9ECBFF"> ../my-app--feature-auth</span><span style="color:#79B8FF"> --no-interactive</span></span>
<span data-line=""><span style="color:#B392F0">cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "依 .eslintrc 修復所有可自動修復的錯誤"</span><span style="color:#79B8FF"> --path</span><span style="color:#9ECBFF"> ../my-app--feature-payment</span><span style="color:#79B8FF"> --no-interactive</span></span></code></pre></figure>
<p>或寫成迴圈：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#F97583">for</span><span style="color:#E1E4E8"> dir </span><span style="color:#F97583">in</span><span style="color:#9ECBFF"> ../my-app--feature-auth</span><span style="color:#9ECBFF"> ../my-app--feature-payment</span><span style="color:#E1E4E8">; </span><span style="color:#F97583">do</span></span>
<span data-line=""><span style="color:#B392F0">  cursor</span><span style="color:#9ECBFF"> agent</span><span style="color:#9ECBFF"> "修復 linter 錯誤"</span><span style="color:#79B8FF"> --path</span><span style="color:#9ECBFF"> "</span><span style="color:#E1E4E8">$dir</span><span style="color:#9ECBFF">"</span><span style="color:#79B8FF"> --no-interactive</span></span>
<span data-line=""><span style="color:#F97583">done</span></span></code></pre></figure>
<p>一次交代完，多個 branch 一起整理——PR 前的收尾作業交給腳本跑，你去做別的事。</p>
<hr>
<p>Worktree 本來就是「多目錄、多 branch」；CLI 本來就是「以目前目錄為上下文」——這兩個組合起來幾乎是天生的。你需要的只是多開幾個終端機視窗。</p>
