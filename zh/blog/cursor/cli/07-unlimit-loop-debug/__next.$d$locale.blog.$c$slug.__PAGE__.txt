3:T3d27,<p>測試掛了，改 code，再跑測試，還是掛，再改——這個迴圈大家都做過。<strong>為什麼要自己來？</strong></p>
<p>寫一個 shell 腳本，把這個迴圈交給 <code>cursor agent</code> 跑：測試失敗就把錯誤訊息餵給 AI，AI 修完再跑，直到測試全過才停。你去喝咖啡、回訊息，等終端機出現 <code>✅ 測試通過！</code> 再回來驗收。</p>
<h2 id="核心邏輯">核心邏輯</h2>
<pre><code>while 測試沒過:
    跑測試 → 收集錯誤訊息
    把錯誤訊息餵給 cursor agent
    cursor agent 修 code
    重新跑測試
</code></pre>
<p>就是「跑測試 → 失敗 → 叫 AI 修 → 再跑」的迴圈，直到綠燈。簡單粗暴，但有效。</p>
<h2 id="前置條件確認">前置條件確認</h2>
<ul>
<li><code>cursor</code> 已安裝且登入（<code>cursor --version</code> 驗證）</li>
<li>專案有<strong>可以在終端機跑的測試指令</strong>，例如 <code>npm test</code>、<code>pytest</code>、<code>go test ./...</code>、<code>cargo test</code></li>
<li>測試失敗時 exit code 不為 0（幾乎所有測試框架預設都這樣）</li>
</ul>
<h2 id="最簡版腳本">最簡版腳本</h2>
<p>建立 <code>debug-loop.sh</code>：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E">#!/bin/bash</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#E6EDF3">MAX_LOOPS</span><span style="color:#FF7B72">=</span><span style="color:#A5D6FF">10</span><span style="color:#8B949E">        # 最多跑幾圈，防止真的無限跑</span></span>
<span data-line=""><span style="color:#E6EDF3">TEST_CMD</span><span style="color:#FF7B72">=</span><span style="color:#A5D6FF">"npm test"</span><span style="color:#8B949E"> # 換成你的測試指令</span></span>
<span data-line=""><span style="color:#E6EDF3">loop</span><span style="color:#FF7B72">=</span><span style="color:#A5D6FF">0</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#FF7B72">while</span><span style="color:#E6EDF3"> [ $loop </span><span style="color:#FF7B72">-lt</span><span style="color:#E6EDF3"> $MAX_LOOPS ]; </span><span style="color:#FF7B72">do</span></span>
<span data-line=""><span style="color:#79C0FF">  echo</span><span style="color:#A5D6FF"> ""</span></span>
<span data-line=""><span style="color:#79C0FF">  echo</span><span style="color:#A5D6FF"> "=== 第 $((</span><span style="color:#FFA657">loop</span><span style="color:#A5D6FF"> + </span><span style="color:#79C0FF">1</span><span style="color:#A5D6FF">)) 圈 ==="</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#E6EDF3">  TEST_OUTPUT</span><span style="color:#FF7B72">=</span><span style="color:#E6EDF3">$(</span><span style="color:#79C0FF">eval</span><span style="color:#A5D6FF"> "</span><span style="color:#E6EDF3">$TEST_CMD</span><span style="color:#A5D6FF">"</span><span style="color:#FF7B72"> 2>&#x26;1</span><span style="color:#E6EDF3">)</span></span>
<span data-line=""><span style="color:#E6EDF3">  EXIT_CODE</span><span style="color:#FF7B72">=</span><span style="color:#79C0FF">$?</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#FF7B72">  if</span><span style="color:#E6EDF3"> [ $EXIT_CODE </span><span style="color:#FF7B72">-eq</span><span style="color:#79C0FF"> 0</span><span style="color:#E6EDF3"> ]; </span><span style="color:#FF7B72">then</span></span>
<span data-line=""><span style="color:#79C0FF">    echo</span><span style="color:#A5D6FF"> "✅ 測試通過！共跑了 $((</span><span style="color:#FFA657">loop</span><span style="color:#A5D6FF"> + </span><span style="color:#79C0FF">1</span><span style="color:#A5D6FF">)) 圈。"</span></span>
<span data-line=""><span style="color:#79C0FF">    exit</span><span style="color:#79C0FF"> 0</span></span>
<span data-line=""><span style="color:#FF7B72">  fi</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#79C0FF">  echo</span><span style="color:#A5D6FF"> "❌ 測試失敗，讓 AI 來修..."</span></span>
<span data-line=""><span style="color:#79C0FF">  echo</span><span style="color:#A5D6FF"> "</span><span style="color:#E6EDF3">$TEST_OUTPUT</span><span style="color:#A5D6FF">"</span><span style="color:#FF7B72"> |</span><span style="color:#FFA657"> tail</span><span style="color:#79C0FF"> -30</span></span>

<span data-line=""><span style="color:#FF7B72">done</span></span>

<p>執行：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">chmod</span><span style="color:#A5D6FF"> +x</span><span style="color:#A5D6FF"> debug-loop.sh</span></span>

<p>跑起來之後就可以去做別的事了。若跑滿 <code>MAX_LOOPS</code> 還沒過，代表問題超出 AI 能自己解決的範圍，這時才需要人介入。</p>
<h2 id="依專案調整">依專案調整</h2>
<p><strong>換測試指令</strong>（第 3 行）：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#E6EDF3">TEST_CMD</span><span style="color:#FF7B72">=</span><span style="color:#A5D6FF">"pytest -x"</span><span style="color:#8B949E">            # Python，-x 遇第一個錯就停</span></span>
<span data-line=""><span style="color:#E6EDF3">TEST_CMD</span><span style="color:#FF7B72">=</span><span style="color:#A5D6FF">"go test ./..."</span><span style="color:#8B949E">        # Go</span></span>
<span data-line=""><span style="color:#E6EDF3">TEST_CMD</span><span style="color:#FF7B72">=</span><span style="color:#A5D6FF">"cargo test"</span><span style="color:#8B949E">           # Rust</span></span>
<span data-line=""><span style="color:#E6EDF3">TEST_CMD</span><span style="color:#FF7B72">=</span><span style="color:#A5D6FF">"./vendor/bin/phpunit"</span><span style="color:#8B949E"> # PHP</span></span></code></pre></figure>
<p><strong>調最大圈數</strong>：5 圈保守（問題複雜的話 AI 比較快卡死）、15 圈給點餘裕——設太大只是在浪費 quota，設太小又不夠。10 是個不錯的起點。</p>
<p><strong>讓 AI 有更多背景資訊</strong>，在 <code>cursor agent</code> 指令裡說清楚：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#A5D6FF"> "測試失敗，錯誤如下。</span></span>
<span data-line=""><span style="color:#A5D6FF">測試框架是 Jest，語言是 TypeScript。</span></span>
<span data-line=""><span style="color:#A5D6FF">不要改測試檔案，只改 src/ 底下的檔案。</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#A5D6FF">錯誤訊息：</span></span>
<span data-line=""><span style="color:#E6EDF3">$TEST_OUTPUT</span><span style="color:#A5D6FF">"</span><span style="color:#79C0FF"> --model</span><span style="color:#A5D6FF"> gpt-codex-5.3-high</span><span style="color:#79C0FF"> --no-interactive</span></span></code></pre></figure>

9:T3d27,<p>測試掛了，改 code，再跑測試，還是掛，再改——這個迴圈大家都做過。<strong>為什麼要自己來？</strong></p>
<p>寫一個 shell 腳本，把這個迴圈交給 <code>cursor agent</code> 跑：測試失敗就把錯誤訊息餵給 AI，AI 修完再跑，直到測試全過才停。你去喝咖啡、回訊息，等終端機出現 <code>✅ 測試通過！</code> 再回來驗收。</p>
<h2 id="核心邏輯">核心邏輯</h2>
<pre><code>while 測試沒過:
    跑測試 → 收集錯誤訊息
    把錯誤訊息餵給 cursor agent
    cursor agent 修 code
    重新跑測試
</code></pre>
<p>就是「跑測試 → 失敗 → 叫 AI 修 → 再跑」的迴圈，直到綠燈。簡單粗暴，但有效。</p>
<h2 id="前置條件確認">前置條件確認</h2>
<ul>
<li><code>cursor</code> 已安裝且登入（<code>cursor --version</code> 驗證）</li>
<li>專案有<strong>可以在終端機跑的測試指令</strong>，例如 <code>npm test</code>、<code>pytest</code>、<code>go test ./...</code>、<code>cargo test</code></li>
<li>測試失敗時 exit code 不為 0（幾乎所有測試框架預設都這樣）</li>
</ul>
<h2 id="最簡版腳本">最簡版腳本</h2>
<p>建立 <code>debug-loop.sh</code>：</p>

<span data-line=""> </span>

<h2 id="依專案調整">依專案調整</h2>
<p><strong>換測試指令</strong>（第 3 行）：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#E6EDF3">TEST_CMD</span><span style="color:#FF7B72">=</span><span style="color:#A5D6FF">"pytest -x"</span><span style="color:#8B949E">            # Python，-x 遇第一個錯就停</span></span>
