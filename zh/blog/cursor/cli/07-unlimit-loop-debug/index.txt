1b:T3d27,<p>測試掛了，改 code，再跑測試，還是掛，再改——這個迴圈大家都做過。<strong>為什麼要自己來？</strong></p>
<p>寫一個 shell 腳本，把這個迴圈交給 <code>cursor agent</code> 跑：測試失敗就把錯誤訊息餵給 AI，AI 修完再跑，直到測試全過才停。你去喝咖啡、回訊息，等終端機出現 <code>✅ 測試通過！</code> 再回來驗收。</p>
<h2 id="核心邏輯">核心邏輯</h2>
<pre><code>while 測試沒過:
    跑測試 → 收集錯誤訊息
    把錯誤訊息餵給 cursor agent
    cursor agent 修 code
    重新跑測試
</code></pre>
<p>就是「跑測試 → 失敗 → 叫 AI 修 → 再跑」的迴圈，直到綠燈。簡單粗暴，但有效。</p>
<h2 id="前置條件確認">前置條件確認</h2>
<ul>
<li><code>cursor</code> 已安裝且登入（<code>cursor --version</code> 驗證）</li>
<li>專案有<strong>可以在終端機跑的測試指令</strong>，例如 <code>npm test</code>、<code>pytest</code>、<code>go test ./...</code>、<code>cargo test</code></li>
<li>測試失敗時 exit code 不為 0（幾乎所有測試框架預設都這樣）</li>
</ul>

<p><strong>換測試指令</strong>（第 3 行）：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#E6EDF3">TEST_CMD</span><span style="color:#FF7B72">=</span><span style="color:#A5D6FF">"pytest -x"</span><span style="color:#8B949E">            # Python，-x 遇第一個錯就停</span></span>

25:T3d27,<p>測試掛了，改 code，再跑測試，還是掛，再改——這個迴圈大家都做過。<strong>為什麼要自己來？</strong></p>
<p>寫一個 shell 腳本，把這個迴圈交給 <code>cursor agent</code> 跑：測試失敗就把錯誤訊息餵給 AI，AI 修完再跑，直到測試全過才停。你去喝咖啡、回訊息，等終端機出現 <code>✅ 測試通過！</code> 再回來驗收。</p>
<h2 id="核心邏輯">核心邏輯</h2>
<pre><code>while 測試沒過:
    跑測試 → 收集錯誤訊息
    把錯誤訊息餵給 cursor agent
    cursor agent 修 code
    重新跑測試
</code></pre>
<p>就是「跑測試 → 失敗 → 叫 AI 修 → 再跑」的迴圈，直到綠燈。簡單粗暴，但有效。</p>
<h2 id="前置條件確認">前置條件確認</h2>
<ul>
<li><code>cursor</code> 已安裝且登入（<code>cursor --version</code> 驗證）</li>
<li>專案有<strong>可以在終端機跑的測試指令</strong>，例如 <code>npm test</code>、<code>pytest</code>、<code>go test ./...</code>、<code>cargo test</code></li>
<li>測試失敗時 exit code 不為 0（幾乎所有測試框架預設都這樣）</li>
</ul>

<span data-line=""><span style="color:#E6EDF3">  TEST_OUTPUT</span><span style="color:#FF7B72">=</span><span style="color:#E6EDF3">$(</span><span style="color:#79C0FF">eval</span><span style="color:#A5D6FF"> "</span><span style="color:#E6EDF3">$TEST_CMD</span><span style="color:#A5D6FF">"</span><span style="color:#FF7B72"> 2>&#x26;1</span><span style="color:#FF7B72"> |</span><span style="color:#FFA657"> tee</span><span style="color:#A5D6FF"> "</span><span style="color:#E6EDF3">$LOG_FILE</span><span style="color:#A5D6FF">"</span><span style="color:#E6EDF3">)</span></span>
<span data-line=""><span style="color:#E6EDF3">  EXIT_CODE</span><span style="color:#FF7B72">=</span><span style="color:#E6EDF3">${PIPESTATUS[0]}</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#FF7B72">  if</span><span style="color:#E6EDF3"> [ $EXIT_CODE </span><span style="color:#FF7B72">-eq</span><span style="color:#79C0FF"> 0</span><span style="color:#E6EDF3"> ]; </span><span style="color:#FF7B72">then</span></span>
<span data-line=""><span style="color:#79C0FF">    echo</span><span style="color:#A5D6FF"> "✅ 測試通過！共跑了 $((</span><span style="color:#FFA657">loop</span><span style="color:#A5D6FF"> + </span><span style="color:#79C0FF">1</span><span style="color:#A5D6FF">)) 圈。"</span></span>
<span data-line=""><span style="color:#79C0FF">    exit</span><span style="color:#79C0FF"> 0</span></span>
<span data-line=""><span style="color:#FF7B72">  fi</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#79C0FF">  echo</span><span style="color:#A5D6FF"> "❌ 失敗，日誌存到 </span><span style="color:#E6EDF3">$LOG_FILE</span><span style="color:#A5D6FF">"</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#FFA657">  cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#A5D6FF"> "測試失敗，錯誤如下，請修 code 讓測試通過：</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#E6EDF3">$TEST_OUTPUT</span><span style="color:#A5D6FF">"</span><span style="color:#79C0FF"> --model</span><span style="color:#A5D6FF"> gpt-codex-5.3-high</span><span style="color:#79C0FF"> --no-interactive</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#E6EDF3">  loop</span><span style="color:#FF7B72">=</span><span style="color:#E6EDF3">$((</span><span style="color:#FFA657">loop</span><span style="color:#A5D6FF"> +</span><span style="color:#79C0FF"> 1</span><span style="color:#E6EDF3">))</span></span>
<span data-line=""><span style="color:#FF7B72">done</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#79C0FF">echo</span><span style="color:#A5D6FF"> "⚠️  達最大圈數，停止。請看 </span><span style="color:#E6EDF3">$LOG_DIR</span><span style="color:#A5D6FF">/ 裡的日誌。"</span></span>
<span data-line=""><span style="color:#79C0FF">exit</span><span style="color:#79C0FF"> 1</span></span></code></pre></figure>
<p>每圈的錯誤都存成獨立檔案，方便對比 AI 改了什麼、問題有沒有在演化。</p>
<h2 id="安全注意事項">安全注意事項</h2>
<table>
<thead>
<tr>
<th>風險</th>
<th>怎麼防</th>
</tr>
</thead>

<tr>
<td>AI 改爛更多檔案</td>
<td>跑前先 <code>git commit</code> 備份，不對就 <code>git checkout .</code> 還原</td>
</tr>
<tr>
<td>跑太多圈浪費 quota</td>
<td>設合理的 <code>MAX_LOOPS</code>，建議 5～15</td>

<td>提示詞明確說「不要改測試檔案」</td>
</tr>
<tr>
<td>每圈失敗原因不同</td>
<td>保留日誌（加強版腳本），方便事後追蹤</td>
</tr>
