<p>想像成三個同事：Agent 是那個「交給我我直接改」的、Plan 是「我先寫方案給你審」的、Ask 是「我只回答不改檔」的——選對人，省事一半。</p>
<h2 id="agent-模式預設">Agent 模式（預設）</h2>
<p>你要的是結果，不是討論會：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#A5D6FF"> "把登入改成用 JWT"</span></span></code></pre></figure>
<p>AI 會讀檔案、改檔案、可能執行指令。每一步你可以接受或拒絕，控制權在你。大多數情況這個模式就夠了。</p>
<h2 id="plan-模式先看計畫再放行">Plan 模式：先看計畫再放行</h2>
<p>不確定怎麼做、或怕 AI 一次改太大？先讓它出計畫：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#79C0FF"> --plan</span><span style="color:#A5D6FF"> "重構整個 API 層"</span></span></code></pre></figure>
<p>AI 會先問幾個問題、提出做法，你同意後才真的動手——不會給你驚喜，也不會給你驚嚇。適合大改動，或那種「我想先看清楚再 commit」的場合。</p>
<h2 id="ask-模式只問不改">Ask 模式：只問不改</h2>
<p>只想看懂這段 code，死都不要讓 AI 碰任何檔案：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> ask</span><span style="color:#A5D6FF"> "src/auth.ts 的邏輯是什麼？"</span></span></code></pre></figure>
<p>只會讀取、分析、回答，不會寫入。適合 CI 環境，或那種「這台機器我只敢看不敢改」的情境——你懂的。</p>
<h2 id="在對話裡切換模式">在對話裡切換模式</h2>
<p>已經開著 <code>cursor agent</code> 對話了？不用跳出去重打，直接用 slash 指令：</p>
<ul>
<li><code>/plan</code> → 切到 Plan 模式，先規劃再說</li>
<li><code>/ask</code> → 切到 Ask 模式，唯讀放心問</li>
</ul>
<p>就像切換人格一樣順。</p>
<hr>
<p>大原則就三字：<strong>要做用 Agent、要看用 Ask、怕搞爛用 Plan</strong>。用熟之後會發現 Ask + Agent 交替是最順的工作流——先問清楚再交辦。</p>

<p>已經開著 <code>cursor agent</code> 對話了？不用跳出去重打，直接用 slash 指令：</p>
<ul>
<li><code>/plan</code> → 切到 Plan 模式，先規劃再說</li>
<li><code>/ask</code> → 切到 Ask 模式，唯讀放心問</li>
</ul>
<p>就像切換人格一樣順。</p>
<hr>
<p>大原則就三字：<strong>要做用 Agent、要看用 Ask、怕搞爛用 Plan</strong>。用熟之後會發現 Ask + Agent 交替是最順的工作流——先問清楚再交辦。</p>
