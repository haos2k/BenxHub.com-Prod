Cursor CLI 完整教學系列 — 終端機裡的 AI 助手

2026 年 2 月 24 日·3 min read

你已經在終端機裡了——SSH 連著伺服器、或 tmux 切了一堆面板——然後還要切到 Cursor 視窗去找 AI，再把答案貼回來。來回幾次之後，你會開始想：有沒有辦法直接在終端機叫 AI？

有，這就是 Cursor CLI 在做的事。一條 cursor agent "幫我改這段" 下去，AI 就在你的目錄裡幫你動手——不用開 IDE、不用滑鼠、不用離開你正在做的事。

為什麼值得學？

情境 沒有 Cursor CLI 有 Cursor CLI
在伺服器上改 code SSH 開著，還得另開 IDE 或遠端同步 終端機直接下指令，就地解決
腳本、CI 自動化 AI 用不進 pipeline，只能手動貼 非互動模式一行搞定，CI 裡也能跑
已經在終端機做事 得切到 IDE，做完再切回來 同一視窗問完繼續做
偏好鍵盤流 免不了滑鼠點選 全部指令完成，手不離鍵盤

核心概念只有一個：CLI 讓 AI 跟著你的工作環境走，不是反過來要你遷就 IDE。

系列地圖

文件 主題 約需時間
01-install 安裝與驗證 5 分鐘
02-basic-usage 基本使用：下指令、對話 10 分鐘
03-modes 三種模式：Agent / Plan / Ask 8 分鐘
04-non-interactive 非互動模式與腳本 8 分鐘
05-tips 實用技巧與常見問題 5 分鐘
06-cursor-cli-with-worktree CLI 搭配 Git Worktree 並行開發 8 分鐘
07-unlimit-loop-debug 無限除錯迴圈：跑到測試通過 10 分鐘
08-worktree-merge Cursor 內建 Worktree 進階應用 8 分鐘
09-worktree-advanced Best-of-N 與 worktrees.json 設定 10 分鐘
10-headless-scripts 無頭模式 --print、--force 與腳本改檔 8 分鐘
11-output-ci 輸出格式與 CI 整合 8 分鐘
12-sessions-cloud 會話恢復與雲端執行 6 分鐘

需要什麼

  • 已安裝 Cursor（或至少能登入 Cursor 帳號）
  • Cursor 訂閱——CLI 需要訂閱才能用，跟 IDE 是同一套
  • 基本終端機操作就夠了，不需要特別的背景知識

從 01-install 開始，五分鐘把 CLI 裝好。
