3:T1e0a,<p><a href="04-non-interactive">04-non-interactive</a> 講了 <code>--no-interactive</code> 讓 Agent 跑完不等人。但如果你想要的是<strong>腳本裡叫 AI 直接改你的檔案、改完腳本繼續跑</strong>——那要再多加兩個 flag：<code>-p</code>（<code>--print</code>）和 <code>--force</code>。</p>
<p>不開 Cursor 視窗、不按鍵確認，一行指令，AI 改完，腳本繼續——這就是無頭模式（Headless）在做的事。</p>
<h2 id="-p----print輸出到終端預設不改檔">-p / --print：輸出到終端，預設不改檔</h2>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#79C0FF"> -p</span><span style="color:#A5D6FF"> "這個專案在做什麼？"</span></span>
<span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#79C0FF"> --print</span><span style="color:#A5D6FF"> "列出 src/ 下所有 API 端點"</span></span></code></pre></figure>
<p><code>-p</code> 的意思是：跑完就結束、結果印到終端，<strong>不加 <code>--force</code> 就不會寫入任何檔案</strong>。只有讀取、分析、輸出。</p>
<p>適合問答、產報告到 stdout、或給 pipe 和後續腳本解析。</p>
<h2 id="--force加了才會真的動檔案">--force：加了才會真的動檔案</h2>
<p>在 <code>-p</code> 底下加 <code>--force</code>（或 <code>--yolo</code>，效果一樣），Agent 就<strong>可以真的寫入、修改、刪除檔案</strong>，完全不問你 Y/N：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#79C0FF"> -p</span><span style="color:#79C0FF"> --force</span><span style="color:#A5D6FF"> "把 src/utils.js 重構成 ES6+ 語法"</span></span></code></pre></figure>

</blockquote>
<h2 id="腳本範例批次加-jsdoc">腳本範例：批次加 JSDoc</h2>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E">#!/bin/bash</span></span>
<span data-line=""><span style="color:#FFA657">find</span><span style="color:#A5D6FF"> src/</span><span style="color:#79C0FF"> -name</span><span style="color:#A5D6FF"> "*.js"</span><span style="color:#FF7B72"> |</span><span style="color:#FF7B72"> while</span><span style="color:#79C0FF"> read</span><span style="color:#79C0FF"> -r</span><span style="color:#A5D6FF"> file</span><span style="color:#E6EDF3">; </span><span style="color:#FF7B72">do</span></span>
<span data-line=""><span style="color:#79C0FF">  echo</span><span style="color:#A5D6FF"> "Processing </span><span style="color:#E6EDF3">$file</span><span style="color:#A5D6FF">..."</span></span>
<span data-line=""><span style="color:#FFA657">  cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#79C0FF"> -p</span><span style="color:#79C0FF"> --force</span><span style="color:#A5D6FF"> "為 </span><span style="color:#E6EDF3">$file</span><span style="color:#A5D6FF"> 加上完整的 JSDoc 註解，直接修改該檔"</span></span>
<span data-line=""><span style="color:#FF7B72">done</span></span></code></pre></figure>
<p>每一個 <code>.js</code> 都會被 Agent 讀寫。適合在專案副本或獨立 branch 上跑，或先對一兩個檔試跑再全批。</p>
<h2 id="腳本範例自動-code-review-並寫報告">腳本範例：自動 code review 並寫報告</h2>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E">#!/bin/bash</span></span>
<span data-line=""><span style="color:#FFA657">cursor</span><span style="color:#A5D6FF"> agent</span><span style="color:#79C0FF"> -p</span><span style="color:#79C0FF"> --force</span><span style="color:#79C0FF"> --output-format</span><span style="color:#A5D6FF"> text</span><span style="color:#FF7B72"> \</span></span>
<span data-line=""><span style="color:#A5D6FF">  "針對最近變更做 code review，重點：可讀性、潛在 bug、安全性、最佳實踐。把結論與具體建議寫入 review.txt"</span></span></code></pre></figure>
<p><code>--output-format text</code> 讓輸出是純文字，方便直接寫進檔案或用 <code>grep</code> 處理。下一篇會講 <code>json</code>、<code>stream-json</code> 的用法。</p>
<h2 id="ci-環境記得設好-api-key">CI 環境記得設好 API Key</h2>
<p>無頭模式通常在沒有 Cursor 視窗的環境跑——CI 機器、遠端伺服器——這些地方要設好授權：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FF7B72">export</span><span style="color:#E6EDF3"> CURSOR_API_KEY</span><span style="color:#FF7B72">=</span><span style="color:#E6EDF3">你的金鑰</span></span></code></pre></figure>
<p>或先在那台機器跑過 <code>cursor auth login</code>（若支援）。沒設好直接跑，Agent 上不了工，腳本就在那邊卡著。</p>
<h2 id="三種模式的差異">三種模式的差異</h2>
<table>
<thead>
<tr>
<th>模式</th>
<th>典型用法</th>
<th>會不會改檔</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>--no-interactive</code></td>
<td>終端機裡跑、可以看輸出，但不用按鍵</td>
<td>依設定，可能會問</td>
</tr>
<tr>
<td><code>-p</code> / <code>--print</code></td>
<td>腳本、CI、完全非互動，輸出到 stdout</td>
<td>預設不改檔</td>
</tr>
<tr>
<td><code>-p --force</code></td>
<td>同上，但允許 Agent 直接改檔</td>
<td>會改，不問</td>
</tr>
</tbody>
</table>
<p>要腳本「真的改檔案」用 <code>-p --force</code>；只要分析或輸出報告到終端，<code>-p</code> 就夠了。</p>
<hr>
<p><code>--print</code> 是容器，<code>--force</code> 才是鑰匙。記住這個分工，腳本裡的 AI 自動化就沒什麼黑魔法。</p>

<h2 id="腳本範例自動-code-review-並寫報告">腳本範例：自動 code review 並寫報告</h2>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E">#!/bin/bash</span></span>

<span data-line=""><span style="color:#A5D6FF">  "針對最近變更做 code review，重點：可讀性、潛在 bug、安全性、最佳實踐。把結論與具體建議寫入 review.txt"</span></span></code></pre></figure>
<p><code>--output-format text</code> 讓輸出是純文字，方便直接寫進檔案或用 <code>grep</code> 處理。下一篇會講 <code>json</code>、<code>stream-json</code> 的用法。</p>
<h2 id="ci-環境記得設好-api-key">CI 環境記得設好 API Key</h2>
<p>無頭模式通常在沒有 Cursor 視窗的環境跑——CI 機器、遠端伺服器——這些地方要設好授權：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FF7B72">export</span><span style="color:#E6EDF3"> CURSOR_API_KEY</span><span style="color:#FF7B72">=</span><span style="color:#E6EDF3">你的金鑰</span></span></code></pre></figure>
<p>或先在那台機器跑過 <code>cursor auth login</code>（若支援）。沒設好直接跑，Agent 上不了工，腳本就在那邊卡著。</p>
<h2 id="三種模式的差異">三種模式的差異</h2>
<table>
<thead>
<tr>
<th>模式</th>
<th>典型用法</th>
<th>會不會改檔</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>--no-interactive</code></td>
<td>終端機裡跑、可以看輸出，但不用按鍵</td>
<td>依設定，可能會問</td>
</tr>
<tr>
<td><code>-p</code> / <code>--print</code></td>
<td>腳本、CI、完全非互動，輸出到 stdout</td>
<td>預設不改檔</td>
</tr>
<tr>
<td><code>-p --force</code></td>
<td>同上，但允許 Agent 直接改檔</td>
<td>會改，不問</td>
</tr>
</tbody>
</table>
<p>要腳本「真的改檔案」用 <code>-p --force</code>；只要分析或輸出報告到終端，<code>-p</code> 就夠了。</p>
<hr>
<p><code>--print</code> 是容器，<code>--force</code> 才是鑰匙。記住這個分工，腳本裡的 AI 自動化就沒什麼黑魔法。</p>
