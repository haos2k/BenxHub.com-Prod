<h2 id="前置確認-zsh-已安裝">前置：確認 Zsh 已安裝</h2>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">zsh</span><span style="color:#79B8FF"> --version</span></span></code></pre></figure>
<p>macOS Catalina（10.15）以後預設就是 Zsh，通常不用另外裝。Linux 的話：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># Ubuntu / Debian</span></span>

<span data-line=""><span style="color:#B392F0">sudo</span><span style="color:#9ECBFF"> pacman</span><span style="color:#79B8FF"> -S</span><span style="color:#9ECBFF"> zsh</span></span>
<span data-line=""> </span>

<h2 id="安裝-oh-my-zsh">安裝 Oh My Zsh</h2>
<p>官方提供兩種方式，選一個跑就好：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># curl（大多數人用這個）</span></span>
<span data-line=""><span style="color:#B392F0">sh</span><span style="color:#79B8FF"> -c</span><span style="color:#9ECBFF"> "$(</span><span style="color:#B392F0">curl</span><span style="color:#79B8FF"> -fsSL</span><span style="color:#9ECBFF"> https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#6A737D"># wget（curl 沒有的環境）</span></span>
<span data-line=""><span style="color:#B392F0">sh</span><span style="color:#79B8FF"> -c</span><span style="color:#9ECBFF"> "$(</span><span style="color:#B392F0">wget</span><span style="color:#79B8FF"> -O-</span><span style="color:#9ECBFF"> https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"</span></span></code></pre></figure>
<p>安裝腳本會自動備份你原本的 <code>~/.zshrc</code> 成 <code>~/.zshrc.pre-oh-my-zsh</code>，不用擔心設定不見。</p>
<p>安裝成功之後終端機會長出 OMZ 的預設樣子——彩色提示符、路徑縮短顯示，跟原本的白底黑字已經不一樣了。</p>

<h2 id="常見問題">常見問題</h2>
<p><strong><code>oh-my-zsh: command not found</code> 一直出現</strong></p>
<p>這是 Zsh 沒有設成預設 shell 的症狀。確認這行：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#79B8FF">echo</span><span style="color:#E1E4E8"> $SHELL</span></span></code></pre></figure>
<p>結果要是 <code>/bin/zsh</code> 或 <code>/usr/bin/zsh</code>。不是的話，重新跑一次 <code>chsh -s $(which zsh)</code> 然後登出登入。</p>
<p><strong>安裝腳本卡住、網路很慢</strong></p>
<p>腳本其實只是在 clone 這個 repo：<code>https://github.com/ohmyzsh/ohmyzsh</code>。你也可以手動 clone：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">git</span><span style="color:#9ECBFF"> clone</span><span style="color:#9ECBFF"> https://github.com/ohmyzsh/ohmyzsh.git</span><span style="color:#9ECBFF"> ~/.oh-my-zsh</span></span>
<span data-line=""><span style="color:#B392F0">cp</span><span style="color:#9ECBFF"> ~/.oh-my-zsh/templates/zshrc.zsh-template</span><span style="color:#9ECBFF"> ~/.zshrc</span></span>
<span data-line=""><span style="color:#79B8FF">source</span><span style="color:#9ECBFF"> ~/.zshrc</span></span></code></pre></figure>
<p>效果一樣。</p>
<p><strong>macOS 上出現 <code>compinit: insecure directories</code></strong></p>
<p>這是 Homebrew 安裝了某些東西後的權限問題，跑這行修：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">chmod</span><span style="color:#9ECBFF"> go-w</span><span style="color:#9ECBFF"> '/usr/local/share'</span></span></code></pre></figure>
<p>具體路徑看報錯訊息，把最後那個路徑換進去就好。</p>

<h2 id="常見問題">常見問題</h2>
<p><strong><code>oh-my-zsh: command not found</code> 一直出現</strong></p>
<p>這是 Zsh 沒有設成預設 shell 的症狀。確認這行：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#79B8FF">echo</span><span style="color:#E1E4E8"> $SHELL</span></span></code></pre></figure>
<p>結果要是 <code>/bin/zsh</code> 或 <code>/usr/bin/zsh</code>。不是的話，重新跑一次 <code>chsh -s $(which zsh)</code> 然後登出登入。</p>
<p><strong>安裝腳本卡住、網路很慢</strong></p>
<p>腳本其實只是在 clone 這個 repo：<code>https://github.com/ohmyzsh/ohmyzsh</code>。你也可以手動 clone：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">git</span><span style="color:#9ECBFF"> clone</span><span style="color:#9ECBFF"> https://github.com/ohmyzsh/ohmyzsh.git</span><span style="color:#9ECBFF"> ~/.oh-my-zsh</span></span>
<span data-line=""><span style="color:#B392F0">cp</span><span style="color:#9ECBFF"> ~/.oh-my-zsh/templates/zshrc.zsh-template</span><span style="color:#9ECBFF"> ~/.zshrc</span></span>
<span data-line=""><span style="color:#79B8FF">source</span><span style="color:#9ECBFF"> ~/.zshrc</span></span></code></pre></figure>
<p>效果一樣。</p>
<p><strong>macOS 上出現 <code>compinit: insecure directories</code></strong></p>
<p>這是 Homebrew 安裝了某些東西後的權限問題，跑這行修：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">chmod</span><span style="color:#9ECBFF"> go-w</span><span style="color:#9ECBFF"> '/usr/local/share'</span></span></code></pre></figure>
<p>具體路徑看報錯訊息，把最後那個路徑換進去就好。</p>
