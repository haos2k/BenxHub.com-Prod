<h2 id="為什麼特別介紹-auto-suggestions">為什麼特別介紹 Auto Suggestions</h2>
<p>如果這系列只讓你記住一件事，那就是 <strong>zsh-autosuggestions</strong>。</p>
<p>它做的事情非常單純：你打指令的時候，它會根據你的歷史記錄，用灰色文字預測你接下來要打什麼——按一下 <code>→</code> 就直接補完。</p>
<p>聽起來很小，但用過之後你回不去。重複的 git 指令、長到記不住的 docker run、每次都要 tab 三次才補完的路徑——全部都能一鍵解決。那篇會講得很仔細，包含進階調校和我自己踩過的坑。</p>
<h2 id="你需要準備什麼">你需要準備什麼</h2>
<ul>
<li>macOS 或 Linux 系統</li>
<li>已安裝 Zsh（macOS Catalina 以後預設就是 Zsh，Linux 的話底下有說明）</li>
<li>終端機基本操作沒問題就夠了，不需要特別的 shell 背景</li>
</ul>
