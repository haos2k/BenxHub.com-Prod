1e:T3a42,<p>Oh My Zsh 內建了一百多個主題，但大多數人裝完玩了兩天就停在 Powerlevel10k——因為它把「好看」和「有用」這兩件事都做到位了。</p>
<p>這篇說清楚怎麼裝、設定精靈怎麼走、以及不想用精靈要怎麼手動改。</p>
<h2 id="為什麼是-powerlevel10k">為什麼是 Powerlevel10k</h2>
<p>其他主題的問題在於：要顯示 git 狀態、Node 版本、Python venv 之類的資訊，每次都得跑一堆子程序——你按 Enter 之後，下一個 prompt 要等一兩秒才出現。</p>
<p>Powerlevel10k 用了一個聰明的做法：<strong>Instant Prompt</strong>。它在 shell 載入時先把上一個 prompt 的結果快取起來，顯示出來之前不等 shell 完整初始化。結果就是，視覺上幾乎感覺不到延遲，但 prompt 裡的資訊還是完整的。</p>

<h2 id="安裝-powerlevel10k">安裝 Powerlevel10k</h2>
<p><strong>第一步：安裝字型</strong></p>
<p>Powerlevel10k 需要支援 Powerline 符號的字型。官方推薦 <strong>MesloLGS NF</strong>：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># macOS 用 Homebrew</span></span>
<span data-line=""><span style="color:#B392F0">brew</span><span style="color:#9ECBFF"> install</span><span style="color:#79B8FF"> --cask</span><span style="color:#9ECBFF"> font-meslo-lg-nerd-font</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#6A737D"># 或手動下載（四個檔案）：</span></span>
<span data-line=""><span style="color:#6A737D"># https://github.com/romkatv/powerlevel10k#meslo-nerd-font-patched-for-powerlevel10k</span></span></code></pre></figure>
<p>裝完之後，去終端機設定（iTerm2 / Terminal.app / Warp 等）把字型改成 <code>MesloLGS NF</code>。這步不做的話，prompt 的圖示會顯示成方塊。</p>
<p><strong>第二步：clone 主題</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">git</span><span style="color:#9ECBFF"> clone</span><span style="color:#79B8FF"> --depth=1</span><span style="color:#9ECBFF"> https://github.com/romkatv/powerlevel10k.git</span><span style="color:#79B8FF"> \</span></span>
<span data-line=""><span style="color:#E1E4E8">  ${ZSH_CUSTOM</span><span style="color:#F97583">:-</span><span style="color:#E1E4E8">~</span><span style="color:#F97583">/</span><span style="color:#E1E4E8">.oh-my-zsh</span><span style="color:#F97583">/</span><span style="color:#E1E4E8">custom}</span><span style="color:#9ECBFF">/themes/powerlevel10k</span></span></code></pre></figure>
<p><strong>第三步：套用主題</strong></p>
<p>打開 <code>~/.zshrc</code>，把 <code>ZSH_THEME</code> 改成：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="zsh" data-theme="github-dark"><code data-language="zsh" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#E1E4E8">ZSH_THEME</span><span style="color:#F97583">=</span><span style="color:#9ECBFF">"powerlevel10k/powerlevel10k"</span></span></code></pre></figure>
<p>然後 <code>source ~/.zshrc</code>，設定精靈應該會自動跳出來。</p>
<h2 id="跑設定精靈">跑設定精靈</h2>
<p>設定精靈會問你一系列問題，根據你的答案生成 <code>~/.p10k.zsh</code>。整個流程大概 3–5 分鐘：</p>
<ol>
<li><strong>字型確認</strong>：精靈會顯示幾個符號，問你看起來有沒有正確——這是確認字型裝好了沒</li>
<li><strong>Prompt 樣式</strong>：幾個視覺風格選一個（精簡/豐富/超豐富）</li>
<li><strong>字符集</strong>：Unicode 或純 ASCII（SSH 環境建議 ASCII 比較不容易出問題）</li>
<li><strong>顯示資訊</strong>：要不要顯示 git 狀態、Node 版本、Python venv 等</li>
<li><strong>Prompt 位置</strong>：左邊和右邊各放什麼</li>
<li><strong>換行</strong>：指令和 prompt 之間要不要空一行</li>
</ol>
<p>如果之後想重新跑精靈：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">p10k</span><span style="color:#9ECBFF"> configure</span></span></code></pre></figure>
<h2 id="手動客製化-p10kzsh">手動客製化 <code>.p10k.zsh</code></h2>

<h2 id="instant-prompt-設定">Instant Prompt 設定</h2>
<p>Powerlevel10k 的 Instant Prompt 需要在 <code>~/.zshrc</code> 的<strong>最頂端</strong>加這段：</p>

<p>如果你的 <code>~/.zshrc</code> 裡有 <code>echo</code> 或其他會輸出文字到 stdout 的指令，Instant Prompt 會報警告。把那些輸出改成寫到 stderr：</p>

<h2 id="為什麼是-powerlevel10k">為什麼是 Powerlevel10k</h2>
<p>其他主題的問題在於：要顯示 git 狀態、Node 版本、Python venv 之類的資訊，每次都得跑一堆子程序——你按 Enter 之後，下一個 prompt 要等一兩秒才出現。</p>
<p>Powerlevel10k 用了一個聰明的做法：<strong>Instant Prompt</strong>。它在 shell 載入時先把上一個 prompt 的結果快取起來，顯示出來之前不等 shell 完整初始化。結果就是，視覺上幾乎感覺不到延遲，但 prompt 裡的資訊還是完整的。</p>

<h2 id="安裝-powerlevel10k">安裝 Powerlevel10k</h2>
<p><strong>第一步：安裝字型</strong></p>
<p>Powerlevel10k 需要支援 Powerline 符號的字型。官方推薦 <strong>MesloLGS NF</strong>：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># macOS 用 Homebrew</span></span>
<span data-line=""><span style="color:#B392F0">brew</span><span style="color:#9ECBFF"> install</span><span style="color:#79B8FF"> --cask</span><span style="color:#9ECBFF"> font-meslo-lg-nerd-font</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#6A737D"># 或手動下載（四個檔案）：</span></span>
<span data-line=""><span style="color:#6A737D"># https://github.com/romkatv/powerlevel10k#meslo-nerd-font-patched-for-powerlevel10k</span></span></code></pre></figure>
<p>裝完之後，去終端機設定（iTerm2 / Terminal.app / Warp 等）把字型改成 <code>MesloLGS NF</code>。這步不做的話，prompt 的圖示會顯示成方塊。</p>
<p><strong>第二步：clone 主題</strong></p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">git</span><span style="color:#9ECBFF"> clone</span><span style="color:#79B8FF"> --depth=1</span><span style="color:#9ECBFF"> https://github.com/romkatv/powerlevel10k.git</span><span style="color:#79B8FF"> \</span></span>

<p>打開 <code>~/.zshrc</code>，把 <code>ZSH_THEME</code> 改成：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="zsh" data-theme="github-dark"><code data-language="zsh" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#E1E4E8">ZSH_THEME</span><span style="color:#F97583">=</span><span style="color:#9ECBFF">"powerlevel10k/powerlevel10k"</span></span></code></pre></figure>

<h2 id="跑設定精靈">跑設定精靈</h2>
<p>設定精靈會問你一系列問題，根據你的答案生成 <code>~/.p10k.zsh</code>。整個流程大概 3–5 分鐘：</p>
<ol>
<li><strong>字型確認</strong>：精靈會顯示幾個符號，問你看起來有沒有正確——這是確認字型裝好了沒</li>
<li><strong>Prompt 樣式</strong>：幾個視覺風格選一個（精簡/豐富/超豐富）</li>
<li><strong>字符集</strong>：Unicode 或純 ASCII（SSH 環境建議 ASCII 比較不容易出問題）</li>
<li><strong>顯示資訊</strong>：要不要顯示 git 狀態、Node 版本、Python venv 等</li>
<li><strong>Prompt 位置</strong>：左邊和右邊各放什麼</li>
<li><strong>換行</strong>：指令和 prompt 之間要不要空一行</li>
</ol>
<p>如果之後想重新跑精靈：</p>

<p>如果你的 <code>~/.zshrc</code> 裡有 <code>echo</code> 或其他會輸出文字到 stdout 的指令，Instant Prompt 會報警告。把那些輸出改成寫到 stderr：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#79B8FF">echo</span><span style="color:#9ECBFF"> "訊息"</span><span style="color:#F97583"> >&#x26;2</span></span></code></pre></figure>
