<h2 id="實用-alias">實用 alias</h2>
<p>alias 是最直接提升效率的東西，每天重複的指令縮短成兩三個字母。</p>
<p>放在 <code>~/.zshrc</code> 的任何地方，或是建一個獨立的 <code>~/.zsh_aliases</code> 再在 <code>.zshrc</code> 裡 source 進來（後者比較好管理）：</p>

<h2 id="函數比-alias-強的情況">函數比 alias 強的情況</h2>

<span data-line=""><span style="color:#B392F0">  tar</span><span style="color:#79B8FF"> -czf</span><span style="color:#9ECBFF"> "</span><span style="color:#79B8FF">${1</span><span style="color:#F97583">%/</span><span style="color:#79B8FF">}</span><span style="color:#9ECBFF">.tar.gz"</span><span style="color:#9ECBFF"> "</span><span style="color:#79B8FF">$1</span><span style="color:#9ECBFF">"</span></span>
<span data-line=""><span style="color:#E1E4E8">}</span></span>
<span data-line=""> </span>

<span data-line=""><span style="color:#F97583">  case</span><span style="color:#FFAB70"> $1</span><span style="color:#F97583"> in</span></span>

<span data-line=""><span style="color:#F97583">    *</span><span style="color:#DBEDFF">.tar.bz2</span><span style="color:#F97583">)</span><span style="color:#B392F0"> tar</span><span style="color:#79B8FF"> -xjf</span><span style="color:#9ECBFF"> "</span><span style="color:#79B8FF">$1</span><span style="color:#9ECBFF">"</span><span style="color:#E1E4E8">  ;;</span></span>

<span data-line=""><span style="color:#F97583">    *)</span><span style="color:#79B8FF">         echo</span><span style="color:#9ECBFF"> "不知道怎麼解：</span><span style="color:#79B8FF">$1</span><span style="color:#9ECBFF">"</span><span style="color:#E1E4E8"> ;;</span></span>
<span data-line=""><span style="color:#F97583">  esac</span></span>
<span data-line=""><span style="color:#E1E4E8">}</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#6A737D"># git commit 快捷（不用每次加引號）</span></span>
<span data-line=""><span style="color:#B392F0">gcm</span><span style="color:#E1E4E8">() {</span></span>
<span data-line=""><span style="color:#B392F0">  git</span><span style="color:#9ECBFF"> commit</span><span style="color:#79B8FF"> -m</span><span style="color:#9ECBFF"> "</span><span style="color:#79B8FF">$*</span><span style="color:#9ECBFF">"</span></span>
<span data-line=""><span style="color:#E1E4E8">}</span></span></code></pre></figure>
<p><code>gcm fix typo in readme</code> 直接 commit，不用包引號。小事，但每天做很多次就有感。</p>

<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">omz</span><span style="color:#9ECBFF"> update</span><span style="color:#6A737D">        # 更新 OMZ 本體</span></span>

<p>第三方外掛（zsh-autosuggestions 等）不會跟著 <code>omz update</code> 更新，要自己進去 pull：</p>

<span data-line=""><span style="color:#79B8FF">cd</span><span style="color:#E1E4E8"> ${ZSH_CUSTOM</span><span style="color:#F97583">:-</span><span style="color:#E1E4E8">~</span><span style="color:#F97583">/</span><span style="color:#E1E4E8">.oh-my-zsh</span><span style="color:#F97583">/</span><span style="color:#E1E4E8">custom}</span><span style="color:#9ECBFF">/plugins/zsh-syntax-highlighting</span><span style="color:#E1E4E8"> &#x26;&#x26; </span><span style="color:#B392F0">git</span><span style="color:#9ECBFF"> pull</span></span>

<h2 id="dotfiles讓設定跟著你走">Dotfiles：讓設定跟著你走</h2>
<p>裝了 Oh My Zsh、設定好 Powerlevel10k、調好 zsh-autosuggestions——這些設定全部都住在幾個檔案裡：</p>
<ul>
<li><code>~/.zshrc</code></li>
<li><code>~/.p10k.zsh</code></li>
<li><code>~/.zsh_aliases</code></li>
<li><code>${ZSH_CUSTOM}/plugins/</code> 底下的外掛</li>
<li><code>${ZSH_CUSTOM}/themes/</code> 底下的主題</li>
</ul>
<p>最簡單的保存方式是把這些設定檔存到 git repo（通常叫做 dotfiles），換機器的時候 clone 下來、跑一個 setup 腳本，全部恢復。</p>
<p>基本結構：</p>
<pre><code>dotfiles/
├── zsh/
│   ├── .zshrc
│   ├── .zsh_aliases
│   └── .p10k.zsh
└── setup.sh
</code></pre>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># setup.sh</span></span>

<span data-line=""><span style="color:#B392F0">ln</span><span style="color:#79B8FF"> -sf</span><span style="color:#9ECBFF"> ~/dotfiles/zsh/.p10k.zsh</span><span style="color:#9ECBFF"> ~/.p10k.zsh</span></span>

<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">git</span><span style="color:#9ECBFF"> clone</span><span style="color:#9ECBFF"> git@github.com:你的帳號/dotfiles.git</span><span style="color:#9ECBFF"> ~/dotfiles</span></span>

<h2 id="讓-shell-速度保持在線">讓 shell 速度保持在線</h2>
<p>設定越加越多之後，shell 啟動速度要定期檢查：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># 測量啟動時間</span></span>
<span data-line=""><span style="color:#F97583">time</span><span style="color:#E1E4E8"> zsh -i -c exit</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#6A737D"># 更詳細的 profiling（在 ~/.zshrc 最頂端加這行）</span></span>
<span data-line=""><span style="color:#B392F0">zmodload</span><span style="color:#9ECBFF"> zsh/zprof</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#6A737D"># ~/.zshrc 最底端加這行</span></span>
<span data-line=""><span style="color:#B392F0">zprof</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#6A737D"># source ~/.zshrc 之後會看到每個部分花了多少時間</span></span></code></pre></figure>
<p>找到拖後腿的東西之後，通常是某個沉重的外掛或是 <code>nvm</code>（Node Version Manager）的載入——這些可以改成 lazy loading，只有第一次用到的時候才載入。</p>

<p>這個系列到這裡就完整了。你現在有：</p>
<ul>

<li>dotfiles 確保這些設定不會因為換機器而消失</li>
</ul>

<h2 id="實用-alias">實用 alias</h2>
<p>alias 是最直接提升效率的東西，每天重複的指令縮短成兩三個字母。</p>
<p>放在 <code>~/.zshrc</code> 的任何地方，或是建一個獨立的 <code>~/.zsh_aliases</code> 再在 <code>.zshrc</code> 裡 source 進來（後者比較好管理）：</p>

<h2 id="函數比-alias-強的情況">函數比 alias 強的情況</h2>
<p>alias 只能做簡單替換，邏輯複雜一點就要用 function：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="zsh" data-theme="github-dark"><code data-language="zsh" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># 建目錄然後直接進去</span></span>
<span data-line=""><span style="color:#B392F0">mkcd</span><span style="color:#E1E4E8">() {</span></span>
<span data-line=""><span style="color:#B392F0">  mkdir</span><span style="color:#79B8FF"> -p</span><span style="color:#9ECBFF"> "</span><span style="color:#79B8FF">$1</span><span style="color:#9ECBFF">"</span><span style="color:#E1E4E8"> &#x26;&#x26; </span><span style="color:#79B8FF">cd</span><span style="color:#9ECBFF"> "</span><span style="color:#79B8FF">$1</span><span style="color:#9ECBFF">"</span></span>
<span data-line=""><span style="color:#E1E4E8">}</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#6A737D"># 壓縮目錄</span></span>
<span data-line=""><span style="color:#B392F0">targz</span><span style="color:#E1E4E8">() {</span></span>
<span data-line=""><span style="color:#B392F0">  tar</span><span style="color:#79B8FF"> -czf</span><span style="color:#9ECBFF"> "</span><span style="color:#79B8FF">${1</span><span style="color:#F97583">%/</span><span style="color:#79B8FF">}</span><span style="color:#9ECBFF">.tar.gz"</span><span style="color:#9ECBFF"> "</span><span style="color:#79B8FF">$1</span><span style="color:#9ECBFF">"</span></span>
<span data-line=""><span style="color:#E1E4E8">}</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#6A737D"># 解壓縮（自動判斷格式）</span></span>
<span data-line=""><span style="color:#B392F0">extract</span><span style="color:#E1E4E8">() {</span></span>
<span data-line=""><span style="color:#F97583">  case</span><span style="color:#FFAB70"> $1</span><span style="color:#F97583"> in</span></span>

<span data-line=""><span style="color:#F97583">    *</span><span style="color:#DBEDFF">.tar.bz2</span><span style="color:#F97583">)</span><span style="color:#B392F0"> tar</span><span style="color:#79B8FF"> -xjf</span><span style="color:#9ECBFF"> "</span><span style="color:#79B8FF">$1</span><span style="color:#9ECBFF">"</span><span style="color:#E1E4E8">  ;;</span></span>
<span data-line=""><span style="color:#F97583">    *</span><span style="color:#DBEDFF">.zip</span><span style="color:#F97583">)</span><span style="color:#B392F0">     unzip</span><span style="color:#9ECBFF"> "</span><span style="color:#79B8FF">$1</span><span style="color:#9ECBFF">"</span><span style="color:#E1E4E8">     ;;</span></span>
<span data-line=""><span style="color:#F97583">    *</span><span style="color:#DBEDFF">.gz</span><span style="color:#F97583">)</span><span style="color:#B392F0">      gunzip</span><span style="color:#9ECBFF"> "</span><span style="color:#79B8FF">$1</span><span style="color:#9ECBFF">"</span><span style="color:#E1E4E8">    ;;</span></span>
<span data-line=""><span style="color:#F97583">    *)</span><span style="color:#79B8FF">         echo</span><span style="color:#9ECBFF"> "不知道怎麼解：</span><span style="color:#79B8FF">$1</span><span style="color:#9ECBFF">"</span><span style="color:#E1E4E8"> ;;</span></span>

<span data-line=""><span style="color:#E1E4E8">}</span></span>

<h2 id="dotfiles讓設定跟著你走">Dotfiles：讓設定跟著你走</h2>
<p>裝了 Oh My Zsh、設定好 Powerlevel10k、調好 zsh-autosuggestions——這些設定全部都住在幾個檔案裡：</p>
<ul>
<li><code>~/.zshrc</code></li>
<li><code>~/.p10k.zsh</code></li>
<li><code>~/.zsh_aliases</code></li>
<li><code>${ZSH_CUSTOM}/plugins/</code> 底下的外掛</li>
<li><code>${ZSH_CUSTOM}/themes/</code> 底下的主題</li>
</ul>
<p>最簡單的保存方式是把這些設定檔存到 git repo（通常叫做 dotfiles），換機器的時候 clone 下來、跑一個 setup 腳本，全部恢復。</p>
<p>基本結構：</p>
<pre><code>dotfiles/
├── zsh/
│   ├── .zshrc
│   ├── .zsh_aliases
│   └── .p10k.zsh
└── setup.sh
</code></pre>

<h2 id="讓-shell-速度保持在線">讓 shell 速度保持在線</h2>
<p>設定越加越多之後，shell 啟動速度要定期檢查：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># 測量啟動時間</span></span>

<span data-line=""> </span>
<span data-line=""><span style="color:#6A737D"># 更詳細的 profiling（在 ~/.zshrc 最頂端加這行）</span></span>
<span data-line=""><span style="color:#B392F0">zmodload</span><span style="color:#9ECBFF"> zsh/zprof</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#6A737D"># ~/.zshrc 最底端加這行</span></span>
<span data-line=""><span style="color:#B392F0">zprof</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#6A737D"># source ~/.zshrc 之後會看到每個部分花了多少時間</span></span></code></pre></figure>
<p>找到拖後腿的東西之後，通常是某個沉重的外掛或是 <code>nvm</code>（Node Version Manager）的載入——這些可以改成 lazy loading，只有第一次用到的時候才載入。</p>
