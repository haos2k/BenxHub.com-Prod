<h2 id="實用-alias">實用 alias</h2>
<p>alias 是最直接提升效率的東西，每天重複的指令縮短成兩三個字母。</p>
<p>放在 <code>~/.zshrc</code> 的任何地方，或是建一個獨立的 <code>~/.zsh_aliases</code> 再在 <code>.zshrc</code> 裡 source 進來（後者比較好管理）：</p>

<h2 id="函數比-alias-強的情況">函數比 alias 強的情況</h2>
<p>alias 只能做簡單替換，邏輯複雜一點就要用 function：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="zsh" data-theme="github-dark-default"><code data-language="zsh" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># 建目錄然後直接進去</span></span>
<span data-line=""><span style="color:#D2A8FF">mkcd</span><span style="color:#E6EDF3">() {</span></span>
<span data-line=""><span style="color:#FFA657">  mkdir</span><span style="color:#79C0FF"> -p</span><span style="color:#A5D6FF"> "</span><span style="color:#79C0FF">$1</span><span style="color:#A5D6FF">"</span><span style="color:#E6EDF3"> &#x26;&#x26; </span><span style="color:#79C0FF">cd</span><span style="color:#A5D6FF"> "</span><span style="color:#79C0FF">$1</span><span style="color:#A5D6FF">"</span></span>
<span data-line=""><span style="color:#E6EDF3">}</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># 壓縮目錄</span></span>
<span data-line=""><span style="color:#D2A8FF">targz</span><span style="color:#E6EDF3">() {</span></span>
<span data-line=""><span style="color:#FFA657">  tar</span><span style="color:#79C0FF"> -czf</span><span style="color:#A5D6FF"> "</span><span style="color:#79C0FF">${1</span><span style="color:#FF7B72">%/</span><span style="color:#79C0FF">}</span><span style="color:#A5D6FF">.tar.gz"</span><span style="color:#A5D6FF"> "</span><span style="color:#79C0FF">$1</span><span style="color:#A5D6FF">"</span></span>
<span data-line=""><span style="color:#E6EDF3">}</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># 解壓縮（自動判斷格式）</span></span>
<span data-line=""><span style="color:#D2A8FF">extract</span><span style="color:#E6EDF3">() {</span></span>
<span data-line=""><span style="color:#FF7B72">  case</span><span style="color:#FFA657"> $1</span><span style="color:#FF7B72"> in</span></span>

<span data-line=""><span style="color:#FF7B72">    *</span><span style="color:#A5D6FF">.tar.bz2</span><span style="color:#FF7B72">)</span><span style="color:#FFA657"> tar</span><span style="color:#79C0FF"> -xjf</span><span style="color:#A5D6FF"> "</span><span style="color:#79C0FF">$1</span><span style="color:#A5D6FF">"</span><span style="color:#E6EDF3">  ;;</span></span>
<span data-line=""><span style="color:#FF7B72">    *</span><span style="color:#A5D6FF">.zip</span><span style="color:#FF7B72">)</span><span style="color:#FFA657">     unzip</span><span style="color:#A5D6FF"> "</span><span style="color:#79C0FF">$1</span><span style="color:#A5D6FF">"</span><span style="color:#E6EDF3">     ;;</span></span>
<span data-line=""><span style="color:#FF7B72">    *</span><span style="color:#A5D6FF">.gz</span><span style="color:#FF7B72">)</span><span style="color:#FFA657">      gunzip</span><span style="color:#A5D6FF"> "</span><span style="color:#79C0FF">$1</span><span style="color:#A5D6FF">"</span><span style="color:#E6EDF3">    ;;</span></span>
<span data-line=""><span style="color:#FF7B72">    *)</span><span style="color:#79C0FF">         echo</span><span style="color:#A5D6FF"> "不知道怎麼解：</span><span style="color:#79C0FF">$1</span><span style="color:#A5D6FF">"</span><span style="color:#E6EDF3"> ;;</span></span>

<span data-line=""><span style="color:#E6EDF3">}</span></span>
<span data-line=""> </span>

<p><code>gcm fix typo in readme</code> 直接 commit，不用包引號。小事，但每天做很多次就有感。</p>
<h2 id="oh-my-zsh-自身的維護指令">Oh My Zsh 自身的維護指令</h2>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">omz</span><span style="color:#A5D6FF"> update</span><span style="color:#8B949E">        # 更新 OMZ 本體</span></span>
<span data-line=""><span style="color:#FFA657">omz</span><span style="color:#A5D6FF"> reload</span><span style="color:#8B949E">        # 重載設定（等同 source ~/.zshrc）</span></span>
<span data-line=""><span style="color:#FFA657">omz</span><span style="color:#A5D6FF"> version</span><span style="color:#8B949E">       # 查目前版本</span></span></code></pre></figure>

<h2 id="dotfiles讓設定跟著你走">Dotfiles：讓設定跟著你走</h2>
<p>裝了 Oh My Zsh、設定好 Powerlevel10k、調好 zsh-autosuggestions——這些設定全部都住在幾個檔案裡：</p>
<ul>
<li><code>~/.zshrc</code></li>
<li><code>~/.p10k.zsh</code></li>
<li><code>~/.zsh_aliases</code></li>
<li><code>${ZSH_CUSTOM}/plugins/</code> 底下的外掛</li>
<li><code>${ZSH_CUSTOM}/themes/</code> 底下的主題</li>
</ul>
<p>最簡單的保存方式是把這些設定檔存到 git repo（通常叫做 dotfiles），換機器的時候 clone 下來、跑一個 setup 腳本，全部恢復。</p>
<p>基本結構：</p>
<pre><code>dotfiles/
├── zsh/
│   ├── .zshrc
│   ├── .zsh_aliases
│   └── .p10k.zsh
└── setup.sh
</code></pre>

<h2 id="讓-shell-速度保持在線">讓 shell 速度保持在線</h2>
<p>設定越加越多之後，shell 啟動速度要定期檢查：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># 測量啟動時間</span></span>

<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># 更詳細的 profiling（在 ~/.zshrc 最頂端加這行）</span></span>

<span data-line=""><span style="color:#FFA657">zprof</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># source ~/.zshrc 之後會看到每個部分花了多少時間</span></span></code></pre></figure>
<p>找到拖後腿的東西之後，通常是某個沉重的外掛或是 <code>nvm</code>（Node Version Manager）的載入——這些可以改成 lazy loading，只有第一次用到的時候才載入。</p>

<h2 id="函數比-alias-強的情況">函數比 alias 強的情況</h2>
<p>alias 只能做簡單替換，邏輯複雜一點就要用 function：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="zsh" data-theme="github-dark-default"><code data-language="zsh" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># 建目錄然後直接進去</span></span>
<span data-line=""><span style="color:#D2A8FF">mkcd</span><span style="color:#E6EDF3">() {</span></span>
<span data-line=""><span style="color:#FFA657">  mkdir</span><span style="color:#79C0FF"> -p</span><span style="color:#A5D6FF"> "</span><span style="color:#79C0FF">$1</span><span style="color:#A5D6FF">"</span><span style="color:#E6EDF3"> &#x26;&#x26; </span><span style="color:#79C0FF">cd</span><span style="color:#A5D6FF"> "</span><span style="color:#79C0FF">$1</span><span style="color:#A5D6FF">"</span></span>

<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># 壓縮目錄</span></span>
<span data-line=""><span style="color:#D2A8FF">targz</span><span style="color:#E6EDF3">() {</span></span>
<span data-line=""><span style="color:#FFA657">  tar</span><span style="color:#79C0FF"> -czf</span><span style="color:#A5D6FF"> "</span><span style="color:#79C0FF">${1</span><span style="color:#FF7B72">%/</span><span style="color:#79C0FF">}</span><span style="color:#A5D6FF">.tar.gz"</span><span style="color:#A5D6FF"> "</span><span style="color:#79C0FF">$1</span><span style="color:#A5D6FF">"</span></span>
<span data-line=""><span style="color:#E6EDF3">}</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># 解壓縮（自動判斷格式）</span></span>
<span data-line=""><span style="color:#D2A8FF">extract</span><span style="color:#E6EDF3">() {</span></span>
<span data-line=""><span style="color:#FF7B72">  case</span><span style="color:#FFA657"> $1</span><span style="color:#FF7B72"> in</span></span>

<span data-line=""><span style="color:#FF7B72">    *</span><span style="color:#A5D6FF">.zip</span><span style="color:#FF7B72">)</span><span style="color:#FFA657">     unzip</span><span style="color:#A5D6FF"> "</span><span style="color:#79C0FF">$1</span><span style="color:#A5D6FF">"</span><span style="color:#E6EDF3">     ;;</span></span>

<span data-line=""><span style="color:#FF7B72">    *)</span><span style="color:#79C0FF">         echo</span><span style="color:#A5D6FF"> "不知道怎麼解：</span><span style="color:#79C0FF">$1</span><span style="color:#A5D6FF">"</span><span style="color:#E6EDF3"> ;;</span></span>

<h2 id="dotfiles讓設定跟著你走">Dotfiles：讓設定跟著你走</h2>
<p>裝了 Oh My Zsh、設定好 Powerlevel10k、調好 zsh-autosuggestions——這些設定全部都住在幾個檔案裡：</p>
<ul>
<li><code>~/.zshrc</code></li>
<li><code>~/.p10k.zsh</code></li>
<li><code>~/.zsh_aliases</code></li>
<li><code>${ZSH_CUSTOM}/plugins/</code> 底下的外掛</li>
<li><code>${ZSH_CUSTOM}/themes/</code> 底下的主題</li>
</ul>
<p>最簡單的保存方式是把這些設定檔存到 git repo（通常叫做 dotfiles），換機器的時候 clone 下來、跑一個 setup 腳本，全部恢復。</p>
<p>基本結構：</p>
<pre><code>dotfiles/
├── zsh/
│   ├── .zshrc
│   ├── .zsh_aliases
│   └── .p10k.zsh
└── setup.sh
</code></pre>
