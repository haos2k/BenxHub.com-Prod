1a:T1e07,<p>你有沒有想過，一台電腦裡面同時跑 Windows、Linux、NAS、防火牆、還有一個 Minecraft 伺服器？聽起來像是把整間公寓塞進一個行李箱——但 Proxmox VE 真的能幫你做到這件事。</p>
<h2 id="一句話解釋-pve">一句話解釋 PVE</h2>
<p>Proxmox Virtual Environment（大家都叫它 PVE）是一個基於 Debian Linux 的<a href="https://www.proxmox.com/en/proxmox-virtual-environment/overview">開源虛擬化平台</a>。它把 KVM 虛擬機和 <a href="04-lxc-containers">LXC 容器</a>整合在一起，再加上一個還算順眼的 Web 管理介面，讓你用瀏覽器就能管一整台伺服器上的所有虛擬環境。</p>
<p>想像一下：PVE 就像一個超級房東，你的實體伺服器是一棟大樓，PVE 負責把它隔成好幾間套房（VM）跟雅房（LXC 容器），每間都有自己的門牌號碼、水電表、網路線，互不干擾。</p>

<h2 id="那-hyper-v-和-xcp-ng-呢">那 Hyper-V 和 XCP-ng 呢？</h2>
<p><strong>Hyper-V</strong>：如果你公司整間都是 Windows、Active Directory 綁得死死的、老闆又已經買了 Windows Server 授權——那 Hyper-V 是合理選擇。但如果你是 Linux 為主或混合環境，PVE 的 Web GUI 跨平台體驗好太多。</p>
<p><strong>XCP-ng</strong>：Xen 架構隔離性確實更強，但社群規模差太多（市佔 2.4% vs PVE 的 13.9%），遇到問題能 Google 到的解法也少很多。除非你有特殊安全需求，否則 PVE 的生態系更完整。</p>
<h2 id="pve-適合誰">PVE 適合誰？</h2>
<ul>
<li><strong>Homelab 玩家</strong>：你家有一台閒置的 PC 或 Mini PC，想拿來搞事</li>
<li><strong>中小企業</strong>：不想被大廠授權費綁架，但又需要企業級功能</li>
<li><strong>學生/工程師</strong>：想學虛擬化、K8s、網路，PVE 是最好的練兵場</li>
<li><strong>從 VMware 逃出來的人</strong>：PVE 8.2+ 甚至有 <a href="https://pve.proxmox.com/wiki/Migrate_to_Proxmox_VE">VMware Import Wizard</a> 幫你搬家</li>
</ul>
<p><strong>不太適合</strong>：只需要跑幾個 Docker container 的場景。那種直接裝 Docker 就好，不用搬出 PVE 這台推土機。</p>

<h2 id="常見問題">常見問題</h2>
<h3 id="q-proxmox-ve-完全免費嗎有什麼限制">Q: Proxmox VE 完全免費嗎？有什麼限制？</h3>
<p>PVE 所有功能都免費開源，沒有功能限制。付費訂閱只是多了企業級軟體源和技術支援，不影響任何功能使用。Homelab 玩家用社群版就完全夠了。</p>
<h3 id="q-pve-適合新手嗎需要-linux-基礎嗎">Q: PVE 適合新手嗎？需要 Linux 基礎嗎？</h3>
<p>PVE 的 Web 介面很直覺，基本操作不需要 Linux 經驗。但如果你想深入調校效能或寫自動化腳本，熟悉基本的 Linux 指令會很有幫助。</p>
<h3 id="q-proxmox-ve-跟-docker-有什麼不同">Q: Proxmox VE 跟 Docker 有什麼不同？</h3>
<p>PVE 是管理整台伺服器的虛擬化平台，可以跑完整的 VM 和 LXC 容器；Docker 是應用層級的容器化工具。兩者不衝突，你可以在 PVE 的 <a href="04-lxc-containers">LXC 容器</a>裡面跑 Docker。</p>
<h3 id="q-從-vmware-遷移到-pve-困難嗎">Q: 從 VMware 遷移到 PVE 困難嗎？</h3>
<p>PVE 8.2 以後內建 VMware Import Wizard，可以直接匯入 ESXi 上的 VM。大部分情況下只要幾個步驟就能完成搬家，不需要重新安裝作業系統。</p>

24:T1e07,<p>你有沒有想過，一台電腦裡面同時跑 Windows、Linux、NAS、防火牆、還有一個 Minecraft 伺服器？聽起來像是把整間公寓塞進一個行李箱——但 Proxmox VE 真的能幫你做到這件事。</p>
<h2 id="一句話解釋-pve">一句話解釋 PVE</h2>
<p>Proxmox Virtual Environment（大家都叫它 PVE）是一個基於 Debian Linux 的<a href="https://www.proxmox.com/en/proxmox-virtual-environment/overview">開源虛擬化平台</a>。它把 KVM 虛擬機和 <a href="04-lxc-containers">LXC 容器</a>整合在一起，再加上一個還算順眼的 Web 管理介面，讓你用瀏覽器就能管一整台伺服器上的所有虛擬環境。</p>
<p>想像一下：PVE 就像一個超級房東，你的實體伺服器是一棟大樓，PVE 負責把它隔成好幾間套房（VM）跟雅房（LXC 容器），每間都有自己的門牌號碼、水電表、網路線，互不干擾。</p>

<h2 id="那-hyper-v-和-xcp-ng-呢">那 Hyper-V 和 XCP-ng 呢？</h2>
<p><strong>Hyper-V</strong>：如果你公司整間都是 Windows、Active Directory 綁得死死的、老闆又已經買了 Windows Server 授權——那 Hyper-V 是合理選擇。但如果你是 Linux 為主或混合環境，PVE 的 Web GUI 跨平台體驗好太多。</p>
<p><strong>XCP-ng</strong>：Xen 架構隔離性確實更強，但社群規模差太多（市佔 2.4% vs PVE 的 13.9%），遇到問題能 Google 到的解法也少很多。除非你有特殊安全需求，否則 PVE 的生態系更完整。</p>
<h2 id="pve-適合誰">PVE 適合誰？</h2>
<ul>
<li><strong>Homelab 玩家</strong>：你家有一台閒置的 PC 或 Mini PC，想拿來搞事</li>
<li><strong>中小企業</strong>：不想被大廠授權費綁架，但又需要企業級功能</li>
<li><strong>學生/工程師</strong>：想學虛擬化、K8s、網路，PVE 是最好的練兵場</li>
<li><strong>從 VMware 逃出來的人</strong>：PVE 8.2+ 甚至有 <a href="https://pve.proxmox.com/wiki/Migrate_to_Proxmox_VE">VMware Import Wizard</a> 幫你搬家</li>
</ul>
<p><strong>不太適合</strong>：只需要跑幾個 Docker container 的場景。那種直接裝 Docker 就好，不用搬出 PVE 這台推土機。</p>

<h2 id="常見問題">常見問題</h2>
<h3 id="q-proxmox-ve-完全免費嗎有什麼限制">Q: Proxmox VE 完全免費嗎？有什麼限制？</h3>
<p>PVE 所有功能都免費開源，沒有功能限制。付費訂閱只是多了企業級軟體源和技術支援，不影響任何功能使用。Homelab 玩家用社群版就完全夠了。</p>
<h3 id="q-pve-適合新手嗎需要-linux-基礎嗎">Q: PVE 適合新手嗎？需要 Linux 基礎嗎？</h3>
<p>PVE 的 Web 介面很直覺，基本操作不需要 Linux 經驗。但如果你想深入調校效能或寫自動化腳本，熟悉基本的 Linux 指令會很有幫助。</p>
<h3 id="q-proxmox-ve-跟-docker-有什麼不同">Q: Proxmox VE 跟 Docker 有什麼不同？</h3>
<p>PVE 是管理整台伺服器的虛擬化平台，可以跑完整的 VM 和 LXC 容器；Docker 是應用層級的容器化工具。兩者不衝突，你可以在 PVE 的 <a href="04-lxc-containers">LXC 容器</a>裡面跑 Docker。</p>
<h3 id="q-從-vmware-遷移到-pve-困難嗎">Q: 從 VMware 遷移到 PVE 困難嗎？</h3>
<p>PVE 8.2 以後內建 VMware Import Wizard，可以直接匯入 ESXi 上的 VM。大部分情況下只要幾個步驟就能完成搬家，不需要重新安裝作業系統。</p>
