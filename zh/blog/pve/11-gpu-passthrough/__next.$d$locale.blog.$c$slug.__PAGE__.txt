3:T321a,<p>虛擬機預設只能用模擬的顯卡，畫面像在看 PowerPoint 投影片。GPU 直通（Passthrough）就是把實體顯卡整張遞進 VM 裡，讓它直接跟硬體對話，效能接近裸機。想在 VM 裡打遊戲、跑 Stable Diffusion、或者讓 Jellyfin 硬解 4K——都靠這招。</p>
<h2 id="前提條件硬體有沒有這個天賦">前提條件：硬體有沒有這個天賦</h2>
<p>不是所有硬體都能玩直通，先確認這張入場券：</p>
<ul>
<li><strong>CPU</strong>：Intel 要支援 VT-d，AMD 要支援 AMD-Vi（選購建議看<a href="01-hardware-guide">硬體選購指南</a>）</li>
<li><strong>主機板 BIOS</strong>：IOMMU / VT-d 選項要打開（有些主機板預設關閉，藏在 Advanced 裡面）</li>
<li><strong>IOMMU Group</strong>：目標 GPU 最好自己獨佔一個 Group，不要跟一堆裝置擠在一起</li>
</ul>
<blockquote>
<p>買主機板之前先查 IOMMU Group 的分組狀況，不然買回來發現 GPU 跟 USB 控制器綁死，會想退貨。</p>
</blockquote>
<h2 id="第一步啟用-iommu">第一步：啟用 IOMMU</h2>
<p>改 GRUB 參數，告訴核心「我要用 IOMMU」：</p>

<span data-line=""><span style="color:#FFA657">update-grub</span></span>
<span data-line=""> </span>

<h2 id="第二步設定-vfio-驅動">第二步：設定 VFIO 驅動</h2>
<p>VFIO 是 Linux 的裝置直通框架。我們要做兩件事：載入 VFIO 模組、阻止主機搶走 GPU。</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># 載入必要模組</span></span>
<span data-line=""><span style="color:#FFA657">cat</span><span style="color:#FF7B72"> >></span><span style="color:#A5D6FF"> /etc/modules</span><span style="color:#FF7B72"> &#x3C;&#x3C;</span><span style="color:#E6EDF3"> 'EOF'</span></span>
<span data-line=""><span style="color:#A5D6FF">vfio</span></span>
<span data-line=""><span style="color:#A5D6FF">vfio_iommu_type1</span></span>
<span data-line=""><span style="color:#A5D6FF">vfio_pci</span></span>
<span data-line=""><span style="color:#A5D6FF">vfio_virqfd</span></span>
<span data-line=""><span style="color:#E6EDF3">EOF</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># 擋掉主機的 GPU 驅動（NVIDIA 為例）</span></span>
<span data-line=""><span style="color:#79C0FF">echo</span><span style="color:#A5D6FF"> "blacklist nouveau"</span><span style="color:#FF7B72"> >></span><span style="color:#A5D6FF"> /etc/modprobe.d/blacklist.conf</span></span>
<span data-line=""><span style="color:#79C0FF">echo</span><span style="color:#A5D6FF"> "blacklist nvidia"</span><span style="color:#FF7B72"> >></span><span style="color:#A5D6FF"> /etc/modprobe.d/blacklist.conf</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># 查 GPU 的裝置 ID</span></span>
<span data-line=""><span style="color:#FFA657">lspci</span><span style="color:#79C0FF"> -nn</span><span style="color:#FF7B72"> |</span><span style="color:#FFA657"> grep</span><span style="color:#79C0FF"> -i</span><span style="color:#A5D6FF"> nvidia</span></span>
<span data-line=""><span style="color:#8B949E"># 輸出類似：01:00.0 VGA [10de:2684]</span></span>
<span data-line=""><span style="color:#8B949E">#           01:00.1 Audio [10de:22ba]</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># 把 GPU 和它的音訊裝置都綁給 VFIO</span></span>
<span data-line=""><span style="color:#79C0FF">echo</span><span style="color:#A5D6FF"> "options vfio-pci ids=10de:2684,10de:22ba"</span><span style="color:#FF7B72"> >></span><span style="color:#A5D6FF"> /etc/modprobe.d/vfio.conf</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># 更新 initramfs 並重開機</span></span>
<span data-line=""><span style="color:#FFA657">update-initramfs</span><span style="color:#79C0FF"> -u</span><span style="color:#79C0FF"> -k</span><span style="color:#A5D6FF"> all</span></span>
<span data-line=""><span style="color:#FFA657">reboot</span></span></code></pre></figure>
<blockquote>
<p>GPU 通常自帶一個 Audio 裝置（HDMI 音訊），記得一起直通，不然 VM 裡會出怪事。就像養貓不能只帶貓不帶貓砂盆。</p>
</blockquote>
<h2 id="第三步檢查-iommu-group">第三步：檢查 IOMMU Group</h2>
<p>確認 GPU 的分組狀況：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FF7B72">for</span><span style="color:#E6EDF3"> d </span><span style="color:#FF7B72">in</span><span style="color:#A5D6FF"> /sys/kernel/iommu_groups/*/devices/*</span><span style="color:#E6EDF3">; </span><span style="color:#FF7B72">do</span></span>
<span data-line=""><span style="color:#E6EDF3">    n</span><span style="color:#FF7B72">=</span><span style="color:#E6EDF3">${d</span><span style="color:#FF7B72">#*/</span><span style="color:#E6EDF3">iommu_groups</span><span style="color:#FF7B72">/*</span><span style="color:#E6EDF3">}; n</span><span style="color:#FF7B72">=</span><span style="color:#E6EDF3">${n</span><span style="color:#FF7B72">%%/*</span><span style="color:#E6EDF3">}</span></span>
<span data-line=""><span style="color:#79C0FF">    printf</span><span style="color:#A5D6FF"> 'IOMMU Group %s '</span><span style="color:#A5D6FF"> "</span><span style="color:#E6EDF3">$n</span><span style="color:#A5D6FF">"</span></span>
<span data-line=""><span style="color:#FFA657">    lspci</span><span style="color:#79C0FF"> -nns</span><span style="color:#A5D6FF"> "${</span><span style="color:#E6EDF3">d</span><span style="color:#FF7B72">##*/</span><span style="color:#A5D6FF">}"</span></span>
<span data-line=""><span style="color:#FF7B72">done</span></span></code></pre></figure>
<p>理想狀態：GPU（VGA + Audio）自己一個 Group。如果跟其他裝置擠在一起，要嘛全部一起直通，要嘛換主機板，要嘛用 ACS Override Patch（有安全風險）。</p>

<h2 id="nvidia-code-43-問題">NVIDIA Code 43 問題</h2>
<p>NVIDIA 早期驅動會偵測「我是不是在虛擬機裡」，發現了就罷工丟出 Code 43 錯誤。解法是把虛擬化的痕跡藏起來：</p>
<pre><code>cpu: host,hidden=1
args: -cpu 'host,+kvm_pv_unhalt,+kvm_pv_eoi,hv_vendor_id=proxmox,kvm=off'
</code></pre>
<blockquote>
<p>好消息：NVIDIA 535 版之後的驅動已經不管這個了。如果你的驅動夠新，可以跳過這步。</p>
</blockquote>
<h2 id="進階玩法">進階玩法</h2>
<p><strong>SR-IOV</strong>：一張實體網卡切成多張虛擬的，各自獨立分配給不同 VM。企業級網卡（Intel X710）和高階 GPU（NVIDIA A100）才有。</p>
<p><strong>vGPU</strong>：把一張 GPU 切成好幾份，每個 VM 分到一小塊。需要 NVIDIA 商業授權，口袋夠深再考慮。</p>
<p><strong>Resource Mappings（PVE 8.0+）</strong>：在<a href="08-cluster">叢集</a>裡給裝置取一個統一名稱，VM 遷移到不同節點時自動對應。不用再每台機器硬編 PCI 位址。</p>

<p>GPU 直通的設定步驟不少，但每一步都有明確的原因。搞定之後，一台 PVE 主機可以同時跑伺服器、跑 AI、跑遊戲——一台當三台用，錢花得值。</p>

<h2 id="常見問題">常見問題</h2>
<h3 id="q-proxmox-顯卡直通一定要-uefi-嗎">Q: Proxmox 顯卡直通一定要 UEFI 嗎？</h3>
<p>強烈建議用 UEFI（OVMF）搭配 q35 機型。SeaBIOS 雖然也能直通，但相容性較差，特別是新款 NVIDIA 和 AMD 顯卡在 UEFI 模式下才能正確初始化 ROM。</p>
<h3 id="q-iommu-group-太大怎麼辦">Q: IOMMU Group 太大怎麼辦？</h3>
<p>首選換一張 IOMMU 分組較好的主機板。如果不想換，可以使用 ACS Override Patch 強制拆分 Group，但這會降低 DMA 隔離安全性，Homelab 可以接受，生產環境不建議。</p>
<h3 id="q-gpu-直通後主機還能用那張顯卡嗎">Q: GPU 直通後主機還能用那張顯卡嗎？</h3>
<p>不行，直通的 GPU 完全交給 VM 控制，主機端看不到也用不了。如果主機也需要顯示輸出，建議用 CPU 內顯或另插一張便宜的亮機卡給主機用。</p>
<h3 id="q-vfio-設定好了但-vm-開機黑螢幕怎麼辦">Q: VFIO 設定好了但 VM 開機黑螢幕怎麼辦？</h3>
<p>檢查三個地方：一是 hostpci 設定要加 <code>x-vga=1</code> 和 <code>rombar=1</code>；二是有些顯卡需要手動指定 ROM 檔案；三是確認 VM 的顯示設定改為 <code>none</code>，避免虛擬顯卡衝突。</p>

9:T321a,<p>虛擬機預設只能用模擬的顯卡，畫面像在看 PowerPoint 投影片。GPU 直通（Passthrough）就是把實體顯卡整張遞進 VM 裡，讓它直接跟硬體對話，效能接近裸機。想在 VM 裡打遊戲、跑 Stable Diffusion、或者讓 Jellyfin 硬解 4K——都靠這招。</p>
<h2 id="前提條件硬體有沒有這個天賦">前提條件：硬體有沒有這個天賦</h2>
<p>不是所有硬體都能玩直通，先確認這張入場券：</p>
<ul>
<li><strong>CPU</strong>：Intel 要支援 VT-d，AMD 要支援 AMD-Vi（選購建議看<a href="01-hardware-guide">硬體選購指南</a>）</li>
<li><strong>主機板 BIOS</strong>：IOMMU / VT-d 選項要打開（有些主機板預設關閉，藏在 Advanced 裡面）</li>
<li><strong>IOMMU Group</strong>：目標 GPU 最好自己獨佔一個 Group，不要跟一堆裝置擠在一起</li>
</ul>
<blockquote>
<p>買主機板之前先查 IOMMU Group 的分組狀況，不然買回來發現 GPU 跟 USB 控制器綁死，會想退貨。</p>
</blockquote>

<h2 id="第二步設定-vfio-驅動">第二步：設定 VFIO 驅動</h2>
<p>VFIO 是 Linux 的裝置直通框架。我們要做兩件事：載入 VFIO 模組、阻止主機搶走 GPU。</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#8B949E"># 載入必要模組</span></span>
<span data-line=""><span style="color:#FFA657">cat</span><span style="color:#FF7B72"> >></span><span style="color:#A5D6FF"> /etc/modules</span><span style="color:#FF7B72"> &#x3C;&#x3C;</span><span style="color:#E6EDF3"> 'EOF'</span></span>
<span data-line=""><span style="color:#A5D6FF">vfio</span></span>
<span data-line=""><span style="color:#A5D6FF">vfio_iommu_type1</span></span>
<span data-line=""><span style="color:#A5D6FF">vfio_pci</span></span>
<span data-line=""><span style="color:#A5D6FF">vfio_virqfd</span></span>
<span data-line=""><span style="color:#E6EDF3">EOF</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># 擋掉主機的 GPU 驅動（NVIDIA 為例）</span></span>
<span data-line=""><span style="color:#79C0FF">echo</span><span style="color:#A5D6FF"> "blacklist nouveau"</span><span style="color:#FF7B72"> >></span><span style="color:#A5D6FF"> /etc/modprobe.d/blacklist.conf</span></span>
<span data-line=""><span style="color:#79C0FF">echo</span><span style="color:#A5D6FF"> "blacklist nvidia"</span><span style="color:#FF7B72"> >></span><span style="color:#A5D6FF"> /etc/modprobe.d/blacklist.conf</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#8B949E"># 查 GPU 的裝置 ID</span></span>
<span data-line=""><span style="color:#FFA657">lspci</span><span style="color:#79C0FF"> -nn</span><span style="color:#FF7B72"> |</span><span style="color:#FFA657"> grep</span><span style="color:#79C0FF"> -i</span><span style="color:#A5D6FF"> nvidia</span></span>
<span data-line=""><span style="color:#8B949E"># 輸出類似：01:00.0 VGA [10de:2684]</span></span>

<h2 id="第三步檢查-iommu-group">第三步：檢查 IOMMU Group</h2>
<p>確認 GPU 的分組狀況：</p>

<span data-line=""><span style="color:#E6EDF3">    n</span><span style="color:#FF7B72">=</span><span style="color:#E6EDF3">${d</span><span style="color:#FF7B72">#*/</span><span style="color:#E6EDF3">iommu_groups</span><span style="color:#FF7B72">/*</span><span style="color:#E6EDF3">}; n</span><span style="color:#FF7B72">=</span><span style="color:#E6EDF3">${n</span><span style="color:#FF7B72">%%/*</span><span style="color:#E6EDF3">}</span></span>
<span data-line=""><span style="color:#79C0FF">    printf</span><span style="color:#A5D6FF"> 'IOMMU Group %s '</span><span style="color:#A5D6FF"> "</span><span style="color:#E6EDF3">$n</span><span style="color:#A5D6FF">"</span></span>

<h2 id="nvidia-code-43-問題">NVIDIA Code 43 問題</h2>
<p>NVIDIA 早期驅動會偵測「我是不是在虛擬機裡」，發現了就罷工丟出 Code 43 錯誤。解法是把虛擬化的痕跡藏起來：</p>
<pre><code>cpu: host,hidden=1
args: -cpu 'host,+kvm_pv_unhalt,+kvm_pv_eoi,hv_vendor_id=proxmox,kvm=off'
</code></pre>
<blockquote>
<p>好消息：NVIDIA 535 版之後的驅動已經不管這個了。如果你的驅動夠新，可以跳過這步。</p>
</blockquote>
<h2 id="進階玩法">進階玩法</h2>
<p><strong>SR-IOV</strong>：一張實體網卡切成多張虛擬的，各自獨立分配給不同 VM。企業級網卡（Intel X710）和高階 GPU（NVIDIA A100）才有。</p>
<p><strong>vGPU</strong>：把一張 GPU 切成好幾份，每個 VM 分到一小塊。需要 NVIDIA 商業授權，口袋夠深再考慮。</p>
<p><strong>Resource Mappings（PVE 8.0+）</strong>：在<a href="08-cluster">叢集</a>裡給裝置取一個統一名稱，VM 遷移到不同節點時自動對應。不用再每台機器硬編 PCI 位址。</p>

<h2 id="常見問題">常見問題</h2>
<h3 id="q-proxmox-顯卡直通一定要-uefi-嗎">Q: Proxmox 顯卡直通一定要 UEFI 嗎？</h3>
<p>強烈建議用 UEFI（OVMF）搭配 q35 機型。SeaBIOS 雖然也能直通，但相容性較差，特別是新款 NVIDIA 和 AMD 顯卡在 UEFI 模式下才能正確初始化 ROM。</p>
<h3 id="q-iommu-group-太大怎麼辦">Q: IOMMU Group 太大怎麼辦？</h3>
<p>首選換一張 IOMMU 分組較好的主機板。如果不想換，可以使用 ACS Override Patch 強制拆分 Group，但這會降低 DMA 隔離安全性，Homelab 可以接受，生產環境不建議。</p>
<h3 id="q-gpu-直通後主機還能用那張顯卡嗎">Q: GPU 直通後主機還能用那張顯卡嗎？</h3>
<p>不行，直通的 GPU 完全交給 VM 控制，主機端看不到也用不了。如果主機也需要顯示輸出，建議用 CPU 內顯或另插一張便宜的亮機卡給主機用。</p>
<h3 id="q-vfio-設定好了但-vm-開機黑螢幕怎麼辦">Q: VFIO 設定好了但 VM 開機黑螢幕怎麼辦？</h3>
<p>檢查三個地方：一是 hostpci 設定要加 <code>x-vga=1</code> 和 <code>rombar=1</code>；二是有些顯卡需要手動指定 ROM 檔案；三是確認 VM 的顯示設定改為 <code>none</code>，避免虛擬顯卡衝突。</p>
