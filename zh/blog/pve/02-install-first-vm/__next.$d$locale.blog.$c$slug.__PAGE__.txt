3:T398f,<p>裝 PVE 的過程比裝 Windows 簡單得多——畢竟它不會問你要不要登入微軟帳號、要不要 Cortana、要不要把 Edge 設成預設瀏覽器。整個安裝流程大概 10 分鐘，比泡麵還快。</p>
<h2 id="第一步下載-iso-並製作-usb-開機碟">第一步：下載 ISO 並製作 USB 開機碟</h2>
<p>去 <a href="https://www.proxmox.com/en/downloads/proxmox-virtual-environment/iso">Proxmox 官網下載頁</a> 抓最新的 ISO（安裝步驟也可以參考 <a href="https://pve.proxmox.com/wiki/Installation">Proxmox 官方安裝指南</a>）。目前最新是 PVE 9.1，大小約 1.2 GB。</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># Linux / macOS：用 dd 燒錄到 USB</span></span>
<span data-line=""><span style="color:#6A737D"># 注意：/dev/sdX 換成你的 USB 裝置，搞錯會把別的磁碟洗掉</span></span>
<span data-line=""><span style="color:#B392F0">dd</span><span style="color:#9ECBFF"> bs=1M</span><span style="color:#9ECBFF"> conv=fdatasync</span><span style="color:#9ECBFF"> if=./proxmox-ve_9.1-1.iso</span><span style="color:#9ECBFF"> of=/dev/sdX</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#6A737D"># 不確定 USB 是哪個裝置？</span></span>
<span data-line=""><span style="color:#B392F0">lsblk</span></span></code></pre></figure>
<p>Windows 的話用 <a href="https://rufus.ie">Rufus</a> 或 <a href="https://etcher.balena.io">balenaEtcher</a>，選 ISO、選 USB、按下去，完事。</p>
<blockquote>
<p>這邊要強調三次：<strong>dd 會無條件覆蓋目標磁碟</strong>。拿錯磁碟你就準備哭了。寫入前多確認一次 <code>lsblk</code> 的輸出，看看大小跟你的 USB 碟吻不吻合。</p>
</blockquote>
<h2 id="第二步安裝-pve">第二步：安裝 PVE</h2>
<p>把 USB 插上去，設定 BIOS 從 USB 開機，然後你會看到 Proxmox 的安裝畫面。</p>
<p>安裝過程中要注意的幾個重點：</p>
<ol>
<li><strong>選目標磁碟</strong>：安裝程式會覆蓋整顆磁碟。如果你有多顆磁碟，可以在這邊選 ZFS RAID-1 mirror（兩顆碟互為鏡像），壞一顆不會死。關於 ZFS 和其他儲存方案的細節，後面會在<a href="05-storage">儲存系統指南</a>詳談。</li>
<li><strong>國家/時區/鍵盤</strong>：台灣選 Taiwan、Asia/Taipei、鍵盤 US。</li>
<li><strong>密碼與 Email</strong>：設一個你記得住的 root 密碼。Email 是拿來收系統通知的，隨便填也行（但建議填真的）。</li>
<li><strong>網路設定</strong>：給 PVE 一個固定 IP。這台機器以後要用 Web 介面管，IP 一直跳會很煩。網路架構的進階設定可以參考<a href="06-networking">網路管理篇</a>。</li>
</ol>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># 安裝完之後，從另一台電腦的瀏覽器打開：</span></span>
<span data-line=""><span style="color:#6A737D"># https://你設定的IP:8006</span></span>
<span data-line=""><span style="color:#6A737D"># 帳號：root</span></span>
<span data-line=""><span style="color:#6A737D"># 密碼：你剛剛設定的那個</span></span></code></pre></figure>
<blockquote>
<p>瀏覽器會跳出 SSL 憑證警告，這是正常的——PVE 用的是自簽憑證。點「進階」->「繼續前往」就好。每次看到這個警告都要點一次，習慣就好。</p>
</blockquote>

<h2 id="第四步下載-vm-映像檔">第四步：下載 VM 映像檔</h2>
<p>要建 VM，你得先有一個作業系統的安裝映像。直接從 PVE 的 Web 介面下載最方便：</p>
<ol>
<li>左側面板 -> 你的節點 -> <code>local (pve)</code> 儲存</li>
<li>點 <code>ISO Images</code> 標籤</li>
<li>點 <code>Download from URL</code></li>
<li>貼上你要裝的 OS 的 ISO 連結</li>
</ol>
<p>常用的幾個：</p>
<ul>
<li><strong>Debian 12</strong>：<code>https://cdimage.debian.org/debian-cd/current/amd64/iso-cd/debian-12.9.0-amd64-netinst.iso</code></li>
<li><strong>Ubuntu Server 24.04</strong>：<code>https://releases.ubuntu.com/24.04/ubuntu-24.04-live-server-amd64.iso</code></li>
</ul>
<p>或者用 CLI 下載：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># 直接把 ISO 下載到 PVE 的 ISO 儲存位置</span></span>
<span data-line=""><span style="color:#79B8FF">cd</span><span style="color:#9ECBFF"> /var/lib/vz/template/iso/</span></span>
<span data-line=""><span style="color:#B392F0">wget</span><span style="color:#9ECBFF"> https://cdimage.debian.org/debian-cd/current/amd64/iso-cd/debian-12.9.0-amd64-netinst.iso</span></span></code></pre></figure>
<h2 id="第五步建立你的第一台-vm">第五步：建立你的第一台 VM</h2>
<p>好戲來了。這就像在組裝一台電腦，只不過所有零件都是虛擬的，裝錯了不會冒煙。</p>
<p><strong>在 Web 介面操作：</strong></p>
<ol>
<li>右上角點 <code>Create VM</code></li>
<li><strong>General</strong>：VM ID 保持預設或自己編號，Name 填個好記的名字（例如 <code>debian-test</code>）</li>
<li><strong>OS</strong>：選剛才下載的 ISO，Guest OS type 選 Linux</li>
<li><strong>System</strong>：Machine 選 <code>q35</code>，BIOS 用 <code>OVMF (UEFI)</code> 或預設的 SeaBIOS 都行</li>
<li><strong>Disks</strong>：Bus 選 <code>VirtIO Block</code> 或 <code>SCSI</code>，大小 20-32 GB 夠測試用</li>
<li><strong>CPU</strong>：1-2 核心，Type 選 <code>host</code>（效能最好）</li>
<li><strong>Memory</strong>：1024-2048 MB</li>
<li><strong>Network</strong>：Model 選 <code>VirtIO</code>，Bridge 用預設的 <code>vmbr0</code></li>
<li><strong>Confirm</strong> -> <code>Finish</code></li>
</ol>
<p>然後選中你的新 VM，點 <code>Start</code>，再開 <code>Console</code> 就能看到 OS 安裝畫面了。</p>
<blockquote>
<p>為什麼磁碟和網卡都建議選 VirtIO？因為效能差距很大。VirtIO 是專門為虛擬化設計的半虛擬化驅動，比模擬傳統硬體快很多。Linux 系統內建支援，Windows 的話需要另外裝 <a href="https://pve.proxmox.com/wiki/Windows_VirtIO_Drivers">VirtIO 驅動</a>。更多 VM 效能調校技巧請看 <a href="03-vm-management">VM 管理完全指南</a>。</p>
</blockquote>

<h2 id="恭喜你有了第一台-vm">恭喜，你有了第一台 VM</h2>
<p>如果你成功看到 OS 的安裝畫面或登入提示，那你已經完成了 PVE 最重要的第一步。就像學做菜，第一道蛋炒飯成功了，後面的佛跳牆也只是步驟多一點而已。</p>
<h2 id="常見問題">常見問題</h2>
<h3 id="q-pve-安裝需要多久會不會很複雜">Q: PVE 安裝需要多久？會不會很複雜？</h3>
<p>整個安裝流程大約 10 分鐘，比裝 Windows 簡單。只要設定目標磁碟、密碼和網路 IP，其他保持預設就好。安裝完從瀏覽器開啟 Web 介面就能開始用。</p>
<h3 id="q-pve-可以跟其他作業系統雙開嗎">Q: PVE 可以跟其他作業系統雙開嗎？</h3>
<p>不建議。PVE 會佔用整顆磁碟，它本身就是一個完整的作業系統。如果想保留原本的系統，建議用另一顆磁碟安裝，或先用 Mini PC 單獨跑 PVE。</p>
<h3 id="q-第一台-vm-建議裝什麼作業系統">Q: 第一台 VM 建議裝什麼作業系統？</h3>
<p>建議從 Debian 12 或 Ubuntu Server 24.04 開始。這兩個對 VirtIO 驅動的支援最好，社群資源也最多。如果只是想輕量測試，也可以先建一個 <a href="04-lxc-containers">LXC 容器</a>更快。</p>
<h3 id="q-web-介面出現-ssl-憑證警告怎麼辦">Q: Web 介面出現 SSL 憑證警告怎麼辦？</h3>
<p>這是正常現象，PVE 預設使用自簽憑證。點瀏覽器的「進階」再選「繼續前往」即可。如果想消除警告，可以之後設定 Let's Encrypt 或自己的 CA 憑證。</p>

9:T398f,<p>裝 PVE 的過程比裝 Windows 簡單得多——畢竟它不會問你要不要登入微軟帳號、要不要 Cortana、要不要把 Edge 設成預設瀏覽器。整個安裝流程大概 10 分鐘，比泡麵還快。</p>
<h2 id="第一步下載-iso-並製作-usb-開機碟">第一步：下載 ISO 並製作 USB 開機碟</h2>
<p>去 <a href="https://www.proxmox.com/en/downloads/proxmox-virtual-environment/iso">Proxmox 官網下載頁</a> 抓最新的 ISO（安裝步驟也可以參考 <a href="https://pve.proxmox.com/wiki/Installation">Proxmox 官方安裝指南</a>）。目前最新是 PVE 9.1，大小約 1.2 GB。</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># Linux / macOS：用 dd 燒錄到 USB</span></span>
<span data-line=""><span style="color:#6A737D"># 注意：/dev/sdX 換成你的 USB 裝置，搞錯會把別的磁碟洗掉</span></span>
<span data-line=""><span style="color:#B392F0">dd</span><span style="color:#9ECBFF"> bs=1M</span><span style="color:#9ECBFF"> conv=fdatasync</span><span style="color:#9ECBFF"> if=./proxmox-ve_9.1-1.iso</span><span style="color:#9ECBFF"> of=/dev/sdX</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#6A737D"># 不確定 USB 是哪個裝置？</span></span>
<span data-line=""><span style="color:#B392F0">lsblk</span></span></code></pre></figure>
<p>Windows 的話用 <a href="https://rufus.ie">Rufus</a> 或 <a href="https://etcher.balena.io">balenaEtcher</a>，選 ISO、選 USB、按下去，完事。</p>
<blockquote>
<p>這邊要強調三次：<strong>dd 會無條件覆蓋目標磁碟</strong>。拿錯磁碟你就準備哭了。寫入前多確認一次 <code>lsblk</code> 的輸出，看看大小跟你的 USB 碟吻不吻合。</p>
</blockquote>
<h2 id="第二步安裝-pve">第二步：安裝 PVE</h2>
<p>把 USB 插上去，設定 BIOS 從 USB 開機，然後你會看到 Proxmox 的安裝畫面。</p>
<p>安裝過程中要注意的幾個重點：</p>
<ol>
<li><strong>選目標磁碟</strong>：安裝程式會覆蓋整顆磁碟。如果你有多顆磁碟，可以在這邊選 ZFS RAID-1 mirror（兩顆碟互為鏡像），壞一顆不會死。關於 ZFS 和其他儲存方案的細節，後面會在<a href="05-storage">儲存系統指南</a>詳談。</li>
<li><strong>國家/時區/鍵盤</strong>：台灣選 Taiwan、Asia/Taipei、鍵盤 US。</li>
<li><strong>密碼與 Email</strong>：設一個你記得住的 root 密碼。Email 是拿來收系統通知的，隨便填也行（但建議填真的）。</li>
<li><strong>網路設定</strong>：給 PVE 一個固定 IP。這台機器以後要用 Web 介面管，IP 一直跳會很煩。網路架構的進階設定可以參考<a href="06-networking">網路管理篇</a>。</li>
</ol>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># 安裝完之後，從另一台電腦的瀏覽器打開：</span></span>
<span data-line=""><span style="color:#6A737D"># https://你設定的IP:8006</span></span>
<span data-line=""><span style="color:#6A737D"># 帳號：root</span></span>
<span data-line=""><span style="color:#6A737D"># 密碼：你剛剛設定的那個</span></span></code></pre></figure>
<blockquote>
<p>瀏覽器會跳出 SSL 憑證警告，這是正常的——PVE 用的是自簽憑證。點「進階」->「繼續前往」就好。每次看到這個警告都要點一次，習慣就好。</p>
</blockquote>

<h2 id="第四步下載-vm-映像檔">第四步：下載 VM 映像檔</h2>
<p>要建 VM，你得先有一個作業系統的安裝映像。直接從 PVE 的 Web 介面下載最方便：</p>
<ol>
<li>左側面板 -> 你的節點 -> <code>local (pve)</code> 儲存</li>
<li>點 <code>ISO Images</code> 標籤</li>
<li>點 <code>Download from URL</code></li>
<li>貼上你要裝的 OS 的 ISO 連結</li>
</ol>
<p>常用的幾個：</p>
<ul>
<li><strong>Debian 12</strong>：<code>https://cdimage.debian.org/debian-cd/current/amd64/iso-cd/debian-12.9.0-amd64-netinst.iso</code></li>
<li><strong>Ubuntu Server 24.04</strong>：<code>https://releases.ubuntu.com/24.04/ubuntu-24.04-live-server-amd64.iso</code></li>
</ul>
<p>或者用 CLI 下載：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># 直接把 ISO 下載到 PVE 的 ISO 儲存位置</span></span>

<h2 id="第五步建立你的第一台-vm">第五步：建立你的第一台 VM</h2>
<p>好戲來了。這就像在組裝一台電腦，只不過所有零件都是虛擬的，裝錯了不會冒煙。</p>
<p><strong>在 Web 介面操作：</strong></p>
<ol>
<li>右上角點 <code>Create VM</code></li>
<li><strong>General</strong>：VM ID 保持預設或自己編號，Name 填個好記的名字（例如 <code>debian-test</code>）</li>
<li><strong>OS</strong>：選剛才下載的 ISO，Guest OS type 選 Linux</li>
<li><strong>System</strong>：Machine 選 <code>q35</code>，BIOS 用 <code>OVMF (UEFI)</code> 或預設的 SeaBIOS 都行</li>
<li><strong>Disks</strong>：Bus 選 <code>VirtIO Block</code> 或 <code>SCSI</code>，大小 20-32 GB 夠測試用</li>
<li><strong>CPU</strong>：1-2 核心，Type 選 <code>host</code>（效能最好）</li>
<li><strong>Memory</strong>：1024-2048 MB</li>
<li><strong>Network</strong>：Model 選 <code>VirtIO</code>，Bridge 用預設的 <code>vmbr0</code></li>
<li><strong>Confirm</strong> -> <code>Finish</code></li>
</ol>
<p>然後選中你的新 VM，點 <code>Start</code>，再開 <code>Console</code> 就能看到 OS 安裝畫面了。</p>
<blockquote>
<p>為什麼磁碟和網卡都建議選 VirtIO？因為效能差距很大。VirtIO 是專門為虛擬化設計的半虛擬化驅動，比模擬傳統硬體快很多。Linux 系統內建支援，Windows 的話需要另外裝 <a href="https://pve.proxmox.com/wiki/Windows_VirtIO_Drivers">VirtIO 驅動</a>。更多 VM 效能調校技巧請看 <a href="03-vm-management">VM 管理完全指南</a>。</p>
</blockquote>

<h2 id="恭喜你有了第一台-vm">恭喜，你有了第一台 VM</h2>
<p>如果你成功看到 OS 的安裝畫面或登入提示，那你已經完成了 PVE 最重要的第一步。就像學做菜，第一道蛋炒飯成功了，後面的佛跳牆也只是步驟多一點而已。</p>
<h2 id="常見問題">常見問題</h2>
<h3 id="q-pve-安裝需要多久會不會很複雜">Q: PVE 安裝需要多久？會不會很複雜？</h3>
<p>整個安裝流程大約 10 分鐘，比裝 Windows 簡單。只要設定目標磁碟、密碼和網路 IP，其他保持預設就好。安裝完從瀏覽器開啟 Web 介面就能開始用。</p>
<h3 id="q-pve-可以跟其他作業系統雙開嗎">Q: PVE 可以跟其他作業系統雙開嗎？</h3>
<p>不建議。PVE 會佔用整顆磁碟，它本身就是一個完整的作業系統。如果想保留原本的系統，建議用另一顆磁碟安裝，或先用 Mini PC 單獨跑 PVE。</p>
<h3 id="q-第一台-vm-建議裝什麼作業系統">Q: 第一台 VM 建議裝什麼作業系統？</h3>
<p>建議從 Debian 12 或 Ubuntu Server 24.04 開始。這兩個對 VirtIO 驅動的支援最好，社群資源也最多。如果只是想輕量測試，也可以先建一個 <a href="04-lxc-containers">LXC 容器</a>更快。</p>
<h3 id="q-web-介面出現-ssl-憑證警告怎麼辦">Q: Web 介面出現 SSL 憑證警告怎麼辦？</h3>
<p>這是正常現象，PVE 預設使用自簽憑證。點瀏覽器的「進階」再選「繼續前往」即可。如果想消除警告，可以之後設定 Let's Encrypt 或自己的 CA 憑證。</p>
