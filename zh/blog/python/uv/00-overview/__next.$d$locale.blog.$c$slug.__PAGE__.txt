3:Tdb1,<p>uv 是 Astral 用 Rust 打造的<strong>極速 Python 套件與專案管理工具</strong>，整合依賴安裝、虛擬環境、Python 版本管理、CLI 工具執行於一身。簡單講：<strong>pip + virtualenv + pyenv + pipx 的合體強化版，還快到你懷疑人生那種。</strong></p>
<p>和 pip、poetry、pipenv 相比，uv 的優勢在於 <strong>10–100 倍的速度</strong>、極低磁碟佔用、單一工具搞定全流程。特別適合日常開發、CI/CD、腳本執行——不用再在好幾個工具之間切換，就像一隻貓只需要一個紙箱，但這個紙箱能變出各種功能，還自帶 turbo 模式。</p>
<h2 id="適用場景">適用場景</h2>
<ul>
<li><strong>新專案從零開始</strong>：<code>uv init</code> 秒建、依賴秒裝，不用再等 pip 轉圈圈</li>
<li><strong>既有 requirements.txt 遷移</strong>：<code>uv pip compile</code> 直接吃，無痛升級</li>
<li><strong>腳本臨時依賴</strong>：<code>uv run --with rich script.py</code>，不用搞 venv</li>
<li><strong>CLI 工具執行</strong>：<code>uvx ruff</code> 隨叫隨用，像 pipx 但快 N 倍</li>
<li><strong>不適合</strong>：還在用 Python 2 的遺產專案——那種先考慮搬遷再說，別逼 uv 穿越時空</li>
</ul>

<li><a href="03-common-patterns">常見模式</a>：依賴管理、uv run、uvx、腳本執行，日常 80% 情境</li>
<li><a href="04-advanced">進階用法</a>：Python 版本切換、pip 介面、Workspace——多專案與遷移</li>
<li><a href="05-best-practices">最佳實踐</a>：避坑策略與維運準則，少踩雷就是省時間</li>
</ol>
