1b:T158e,<p>在狂敲指令之前，先把這四個概念裝進腦子：你會更清楚「依賴寫在哪、lockfile 幹嘛用、venv 什麼時候建」。就像打遊戲先看技能說明，不然會一直送頭。</p>
<h2 id="概念一pyprojecttoml-是專案身份證">概念一：pyproject.toml 是專案身份證</h2>
<p>專案 metadata 跟依賴都寫在這裡，是 PEP 518 的標準格式。</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="toml" data-theme="github-dark"><code data-language="toml" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#E1E4E8">[</span><span style="color:#B392F0">project</span><span style="color:#E1E4E8">]</span></span>
<span data-line=""><span style="color:#E1E4E8">name = </span><span style="color:#9ECBFF">"my-app"</span></span>
<span data-line=""><span style="color:#E1E4E8">version = </span><span style="color:#9ECBFF">"0.1.0"</span></span>
<span data-line=""><span style="color:#E1E4E8">requires-python = </span><span style="color:#9ECBFF">">=3.12"</span></span>
<span data-line=""><span style="color:#E1E4E8">dependencies = [</span></span>
<span data-line=""><span style="color:#9ECBFF">    "requests>=2.31"</span><span style="color:#E1E4E8">,</span></span>
<span data-line=""><span style="color:#E1E4E8">]</span></span></code></pre></figure>
<ul>
<li><strong>手動改</strong>：直接編輯 <code>pyproject.toml</code></li>
<li><strong>用指令改</strong>：<code>uv add requests</code>、<code>uv remove requests</code> 會自動幫你更新</li>
</ul>
<blockquote>
<p>不要混用——要嘛都用手動，要嘛都用指令，不然容易打架。</p>
</blockquote>
<h2 id="概念二uvlock-是依賴快照">概念二：uv.lock 是依賴快照</h2>
<p><code>pyproject.toml</code> 寫的是「我要什麼」（例如 <code>requests>=2.31</code>），<code>uv.lock</code> 記錄的是「實際裝了哪些版本」——精確到每一層依賴。</p>
<ul>
<li><strong>為什麼要有 lockfile？</strong> 確保所有人、CI、生產環境裝出來的依賴完全一致，不會「我這能跑你那爆」。</li>
<li><strong>要 commit 嗎？</strong> 要。<code>uv.lock</code> 應該進版控，讓團隊與 CI 都用同一份依賴樹。</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># 更新 lockfile（例如升級某個套件）</span></span>
<span data-line=""><span style="color:#B392F0">uv</span><span style="color:#9ECBFF"> lock</span><span style="color:#79B8FF"> --upgrade-package</span><span style="color:#9ECBFF"> requests</span></span></code></pre></figure>
<h2 id="概念三venv-是專案專屬沙盒">概念三：.venv 是專案專屬沙盒</h2>
<p>uv 會在專案根目錄建立 <code>.venv</code>，所有 <code>uv add</code> 的套件都裝在這裡，跟系統 Python 隔離。</p>
<ul>
<li><strong>要手動 activate 嗎？</strong> 不用。<code>uv run</code> 會自動用這個環境。</li>
<li><strong>要 commit 嗎？</strong> 不要。<code>.venv</code> 應該在 <code>.gitignore</code> 裡。</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># 手動同步環境（例如剛 clone 下來）</span></span>
<span data-line=""><span style="color:#B392F0">uv</span><span style="color:#9ECBFF"> sync</span></span>
<span data-line=""><span style="color:#79B8FF">source</span><span style="color:#9ECBFF"> .venv/bin/activate</span><span style="color:#6A737D">  # 之後可直接用 python、pytest 等</span></span></code></pre></figure>
<h2 id="概念四uv-run-是無腦執行入口">概念四：uv run 是無腦執行入口</h2>
<p><code>uv run</code> 會：</p>
<ol>
<li>檢查 lockfile 是否與 pyproject.toml 一致</li>
<li>確保 .venv 與 lockfile 同步</li>
<li>在正確環境下執行你指定的指令</li>
</ol>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">uv</span><span style="color:#9ECBFF"> run</span><span style="color:#9ECBFF"> python</span><span style="color:#9ECBFF"> main.py</span></span>
<span data-line=""><span style="color:#B392F0">uv</span><span style="color:#9ECBFF"> run</span><span style="color:#9ECBFF"> pytest</span></span>
<span data-line=""><span style="color:#B392F0">uv</span><span style="color:#9ECBFF"> run</span><span style="color:#9ECBFF"> flask</span><span style="color:#9ECBFF"> run</span><span style="color:#79B8FF"> -p</span><span style="color:#79B8FF"> 3000</span></span></code></pre></figure>
<p>你不用記得 activate，也不用擔心環境錯亂——交給 uv 就好，就像貓不用記得貓砂在哪，身體會自動導航。這種「開了就跑」的體驗，用過就回不去了。</p>

<h2 id="概念二uvlock-是依賴快照">概念二：uv.lock 是依賴快照</h2>
<p><code>pyproject.toml</code> 寫的是「我要什麼」（例如 <code>requests>=2.31</code>），<code>uv.lock</code> 記錄的是「實際裝了哪些版本」——精確到每一層依賴。</p>
<ul>
<li><strong>為什麼要有 lockfile？</strong> 確保所有人、CI、生產環境裝出來的依賴完全一致，不會「我這能跑你那爆」。</li>
<li><strong>要 commit 嗎？</strong> 要。<code>uv.lock</code> 應該進版控，讓團隊與 CI 都用同一份依賴樹。</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># 更新 lockfile（例如升級某個套件）</span></span>
<span data-line=""><span style="color:#B392F0">uv</span><span style="color:#9ECBFF"> lock</span><span style="color:#79B8FF"> --upgrade-package</span><span style="color:#9ECBFF"> requests</span></span></code></pre></figure>
<h2 id="概念三venv-是專案專屬沙盒">概念三：.venv 是專案專屬沙盒</h2>
<p>uv 會在專案根目錄建立 <code>.venv</code>，所有 <code>uv add</code> 的套件都裝在這裡，跟系統 Python 隔離。</p>
<ul>
<li><strong>要手動 activate 嗎？</strong> 不用。<code>uv run</code> 會自動用這個環境。</li>
<li><strong>要 commit 嗎？</strong> 不要。<code>.venv</code> 應該在 <code>.gitignore</code> 裡。</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#6A737D"># 手動同步環境（例如剛 clone 下來）</span></span>
<span data-line=""><span style="color:#B392F0">uv</span><span style="color:#9ECBFF"> sync</span></span>
<span data-line=""><span style="color:#79B8FF">source</span><span style="color:#9ECBFF"> .venv/bin/activate</span><span style="color:#6A737D">  # 之後可直接用 python、pytest 等</span></span></code></pre></figure>
<h2 id="概念四uv-run-是無腦執行入口">概念四：uv run 是無腦執行入口</h2>
<p><code>uv run</code> 會：</p>
<ol>
<li>檢查 lockfile 是否與 pyproject.toml 一致</li>
<li>確保 .venv 與 lockfile 同步</li>
<li>在正確環境下執行你指定的指令</li>
</ol>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#24292e;color:#e1e4e8" tabindex="0" data-language="bash" data-theme="github-dark"><code data-language="bash" data-theme="github-dark" style="display: grid;"><span data-line=""><span style="color:#B392F0">uv</span><span style="color:#9ECBFF"> run</span><span style="color:#9ECBFF"> python</span><span style="color:#9ECBFF"> main.py</span></span>
<span data-line=""><span style="color:#B392F0">uv</span><span style="color:#9ECBFF"> run</span><span style="color:#9ECBFF"> pytest</span></span>
<span data-line=""><span style="color:#B392F0">uv</span><span style="color:#9ECBFF"> run</span><span style="color:#9ECBFF"> flask</span><span style="color:#9ECBFF"> run</span><span style="color:#79B8FF"> -p</span><span style="color:#79B8FF"> 3000</span></span></code></pre></figure>
<p>你不用記得 activate，也不用擔心環境錯亂——交給 uv 就好，就像貓不用記得貓砂在哪，身體會自動導航。這種「開了就跑」的體驗，用過就回不去了。</p>
