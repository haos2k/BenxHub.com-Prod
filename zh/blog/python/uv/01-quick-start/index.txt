<h2 id="最小範例建立第一支專案">最小範例：建立第一支專案</h2>
<h3 id="步驟-1驗證-uv-已安裝">步驟 1：驗證 uv 已安裝</h3>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">uv</span><span style="color:#79C0FF"> --version</span></span></code></pre></figure>
<p>有版本號就代表裝好了。沒有？回去跑安裝腳本，然後重開 terminal。</p>
<h3 id="步驟-2初始化專案">步驟 2：初始化專案</h3>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> init</span><span style="color:#A5D6FF"> my-app</span></span>
<span data-line=""><span style="color:#79C0FF">cd</span><span style="color:#A5D6FF"> my-app</span></span></code></pre></figure>
<p>uv 會自動建立 <code>pyproject.toml</code>、<code>.python-version</code>、<code>main.py</code>、<code>README.md</code>。結構大概長這樣：</p>
<pre><code>my-app/
├── .gitignore
├── .python-version
├── README.md
├── main.py
└── pyproject.toml
</code></pre>

<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> run</span><span style="color:#A5D6FF"> main.py</span></span></code></pre></figure>
<p>會看到 <code>Hello from my-app!</code>——恭喜，第一個專案誕生。</p>

<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> add</span><span style="color:#A5D6FF"> requests</span></span></code></pre></figure>
<p>接著改一下 <code>main.py</code>，加幾行試試：</p>

<span data-line=""><span style="color:#79C0FF">print</span><span style="color:#E6EDF3">(r.status_code)</span></span></code></pre></figure>
<p>再執行：</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> run</span><span style="color:#A5D6FF"> main.py</span></span></code></pre></figure>
<p>看到 <code>200</code> 就代表依賴有正確裝進虛擬環境——不用手動 <code>pip install</code>，也不用 <code>source .venv/bin/activate</code>，這種無腦感就是 uv 的快樂泉源。</p>

<figure data-rehype-pretty-code-figure=""><pre style="background-color:#0d1117;color:#e6edf3" tabindex="0" data-language="bash" data-theme="github-dark-default"><code data-language="bash" data-theme="github-dark-default" style="display: grid;"><span data-line=""><span style="color:#FFA657">uv</span><span style="color:#A5D6FF"> add</span><span style="color:#A5D6FF"> requests</span></span></code></pre></figure>

<p>看到 <code>200</code> 就代表依賴有正確裝進虛擬環境——不用手動 <code>pip install</code>，也不用 <code>source .venv/bin/activate</code>，這種無腦感就是 uv 的快樂泉源。</p>
